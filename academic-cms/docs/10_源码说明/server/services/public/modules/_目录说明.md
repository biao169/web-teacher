# server/services/public/modules 目录

本目录记录 8 个直属项目文件。

| 文件 | 功能定位 |
| --- | --- |
| [courses.ts](courses.ts.md) | 公开课程列表/详情服务，沿用翻译和媒体权限；选择请求提供完整公开简介，普通列表仍使用摘要。 |
| [news.ts](news.ts.md) | 列表保持摘要元数据，详情富文本媒体分离投影图片与PDF，为公开PDF生成每次可重新校验的读取地址。 |
| [patents.ts](patents.ts.md) | 公开专利服务：复用查询、翻译与媒体装配；同步新增筛选字段和紧凑列表投影。 |
| [projects.ts](projects.ts.md) | 双语项目列表与详情模型，透传原始万元金额供统一显示与复制格式化。 |
| [publications.ts](publications.ts.md) | 公开论文服务：普通列表仍轻量；有界选择投影装配当前格式与公开PDF；详情的四种格式复用同一个publicCitation函数。 |
| [research.ts](research.ts.md) | 普通研究列表仅提供两行适用摘要；详情和按UID复制保留完整说明，复用本地化和权限。 |
| [students.ts](students.ts.md) | 学生双语模型及后台分类映射；额外返回按显示顺序本地化的分类信息供默认分区。 |
| [team.ts](team.ts.md) | 教师列表与详情服务；详情共用平台URL和数值投影，保持长简介预算及分批翻译。 |
