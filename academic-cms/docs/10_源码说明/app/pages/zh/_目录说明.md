# app/pages/zh 目录

| 文件 | 功能定位 |
| --- | --- |
| [contact.vue](contact.vue.md) | 中文留言页，显式导入正确的ContactForm组件，保留公开SEO及共用布局。 |
| [index.vue](index.vue.md) | 双语首页或研究方向详情入口，共用公开数据、SEO与内容模板；首页引文等待有界准备完成SSR。 |
| [login.vue](login.vue.md) | 公开站页面入口，对应路由 /zh/login；负责获取页面数据、设置 SEO 并渲染内容组件。 |
| [register.vue](register.vue.md) | 公开站页面入口，对应路由 /zh/register；负责获取页面数据、设置 SEO 并渲染内容组件。 |
| [setup.vue](setup.vue.md) | zh 语言的管理员初始化入口。 |
