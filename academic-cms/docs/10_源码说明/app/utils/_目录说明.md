# app/utils 目录

本目录记录 6 个直属项目文件。

| 文件 | 功能定位 |
| --- | --- |
| [interaction-errors.ts](interaction-errors.ts.md) | 项目支持文件；为工程运行、依赖锁定或开发工具提供配置。 |
| [media-fallback.ts](media-fallback.ts.md) | 头像姓氏、新闻首分类和编辑字段的媒体缺失文字规则，兼容中文复姓与英文姓氏。 |
| [pdf-document.ts](pdf-document.ts.md) | 仅在PDF进入视口后动态加载PDF.js兼容构建和本地Worker；关闭提前抓取与流式整篇下载，通过Range读取所需字节，字体和CMap来自本地静态资源。 |
| [public-clipboard.ts](public-clipboard.ts.md) | 支持即时或Promise复制载荷，在等待公开内容前同步调用富文本剪贴板写入；完整载荷通过验证后才允许纯文本降级，取消时拒绝过期后续写入，缺失能力或失败真实抛出。 |
| [public-dialog.ts](public-dialog.ts.md) | 优先原生模态预览，缺少接口时提供页面内预览、可达关闭按钮与焦点处理。 |
| [request-backoff.ts](request-backoff.ts.md) | 解析429的Retry-After秒数/日期及nuxt-security的x-ratelimit-reset毫秒时间戳，返回有界冷却时间，不自动重放写请求。 |
