# 网站功能总览

本文说明当前教师网站及已接入的文件快传工具。各项功能是否向某位用户开放，由内容可见性、账号权限和后台开关共同决定。

## 站点组成

| 区域 | 主要用途 | 入口 |
| --- | --- | --- |
| 教师网站前台 | 展示团队资料、研究成果、教学内容和动态，接收留言 | 中文 `/zh`、英文 `/en` |
| 教师网站后台 | 内容维护、辅助录入、媒体管理、翻译、权限及备份 | `/admin` |
| 文件快传前台 | 文件与文件夹发送、接收、临时分享、传输恢复 | `/zh/transfer`、`/en/transfer` |
| 文件快传管理 | 在一个页面管理开放范围、速率、个人额度、VPN 流量和临时存储 | `/transfer-admin/` |

文件快传使用独立目录、独立服务和独立数据库。其前台嵌入教师网站公共布局，共用顶部导航、语言和阅读样式；管理页独立，通过教师后台侧栏入口进入。

## 前台现有功能

| 功能 | 使用与展示规则 |
| --- | --- |
| 中英文浏览 | 切换中英文页面；有人工英文内容时优先使用，否则读取有效翻译缓存，缺失时回退原文 |
| 阅读样式 | 浅绿色界面；标准、舒适、大字三档字体；保留阅读偏好；右下角返回顶部 |
| 顶部导航与账号 | 展开导航并突出当前入口；顶部登录、账号、退出及按权限出现的后台按钮；阅读控制行显示登录者名称 |
| 首页教师 | 展示公开、启用、精选成员中排序第一位教师；完整显示已保存的个人简介；展示照片、可公开联系方式及学术链接 |
| 学术链接数值 | ORCID、个人主页、Google Scholar、DBLP、GitHub、CNKI 的链接可附带后台配置数值；没有配置的数值不显示，0 是有效数值 |
| 首页快捷按钮 | 名称、位置、路由和筛选链接由“导航与按钮”维护 |
| 研究方向 | 首页以标签罗列，不提供首页研究方向多选或复制；独立研究方向页提供列表能力 |
| 紧凑列表 | 论文、项目、专利软著、学生、课程等按统一节奏排列；浅色标签、适用条目的两行简介、小复选框 |
| 动态检索 | 搜索和筛选在一行排列，空间不足换行；筛选选项随条件变化；支持后台配置的固定筛选入口 |
| 逐页加载 | 滚动接近列表底部加载后续数据；加载失败可重试，提供适用的手动加载入口 |
| 复制 | 论文、项目、专利、学生、研究方向、课程支持选择后直接复制；论文支持多种引用格式 |
| 学生分类 | 按分类分区展示，可配置分类名称、匹配词与顺序 |
| 新闻正文 | 列表显示标题及相关信息；详情在封面下展示正文、图片和内嵌 PDF |
| PDF 阅读 | 正文内直接衔接 PDF，仅用分隔线区分；按滚动逐页渲染，高度随已加载页面增加 |
| 留言 | 独立留言入口；新闻允许留言时展开留言表单；留言进入后台处理 |
| 页脚 | 从“网站设置”读取 HTML 页脚，支持安全文本格式和链接 |
| 前台缓存 | 缓存公开数据并合并适用的重复请求；内容、配置或有效译文变化时更新相关缓存 |

## 后台现有功能

| 类别 | 功能 |
| --- | --- |
| 内容维护 | 教师与团队、研究方向、论文、项目、专利软著、学生、学生分类显示、课程、新闻和留言的表单管理；适用列快速编辑、批量更新、列头筛选与排序 |
| 展示控制 | 可见性、精选、启用、排序、发布时间、联系方式和附件可见性 |
| 辅助输入 | 指定字段的历史值联想、多值去重、引用文本解析、DOI/题名检索、元数据差异勾选回填、引用和高亮文本生成 |
| 富文本 | 新闻可视化编辑；标题、文字样式、列表、引用、代码、对齐、链接、分隔线、图片排版、PDF 插入和前台预览 |
| 媒体 | 上传、检索、分类、预览、图片裁剪、选取、引用检查、回收站、恢复和到期清理 |
| 翻译 | 来源扫描、执行一批、自动运行至完成、暂停、重试、人工修订、缓存失效及服务配置 |
| 网站设置 | 品牌名称、图标、SEO、HTML 页脚、首页内容数量 |
| 导航与按钮 | 中英文文本、图标、样式、路由、锚点、位置、排序、可见性及筛选链接生成 |
| 账号权限 | 用户、角色、模块动作权限、可见性范围、会话和密码管理；登录密码至少 6 位 |
| 数据与运行 | 操作日志、系统检查、JSON/CSV 导出、JSON 导入和加密备份恢复 |

## 数据对象与关系

教师数据库包含 27 张表、394 个字段，涵盖业务内容、配置、媒体、翻译、账号会话、限流和缓存等系统状态。文件快传另外使用 12 张表、70 个字段。

| 对象 | 主要关联 |
| --- | --- |
| 教师、学生 | 头像关联媒体；联系方式有独立可见性 |
| 论文 | PDF 关联媒体；保存原始引用、结构化元数据、多格式引用和高亮文本 |
| 专利、课程 | 证书、大纲或材料关联媒体；课程材料有独立可见性 |
| 新闻 | 封面及正文内图片/PDF 关联媒体，可关联论文、项目、学生 |
| 网站设置 | 品牌图片关联媒体；首页主教师实际按公开、启用、精选及排序选取 |
| 留言 | 可保存附件引用；新闻留言来源保存在正文前缀及操作日志详情中 |
| 用户和角色 | 用户关联角色，角色关联模块权限，会话关联用户 |
| 翻译 | 按来源记录、字段、语言及内容版本维护译文缓存 |

完整字段、类型、默认值和关联见 [02_database_schema.md](02_database_schema.md)。前台与后台具体用法分别见 [03_frontend_requirements.md](03_frontend_requirements.md)、[04_admin_requirements.md](04_admin_requirements.md)。

## 使用边界

前台内容列表查询公开数据，登录不会自动把隐藏内容加入公共列表。媒体是否可读取还取决于引用记录和附件权限。

辅助输入提供建议，回填后仍需保存表单。英文浏览不会在访客请求中临时调用外部翻译服务。新闻留言是提交给管理员的联系记录，当前没有公开评论楼层或公开回复线程。

文件快传能显示和控制已配置的速率、额度与链路；受限 VPN 链路是否可用，还取决于网络核验、计量状态和保护条件。当前没有运营商出口硬限额能力，严格保护条件不满足时会禁用相关链路。
