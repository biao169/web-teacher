# 后台功能与录入说明

## 入口与权限

从顶部有权限的“后台”按钮或 `/admin` 进入。侧栏只显示当前账号可访问模块；查看、新建、修改、删除、导出分别受权限控制。登录密码至少 6 位，无强制大小写、数字和符号组合要求。加密备份口令另有要求，不与账号密码规则混用。

| 入口 | 主要功能 |
| --- | --- |
| `/admin` | 控制台与可用管理入口 |
| `/admin/settings/site` | 站点名称、图片、SEO、HTML 页脚、首页数量 |
| `/admin/settings/global` | 注册、匿名留言、上传、翻译、论文元数据等设置 |
| `/admin/navigation` | 导航、按钮及固定筛选链接 |
| `/admin/profiles` | 教师与团队 |
| `/admin/research` | 研究方向 |
| `/admin/students` | 学生 |
| `/admin/student-categories` | 学生分类显示 |
| `/admin/publications` | 论文及录入辅助 |
| `/admin/projects` | 科研项目 |
| `/admin/patents` | 专利与软著 |
| `/admin/news` | 新闻动态与富文本编辑 |
| `/admin/courses` | 课程 |
| `/admin/messages` | 留言处理 |
| `/admin/media` | 媒体资源与选择器 |
| `/admin/translation` | 翻译扫描、批处理与人工维护 |
| `/admin/auth` | 用户、角色、权限及会话管理 |
| `/admin/logs` | 操作日志 |
| `/admin/import-export` | 导入导出及加密备份恢复 |
| `/admin/system-check` | 后台模块与功能入口连通性检查 |

文件快传侧栏入口由接入模块提供，管理页为 `/transfer-admin/`，并检查工具管理员授权。

## 通用录入方式

列表支持适用的搜索、筛选和分页。打开记录后，按分组填写表单，媒体字段从媒体选择器选取，关联字段选择已有记录。必填、长度、数字范围、日期、URL、邮箱和枚举由表单及服务端校验。

适用表格支持列头筛选、排序、拖动调整列宽及列宽偏好保存；可快速切换有编辑权限的状态、公开、启用或精选字段。当前内容列表每页最多选择 25 条执行单字段批量更新，只有模块开放的字段可以批量修改。

| 模块 | 可批量维护的主要字段 |
| --- | --- |
| 教师 | 可见性、启用、精选、排序 |
| 研究方向 | 可见性、排序 |
| 论文 | 内容/PDF 可见性、精选、排序 |
| 项目、专利 | 可见性、精选、排序 |
| 学生 | 内容/联系方式可见性、精选、排序 |
| 学生分类显示 | 启用、显示顺序 |
| 课程 | 内容/材料可见性、精选、排序 |
| 留言 | 处理状态 |
| 导航 | 可见性、启用、排序 |
| 新闻 | 可见性、精选、允许留言、排序 |
| 媒体 | 分类 |

导航、新闻等使用通用资源工作台的整数批量字段还可按当前列表顺序设置起始值与步长。普通内容批量更新为统一值，不应假定所有模块都有递增排序模式。内容记录删除前需要确认，删除后没有媒体回收站那样的记录恢复入口。

辅助工具的回填首先作用于当前表单，点击保存后才写入数据库。记录被其他操作更新时，会提示版本冲突，需重新读取并确认，避免覆盖较新的内容。

`uid` 是稳定业务标识，`id` 是数据库内部编号；`created_at`、`updated_at` 由系统维护。排序通常数值越小越靠前，但各内容模块还有自己的日期或列表排序规则。公开、启用、精选是不同控制项；勾选精选不会自动公开内容。

## 内容模块与主要字段

| 模块 / 数据表 | 录入内容 | 展示控制及录入辅助 |
| --- | --- | --- |
| 教师 / `profiles` | 中英文姓名、角色、职称、单位、实验室、联系方式、简介、教育经历、工作经历、招生说明、照片、六类学术链接与数值 | 内容及联系方式可见性、启用、精选、排序；角色/职称/单位/实验室历史建议；首页主教师取首位公开启用精选记录 |
| 研究方向 / `research_interests` | 中英文名称、说明 | 可见性、排序；首页只展示标签 |
| 论文 / `publications` | 题名、作者、期刊/会议、年卷期页、DOI、来源、类型、作者角色、通讯作者、索引、标签、摘要、关键词、PDF、原始引用及各格式引用/高亮/BibTeX | 内容/PDF 可见性、精选、排序；历史建议、引用解析、DOI/题名检索、差异回填、引用生成 |
| 项目 / `projects` | 名称、来源、基金、编号、承担角色、负责人、成员、日期、状态、经费、简介 | 可见性、精选、排序；历史建议；经费按万元保存 |
| 专利软著 / `patents` | 名称、国家/地区、类型、申请/授权号、发明人、权利人、日期、法律状态、简介、证书 | 可见性、精选、排序；历史建议及 PatentsView 元数据查询入口 |
| 学生 / `students` | 姓名、学号、培养层次、分类、年级、方向、状态、联系方式、入学/毕业日期、去向、获奖、简介和照片 | 内容/联系方式可见性、精选、排序；历史建议；分类分区由显示配置维护 |
| 分类显示 / `student_category_displays` | 分类 Key、中文标签、英文标签、匹配关键词 | 启用、显示顺序；关键词多值建议 |
| 新闻 / `news` | 标题、Slug、分类、封面、正文、正文格式、关联论文/项目/学生 | 允许留言、发布时间、可见性、精选、排序；富文本编辑和实时预览 |
| 课程 / `courses` | 名称、学期、授课对象、简介、参考资料、大纲、材料 | 内容/材料可见性、精选、排序；学期和授课对象历史建议 |
| 留言 / `messages` | 姓名、邮箱、类型、主题、正文、附件引用 | 处理状态和记录可见性；前台新闻留言带新闻来源信息 |

逐字段的 SQL 类型、空值、默认值、校验和外键见 [02_database_schema.md](02_database_schema.md)。

## 辅助输入

历史值建议只在配置的字段中提供。聚焦或输入后可选已有值，也可以直接输入新值；多值字段用分号或换行分隔，候选会排除已选择值，选择新候选时保留之前的项。

论文编辑支持粘贴引用文本解析为字段，或使用 DOI/题名查询 Crossref、OpenAlex、Semantic Scholar、DataCite、Europe PMC、PubMed。查询结果与当前值并排比较，勾选要接纳的字段回填，可撤销辅助回填；不会直接发布记录。

引用生成器使用当前表单元数据生成 GB/T、Elsevier、APA、IEEE、BibTeX，并生成相应高亮文本。作者高亮使用可识别的首页教师中英文姓名；生成结果仍应检查缺失字段和姓名匹配。

专利查询入口按号码调用 PatentsView；EPO 配置字段的存在不代表当前已有 EPO 查询通道。历史值建议也可通过 `/admin/translation/suggestions` 查看。详见 [05_input_assistance.md](05_input_assistance.md)。

## 新闻富文本编辑

在新闻表单填写标题、Slug 等必要信息，通过“保存草稿并打开富文本”或已有记录的富文本入口进入编辑器；有未保存修改时先保存再进入。

支持段落、二至四级标题、粗体、斜体、下划线、删除线、列表、引用、代码块、对齐、链接、分隔线、撤销和重做。图片可从媒体库插入，也可粘贴或拖入本地图片上传；支持替代文字、拖动位置和左/右浮动、居中、宽图等排版。

PDF 从媒体库插入正文，前台在所在位置逐页展示。实时预览使用与前台一致的安全正文处理，预览不等于保存或发布。保存富文本后 `content_format` 为 `html`。详细用法见 [06_rich_text_and_pdf.md](06_rich_text_and_pdf.md)。

新闻列表提供“立即发布”“撤回”和富文本入口；已公开发布的新闻可直接“前台查阅”。发布与撤回会更新对应公开状态，操作仍受权限和记录版本检查。

## 媒体、导航和网站设置

媒体选择器可搜索、分类、预览和上传。图片裁剪支持预设比例、输出尺寸、缩放、焦点拖动和输出质量；可使用原图。媒体按 object key 引用；使用中的文件不能移入回收站。回收站支持恢复，保留期届满后可清理。

导航与按钮支持中英文名称、图标、样式、位置、路由、外链、锚点和排序，并可生成固定筛选列表链接。网站设置中的 `footer_text` 支持安全 HTML，统一控制前台页脚。

全局设置可调整注册、匿名留言、媒体上传、翻译服务、翻译批量/并发/超时、论文元数据服务和默认引用样式。个别兼容配置字段仍可保存，但不参与当前页面功能，具体见字段字典及各专题说明。

## 翻译管理

“执行下一批”只执行一次有上限的批次。“自动运行至完成”会在当前管理页面持续扫描、分批执行和等待重试；需要保持页面打开。暂停或离开页面后，不再调度后续批次，已经开始的请求可能完成。

支持失败重试、查看错误、人工修改译文和使缓存失效。人工维护译文不会被普通自动任务覆盖；原文改变后，旧来源版本不再当作当前有效译文使用。英文前台读取已有译文，不现场发起翻译请求。详见 [08_translation.md](08_translation.md)。

## 留言、账号与数据维护

留言管理可查看来源信息、搜索和按状态处理；当前没有自动邮件回复或公共评论线程。配置通知邮箱不等于已配置邮件发送服务。

账号管理维护角色、模块权限、可见性范围、账号状态及会话。操作日志记录关键新增、修改、删除、导入和权限操作，便于按模块或目标查阅。

数据管理支持安全 JSON 和 CSV 导出、JSON 导入、加密 `.acms` 备份及恢复。CSV 为导出格式，当前导入界面接收 JSON 或 `.acms`。导入先预检，再明确执行合并或替换；加密备份口令至少 15 位。教师数据与文件快传数据分别备份。详见 [10_accounts_and_messages.md](10_accounts_and_messages.md)、[11_data_backup.md](11_data_backup.md)。
