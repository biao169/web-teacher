# 新闻富文本与 PDF 使用说明

## 打开与保存

在“新闻动态”新建或编辑记录，填写标题、Slug、分类等基本信息。新记录使用“保存草稿并打开富文本”，已有记录从富文本编辑入口打开；表单有修改时先保存，再进入编辑器。

正文保存在 `news.content`，格式保存在 `news.content_format`，支持 `plain`、`markdown`、`html`。可视化编辑器保存 HTML。已有 Markdown 进入可视化编辑时会保留为文本内容，不能把它当作无损 Markdown 可视化往返编辑器。

正文保存与是否公开是不同控制项：前台可见性、发布时间、精选、排序、允许留言仍由新闻表单管理。预览不会发布记录。

## 编辑能力

| 功能 | 用法 |
| --- | --- |
| 段落与标题 | 使用普通段落、二级、三级和四级标题组织内容 |
| 文字格式 | 粗体、斜体、下划线、删除线，或清除格式 |
| 列表 | 无序列表、有序列表 |
| 内容块 | 引用块、代码块、水平分隔线 |
| 对齐 | 左对齐、居中、右对齐、两端对齐 |
| 链接 | 为选中文字设置允许的 HTTP、HTTPS 或邮件链接 |
| 编辑历史 | 撤销、重做；常规保存保留当前编辑上下文 |
| 图片 | 媒体库插入、本地图片粘贴或拖入上传、替代文字和布局 |
| PDF | 从媒体库插入 PDF 文档，可填写标题 |
| 前台实时预览 | 查看经过前台安全处理后的实际正文效果 |

当前工具栏不提供表格编辑、任意 iframe、视频嵌入或 Word 文档在线编辑。媒体库可预览视频，并不表示富文本工具栏提供视频插入。

## 插入与排版图片

可从媒体库选取已上传图片。也可把本地图片粘贴或拖入编辑器，系统上传到媒体库后插入受管理的图片引用。一次粘贴或拖入最多处理 10 张图片；上传仍受全局媒体大小、格式和权限限制。

图片可配置替代文字，默认从文件名生成，可修改；替代文字最多 500 字符。可拖动已插入图片改变位置，并选择普通独占、左浮动、右浮动、居中或宽图布局。移动端会将不适合窄屏的浮动排版还原为更易阅读的排列。

正文存储 object key，而不是开发机路径。删除文章中的图片节点不等于删除媒体库文件；媒体是否能回收，仍需检查其他引用。

## 插入 PDF 与前台阅读

先上传 PDF 到媒体库，再把光标放在正文目标位置，通过 PDF 插入入口选择文件。编辑器记录媒体 Key 和可选标题，保存后前台在同一位置展开阅读。

PDF 与前文之间使用分隔线衔接，没有浏览器 PDF 工具栏或 iframe 外框。组件接近视口后加载文档，先显示第一页；滚动到已显示页末端后继续渲染下一页。每页按自己的宽高比显示，整个网页高度随页面逐步增加，不使用固定高度的小窗口滚动。

没有自动滚动观察能力时提供“加载下一页”；加载错误可点击重试。带可提取文本的 PDF 提供适用的文本层，扫描图片 PDF 本身不会自动 OCR。

按页渲染不等于服务端已把文件切成多个 PDF；浏览器可能获取更多原始字节。当前内嵌组件固定使用 PDF.js，`news_pdf_engine`、`news_pdf_allow_download`、`news_pdf_watermark` 是保留配置，不控制这里的引擎、下载或水印。不能把页面不显示下载按钮当作禁止复制原文件的保证。

## 预览与安全格式

“前台实时预览”通过与前台相同的安全处理检查正文。允许的标题、段落、文字格式、列表、链接、受管理图片和 PDF 会保留；脚本、事件属性、任意嵌入框架及未允许的样式不会按原样执行。

直接输入 HTML 也受此规则约束。新闻正文和页脚的 HTML 用途不同，页脚不提供完整文章编辑器。编辑器暂时加载失败时可重试，已有正文不会因编辑器初始化失败而自动清空。

## 常见情况

| 情况 | 检查方式 |
| --- | --- |
| 列表看不到正文 | 新闻列表只显示标题相关信息，打开详情阅读正文 |
| 内容保存了但前台不出现 | 检查新闻可见性、发布时间、Slug 和保存结果 |
| 图片或 PDF 不可用 | 检查媒体对象存在、状态正常，以及引用记录允许前台访问 |
| PDF 较慢 | 文档接近视口才开始准备，继续滚动可加载后续页；错误时重试 |
| 粘贴后样式减少 | 内容经过允许格式清理，重新使用编辑器提供的格式即可 |
| 想恢复刚才的文字修改 | 使用撤销；不要把浏览器返回当作保存 |
