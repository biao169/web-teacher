# 独立运行数据

默认 `storage/data/metadata.sqlite`，schema 8：原实例信息、工具管理员授权、短期签名 nonce、版本化配置、个人用量账本、VPN 观测／预留及审计、临时分享清单与令牌摘要、恢复任务与身份绑定凭据摘要。配置和 VPN 审计分别最多保留 100 条。
`temporary/<UUID>/` 保存临时分享文件，使用数字索引，目录结构存于已校验清单；内容为私有目录中的明文，不进入教师媒体库。`checkpoints/` 保留为兼容目录，实际检查点统一保存在 SQLite。重启保留有效恢复任务的部分上传，清理其他未完成上传，保留已完成有效分享；删除成功后释放空间预留。
`initialize-bridge.mjs` 在数据目录创建专用 `teacher-signing-key.pkcs8`，供配套教师进程读取；服务本身只配置公钥。
分机或不同运行账号部署时，私钥只提供给教师身份适配器，工具服务只获得公钥。
接入脚本原文件副本位于 `storage/integration-backups/`；脚本不会删除用户数据或备份。
运行数据、密钥和真实配置不进入源码包。升级前停止服务，整体备份实际 dataDirectory；schema 8 不能由旧版服务直接打开。

`telemetry/vpn-snapshot.json` 为可选本机账单快照，只供受信任采集器更新。导入及校准方法见 `docs/vpn-budget.md`，数据文件不进入源码包。

恢复窗口默认 24 小时，最多 72 小时且不超过分享有效期；最多 1000 项，过期清理恢复元信息。恢复不清空个人／VPN 已用量。浏览器本机记录由用户主动启用，最多 10 项；不属于服务器存储目录。
