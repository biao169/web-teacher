# 断点恢复与任务体验（第 9/10 步）

本步把恢复能力接入现有 LAN、公网直连、服务器中继和临时分享。没有增加页面、运行依赖或教师源码改动。恢复继续使用原任务身份、内容清单摘要、传输方式和个人授权账目；每次重新连接仍通过教师最新会话和路径检查。

## 使用流程

- **暂停和继续**：连接获准后出现暂停按钮。暂停或网络中断后，界面显示服务器已确认的保存量及恢复截止时间；选择“恢复同一任务”。在线直连／中继需要两端都恢复，临时上传或领取只需当前端恢复。
- **自动重试**：网络中断默认最多重试 3 次，按 1、2、4 秒等待；保持同一种方式，不自动改走 VPN／中继。已保留发送文件、接收文件句柄时可自动继续；需要重新选择保存位置或 ZIP 时会等待操作。权限、计量、预算、文件校验等错误不反复自动重试。页面可立即重试或停止自动重试。
- **刷新／关闭后的恢复**：可选勾选“在本机保留恢复记录”，默认关闭，最多 10 项。重新进入同一账号与发送／接收视图后，在本机记录中点击恢复。发送方重新选择原文件／文件夹；接收方重新选择原输出文件或上次创建的 `transfer-...` 子文件夹。文件句柄和文件正文不保存到本机记录，不能承诺关闭浏览器后仍继续后台传输。
- **取消**：活动任务取消会结束连接；已暂停任务会用原凭据请求服务器撤销恢复。连接故障时若取消尚未成功，保留错误和记录供再次操作。单纯“移除此机记录”只删除该浏览器的记录，不撤销已经创建的分享链接；链接撤销仍使用原分享操作／后台维护。
- **账号切换**：暂停原任务并隐藏原账号记录。恢复凭据还需原身份；匿名必须保留原签名 Cookie，清 Cookie 或改用其他浏览器不会获得原匿名任务的恢复权。

本机记录包含恢复凭据、方式、任务统计、检查点、期限，以及接收文件／容器名称（用于选回原位置），不保存发送文件清单或正文。默认不启用；关闭选项会删除当前任务的本机记录，其他已有记录可逐项移除。本机存储被浏览器禁用或写入失败时，页面提示保持当前页。记录过期会在下次读取时隐藏，服务器按期限清理恢复元信息。

## 不重复扣个人额度

个人额度继续按整项授权大小、发送＋接收计入最初授权日／月。恢复时重新启用原 `transfer_allowances` 记录，保留 `authorized_at`，不新建另一笔扣额；跨日恢复也保留最初的归属日期。恢复仍占用个人／匿名共享并发，并需当前身份、方向、方式和文件限制获准。

临时领取第一次确认才占用一次领取和整项接收额度。在同一有效恢复任务内重试，不再调用新的领取，不再扣次数；所以领取上限为 1 的任务也可恢复。重新用分享链接发起另一项领取，则是新任务，照常核算次数和额度。已授权任务失败或取消不退款。

VPN 是另一套账本。所有重传、重新读取清单、中继和暂存响应继续申请新的有界预算，不能用旧短时额度令牌放行。已发出预算仍保守保留待对账。预算不足或计量失效会停止传输并保留可恢复进度，待条件恢复后手动继续。严格模式没有硬出口限制时仍禁用计费链路，不因续传而绕过。

任何统一配置保存都会使旧版本任务失效，需要重新创建任务；不能借旧恢复凭据保留被撤销的权限或旧限速。恢复窗口由创建时配置确定，后续配置修改不会延长旧凭据。

## 检查点及磁盘写入

检查点记录清单摘要、已完成文件索引、当前文件偏移、累计字节、块摘要链、整个已完成前缀的摘要链和固定块大小。只有接收端**校验成功、写入提交、服务器确认**后，才更新服务器检查点。

浏览器文件／目录写入复用 File System Access 接口：每次提交关闭 writable，后续以 `keepExistingData` 打开并定位到确认偏移。恢复前先读取并校验本机已完成前缀；校验成功后才截去未确认尾部并续写。目录中已完成文件只核验后跳过，保留空文件与可采集空目录。收到新块后继续校验 SHA-256 和文件摘要链。[File System Standard](https://fs.spec.whatwg.org/)

浏览器重新打开保留数据的写入流可能复制已有文件，所以检查点采用**配置最小间隔与单文件大小 ÷ 32 的较大值**，每个大文件约最多 32 次提交；小文件在结束时提交。这减少频繁复制，同时保持脚本内存有界。网络故障时会补传未提交部分；浏览器的最大未确认区间约为该间隔加一帧，不能无条件宣称只损失 4 MiB。文件系统实际提交／复制性能仍需目标浏览器和磁盘实测。

服务器临时上传使用可定位的文件读写和 `fsync`，按配置间隔及每个文件结束时提交检查点。默认最小间隔 4 MiB，可在后台调成 1–16 MiB；服务器通常最多补传这一间隔附近的未确认块。不能把尚在 writable 临时数据中的字节当成可恢复的已保存进度。

接收端写入完成后，如果检查点消息／确认在断网时丢失，恢复以服务器检查点为准：本机可能已有更长尾部，该部分可重传，不会被直接当成已确认数据。控制协议一项任务只有一个待响应文件拉取，恢复也不会建立无界的请求队列。

**ZIP 和兼容下载**没有可独立验证、续写的 ZIP 检查点，本版在原授权任务中重新生成。失败的兼容下载不留整文件缓存，原 128 MiB 合计内存上限保持；支持流式写入的 ZIP 不使用整包内存缓存。目录／单文件的实际续写要求相应浏览器接口，保存目录不是所有浏览器都有的能力。

## 恢复的内容校验

发送清单在准备时按规范化相对路径稳定排序并复制快照，因此重新选择同一集合、选择顺序不同也能得到相同清单摘要。原选择列表不会被修改。重新选择的文件名、目录结构、大小及修改时间须与原清单一致。

恢复前重新读取已完成内容，计算与检查点相同的摘要链。发送端验证原文件，接收端验证磁盘前缀，临时上传由服务器也验证私有文件前缀。内容被改动、文件缺失、位置选错或清单不匹配时先拒绝，不继续覆盖数据。校验分块执行并定期让出事件循环；已完成前缀不经过网络，但本机复核需要时间。特别大的已完成前缀仍需磁盘读取，不能承诺瞬时恢复。

浏览器端 Blob 文件和服务器磁盘支持从偏移读取剩余内容；其他已存在的流式来源使用有界的本地跳过读取。显示进度约每 100 毫秒更新，提供测得速度和剩余时间估算。估算会随网络和磁盘速度变化，不表示保证完成时间。

## 独立存储与生命周期

schema 8 新增 `recovery_tasks`、`recovery_members`，仍在工具独立 SQLite 中。服务器保存令牌散列，按原身份＋发送／接收方向＋方式查找。恢复凭据不放入 URL、管理列表或公共缓存，不能单凭知道任务 ID 恢复。校验点更新使用事务，拒绝倒退、越界和块大小更换。最多保留 1000 项恢复任务，默认期限 24 小时，可配置 1–72 小时；临时分享的恢复期限还受分享有效期约束。

已完成记录在恢复窗口内可回应已完成，避免结束确认丢失后再传一次。取消使恢复失效。服务重启将活动恢复记录设为暂停、结束旧并发占用；保留已授权额度和有效临时上传的部分内容。过期或已取消、没有活动恢复凭据的未完成上传会标为失败，随后按原临时清理周期删除。已完成有效分享继续保留。

`storage/data/checkpoints/` 保留为兼容目录，检查点实际放在 SQLite 中，未引入第二份 JSON 检查点账本。一个数据目录由一个独立快传服务进程使用；多个浏览器并发仍由服务端统一控制。

## 升级与验证

从第 8 步升级：结束旧任务并刷新已打开页面；停止两个服务，整体备份实际工具数据目录、配置和密钥，更新完整工具目录，冻结安装后重新构建教师站。schema 7 → 8 保留已完成临时分享、文件、原权限、设置版本和账本。没有恢复凭据的第 8 版中断任务不能追溯续传。回滚必须恢复升级前备份，旧服务不能直接打开 schema 8。

本步自动化覆盖真实 WebSocket 和独立磁盘服务的中断／重启、四种方式恢复、目录和空文件、个人只计一次、临时次数不重复、重复传输产生新 VPN 预算、丢失确认、错误身份、过期、取消、源码升级、本机记录与界面交互。RTC 和浏览器磁盘行为使用可检查适配器；刷新测试是新控制器读取序列化记录，不是浏览器引擎实测。

真实浏览器权限提示、后台挂起、多 GiB 复制开销、Windows 文件系统、双机公网 ICE、手机网络及实际 VPN 出口硬限额仍需第 10 步现场部署验收。没有新增运行依赖或部署公网。
