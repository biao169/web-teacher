本步新增 10 项 Node 检查：备份保留有效配置、专用私钥、数据库和实际文件字节；新目录恢复及不覆盖已存在目标；活动服务拒绝第二实例和备份，停止后释放、恢复数据可重新启动；内容篡改、额外文件、路径越界、重复清单、符号链接拒绝；仅已不存在的 PID 可解锁；构造失败释放运行锁；复制到新路径的维护 CLI 强制停机声明，诊断不改数据库或泄露密钥；源码哈希变更检出；非默认 WAL 日志模式拒绝直接复制；只启用中继时健康接口正确报告全局可用性。

备份使用真实 Node 文件流及 SQLite 独占事务；大文件逐块复制，输出独立目录而非内存压缩包。默认 DELETE 日志模式才可直接备份；自行更改日志模式不会被默默当作完整数据库复制。单实例锁在 createService 进入数据库前取得，正常关闭或构造失败释放；异常进程退出保留锁，由受限 unlock-stale 或审阅后的 systemd 启动前命令处理。不会终止未知 PID。

生产集成在第九步 32 项基础上新增两组：工具停止后教师中英文八类内容页面均保持一个导航和页脚；独立工具在原端口重启后，既有教师进程恢复工具 API 与当前账号验证，无需重启教师站。原真实 WSS 代理中继、暂存分享、暂停／恢复、内容比对、CSRF、权限、会话退出／停用等均通过。教师自身 74 项回归涵盖原导航、内容、筛选／缓存、登录与六位密码要求。

源码包附 SOURCE-MANIFEST.json；配套证据包包含最终通过日志和解压后离线安装、从不同工作目录执行完整 Node 测试以及前后哈希记录。源码与证据均不包含实际数据库、密钥、身份会话、用户临时文件或现场 VPN 快照。

本版没有新 npm 依赖、没有新教师业务改动、没有安装 TURN/tus 或额外后台服务。新增只读诊断、备份恢复和启动入口仍位于独立工具目录，业务控制继续在同一个快传管理页。教师源码最小接入补丁与撤回脚本保持原三处。

**未通过自动化替代的项目**：Windows 批处理／ACL、真实浏览器权限窗口／布局／挂起、双机 LAN 与公网 ICE、手机切网、多 GiB 浏览器磁盘复制、实际供应商计费出口、Nginx 目标配置加载、公网部署以及出口硬截断。没有安装 Nginx，所以模板只根据官方 WebSocket 代理要求提供，未声称 nginx -t 通过。systemd 模板语法验证也不代表实际进程托管或重启验收。

VPN 仍为可核验采样与保守预算预留，严格模式继续阻止缺少硬出口保护的计费链路；`hardExitCapAvailable:false`。同任务恢复不重复个人／领取额度，真实重传仍消耗新 VPN 预算。恢复旧备份会带回旧账本，管理员必须对照当前真实账单再开放，不能作为清空已消耗流量的方法。
