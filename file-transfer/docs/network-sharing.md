# 广域网、中继与临时分享（第 8/10 步）

本步在原发送／接收页增加传输方式选择，在原管理页开放对应规则和临时文件维护。前台默认选择局域网。直连不成功时，发送方可明确改选其他方式并生成新链接；本版不在原任务内自动降级或迁移链路。

## 使用方式

| 方式 | 用户获得什么 | 必要条件 | 文件经过哪里 |
| --- | --- | --- | --- |
| 局域网直连 | 同网直接发送，默认不限速 | 双方在线、已核验的私有 IPv4 范围、支持可检查的 WebRTC 连接 | 两端之间；网站和信令仍会访问服务器 |
| 广域网直连 | 跨网络直接发送，减少服务器文件转发 | 双方在线、已核验绕开受限 VPN 的公网 IPv4 范围、可验证的 UDP host/srflx 候选 | 两端之间；可选 STUN 发现候选 |
| 服务器中继 | UDP 不可用时可选，服务器逐块执行权限、速率与预算 | 双方在线，WSS 可达，当前角色和服务器路径获准 | 两端与独立工具服务之间，通过教师同源代理 |
| 临时分享 | 上传完成后可以离开，对方稍后领取 | 存储容量、有效期、次数、双方各自的规则和路径预算许可 | 工具独立私有目录；不进入教师媒体库 |

先选文件或目录，再选方式。在线模式生成接收码／链接，双方确认后由接收方选择保存方式。临时模式上传完成后提供含随机凭据的链接；接收方先查看内容概况、期限和剩余次数，再点击“确认领取”。文件夹、空文件和采集接口提供的空目录保留原有相对结构。接收方可使用浏览器支持的目录保存或 ZIP；不支持流式落盘时，兼容下载合计上限仍为 128 MiB。

仅查看分享不消耗领取次数。确认领取成功时，占用一次领取和整项接收额度；随后取消、保存失败或断连不退回。准入／个人额度失败发生在领取之前，不占次数。上传同样按整项发送额度计入；个人额度是授权口径，VPN 是独立的出口口径。分享上传完成后发送方可以离线，页面刷新后请保留先前复制的链接；服务器不保存可恢复的明文领取凭据。发送者在当前完成页面可以撤销，管理员可在统一后台撤销或清理。

## 后台配置

1. 在“链路与速率”勾选所需方式，同时在匿名／登录／角色／个人规则中允许该方式及发送、接收方向。管理员权限本身不等于传输权限。局域网限速默认留空，仍可配置。
2. 广域网直连填写真实公网 IPv4 CIDR 白名单，最多 16 个，掩码 /8 至 /32，必须网络对齐。私有、回环、共享地址、文档测试、保留等范围拒绝。确认这些路径确实绕开受限 VPN；浏览器候选无法证明底层隧道路线。可选最多 3 个 `stun:`／`stuns:` 地址，无默认第三方 STUN、无 TURN 凭证。
3. 中继和临时分享设置“服务器文件链路”：未知、经过受限 VPN、或已核验不经过。核验范围必须涵盖**浏览器 → 教师代理 → 独立工具服务**的相关路径，不能只核验回环服务端口。声称不经过但未勾选实际核验时仍禁止。
4. 计费路径要求第 7 步统计和预算有效。默认严格模式缺少真实出口硬限额，继续禁止计费链路；主动使用估算模式并配置有效计量后，应用层中继／暂存才可申请短时预算。未知路径默认禁止；管理员选择按计费处理时也必须满足预算条件。
5. “临时文件”设置保存时长、最大领取次数、总容量和检查间隔。下面显示最新 100 项与总占用，可撤销和清理到期／撤销／失败项。一次清理最多 20 项，跳过活动任务；删除成功才释放预留空间，失败保留并下次重试。未保存配置时，维护按钮禁用。

更改配置会撤销旧版本任务授权。期限和最大领取次数在创建分享时固定，后续修改默认值影响新分享；立即关闭现有分享请撤销。过期访问立即失败，磁盘清理按周期执行。达到领取上限会阻止新领取，文件仍保留至到期或被撤销清理，以免删除最后一次正在领取的文件。

## 轻量实现及协议边界

本步把原计划的 TURN 中继调整为已有 **ws** 依赖上的 **WSS 应用层文件中继**，无需新增 coturn、tus 或第三个服务。这样可以在每次拉取响应之前预留预算，也能用于只允许 TCP/HTTPS 的环境。`ws` 提供服务端 WebSocket、帧大小上限等底层能力；本工具另行实现文件拉取、授权与计量。[ws 项目](https://github.com/websockets/ws)、[ws API](https://github.com/websockets/ws/blob/master/doc/ws.md)

这是本项目的实现取舍，不宣称 WebSocket 是 TURN。coturn 的连接数、每秒速率及认证配置不能直接替代本项目的日／月累计预算，TURN 还需要额外的实时停用设计；本版不生成 TURN 凭据，也未部署 coturn。[coturn 配置](https://github.com/coturn/coturn/blob/master/docker/coturn/turnserver.conf)

广域网候选只保留已核验白名单中的 UDP host/srflx。两端上报选中的地址和端口必须互相对应，并匹配各自已发布候选；本机统计只返回私有 host 时，只有存在匹配 relatedAddress/relatedPort 的已发布 srflx 才能映射。地址隐藏、IPv6、无法证明候选对应或可能计费的 P2P 均不放行。这些检查约束正常客户端和信令准入，不能代替部署路由验证或阻止双方自行绕过工具通信。[W3C WebRTC Statistics](https://www.w3.org/TR/webrtc-stats/)、[W3C WebRTC](https://www.w3.org/TR/webrtc/)

中继／暂存复用 `/transfer-api/v1/signal` 的实时教师会话授权，文件使用有界 JSON/base64 帧；原始帧最多 16 KiB，每次只允许一个待响应拉取，按清单、文件索引、连续偏移、块 SHA-256 和文件摘要链检查。控制清单最多 **256 KiB**；直连原上限保持不变。大量小文件可能先达到清单上限，需拆分任务。后台和前台均提示这项限制。base64 会增加转发字节，预算按有界封装开销和安全余量预留，不能将文件原始大小当成 VPN 用量。

受控文件响应在请求前预扣，最长 2 秒窗口；统计失联、额度不足、配置失效或撤销后停止后续拉取。已发出预算保留待对账，可能暂时与观测流量重复计入。浏览器发给服务器的恶意超额网络数据、其他共用 VPN 服务流量和操作系统在途数据不能由应用层事后校验阻止，因此**仍不是供应商硬限额**。`hardLimitAvailable:false` 保持真实，严格模式不放行计费链路。详细口径见 [VPN 流量与额度](vpn-budget.md)。

## 存储、隐私和恢复

临时内容位于 `storage/data/temporary/<随机 UUID>/`，磁盘文件采用数字索引，相对路径只存放在已校验清单中。私有目录／文件采用 0700／0600 权限（以系统支持为准），拒绝符号链接、异常硬链接和被替换的文件。随机领取凭据只在创建时返回，数据库保存 SHA-256 摘要；链接片段不会作为普通 HTTP URL 发送，但持有链接且符合接收权限的人仍可领取，请按私密链接保管。

中继使用 HTTPS/WSS 逐跳加密，服务端可以接触文件内容。临时文件在独立磁盘中以明文保存，本版没有端到端加密、病毒扫描或存储加密功能。清理是文件系统删除，不是物理介质安全擦除。

容量预留包含文件字节、每个文件 4096 字节和 256 KiB 清单余量，不代表所有文件系统的精确物理占用；独立目录所在磁盘仍需有足够空间。最多保留 1000 项分享。服务重启保留已完成且未过期分享，保留具有有效恢复凭据的未完成上传，其余标为失败并逐批清理，结束遗留分享用量任务；不会退回已经授权的个人额度或已发出 VPN 预算。第 9 步已接入同一方式的断点恢复；网络切换后重新核验原方式，不自动切换传输方式。详见 [任务恢复](recovery.md)。

## 升级与验证边界

停止两个服务，备份实际数据目录、配置和签名密钥，更新整个 `file-transfer/` 目录，保留运行数据；冻结安装后重新构建教师服务。服务端复用 `web/files/direct.mjs` 等纯 JavaScript 协议文件，部署时不能只复制 `server/`。

schema 6 → 7 增加临时分享表、默认关闭的公网／服务器路径核验字段，并把旧规则 `turn-relay` 映射为 `server-relay`。保留配置版本、权限、个人账本和 VPN 待对账。升级不会自动满足新链路的核验条件。回滚使用升级前备份，旧服务不可直接打开 schema 7。

本步验证真实 Node WebSocket 中继、磁盘暂存、离线后领取、目录结构、SHA 校验、预算失联停传、领取次数、撤销、清理、迁移及生产教师代理。RTC 和目录保存使用可检查适配器；Vue 使用 happy-dom，不是浏览器渲染引擎。真实 Windows、双机公网 ICE、移动浏览器、多 GiB 磁盘和供应商 VPN／出口硬限额尚待第 10 步部署验收；本步未部署公网服务。

第 9 步更新：已获准的同一临时领取任务可在恢复窗口内继续，不消耗第二次领取；新的独立领取仍计次数。恢复窗口还受分享有效期约束。
