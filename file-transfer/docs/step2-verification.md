## 关键行为

- 中英文页仅一份教师顶部导航和页脚；当前快传导航高亮；语言切换保留接收视图。
- 未配置快传导航时补充默认入口；已配置自定义内部导航时保留其名称且不重复添加。
- 匿名、普通用户和未单独授权的教师管理员不能读取工具管理 API。
- 明确授权的 UID 可访问管理 API；撤销后下一请求拒绝。
- 教师退出后，继续使用原 Cookie 访问工具会被拒绝；账号停用同样拒绝。
- 角色变化读取最新值；角色名称或等级不产生新的管理权限。
- 即使已授权，必须修改密码的账号也不能访问管理 API。
- 签名过期、错误密钥、篡改、算法替换、跨路径使用和重复使用均拒绝；nonce 在服务重启后仍生效。
- 客户端角色头、伪造 Authorization、跨站请求和未开放写操作不能取得权限。
- 快传进程停止后，工具页与教师首页仍可打开；工具身份接口返回明确的不可用状态。
- 源码迁移到中文/空格路径后，初始化、重启和停止均可用；重复初始化不更换私钥，也不输出私钥。
- 安装脚本先完整预检；不兼容文件会使整个操作停止；撤回保留用户在其他位置追加的修改。
