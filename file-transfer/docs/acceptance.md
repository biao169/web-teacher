# 集成验收与现场记录

代码版本：0.10.0；数据库 schema 8。代码、自动化验证和部署材料交付不等于公网正式验收。当前有 Linux 真实 HTTP／WebSocket、SQLite、磁盘和教师生产包联调；浏览器原生文件权限／RTC 使用可检查适配器，Vue 交互使用 happy-dom。没有远程部署凭据或目标双机网络，本次未替用户勾选任何现场通过项。

## 目标环境填写

- 日期／执行者：待填

- Node／pnpm 版本、操作系统：待填

- 接收端设备／浏览器版本：待填
- 实际 LAN 网段、公网出口与所选候选：待填
- VPN 计量源、供应商口径、日／月限额、初始已用量：待填

- 测试证据位置：待填；不记录密钥、恢复令牌或有权限的分享链接

## 交付判定

代码交付可以标记完成；将模板装到服务器、开放用户和真实网络测量应分别记录执行时间、结果和证据。存在缺失的硬出口控制时，保持本版严格模式行为，不把估算保护改名为硬保护。不具备某浏览器文件夹 API 时，应按 ZIP 兼容流程验收，不以功能缺失伪装为文件夹保存成功。

现场出现失败时保留原文件和备份，记录方式、时间、错误码、是否已确认检查点、是否实际经过 VPN；隐去访问凭据。依据 [部署手册](deployment.md) 与 [恢复说明](recovery.md) 定位，不通过清空账本、重建密钥或把未知路径标为绕开 VPN 来消除错误。
