# 实时管控与资源保护

实时管控是这个工具的安全核心。目标是在传输便利和服务器安全之间做硬边界：当带宽流量不足、磁盘空间不足或管理员远程关闭时，优先保护 web03 网站和服务器。

## 需要实时监控的指标

```text
当前活动任务数
当前总上传速度
当前总下载速度
单任务上传速度
单任务下载速度
今日累计流量
本周累计流量
本月累计流量
本年累计流量
单用户周期流量
本机临时目录已用容量
本机磁盘剩余容量
云端暂存已用容量
云端流量消耗
中转队列长度
WebSocket 连接数
失败任务数
```

## 流量额度控制

后台允许设置周期总流量：

```text
daily_traffic_quota_gb
weekly_traffic_quota_gb
monthly_traffic_quota_gb
yearly_traffic_quota_gb
```

统计口径建议：

```text
直连传输:
  可记录估算流量和任务元数据。

web03 实时中转:
  以 web03 实际入站 + 出站计量。

云服务器实时中转:
  以云中转节点回传的计量为准。

本机临时落盘:
  上传写入 + 下载读取都计入。

云端临时暂存:
  上传到云端 + 从云端下载都计入。
```

## 流量不足时的提示与阻断

建议设置两级阈值：

```text
warning_threshold_percent = 80
critical_threshold_percent = 95
```

当达到 warning：

```text
前台显示提示：
  当前传输流量额度即将用尽，后续任务可能被限速或暂停。

后台显示告警：
  今日/本周/本月/本年流量已达到阈值。
```

当达到 critical：

```text
阻止创建新任务。
可选暂停低优先级任务。
可选中断临时暂存上传。
管理员后台显示红色告警。
```

用户提示文案建议：

```text
当前传输流量额度不足，系统已停止创建新的传输任务。请稍后再试或联系管理员。
```

## 磁盘空间保护

磁盘保护主要针对本机临时落盘和日志增长。

建议后台设置：

```text
min_free_disk_gb = 10
min_free_disk_percent = 15
local_temp_total_quota_gb = 50
local_temp_per_session_quota_gb = 10
```

当磁盘达到 warning：

```text
前台提示磁盘空间紧张。
禁止新的本机临时落盘任务，仍允许局域网直连。
后台提醒管理员清理临时文件。
```

当磁盘达到 critical：

```text
立即禁止新的本机临时落盘任务。
禁止新建需要服务器暂存的任务。
可中断正在写入本机临时目录的任务。
保留局域网直连或纯实时转发能力，具体由后台策略决定。
```

用户提示文案建议：

```text
服务器临时存储空间不足，系统已暂停需要暂存的传输。可尝试局域网直连或联系管理员。
```

## 带宽保护

带宽保护使用令牌桶或滑动窗口实现：

```text
全局令牌桶
用户令牌桶
任务令牌桶
```

优先级建议：

```text
管理员任务 > 已登录用户任务 > 匿名随机码接收任务
局域网直连 > 实时中转 > 临时暂存
已接近完成任务 > 刚开始任务
```

当带宽不足：

```text
先限速。
再阻止新任务。
最后按后台策略暂停或中断低优先级任务。
```

## 管理员远程关闭

后台总开关关闭时可选策略：

```text
graceful
  停止创建新任务，活动任务继续完成。

pause_active
  停止创建新任务，暂停活动任务。

immediate
  立即中断所有活动任务，释放资源。
```

前台提示文案：

```text
文件传输功能已由管理员暂时关闭。当前任务已停止，请稍后再试。
```

## 保护优先级

当策略冲突时，按以下优先级执行：

```text
1. 保护 web03 网站正常运行。
2. 保护服务器磁盘不被占满。
3. 遵守管理员远程关闭和权限控制。
4. 遵守周期流量额度。
5. 遵守带宽限制。
6. 尽量让已开始且接近完成的任务顺利结束。
```
