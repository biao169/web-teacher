# 前台界面规划

## 首页

路径：

```text
/transfer/
```

主要区域：

```text
创建传输
输入随机码
最近任务
当前系统状态
```

系统状态展示：

```text
局域网加速可用
web03 中转可用
云服务器中转可用
临时暂存可用
今日流量剩余
服务器暂存空间状态
```

## 传输房间

路径：

```text
/transfer/r/<room_id>/
```

主要功能：

```text
拖拽多文件
拖拽文件夹
显示文件树
显示连接链接
显示二维码
显示随机码
选择连接模式：自动 / 局域网 / web03 中转 / 云中转 / 临时暂存
显示实时速度
显示总进度和单文件进度
暂停、继续、取消
```

## 接收页面

路径：

```text
/transfer/receive/<room_id>/
```

主要功能：

```text
输入随机码
确认接收
选择保存目录
保留文件夹结构
显示实时接收速度
显示剩余时间
显示异常提示
```

浏览器支持 File System Access API 时：

```text
用户选择保存目录
系统逐文件写入
保留目录结构
```

浏览器不支持时：

```text
降级为多文件下载
或提供可选压缩包下载
但不强制压缩包
```

## 告警提示

流量接近上限：

```text
传输流量额度即将用尽，后续任务可能被限速或暂停。
```

流量已不足：

```text
当前传输流量额度不足，系统已停止创建新的传输任务。请稍后再试或联系管理员。
```

磁盘空间紧张：

```text
服务器临时存储空间紧张，新的暂存任务可能被暂停。
```

磁盘空间不足：

```text
服务器临时存储空间不足，系统已暂停需要暂存的传输。可尝试局域网直连或联系管理员。
```

管理员关闭：

```text
文件传输功能已由管理员暂时关闭。当前任务已停止，请稍后再试。
```
