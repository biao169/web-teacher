本模块接入指定的 `teacher-site-windows-v0.15.160-step6.zip`，没有参考或复用其他网站版本。网站的前台、登录、权限、CSRF、日志、缓存和快传沿用该基线。`core/`、`runtime/`、`adapters/`、`transport/` 为重新设计的同步引擎；`integration/` 是教师网站适配；`frontend/` 共用网站后台布局；`worker/` 是私有原生流式媒体服务。

## 使用

1. 在两端网站后台生成或粘贴相同的64位十六进制同步密钥并分别保存。环境变量 TEACHER_SYNC_KEY 仅作后备；后台配置优先，无需重启。详见 [配置教程](../docs/sync-key-setup.md)。
2. 使用网站系统管理员登录 `/admin/site-sync`，分别填写另一端的 HTTPS 根域名，保存连接及当前授权。密钥缺失时普通网站仍可访问，同步不能执行。
3. 在接收端创建手动拉取任务，预览后勾选并批准；或只在接收端开启定时计划。发送端“请求对端拉取”只提交提案，对端仍需批准。避免对同一模块同时开启双向自动覆盖。
4. 后台可调连续快速重试次数、重试间隔和正文切片大小。正文切片范围 256 字节至 64 KiB；资源错误会降低切片，持久化进度增加会重置连续失败计数。任务没有整体完成期限，超出快速重试预算后继续慢速重试，只有权限、冲突等不可恢复错误暂停，保留进度，后台可恢复。
5. 更改账号状态、密码、角色或权限会撤销同步授权；修正权限后重新保存连接，再预览新任务。连接绑定创建它的管理员，不允许其他账号悄悄接管。

## 数据边界

一次任务最多选取所有模块合计最新 500 条主记录；按稳定游标逐条发现，不一次载入整库。支持 profiles、students、research_interests、projects、publications、patents、courses、news、student_category_displays、navigation_items、site_settings、translation_cache。账户、会话、全局凭据、私信及日志不对外同步。

新闻关联的论文、项目、学生及站点首页教师作为必要依赖一并处理。已存在且版本不同的依赖会暂停，需先同步其模块。主记录使用版本条件写入，避免覆盖预览后的本地修改。删除仅依据明确墓碑；不会因接收端多出记录而删除。未被同步引用的本地媒体不受影响。

单条正文（含依赖与媒体元数据）最多 200,000 字节，媒体最多 16 个，每个 1 字节至 20 MiB。暂不接入外链媒体和静态资源媒体。超界任务停止该项并显示错误，不能静默截断。源端快照按接收任务隔离，访问续期 7 天；长期完全不推进且快照已被清理的任务需重新预览。任务无整体期限并不保证已消失的源文件可恢复。

正文由 SQL 提取有限片段；媒体在本地文件流或 JS 原生 `ReadableStream` 传递，避免进入 Python Worker 内存。R2 非末尾 multipart 分片必须至少 5 MiB，因此自适应缩小主要用于正文片段，不能无限缩小 R2 存储分片。媒体版本映射复用已导入的资产；当前可能仍重复传输媒体字节，未承诺全量去重下载。

## 数据库与部署

唯一初始化 SQL 是 `database/schema.sql`。JSON schema 快照用于精确比对，Python 迁移计划用于升级，不另设初始化 SQL。

本地启动/初始化会检查结构：空库初始化；当前结构直接使用；精确 v0.15.160 结构先备份，再事务升级；其他未知结构停止且保留原库。备份名为 `*.before-v0.16.001-*.sqlite3`。原网站业务数据保留，旧同步连接与任务不自动续接，保留在备份中。

Cloudflare 正式部署流程会检查 D1：默认 `TEACHER_D1_INIT=auto`，精确 v0.15.160 升级前保存 Time Travel bookmark，再执行原子 D1 batch，最后重新检查结构。需要 `CLOUDFLARE_ACCOUNT_ID` 与有 D1 编辑权限的 `CLOUDFLARE_API_TOKEN`。`TEACHER_RECOVERY_DIR` 指定持久恢复记录目录，默认执行目录下 `sync-recovery/`；`check` 模式只检查，不升级。运行中的生产站点升级应安排维护窗口，避免旧程序写入已更替的同步表。

正常 Cloudflare 部署同时生成并发布 `<主 Worker 名>-sync-native` 私有 JS Worker，通过 `SYNC_NATIVE` service binding 连接，共用主站 D1/R2 与媒体前缀，不提供独立公网域名。若部署环境提供 `TEACHER_SYNC_KEY`，发布器向主站和辅助服务配置同名 Secret，主站临时0600密钥文件用后删除；未提供时保留已有 Secret。推荐部署后在两端后台保存同一密钥，本站主站和辅助服务共用数据库配置。

本地后台每 5 秒尝试一个有限步骤；Worker Cron 复用现有维护入口，无到期任务时不加载完整站点。共享数据库租约防止并发重复执行。同步错误使用现有轮转日志，不另建无限增长文件；`SYNC_HISTORY_DAYS` 默认 90 天，终态记录及过期源快照逐条清理，运行中任务不因历史保留期被删除。SQLite 升级备份和 D1 恢复记录由管理员保管，不作为日志自动删除。
