## 验收中修复的问题

同步执行步骤的重试门禁原先在进入取消逻辑之前运行，导致失败任务可能不能取消。本版只让显式取消绕过推进冷却和“未确认尝试次数”限制；依然获取原任务锁并执行原有权限校验，进入清理阶段，不继续提交待同步的业务记录。新增暂停/中断两种状态下的回归测试，验证普通推进仍被拒绝、取消成功、未写入学生记录。

历史测试按现有功能更新：模拟源码包含site_sync和必要部署入口；不存在的系统账号不期待userdel；受管路径检查允许只读探测；自动同步排序采用更新时间/ID/模块；涉及Worker的媒体分片使用16 KiB；旧错误恢复测试显式手动继续，冷却测试在隔离数据中模拟时间已过；Cron按指定时间槽只执行一类维护，空闲时不输出日志。没有为这些测试取消生产重试限制或降低权限门槛。

## 统一验收入口

原 `tests/run_acceptance.py` 未包含Worker测试目录。本版将 `deploy/cloudflare/tests` 纳入默认Python验收，并增加离线部署产物检查。

在已安装测试依赖的源码目录执行：

```sh
python -B tests/run_acceptance.py --dom --report acceptance-report.json
```

仅执行离线部署产物检查：

```sh
python -B tests/stage_release_v160.py
```

工具只在临时目录组装，退出后清理；不安装依赖、不访问生产数据库、不连接服务器、不发布站点。模拟域名和D1 UUID只是占位测试输入，不是实际部署配置。

## 上线检查顺序

1. 使用完整源码包更新，保持现有数据库、媒体及运行配置；确认 `site_sync/` 随包存在。
2. 检查主域名与每个允许域名的首页、中英文页面、图标、分页、搜索。
3. 分别登录各域名，检查后台保存、数值字段显示、快传和同步页面；确认未允许域名不能进入。
4. 用测试记录验证后台更新、隐藏及翻译修改后下一次前台请求显示正确结果。
5. 检查日志管控页面，先预览；仅在认可删除范围后执行生产日志清理。
6. 检查Worker真实资源指标与定时任务；VPS检查服务日志轮转、代理和权限。
