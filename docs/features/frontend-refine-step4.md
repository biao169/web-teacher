# 前台逐项优化第四步：0.15.61

基于0.15.60，完成论文卡片和多格式复制。

## 界面与使用

论文继续按网站配置显示已保存的GB/T、Elsevier、APA或IEEE引文；姓名高亮在原安全文本节点上增加下划线和字重，复制内容不带下划线符号。卡片末行左侧为具体DOI地址、原文/公开PDF入口及复制图标，右侧为类型、收录、作者角色、标签与通讯作者；窄屏分组换行。标签仍不混入引文复制，不新增论文详情页。

论文多选工具行增加复制格式选择：GB/T、Elsevier、APA、IEEE、BibTeX。默认跟随网站显示格式；切换不提交筛选、不修改设置或卡片、不清除勾选。单条按钮遵循该页选择，首页单条复制使用站点显示格式。BibTeX复制保存的数据文本，保留换行、空格及人工编辑，不重新生成。

## 分批读取与失败处理

复制当前显示格式时复用已加载引文；其他格式由新增只读接口GET /api/public/publications/citations读取，format指定一种格式，重复uid参数每批1—20条，客户端串行调用。接口使用原public scope，只SELECT uid及一种白名单引用字段，每条最多65536字符，不读整个论文，不返回隐藏记录，不自动翻译/联网补查，不写库。响应no-store；前台校验格式、UID集合、长度、重复项并按页面选择顺序组合，返回顺序不同也不打乱复制。

所选格式缺失、过长或条目不可见时，提示数量并停止整组复制，不拼接基础著录信息、不混用其他格式或跳过记录。已加载显示格式为“引文未填写”提示时，同样不复制这段提示作为引用。读取错误保留选择，用户可重试；不持久缓存替代格式，每次重新读取。改变复制格式、筛选条件、选择状态或离开页面会取消尚未进入剪贴板写入阶段的读取请求，迟到响应不能触发复制。

成功后使用既有Clipboard API/兼容复制方法；若浏览器拒绝自动复制，提供只读文本框，里面是所选格式完整文本，可手动选中复制，避免误复制页面上另一种格式；再次切换格式或选择时清除旧手动文本。
