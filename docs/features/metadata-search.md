# 论文元数据检索与供应商配置

论文编辑页的“论文元数据检索”和论文列表的“独立元数据检索”复用同一查询组件。支持 DOI、doi.org 链接和题名；自动识别也可切换成明确的 DOI 或题名模式。每次最多返回5个候选，不查询论文全文或下载附件。

## 服务与匹配

| 服务 | DOI方式 | 题名方式 | 可选部署密钥 |
| --- | --- | --- | --- |
| Crossref | works精确DOI | query.title相关性查询 | 不需要 |
| OpenAlex | works DOI过滤 | search检索，可能涉及题名之外的索引 | TEACHER_OPENALEX_API_KEY |
| Semantic Scholar | paper/DOI标识 | paper/search | TEACHER_SEMANTIC_SCHOLAR_API_KEY |
| DataCite | dois精确DOI | titles.title短语 | 不需要 |
| Europe PMC | DOI字段 | TITLE短语 | 不需要 |
| PubMed | ESearch文章标识 | ESearch标题字段，再取ESummary | TEACHER_PUBMED_API_KEY |

DataCite同时收录数据集等科研成果，题名检索不保证返回期刊论文。各服务的相关性与收录范围不同，候选必须人工核对。精确DOI查询要求候选自身提供匹配的DOI；不以查询词替代缺失的服务标识。按DOI或题名与年份去重，缺少必需题名的结果不提供回填。

“默认服务”仅查询全局设置中的默认服务；选择具体服务仅查询该服务；“按配置顺序回退”逐家尝试启用列表，得到候选后停止。不会自动混合不同服务的论文或补齐另一篇论文的字段。逐家显示未找到、限流、未配置/未启用、拒绝访问、超时、格式无效或成功；成功缓存额外标明“缓存”。没有结果时可更换关键词/服务手动重试，没有定时重试或常驻检索进程。

## 供应商设置

全局设置中的原生字段 `publication_metadata_provider` 保存默认标识；`publication_metadata_providers` 保存有序服务标识数组。页面用复选框和1–6顺序输入控制，无需手写JSON。默认服务必须启用；相同顺序按页面服务排列顺序处理。原生空数组且已选默认时仅使用默认单服务；默认和列表都为空时默认Crossref，并提供Crossref、DataCite、Europe PMC、PubMed的公共来源顺序。只有显式选择回退才使用该顺序，不在启动时写入或覆盖配置。

`publication_suggestion_cache_seconds` 是原有字段，本功能启用它控制元数据成功缓存，范围0–86400秒，0关闭。它不改变历史输入建议查询。数据库列、类型、默认值与约束均不变；其他预留缓存字段仍按原边界处理。

上述三种可选密钥由服务器环境变量或Worker同名Secret提供；页面只显示是否配置，不回显密钥。`TEACHER_METADATA_EMAIL` 是可选服务联系邮箱，仅随Crossref/PubMed请求发送。配置该变量意味着允许向对应服务发送此联系信息。没有凭据时尝试公共访问，可用性和额度由服务方决定；填写错误、无权限或受到限制都会显示状态。此处不提供任意API地址，也不把密钥塞入原生服务数组。

服务卡片与翻译复用模板，可查看有效端点、凭据状态和显式测试连接。“填入推荐设置”仅填入本组草稿，密钥及其他设置保留；测试发送固定题名，不写候选缓存或论文。规则见[服务预设与连接测试](translation-services.md)。

无效设置不阻止手动编辑论文，检索区域提示管理员修复；保存设置使用全局设置编辑权限、CSRF和原生更新时间校验，保存失败保留当前输入。

## 候选、差异与保存

题名查询先展示候选卡片，明确选择具体论文后自动填入对应输入框；单个精确DOI候选也需要先选择。支持原题名、作者、通讯作者、期刊/会议、年份、卷期页、DOI、URL、论文类型与关键词。字段只在来源确实提供并通过校验时出现，缺失值不清空原字段；没有摘要或中英文双标题输入。

选定候选后自动填入来源提供的非空字段，字段原值与独立撤销显示在输入框下方；后续手工修改受保护。原始引文解析继续勾选回填，并共用逐字段撤销。受保护手工引文不会因元数据变化自动覆盖。回填仅改变草稿，底部保存按钮才写入论文。详情见[论文引文与差异核对](publication-assistance.md)。

修改查询词、类型或服务会清空旧候选并取消旧等待；取消按钮、页面离开及保存也停止等待，迟到响应不会替代新状态。浏览器最长等待25秒，失败可重试且保留草稿。第三方文字采用文本节点显示，网页标记不会执行。

独立检索页只查看候选字段，不自动创建论文、不修改其他正在编辑的表单。它需要论文查看权限；编辑页查询需要论文新增/编辑权限，有条目标识时还验证记录可见性。固定导航入口检索前后复核导航更新时间与原记录是否在固定范围，正式回填保存继续验证当前表单是否符合该范围。

## 资源与适配

本地urllib与Worker fetch共用固定HTTPS主机/路径白名单，不跟随重定向；单次响应上限1MiB。一次供应商尝试等待最多8秒，供应商回退共享20秒等待预算；PubMed两次HTTP请求计在同一次尝试内。单连接设置6秒超时，Worker会中止请求；本地线程在等待取消后仍可能完成底层网络收尾，这些时限不构成整个操作含DNS/缓存的绝对墙钟保证。

仅缓存成功候选，缓存位置为已有cache_dir或R2缓存绑定/前缀下 `metadata/v2/`。64个固定槽，每槽最多192KiB，正常新缓存文件内容总量上限12MiB；摘要同时包含服务、查询类型、文本和凭据指纹。碰撞替换旧槽，过期或损坏重新查询；旧版本缓存文件不在本功能限额内，不随更新删除。缓存无业务记录写入和密钥明文；缓存故障不阻止正常查询，缓存命中仍检查权限。

没有新增生产依赖、数据库表或构建步骤。前台模板不变。Windows/Linux读取服务器环境变量，Worker入口读取同名环境绑定；API可用性需要在实际部署网络和凭据条件下核实。

## 官方接口参考

Crossref的公开检索与联系信息规则见[访问与认证](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/)。OpenAlex的search检索范围与密钥说明见[搜索](https://help.openalex.org/api/searching/)及[认证](https://help.openalex.org/api/authentication/)。Semantic Scholar的paper接口见[Graph API](https://api.semanticscholar.org/api-docs/graph)。DataCite的题名字段与分页见[查询语法](https://support.datacite.org/docs/queries)和[查询参数](https://support.datacite.org/docs/api-queries)。PubMed搜索与汇总接口见[NCBI E-utilities参考](https://www.ncbi.nlm.nih.gov/books/NBK25499/)。服务额度随供应商政策变化，本功能不预设免费额度承诺。


论文页与独立检索页的辅助加载错误会显示明确提示；论文页只有选中候选后才回填字段，并在各字段下保留原值及撤销。联网服务超时、限流和配置错误在检索区域显示，输入解析和其他表单控件保持可用。
