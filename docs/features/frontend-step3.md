# 第三步：教师与学生前台（0.15.47）

本版是可运行的前台阶段交付，不将取数缺口标为已完成。基于0.15.46，正式路由仍为/zh或/en下的profiles、students及对应详情。没有新的依赖或数据库迁移。

## 已完成

- 人员共用字段/卡片/详情模板。一行一卡，紧凑元信息，透明无边框contain头像；右下角展开/详情图标不占独立整行。教师已有简介显示2行，点击读取完整公开简介再展开，不把2000字摘要当全文。学生也可通过展开或详情读取简介。
- 教师序号从1递增，学生按当前筛选总数递减；服务器模板计算页偏移，滚动追加与显式分页均连续。
- 关键词搜索、学生分类/学位/研究方向/状态精确输入筛选，原有筛选保留；排序字段/方向、10或20条批次。控件为真实GET表单，禁用JavaScript仍可提交和打开详情。
- 全选仅作用于已加载记录，滚动追加保留旧选择，新记录不自动选择；支持取消选择、白名单基本字段复制、成功/失败反馈、Clipboard API与回退。筛选/显式翻页后选择清空提示。复制完整简介和详情字段使用详情页的复制当前条目。
- 详情提供公开教育、工作、招生、实验室、学术主页；学生入学/毕业日期、获奖、去向、主页等字段；学号和隐藏联系方式不出现在展示/复制数据中。纯文本字段自动转义。
- 英文控件、键盘焦点、ARIA展开/状态、懒加载头像、无脚本回退；展开请求只在点击时发出，失败保留原文且可重试，页面离开时取消请求。
