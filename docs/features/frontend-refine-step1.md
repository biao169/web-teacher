# 前台逐项优化第一步：0.15.58

基于0.15.57；只实施统一基础及项目字段可见范围。

## 内容

- `frontend/shared/static/css/public-theme.css`是正式前台UI字体、字号、字重、行高与配色维护入口。优先修改语义变量public-ink/muted/accent/surface/page/line/font-body；编号变量保留原页面的细分字号和颜色。其他页面CSS保留布局并引用变量。阅读模式及共享正文的前台覆写也集中于此。第三方库、PDF原始文字、官方图像和历史设计样稿不改写。
- 主站与独立快传门户从本地shared静态目录读取相同主题；后台不加载新主题。shared/base.html仅更新公开CSS缓存版本。
- public-controls.css/js共用无边框图标按钮、媒体回退与约400px后出现的返回顶部。支持键盘焦点、减少动画偏好、窄屏安全区、历史恢复及无IntersectionObserver兼容。
- person-media.html统一教师/学生卡片占位。中文识别常见复姓；英文使用姓名首字母组合；无图、不可见及加载失败均回退。图片完整显示，占位不混入条目复制。首页及详情的组件接入随第二步完成。
- 项目权限复用每次请求解析的有效会话及projects.can_view。未登录、一般用户、仅其他模块权限账号的SQL投影排除principal/amount/members；项目查看授权账号可读取。撤权后下一次分片立即执行新范围，首页同样适用，仍只查询公开项目。动态no-store、筛选白名单与既有媒体鉴权保留。

## 验证

全量初次运行：339项Python通过，1项失败为旧CSS缓存版本断言；128项模拟DOM测试全部通过。将断言更新到本版后，对应首页模块6项全部通过，全部340项Python已有通过记录。新增覆盖身份差异、撤权、SQL投影、首页/列表/分片、头像回退、主题引用、返回顶部和后台隔离。未再次重复全量，以针对性复核关闭唯一失败。

Cloudflare本地准备成功，未部署；打包前核对生成模板/静态资源与源文件一致。Windows/Chrome/Edge真实浏览器视觉验收尚未执行，模拟DOM通过不替代视觉验收。

唯一后端功能变更为backend/app/native/public_data.py中的项目公开读取投影；管理UI、认证、数据库、上传及快传业务代码不变。快传仅portal.html/css接入主题和返回顶部。无新增数据库迁移，0.15.53—0.15.57升级沿用既有数据配置；更早版本仍遵循README迁移说明。未操作用户实际数据，示例导入不会自动运行。
