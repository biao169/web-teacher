# 导航编辑双界面与后台包含筛选 v0.15.92

## 使用

1. 在固定筛选与预览中，选择前台界面或后台界面。一个按钮对应一个目标；后台目标自动选择后台侧栏，切回前台时默认顶部导航，可再改为首页或页脚。
2. 内容列表页面可添加条件：字段、等于/包含、值。文本包含按字面匹配，多个条件同时满足。数值、开关、固定枚举和日期等仍按适用方式精确匹配。
3. 条件修改后自动预览，也可点击预览结果并分页检查；最后统一保存。首页、留言、登录、快传不是条目列表，不提供固定条目预览。
4. 切换目标会清除旧目标条件；重置可恢复进入编辑器时的目标、条件、位置与路径，不影响其他表单文本。

## 复用与兼容

复用 filtering 的条件规范化、字段白名单、参数化 SQL 和包含转义；复用现有预览接口、分页和权限检查。后台 FixedScope 保留完整条件，而字典视图只表示需要预填/锁定的等于条件，避免把包含关键词误作完整字段值。列表、编辑共用固定范围说明模板。

后台固定包含贯通保存/导入、列表、导出、历史建议以及编辑/删除检查。后续搜索条件始终与固定范围取交集。前台仍仅使用公开字段及记录，中文关键词保持 ASCII 编码路径，数据库 schema.sql 与 v0.15.91 完全一致。
