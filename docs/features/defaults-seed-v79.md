# 示例导入、英文默认入口和根目录数据（0.15.79）

## 原因与修复

在隔离空数据库重现基础 seed 函数，9 类内容各 10 条均可成功写入。入口则强制检查网站端口未占用，导致运行中追加被拒绝；此前开发与普通启动使用不同默认目录，也可能导致导入后查看另一个站点仍为空。没有用户本机错误日志，不能断言这就是其本机唯一故障原因。

本轮移除非破坏性基础 seed 的端口阻断，保留重建和其他维护入口的停服要求。基础导入默认开发配置；--profile normal 使用普通配置。默认开发/普通数据库和媒体路径完全一致；显式配置仍优先。新增测试实际监听端口，导入两次，确认不重复且中英文首页立即能查到示例。

根地址 / 重定向 /en；未指定语言的公开登录/注册也默认英文，/zh 保留。

默认运行数据放在项目根目录 data/，数据库 data/database/site.sqlite3、媒体 data/media、缓存 data/cache、快传 data/transfer-data。源内路径校验仅允许专用 data/ 或快传目录，仍禁止写入业务源码目录。Git 和两类发布包排除运行数据。

生产部署数据位于 /opt/teacher-site/data，每个 release 的 data 链接到同一持久目录；快传仍使用 /opt/teacher-site/transfer-data 与 release 根目录链接。初始化、权限、服务可写目录、路径展示、卸载及共享配置生成同步调整。普通源码更新保留数据。无迁移/备份，旧安装地址及已有显式配置不会被静默搬动。

## 使用

默认 Windows：启动 start.cmd 后可直接运行 add-demo-data.cmd，查看 Database 输出，再刷新网页。无需重启；start.cmd 每次重建是原有明确开发规则，若要保留本次内容重启请用 start-existing.cmd。

如 local.cmd 明确指定 TEACHER_DEV_*，开发数据仍使用该配置；如果 start-normal.cmd 明确指定 TEACHER_CONFIG，示例脚本也传 --profile normal。需要新默认时取消对应自定义值。运行数据不随下载的源码包分发。
