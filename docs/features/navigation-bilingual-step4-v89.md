# 双语搜索与动态选项译文（0.15.89）

## 本步实现

新增public_translation.py，复用translation_index的公开来源、有效候选与排序规则，提供SQL有效译文表达式及每批下拉选项标签。Content.listing仅在公开查询包含q时加入译文分支，原后台列表查询保持不变。

搜索执行顺序：公开可见性 AND 服务端固定条件 AND 用户字段条件 AND（原文关键词 OR 人工英文关键词 OR 有效缓存英文关键词）。匹配与计数在LIMIT之前执行，多个字段同时命中也只返回一条记录。搜索是字面子串，ASCII大小写不敏感，百分号、下划线和反斜杠不作为通配符。

SQL中的译文选择遵守本条停用、本条人工/明确复用、无冲突共享、可用本条自动译文的顺序。原生英文维护字段优先。复用只使用中文到英文、纯文本、成功且当前有效的缓存，并核对源字段文本、格式及来源公开状态。Windows/Ubuntu的SQLite连接提供确定性SHA-256函数，额外排除摘要不符缓存。旧D1兼容分支仍核对原文、格式及来源状态，但没有本地SHA函数；本轮未在D1实机验收。

公开译文展示同步排除项目负责人、成员作为共享捐赠来源，避免私密字段译文被复用到其他公开记录。管理员本条私密信息的显示权限维持原样。翻译管理、扫描和手工维护入口仍使用原权限规则。

## 下拉标签

中文页面保留原文。英文页面返回labels映射，values仍为中文原值。模板自动转义；后续选项使用Option文本节点，不将译文当HTML执行。保留已有承担角色英文标签作为无缓存时的后备。

每批最多50个值，按这些值的摘要收窄缓存查询，复用现有摘要索引。固定入口只统计固定范围内的公开记录。已选值超出首批时单独读取标签，读取前检查该值仍属于固定范围。

同一原值在范围内存在不同本条译文时，标签回退原文；不同原值翻译相同不合并选项。组合多值字段只使用精确词条缓存，不能将整段英文译文按位置拆分后强行对应中文词条。

## 复用与未改内容

复用第三步ASCII状态编码、稳定入口、分页、导航版本检查和前台筛选模板；无新SQL初始化文件、数据库表、迁移或备份逻辑。不增加在线翻译请求，不写入搜索索引或缓存，不引入框架依赖。

## 验证

144项Python测试通过：本步34项，以及翻译共享、统一筛选、固定入口和动态筛选回归110项。66项模拟DOM测试通过，包括译文标签、原值保留、同名选项、HTML文本安全、语言/固定范围传递、复制、编码及滚动分页。

独立临时SQLite样例：500条项目、500条缓存，统计500条匹配并返回首批10条耗时约0.16秒；50项下拉读取约0.012秒。这是当前测试环境单次结果，不代表生产响应时限，也未计入浏览器渲染或网络耗时。

测试日志与机器可读结果随包保存在本目录。未进行Windows实机浏览器视觉验收或D1实机验收。搜索不提供机器翻译、自动同义词扩展或未缓存中文文本的英文语义检索。
