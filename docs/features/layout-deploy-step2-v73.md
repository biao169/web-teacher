# 布局与部署整理：第二步（0.15.73）

基于0.15.72，完成项目卡片状态右置与前台私密字段范围收紧。没有部署，没有修改实际数据、SQL结构、后台CRUD或部署脚本。

## 布局和复制

项目共享模板仍用于首页、完整列表和滚动追加片段。正文与状态采用两列布局，状态固定在右侧顶部，长状态可换行；手机仍靠右，标题不会与标签覆盖。没有状态时不生成空列。

正文保留来源/基金计划、标题、编号、主持/参与、周期；获准管理员追加负责人、金额、成员，状态在DOM中位于正文之后。金额仍使用已有万元/英文CNY格式化函数。原生选择复制及多选复制继续使用同一个data-project-text容器：单张卡片一段，多个卡片用段落分隔，部分选中仅复制所选文字；序号/选择框不混入。

## 前台私密字段判定

统一project_private_allowed函数要求当前有效会话解析出的is_system=1，且具备projects.can_view，并且不处于必须修改密码状态。复用既有系统管理员标志，不依赖用户名、角色名称或URL参数。

不符合条件时，public_listing在SELECT字段列表中直接排除principal、amount、members，原始公开数据结果、HTML及分片JSON均没有这些字段。首页和列表复用同一读取函数。匿名、普通账号、可进入其他后台的账号、有项目全部操作权限但非系统管理员的角色均不显示。角色调整、会话撤销及权限撤销在后续请求生效；已经合法读取到浏览器的内容不能远程收回。

项目公开搜索仍只搜索已有公开字段；私密字段筛选、聚合入口仍被拒绝；英文翻译只覆盖本次已允许返回的字段，不补回被移除的私密字段。响应继续no-store。后台原有角色/模块授权与业务操作范围未在本次扩大或重设。
