# 0.15.32：第一步，共享列表恢复与故障隔离

本次只修改共享列表的前端启动、事件生命周期和加载提示。未修改数据库结构、权限判定、翻译共享、媒体字节读取或账号删除规则；未部署到用户正在运行的网站。

## 已确认的问题与证据边界

0.15.31 的列表控制器静态依赖列宽、媒体、翻译等附加模块，且先初始化这些功能再绑定表头。任一依赖加载或初始化失败，都可能阻止整个列表挂载。入口脚本还会禁用包括普通搜索在内的列表按钮，异常路径没有完整恢复。

现有表头的升降序与查询参数处理逻辑并非全部缺失。本次复用该逻辑，调整启动和隔离方式，不为教师、论文、媒体等页面另写一套筛选器。测试中的故障注入已验证隔离行为；尚未取得用户 Windows 环境中最初失败的静态请求和控制台记录，不能断言现场必然由某一个脚本或并发限制触发。

## 修改内容

| 共享位置 | 修改内容 |
| --- | --- |
| `native-table-headers.js` | 无外部依赖的表头入口；复用 `mountTableHeaders`；避免重复挂载，保留筛选、排序和横向滚动恢复。 |
| `native-list.js` | 先绑定核心操作，再按页面实际控件加载列设置、媒体、翻译导出等；单个附加功能失败显示独立提示。 |
| `native.js` | 不再禁用普通搜索；只管理对应功能的按钮；缩小加载范围，顺序启动页面辅助模块，降低突发请求量。 |
| `native-columns.js` | Canvas 不可用时使用原有估算方式；销毁时一并撤销事件监听。 |
| 共享布局及列表模板 | 独立加载表头脚本；增加加载失败与无 JavaScript 提示；Quill 仅在新闻编辑页面加载。 |
| 局部刷新 | 替换前更新规范化 URL；清理旧监听器；继续复用原模板，保留草稿、选择、焦点及列设置。 |

运行依赖及后端业务文件保持不变。Node/jsdom 仅用于可选测试，不是启动网站所需组件。

## 本轮验证

- 25 项真实接口/模板测试通过：18 个模块的完整列表与局部列表、排序筛选、10/20/50/100 每页数量、越界页码、静态脚本 MIME/缓存策略、CSRF/版本冲突以及新闻编辑资源保留。
- 10 项模拟 DOM 测试通过：升/降/升切换、文字/布尔筛选及清除、固定范围保护、Escape/外部点击、列设置/媒体/核心脚本失败、存储与 Canvas 不可用、重复挂载及连续局部刷新，以及写入成功后读取失败时只重试读取。
- 46 个第一方 JavaScript 文件通过语法检查。
- 测试全部使用临时 SQLite 和合成账号；未连接或修改用户业务数据。
- 接口测试有一个依赖库弃用警告，模拟测试有 Node VM Modules 实验性提示；均无测试失败。

当前环境未完成真实 Windows/Edge/Chrome 点击验收，模拟 DOM 不验证实际布局、下载、网络时序或 Windows 启动器。浏览器连接无法打开本地测试地址，因此不能将本次结果表述为生产环境问题全部解决。

## Windows 更新与验收

1. 先备份现有数据与配置，停止本站进程；将新包解压到新文件夹，不覆盖正在运行的目录。
2. 保持 README 中的数据库、媒体和启动器数据路径设置不变；从新目录使用原启动入口。不要运行重置或添加示例脚本。
3. 完整刷新浏览器，依次检查教师、论文、媒体、翻译、用户、角色列表：点击表头文字能打开筛选，连续点击箭头能切换升降序；布尔值“0”也能筛选。
4. 同时设置搜索、多个列筛选及排序，切换每页数量并进行一次允许的快捷开关操作，确认列表更新后条件仍在。
5. 若仍失败，请提供对应页面地址、浏览器控制台首条错误，以及失败静态资源请求的 URL/状态码；不要发送 Cookie、令牌或密码。
