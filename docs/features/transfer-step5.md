# 第五步：文件快传配额和管理（0.15.41）

本版完成本轮五步优化的最后一步，保留前四步账号、媒体、页脚、论文和翻译修改。

## 入口和配置

从主站“文件快传”进入，具备独立快传管理授权的账号可以看到设置和用量卡片。按功能分为访问与分享、全站额度、注册用户默认、匿名共享、用户与角色专属规则；窄屏自动换行，保留清楚的标签与边距。沿用原任务列表、筛选排序、分块上传、暂停/撤销/清理，不增加前端编译依赖。

| 控制项 | 行为 |
| --- | --- |
| 全站每日／每周／每月流量 | 所有身份上传与下载合计，同时受三个周期上限约束 |
| 注册用户默认额度 | 每位用户各有日／周／月额度；身份不随角色变更重置 |
| 用户／角色专属规则 | 可添加、修改、删除，用户优先于角色，角色优先于默认；最多100条 |
| 单个上传文件大小 | 全站和身份限制同时生效；硬上限200MiB，可配置更小或0禁用新上传 |
| 匿名接收 | 显式允许后才能接收有效分享；匿名无法上传、查看管理或其他任务 |
| 匿名共享额度 | 所有匿名接收者共用日／周／月额度和并发上限，不按IP分池 |
| 上传／下载开关 | 对专属规则也有效；上传入口及后续块检查上传开关，下载入口检查下载开关 |
| 分享有效期／次数 | 新任务采用配置；有效期1至168小时，下载次数1至10000 |
| 并发数 | 每身份每方向1至100；匿名保存时同步默认匿名规则 |
| 临时存储上限 | 包含未完成及尚未清理文件的预留，只有真实清理后才释放空间 |

单位采用整数字节，1 MiB = 1,048,576 字节，1 GiB = 1,073,741,824 字节。流量和文件额度留空为不限，0拒绝新授权；存储上限、并发数、有效期、下载次数必须填写正整数。

专属规则填写主站账号的UID或角色ID，不使用昵称。主站与快传可独立部署，因此此处不假装能搜索主站账号，填写前应核对主站记录。空白专属额度表示不限，不继承默认额度，但不能绕过全站总量或文件上限。删除规则在保存后生效，恢复下一层匹配。原有规则的其他扩展字段保留。

“默认注册用户分享”只控制默认身份规则；关闭所有用户的上传或下载请使用总开关。VPN计量仍未实现，VPN保护开启时拒绝传输。本版不增加匿名上传、P2P或VPN出口流量计量。

## 计量与生效时机

仍使用原有 `tool_settings` JSON 与 `transfer_allowances` 账本，不增加数据库表、字段或第二套记账。开始上传或下载时，在同一SQLite/D1事务中检查配置版本、全站及身份日/周/月已用与预留量，再预留全部授权字节；并发请求不能各自绕过剩余额度。

每日零点、每周周一零点、每月一日零点开始，按所选 Asia/Shanghai 或 UTC 结算。使用授权开始时间归属周期，跨日/周/月的旧授权不重复占用新周期。调整配额不撤销已预留授权；结束、撤销、断连或到期只释放未用部分，已传输的字节不退款。上传成功提交后记账，下载发送前记账；下载次数在授权开始时计次，失败重试可能再次消耗次数。

已有下载流不会仅因关闭下载开关立即收回授权；需从任务列表暂停或撤销，下一次分块状态检查生效。已发出的字节无法撤回。

后台“流量使用情况”显示全站及指定用户（UID）或匿名共享池的日/周/月已用及预留、上限和剩余。查询角色额度时同时填写该用户当前角色ID。独立快传不验证UID/角色是否存在于主站，填错会按输入身份查询并展示对应匹配规则，应核对输入。关闭工具时管理员仍可查看用量；普通用户只能读取自己的用量，不可查看全站统计。

用量在打开页面、保存设置或点击刷新时更新；任务列表自动刷新不会覆盖设置草稿。保存期间锁定设置输入；发生版本冲突保留草稿，不自动重试写入。保存继续校验CSRF、来源、独立管理员授权和设置版本，并保留审计。
