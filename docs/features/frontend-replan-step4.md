# 前台重规划第四步：工具栏、筛选与分片交互（0.15.56）

在0.15.55基础上统一八类公开列表的搜索、筛选、排序和选择操作。继续使用原Jinja模板、CSS和原生JavaScript，管理界面、数据库结构、权限与快传功能没有变动。

## 工具栏与下拉

搜索行顺序为关键词、按模块预设的分类、搜索/应用、重置；操作行顺序为全选已加载、选择计数、复制、取消选择、后台顺序升降序、结果数。去掉排序字段和每批数量控件；桌面控件约32px，手机约40px，窄屏自然换行。保留搜索/应用按钮：选择候选后按此按钮统一应用各条件；升降序切换直接提交当前条件。

filter-control.html是所有分类的统一模板。public-filters.js增强已有原生select，select仍持有真实表单值。折叠按钮用当前字体下默认标签的宽度占位；长值只截短按钮显示，完整值放在可访问名称、提示和独立候选面板里，不撑宽搜索行。候选可换行、纵向滚动，面板受当前视口约束，小高度视口使用可容纳的面板位置。

支持方向键、Home/End、Enter/空格选择、字符前缀定位、Esc关闭并返回焦点、Tab进入更多选项或继续表单。每次只展开一个面板；点击外部、焦点离开或提交关闭。候选值以textContent/Option渲染，不插入未经转义HTML。无JavaScript时保留原生下拉和GET表单；原生回退包含首批及当前值，更多候选仍需要JavaScript读取。

## 按模块筛选

| 模块 | 分类来源 |
| --- | --- |
| 教师 | 职称、单位 |
| 学生 | 学生分类属性、学位、年级、状态、研究方向；显示分组仍按后台启用的学生分类规则 |
| 论文 | 论文类型、年份、收录类型、具体期刊/会议名称 |
| 项目 | 来源、基金计划、状态、承担角色 |
| 专利软著 | 类型、法律状态、国家/地区、申请年份、授权年份 |
| 课程 | 学期、授课对象 |
| 新闻 | 分类、发布年份 |
| 研究方向 | 关键词，不添加虚构分类 |

候选从全部允许公开的记录统计，不随当前分页、关键词或其他选项缩减；无值分类隐藏，当前已选项即使不在首批或筛选后为空也保留。每次最多返回50个候选，更多选项分页读取，不把整批记录正文传给浏览器。英文界面使用英文控件名，候选保持原始字段值，保证与SQL筛选一致，不临时机翻后拿译文当筛选键。

多值字段复用现有suggestions.MULTIVALUE目录和分号、中文分号、CR/LF分隔规则。SQL中去除首尾空格/制表符并按完整词匹配，SCI不会匹配ESCI；引号、反斜杠、%、_作为普通文字处理。候选按SQLite NOCASE去重，原完整组合值的旧链接仍能精确匹配。这里不新增Unicode宽窄字转换或模糊匹配规则。

申请/授权/发布年份直接由原业务日期聚合，没有冗余年份字段或迁移；隐藏条目、未启用教师、未来新闻继续服从原公开范围，不能贡献候选或返回内容。

## 后台排序与兼容

所有普通列表公开查询固定为后台sort_order；旧链接传入name、created_at、year等字段也会规范为后台顺序，后续分页URL使用规范值。升降序同时调整同值记录的稳定ID顺序。

学生固定先按后台学生分类规则排序，升降序仅影响组内sort_order及ID，不反转分类本身。教师序号仍从1开始，其余模块按当前结果总数倒序编号；序号与数据排序是两回事。

正常请求仍为10条/批；服务端保留旧size链接兼容和20条上限，旧50/100链接按20处理。界面没有每批数量选择，提交新筛选回到默认10条和第一页。

## 请求与选择状态

复用原有单请求滚动队列、UID去重、普通分页、失败重试和节省流量模式。提交搜索、重置、切换排序或普通分页前，通知队列暂停并取消当前分片/候选/简介请求；迟到响应不能再追加旧内容，勾选清空。只在候选面板内选择、尚未提交时不重置列表。

自动滚动追加保留已有勾选，新记录默认不勾选；结果总数随最新分片更新，已选/已加载计数仍依据当前DOM。复制继续使用第三步的已加载内容，不读取额外详情。常规offset分页不是快照：后台并发编辑时仍可能需要刷新，但重复UID不会重复插入。

## 改动边界与验证

服务端只调整public_data.py的公开排序、候选聚合和公开筛选谓词，并将content.py中的public=True筛选分支交给该谓词。管理查询仍使用原有字段白名单与整字段等值匹配，所有管理写入、权限、数据库、上传和快传实现保持不变。与0.15.55相比，上述两文件之外，受保护范围507个既有文件逐字节一致。

测试涵盖八模块旧排序兼容/分片稳定性、多值精确匹配/特殊字符、全公开范围/候选分页、日期年份及权限、无脚本回退、长文本/窄视口模拟、键盘焦点、失败重试、切换排序取消迟到响应、追加选择与总数更新。真实浏览器像素、触控及Windows实机效果尚未验收；模拟DOM几何检查不能替代真实排版测试。
