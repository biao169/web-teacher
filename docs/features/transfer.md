# 独立文件快传

使用原始12张表70个字段，SQLite/D1共用业务层。temporary_shares保存任务，recovery_tasks保存续传和清理检查点，transfer_allowances保存流量授权；正文使用不超过1MiB的对象分块，单文件上限200MiB。主站和快传可部署于不同服务器或Worker，数据库、缓存及文件目录/R2绑定与前缀独立配置。

服务通过教师站POST提交的签名短时票据建立自己的五分钟会话，消耗一次性nonce。管理权限每次从admin_grants复核，普通用户只能查看自己的任务。任务链接只保存摘要，下载受身份规则、次数和期限限制。会话失效后通过“刷新登录”重新进入；未完成上传重新选择原文件，校验已传前缀后继续。

## 最近任务与全范围控制

按创建时间倒序，默认每批20条，可选50或100条。100仅是每批上限，任务总数没有100条限制；筛选、上一批、下一批、跳转和最近一批覆盖全部任务记录。文件名、任务编号、状态可组合筛选。普通GET表单支持无JavaScript分页。

管理员可逐条、当前批次所选、全部匹配任务暂停、恢复、撤销、停止并清理。全部匹配操作先固定创建时间边界，按任务编号分批执行，每次复核当前筛选及可操作状态；只纳入启动操作时已经创建的任务。每请求至多控制10条或推进一个任务的8个文件块，不将全部任务载入内存。所选任务校验状态与updated_at；不自动重试失败或结果未知的写入，已完成结果保留。批次游标绑定账号、用途、短时有效期，并且只能消费一次。

每10秒只刷新任务区域；选中任务、编辑筛选或焦点处于列表时暂停自动刷新，上传控件及设置草稿不会被替换。手动刷新可重新选择任务。列表显示已上传字节、下载次数、下载租约以及创建和任务最近活动时间（UTC）；“下载租约”是尚未结束的授权数，并非网络连接探测结果。服务异常中断时租约到期后释放。

暂停/撤销/清理在下一次分块状态检查生效；下载限速等待期间也会检查。不能收回已发送的字节。恢复上传需要原文件；已中断的HTTP下载需要重新请求，开始一次下载就消耗一次下载次数。暂停保留未用上传额度，撤销或到期释放未用额度。

## 缓存文件与清理

“停止并清理”先持久撤销任务和释放未用额度，然后分批删除已登记分块。清理租约防止并发清理覆盖进度；失败保存已删除位置并显示“清理失败”，再次操作继续。完成后保留“文件已清理”的历史任务，不再占用存储额度，分享链接失效。存储预留一直计入容量，直到文件清理完成；撤销本身不会假装文件已经腾出空间。

缓存界面分别扫描临时文件目录、辅助缓存目录和“删除待重试”。按配置根目录/R2前缀每批读取至多20个目录条目；文件路径、实际大小和任务引用可见。目录扫描可以继续到末尾；目录变化可能改变扫描位置，删除后从第一批重新扫描。历史清理失败意图也可分页查看。

属于尚未清理任务的文件禁止单独删除，应从任务列表停止并清理。孤立文件和辅助缓存文件可逐个或勾选当前批次删除，删除前确认。签名预检绑定操作人、路径和对象版本；更改或替换后的文件需要重新扫描。删除意图存入原生service_meta，失败后可重试；成功后清除意图。拒绝目录、符号链接、Windows联接点、父路径及配置范围外文件，不递归删除任意目录。

本地文件和R2都在删除前复核版本；这是应用级复核，不承诺阻止外部程序在复核后瞬间替换文件。因此共享目录不应允许其他应用覆盖快传对象键。上传中已写入但尚未确认的孤立分块可在任务终止并完成清理后通过目录扫描发现。

## 日/周/月流量额度

上传和下载共用当前身份的额度，用户不因角色变化获得新身份池；匿名接收使用共享池。用户专属、角色、注册/匿名默认规则依次优先。后台可配置注册用户每日/每周/每月默认额度、匿名共享额度、临时文件总存储上限和结算时区。空值不限，0拒绝新授权；支持Asia/Shanghai与UTC。0.15.41新增全站总额度、单文件大小、用户/角色专属规则编辑器及管理员用量查询，详见[第五步说明](transfer-step5.md)。

开始上传或下载时，数据库事务检查日/周/月额度及设置版本并预留本次字节；有效下载授权同时受身份并发限制，匿名取身份规则与共享并发上限中的较小值。上传以成功提交的分块记账，下载在发出分块前记账；与任务状态/检查点同事务，重复提交和并发竞争不能重复成功。取消、清理、断连或租约到期只释放尚未使用的额度，已传部分不退款。下载是服务器已授权发送量，不是接收端落盘确认。显示用量包含已用与预留。

按授权时间归属日/周/月周期，跨日继续完成原授权，不在新周期重复占用；调整流量与大小额度只影响后续授权；身份准入与上传下载开关在各请求入口检查，已有下载流需要从任务列表暂停或撤销。旧版未完成任务在首次继续上传时为剩余字节创建授权，不伪造更新前的历史流量。旧版已完成分享仍按新的下载授权记账。

工具启用、注册用户临时分享、匿名接收及VPN保护可在后台控制。VPN实际计量、P2P传输、文件夹上传及完整原版工具设置尚未实现；启用VPN保护仍拒绝传输。默认设置禁用服务和临时分享。


## 示例任务与缓存

管理员可在“示例任务”区明确生成可下载、暂停、撤销的小文本任务，以及一份真实辅助缓存。使用原有上传、控制、权限及额度服务，不调整当前设置；设置未保存草稿保留。重复点击保留已存在状态，清理后不会再自动补回；失败后的已提交部分在原有任务/缓存列表核对。示例不是系统自动产生的真实用户历史。详见[成套示例中心](examples.md)。
