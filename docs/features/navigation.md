# 后台导航与固定筛选

“导航与按钮”使用原生navigation_items记录。名称、图标、路径、展示位置、可见性、启用状态及排序在同一编辑表单维护；“固定筛选与预览”区加入统一顶部目录。后台侧栏保留19个基础入口，并按导航配置及角色权限追加自定义入口。

## 选项与外观

类型、位置、图标和样式使用集中注册的中文下拉项，选择后说明同步显示在控件下方，也提供悬停提示。已有未知值作为“当前自定义值”回显，修改其他字段不会清空它；不将未知图标或样式作为可执行内容。

| 配置 | 当前行为 |
| --- | --- |
| 类型 | 站内页面、外链、锚点、按钮链接；最终跳转仍由路径决定 |
| 后台侧栏 | 支持八类内容模块、固定范围、权限校验和ASCII入口 |
| 前台顶部 | 公开且启用的站内链接展示于顶部 |
| 首页主区域、页脚 | 当前仍合并到前台顶部，尚无独立落点 |
| 外链 | 可以保存；当前访客模板不展示外部地址 |
| 图标 | 文件、人物、书籍、搜索复用现有图标；实际用于后台侧栏 |
| 样式 | 普通、强调、描边实际用于后台侧栏；当前项保持统一高亮 |

前台界面下拉提供首页、内容模块、联系、登录和快传入口；后台界面下拉提供内容模块。两者互斥选择，并同步显示位置，复用同一条件编辑器与只读预览。

锚点名可显式应用到站内路径，例如main生成/zh#main。工具要求1–200个非空白字符，不含#、/、?；中文锚点写入路径时编码，目标页面仍需存在该区域。单独保存fragment不会改变实际跳转。切换类型时保留已填写锚点，不自动清空其他草稿。

图标和样式在工具区提供外观示意，保存后侧栏使用同一白名单。前台仍使用中文导航文本，不区分图标/样式；本功能不改变前台布局。

## 条件编辑

选择教师与团队、学生、研究方向、项目、论文、专利软著、课程或新闻作为目标模块，可以添加最多12个等于或文本包含条件。所有条件必须同时满足，同一字段不能重复。可删除任意条件，也可保留零个条件以显示目标模块中当前账号有权查看的全部记录。

条件字段来自原生结构白名单，按模块常用摘要字段优先排列。枚举和开关采用选择框，其他值采用文本输入。每个值为1—500个字符，不允许空条件或控制字符。整数条件规范为十进制整数，开关只允许0或1；文本条件为精确相等，不支持包含、范围或OR表达式。需要追加包含搜索时，在保存后的列表入口搜索或使用表头筛选。

选择目标会将草稿位置设为admin-sidebar、类型设为route；入口标识为空时生成ASCII标识。标题、可见性和启用状态仍由用户填写，选择目标不会自动发布或启用入口。

已有后台导航打开后回显模块、字段和值。手工修改路径时，服务器严格解析并同步可视化条件；无效路径原文保留，显示修正提示，不会用旧条件静默覆盖。“重置筛选草稿”恢复打开页面时的目标、条件、路径、位置、标识和类型，保留标题等其他输入。

## 路径与入口

固定条件保存在path，例如`/admin/publications?f.year=2026`。中文及特殊字符通过URL编码保存，编码后的路径最多16384个字符。后台路径只允许受支持的模块与`f.字段=值`参数；外部来源、路径锚点、重复字段、未知参数、无效百分号编码都被拒绝。锚点字段及普通前台/外部链接不使用此后台生成器。

侧栏实际入口使用`/admin/n/ASCII标识`，中文固定值不显示在浏览器入口地址栏。标识为1—80位小写字母、数字、下划线或短横线，并在保存事务中检查唯一性。从`/admin/模块?nav=标识`访问列表时规范跳转到上述入口；错误模块和相冲突的导航上下文被拒绝。

入口高亮和顶部面包屑使用当前自定义导航，编辑后“保存并返回”回到同一固定范围。普通模块入口继续按照模块权限显示其授权数据；固定导航用于保存列表范围，不是额外授予或收回数据权限的机制。

## 只读预览

修改条件后约450毫秒自动预览，也可点击“预览结果”。中文输入法组词期间等待输入完成。预览复用真实列表的可见性、固定条件和分页查询，只返回当前页所需的摘要字段，每个文本单元格最多500个字符，不返回完整正文或联系方式。

预览支持10、20、50、100条每页，显示总数和页码。短分页显示全部页码，大量页码显示首末页和当前页附近按钮。没有命中时显示空结果。名单为只读，不提供绕过草稿上下文的编辑操作。

预览通过POST提交，不保存导航或业务记录，不写业务操作日志；会话活动时间仍正常更新。旧请求被取消或作废，只有对应当前草稿的响应可以更新结果。请求失败保留输入，允许修改条件后重试。普通链接位置不会启用后台筛选预览。

能编辑导航配置不代表能查看目标模块的数据。服务器分别检查导航创建/编辑权限与目标模块查看权限；缺少目标权限时仍可回显和修正已授权的导航配置，但预览返回拒绝。使用已启用导航不要求具备导航管理权限，仍要求目标模块及导航本身可见。

## 固定范围保护

| 操作 | 行为 |
| --- | --- |
| 搜索、表头筛选、排序、分页 | 可见性范围AND固定条件AND追加条件；清除搜索只移除追加条件。固定列的筛选输入与清除按钮锁定，仍可排序。 |
| 列表快捷开关 | 被固定的开关字段不显示快捷修改按钮；服务端也检查保存前后范围。 |
| 打开编辑、删除 | 条目必须已在当前固定范围内，不能通过修改UID处理范围外条目。 |
| 保存 | 保存前后的条目都必须满足固定条件，不能把范围外条目“搬入”或将范围内条目移出。 |
| 新增 | 自动填入可编辑的固定值，0开关保持关闭；包含ID等系统字段的范围不提供新增入口。 |
| 导出 | 保留固定与追加条件；交付响应前复核导航版本和启用状态。原有单次条数和体积限制仍适用。 |

编辑表单与列表快捷操作携带导航updated_at。导航设置变化后，旧页面不能继续提交，需重新打开入口；保存冲突保留当前草稿。条目写事务再次检查导航版本、启用状态、展示位置及原有会话/条目版本，防止检查后规则改变仍执行旧操作。禁用或删除导航后，该入口不再可用。

## 布局与资源

工具区、条件行和预览复用Bootstrap控件、共享分页及后台主题。手机上控件换行，名单在自身容器横向滚动，底部保存栏仍固定。颜色、字体和字号由admin-theme.css控制，布局在admin.css。

不增加数据库字段、运行库、后台进程或前端编译。数据库负责筛选、计数和分页；应用只读取当前页预览摘要，查询耗时仍随数据量和条件而变化。数据库、缓存、媒体配置及访客前台保持既有行为。


## v0.15.92 双界面编辑

“常用页面”改为“前台界面”，“目标模块”改为“后台界面”。直接选前台或后台目标，不再要求先去修改显示位置。两者复用同一个固定条件草稿与预览区域，切换目标清空旧条件；手动修改显示位置仍保留条件并重新校验字段范围。

后台 `f.字段` 保持精确相等语义，新增 `c.字段` 为字面包含匹配；百分号、下划线及反斜线不作为通配符。后台保存、数据恢复、列表、分页、导出、历史建议、编辑和删除均使用同一固定条件。包含条件不作为字段默认值或只读锁定值，但保存后的完整字段仍须满足条件。

前台公开字段白名单、权限校验与 ASCII 入口保持原有规则。此次未修改 schema.sql，也不需要重建数据库。
