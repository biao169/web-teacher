# 前台逐项优化第二步：0.15.59

基于0.15.58；完成首页与教师列表/详情的模板与样式改造。

## 首页与教师

首页教师左卡含头像/姓氏占位、姓名、职称/头衔、团队角色、单位、实验室/团队和简介；右卡含允许公开的办公室、邮箱、电话和学术社交链接。桌面3:2布局且顶部/底部对齐，850px以下单列，不设固定内容高度。右卡无任何可显示信息时自动取消，避免空白卡片；无首页教师时保留站点标题、副标题。

首页教师姓名可点击详情；删除原硬编码“教师详情”按钮，下方只渲染后台已配置、启用且当前身份可见的hero导航项。没有配置时没有按钮区域。

列表按姓名、职称/团队角色、单位/团队、联系方式、平台链接、简介的阅读顺序显示。简介沿用两行和原折叠行为；详情按钮改为既有Bootstrap Icons外链图标、无边框样式，与简介折叠按钮处于卡片右侧，不新增独占一行。教师/学生头像回退复用上一步组件，首页与教师详情也接入；中文常见复姓、英文首字母组合、头像加载失败回退均保留。

教师详情顶部共用双卡，正文依次为个人简介、教育经历、工作经历、招生信息；空区隐藏，教育/工作宽屏并列，手机单列。复制仍使用原公共复制控制器及data-copy-field，不复制装饰头像和操作按钮。

## 学术链接与数值

ORCID、Google Scholar、DBLP、GitHub、CNKI使用官网下载的原始图标，随包本地提供；来源记录见frontend/public/static/vendor/brand-icons/sources.json及README.md，不进行调色或裁剪。个人主页使用既有通用链接图标。平台名与实际URL/编号同时显示，长链接允许换行；ORCID编号按既有格式规则构建https://orcid.org/链接，不改存值。

后台“显示数值”是各平台可选手填整数，不代表自动统计的点击/被引/论文数。前台不再渲染这些没有明确指标名的裸数字，后台字段和现有数据保持原样；仅有数值没有链接时不显示空平台行。

## 维护与范围

新增faculty.css只维护布局并引用主题变量；所有新增字体、字号和配色参数仍在frontend/shared/static/css/public-theme.css。首页/列表/详情共用person-identity、person-connections、person-links、person-overview及person-media模板，没有复制三套字段规则。

本步backend、database、frontend/admin、transfer、deploy和shared/templates与0.15.58逐文件一致。服务端已提供全部所需字段；沿用contact_visibility，仅public联系方式可展示，其他范围不因登录而额外公开。没有迁移、后台配置变更或自动示例导入，没有部署或操作用户实际数据。0.15.53及以后升级无需新增迁移；更早版本遵循README。
