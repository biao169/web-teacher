# 固定导航完整操作链联调（0.15.90）

## 找到并修复的问题

1. 详情返回列表此前主要依赖前端脚本添加from；服务器模板没有保留筛选。改为服务器生成可直接使用的详情链接和返回链接。
2. 详情切换语言只修改外层路径，内层from仍是旧语言，导致返回校验拒绝并丢失筛选。服务器现在同时转换内层列表语言，前端尊重已规范的语言链接。
3. 详情页登录next此前指向列表。现在指向当前详情，并带安全返回上下文。
4. 分片此前核对模块、语言、页码和固定入口版本，但未核对临时搜索状态。现在为规范查询增加query_id，浏览器同时校验响应及后续链接中的查询，拒绝将不同条件的记录追加到当前列表。

## 复用与规则

复用public_navigation的条件校验与ASCII编码；新增list_return及query_identity小函数。沿用详情、列表、语言导航模板和public-people/public-stream控制器，没有新表、SQL初始化文件或前端框架。

返回地址只接受本站相对路径、相同模块或相同固定入口，允许将该路径的中英文前缀转换为当前语言。外部地址、其他入口、非法筛选或过期固定版本回退本入口。嵌套from不递归处理。查询标识用于响应一致性，不是权限令牌；固定条件仍每次从后台读取。

第一页及普通下一页保留各自页码。详情链接由分片所属页生成，返回时可重新打开该页；浏览器后退是否恢复所有已追加DOM和滚动位置由浏览器页面缓存决定，本版不另行保存整个列表。

## 联调结论

- 固定范围与临时搜索/字段筛选取交集；重置只移除临时条件。
- 语言切换保留固定入口、编码条件及排序；详情来回同样成立，无脚本也可使用。
- 升降序、筛选和重置属于新查询，清空当前勾选；切换引用格式保留勾选与显示格式。
- 追加加载不清除原勾选，新条目保持未选；复制按当前已选条目及指定格式执行。
- 简介、引文、候选项继续携带入口和版本；停用或修改入口后的旧请求被拒绝。
- 新闻仍在新标签打开详情，PDF与附件权限、水印路径沿用原逻辑。
