# 账号、角色与权限

账号管理与角色权限共用后台列表、分区表单、顶部目录和固定保存栏。基础侧栏仍为19个入口，账号入口内可切换“用户管理”“角色与权限”；只有角色查看权限时，入口直接进入角色列表。标准功能入口保留，未授权入口显示锁标识并可点击查看提示；自定义导航仍按启用状态、可见范围和目标权限隐藏。操作按钮按实际授权显示。

## 列表与账号编辑

用户列表展示用户名、显示名称、邮箱、角色名称、账号状态、要求修改密码、记录可见性、最近登录和更新时间。角色列表展示名称、等级、描述、可见范围、系统标识、启用状态、可查看的成员数和授权概览。成员计数仅包括当前用户有权查看的账号，不泄露受限记录。

列表沿用表头位置筛选/排序、拖动列宽、列显示设置、多选、分页及左右固定列；操作列按实际按钮自适应。角色、账号状态和可见范围用中文显示，筛选仍提交数据库原值；范围采用JSON值的包含查询。时间使用后台统一时区和易读格式，状态有图标和文字，不只靠颜色辨认。

新建用户默认已启用并要求首次修改密码；角色必须明确选择，候选只提供启用角色，系统管理员角色带文字提示。已有禁用账号不会因查看或更新版本而自动启用。

账号编辑在一页内划分账号资料、角色与状态、密码区块，已有账号另有登录会话区。桌面短字段三列排列，较窄屏幕两列，手机一列。新账号要求初始密码与确认密码相同，界面默认勾选首次修改密码。现有账号的密码留空时保持原密码；密码及摘要不回显、不写入浏览器持久存储或操作日志。

设定新密码、更换角色或改变账号状态时，服务端撤销该用户已有会话。管理员重置自身密码后返回登录页，要求自身修改密码时进入账户安全页，避免保存成功后跳到失效会话保护的页面。不能停用当前账号或移除自身管理角色。

## 角色与权限矩阵

角色资料、可查看记录范围、启用状态和模块权限位于同一表单。范围以中文复选项配置，保存为原生visibility_scopes JSON数组；空选表示没有相应记录范围。等级是角色属性，实际请求仍分别验证模块操作、记录范围和账号/角色状态。

权限矩阵按教学与科研、内容资源、网站配置、管理与工具分组，覆盖20个授权模块的允许进入、新增、编辑、删除和导出，复用已有auth_permissions字段。“允许进入”映射can_view，是本模块其他操作的前提。可组合功能分类与中文模块名/模块标识筛选、按行或按列勾选、全选或清除当前显示模块；这些操作仅改变页面草稿，统一保存后生效。过滤隐藏的模块仍参与提交，保持原先选择。

“撤销修改”撤销最近一次批量勾选或关闭入口中未被随后手工修改的项目，不覆盖之后的手工修改。关闭入口同时清除该行其他操作；批量授予操作会同时开启入口。待保存摘要逐项列出新增和撤销的授权，筛选时也保留全部变更。行列复选框显示未选、部分选中、全选三种状态；可进入模块数和授权项数实时更新。矩阵内部滚动、固定表头与模块列，页面目录及保存栏保持可达。

系统角色的已保存权限只读展示，启用开关锁定；服务端同时拒绝伪造停用或权限替换请求。自定义角色可编辑矩阵。账号和授权的写入仍仅系统管理员可用，即使普通角色获授相关模块编辑动作，也不能绕过此限制。

## 保存与资源边界

统一表单校验会话、来源、CSRF、模块权限、范围和updated_at版本，角色资料、权限替换与审计在同一事务内完成。过期保存不覆盖其他人的修改。服务端校验或网络失败时，当前输入、权限选择和矩阵筛选保留在页面中，解锁后可核对重试；刷新或关闭页面不会自动恢复草稿。

列表只对当前页派生授权数和成员数，标识分批最多40项；角色名候选读取最近100项并补齐当前页已有角色。编辑器继续使用共享有界关联选择。权限矩阵固定20模块100项，不增加后台进程、运行依赖或数据库字段。

后台字体、字号与语义色由admin-theme.css集中控制。admin.css仅负责布局及引用主题变量；外层工作区禁止程序性滚动，仅内容区、导航区和矩阵内部滚动，避免锚点跳转挤走固定栏。

本功能使用原生账户表，不创建额外用户体系。登录会话区可查询活动/过期/撤销历史并进行单条、所选或全部其他活动会话撤销，账号草稿保持不变；详见[账号登录会话](account-sessions.md)。界面不提供原生表中不存在的设备名称或IP信息。

## 受限导航与即时权限

点击带锁的标准入口时弹出“权限不足”，说明功能名称，保留当前表单和地址。鼠标与键盘Enter操作一致；Escape或“知道了”关闭后恢复焦点。弹窗可短暂轻抖，系统设置减少动态效果时不播放动画；手机抽屉中的操作也不丢失草稿。无JavaScript时普通链接交由服务端显示受限页面。

异步编辑保存、列表操作及辅助请求通过同一请求封装处理401/403，不自动重放写入。权限不足、会话过期、必须修改密码、页面验证过期分别显示原因；过期登录可在新标签打开登录页，保留本页输入。直接访问受限地址仍返回HTTP 403；伪造接口或撤销后的旧页面均由服务端拒绝。

每次请求重新读取当前角色；关闭“允许进入”后，即使旧数据中还保留某项操作位，也不能执行操作。写入事务再次检查入口权限及角色/账号版本；提交缺少入口的操作组合会被拒绝，不隐式改写旧角色。

已授权编辑的模块不会因为关联模块不可进入而整页失败：相关选择项只读、不读取受限标题、不提交覆盖值，其余资料可以保存。服务端同时拒绝伪造关联修改，包括清空。更改账号/角色仍仅系统管理员可执行，系统角色保护与记录可见范围规则保持。

## 删除账号与角色（0.15.37更新）

单条删除、删除所选、确认、冲突提示和列表刷新沿用共享列表。只有系统管理员且具有对应模块进入、删除权限时可操作，记录范围和导航固定筛选仍生效。受保护记录显示锁标识，悬停可查看原因；服务端同步验证，不能通过伪造请求绕过。

允许删除普通账号；当前登录账号、初始化账号及最后一个可用系统管理员不可删除。0.15.37起，其他系统管理员账号可以由具备删除权限的系统管理员删除，提交时再次检查剩余可用管理员。允许删除未被任何账号使用的自定义角色；系统角色、注册默认角色不可删除。角色关联检查包括隐藏、锁定、禁用账号，不因列表筛选而忽略。

每个删除事务同时复核当前权限、会话、记录版本及保护条件。账号删除级联清除主站登录会话，角色删除同时清理auth_permissions，审计写入与删除同成同败；历史审计保留。批量操作逐条提交，首次失败停止，已成功项目不撤回，并显示成功、失败、未处理数量。

不删除独立快传任务和业务内容。快传已签发的60秒桥接票据、300秒短时会话仍按原有效期失效；账号删除会阻止主站签发新票据，但不提供跨服务即时撤销。详见[第四步交付说明](accounts-step4.md)。
