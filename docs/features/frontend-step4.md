## 已交付

论文、项目、专利软著、新闻、课程、研究方向：一行一卡、紧凑信息、序号、搜索、已有公开字段精确筛选、排序、10/20条分批、选择复制、完整公开文字详情。工具行、选中计数、复制回退、返回原检索URL及追加事件复用人员组件；前台模板配置统一定义字段，不新增六套独立交互。

- 论文：详情提供作者、期刊会议、年份卷期页码、通讯作者、DOI、原文及允许公开PDF；沿用既有authorMarkers纯函数显示通讯作者*及加粗，不改写原始作者和引文。标签不参与选中/批量复制。基本信息复制无需附加请求；按GB/T、Elsevier、APA、IEEE、BibTeX复制时，串行读取已选论文的现有公开详情，不抓未选记录、不下载所有页面。若引文缺失、权限变化或读取失败，整批提示未复制，不静默缺条、不编造引文。详情也可单独复制每种已存引文。
- 项目：强调来源及基金/计划，展示负责人、角色、编号、周期、状态；详情增加成员，简介和经费均不展示。
- 专利软著：详情展示类型、国家、发明人/作者、申请/授权号与日期、权利人、状态及说明。
- 新闻：标题及详情链接均新标签打开，封面在卡片中contain居中、透明无边框；详情复用已净化富文本与PDF阅读器，保留编辑器尺寸/对齐。正文复制保留段落和换行，不复制阅读器操作按钮。
- 课程、研究方向：卡片摘要最多2行，详情显示完整说明及现有参考资料。

原首页模块与人物分组保持现有行为，普通分页作为滚动读取失败/无脚本的回退。新闻外的详情在当前标签打开并可返回原筛选、页码。
