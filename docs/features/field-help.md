# 后台字段功能与填写说明

所有原生编辑字段共用服务端字段描述和Jinja控件。说明显示在输入项下方，包含用途、填写格式、单位、必填或可选、留空行为及有效范围；通过aria-describedby关联输入。业务含义按模块维护，类型、数字范围、原生默认值等读取真实校验描述，不将历史文档中的目标能力当成已实现功能。

普通字段无JavaScript也能显示说明。动态固定筛选、论文候选核对、媒体搜索/上传和裁剪等辅助控件使用同一说明组件；只观察编辑和辅助区块，控件不会重复绑定。说明使用文本输出，未知导航值也不作为HTML或任意CSS执行。

## 覆盖范围

| 范围 | 说明内容 |
| --- | --- |
| 教师、学生、研究方向、项目、论文、专利、课程、动态 | 名称、自由经历文本、社交链接、原生关联、附件、可见范围、时间和生成引文保护 |
| 学生分类与导航 | 匹配规则、AND条件、精确相等、输入限制、预览与保存的区别 |
| 网站与全局设置 | 当前生效条件、默认值、上传单位、回收期限、缓存和服务执行边界 |
| 账号与角色 | 密码及确认、角色范围、空范围、模块权限矩阵、隐藏选择的保留 |
| 服务密钥及论文服务 | 留空保留密钥、不回显原值、启用顺序及默认服务要求 |
| 媒体与编辑辅助 | 选择、上传、标题、分类、正文说明、裁剪坐标、比例、缩放及输出 |
| 翻译和留言 | 人工译文的来源关联、留言处理标记与实际发送行为的区别 |

密码使用6–128个字符、UTF-8最多512字节；已有账号编辑时密码留空不变。翻译密钥最多4096个不含空白的ASCII字符，其他保留服务密钥最多8192字符；留空不改，原值不写入表单。权限范围可全部取消，保存为空范围，不自动补回公开范围。

## 按实际实现解释设置

- 全局服务读取最早创建的配置；新增第二条不会自动切换。网站设置使用最早创建的启用记录。
- 媒体单文件限制按MiB计算，实际上传仍受20MiB硬上限约束。回收期限0表示立即到期，仍须清理预检与确认。
- 论文元数据缓存设置0关闭；与历史输入建议无关。默认查询仅访问指定服务，选择回退才按配置顺序尝试。
- 五家翻译服务共用预设与显式测试，总等待设置已参与执行；每批条数控制下一批1–50条，配置并发是上限，低资源调度实际串行执行。Google、DeepL、Microsoft及官方托管LibreTranslate需要真实凭据。专利联网查询、邮件通知也尚未接入。
- Logo、favicon、社交分享图和SEO配置目前未接入对应访客展示。页脚按纯文本显示，不执行HTML。
- 首页论文/动态从最多10条候选中取值，数量0使用3条回退值。研究方向没有精选字段，首页按公开内容查询。
- 新闻发布时间为空不发布，未来时间到达后才可公开。项目简介仅供内部保存，不传给访客页面。

这些说明描述当前行为，不替代服务端授权或校验。字体、字号、行高和颜色集中于admin-theme.css，布局复用admin.css；手机自动换行，下方说明无需鼠标悬停即可阅读。
