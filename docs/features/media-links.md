# 媒体链接与统一媒体控件

教师/学生头像、网站三种图片、新闻封面、论文PDF、专利证书、课程大纲/资料和留言附件，共11个原生字段使用同一控件：媒体链接输入、选择/上传、适用图片编辑、清空及完整等比预览。新闻正文的图片和PDF也使用同一选择器。

## 输入、选择与保存

| 输入来源 | 行为 |
| --- | --- |
| 本站 `/media/媒体UID` 或同一站点的完整链接 | 复用现有记录，不重复登记；不能附带查询参数或锚点。后台私有预览链接也可解析 |
| 媒体库 | 搜索全部适用的活跃媒体，按10/20条分页；选中后显示链接及预览 |
| 本地上传 | 复用上传限额、签名、类型、配额和存储服务；成功后保留在媒体库 |
| HTTP/HTTPS外链 | 选择适用类型，按原生external存储类型登记；文件仍留在来源网站 |
| 清空 | 只清除此字段的引用草稿；保存后生效，媒体记录和文件不自动删除 |

输入框是用户交互入口；数据库字段仍保存media_assets.object_key，不改为UID、不新建兼容表。后台内部原生键与可见链接由统一方法同步，不需要用户手工查找对象键。已有不可用关联保持可见，并提示检查或重新选择。

输入链接及“预览链接”只检查格式并显示草稿，不写入媒体库。整表保存时，新外链登记、业务引用及操作日志处于同一个事务；字段校验、权限、导航范围、版本或数据库约束失败时一起回滚。

选择器“登记并选择”是明确的独立登记动作。登记后还需确认使用并保存内容；取消选择不会删除已经登记或上传的媒体。相同规范链接复用同一条记录，不修改共享记录的URL或类型。修改某个字段中的外链会选择/创建另一条媒体记录，其他使用位置不变。

## 外链类型与可用性

外链支持PNG、JPEG、GIF、WebP图片、PDF、MP4/WebM视频和ZIP，实际可选范围由当前字段决定。类型由用户声明；文件名扩展名仅帮助选择，不代表内容已验证。无扩展名链接需手工选择类型。本站已登记文件使用其原有类型，不能把已有PDF改选成头像。

图片/视频由浏览器实际加载并完整等比显示，短边留白。失效、格式不符、混合内容限制或网络拒绝时提供提示并保留草稿。PDF可尝试浏览器预览，外链框架使用sandbox隔离；来源禁止嵌入或浏览器无法显示时使用“打开文件”。ZIP只提供文件入口。

服务器不下载、代理、嗅探或缓存外部正文，也不验证远程DNS、重定向或文件大小。地址检查拒绝危险协议、账号密码、控制字符、无效转义、本机/内网及保留IP、内部主机名和非标准端口；普通域名的最终解析仍由浏览器及来源网站决定。

域名按IDNA处理，中文路径编码；保留已有转义字节、查询顺序、重复参数、大小写敏感令牌及锚点，避免破坏签名链接。最长4096字符，以编码后的长度再检查。应用查询带签名的关联键时使用POST请求体，不将其放入查找接口的查询参数；业务日志只记操作，不序列化链接正文。

## 权限、引用和回收

选择、解析及登记同时检查媒体查看权限、目标内容创建/编辑权限及固定导航范围。新增登记还需媒体新增权限；只具查看权限时可复用已登记资源。选择确认核对原生更新时间、活跃状态及类型。整表提交在事务中再次核对已有媒体版本、登记权限和业务权限。

新闻图片/PDF以 `/media/UID` 节点插入，继续使用现有HTML清理、最多10个媒体、精确引用及生效译文关联规则。外链与上传文件共用使用位置统计和受限来源保护。只有保存内容才建立正式引用。

公开 `/media/UID` 入口先检查活跃状态及实际公开引用，再重定向到已校验的外部地址。后台预览先检查登录和媒体权限，可预览回收站记录。两类入口均不缓存，不向远程发送本站来源页地址。

本站权限只控制本站展示和入口，不能撤回已被获得的外部地址，也不能控制对方网站的权限。需要私密附件时使用本站上传文件。

回收、恢复、解除引用及永久清理复用原有方法。引用中的外链不能回收；回收后公开入口拒绝访问，后台仍可预览。永久清理只删除已到期、无引用的外链登记，不请求或删除远程文件。

## 目录与资源

external不参与本地/R2存在性检查，目录报告单独显示“外部链接（未验证）”。旧报告可以继续查看和续扫。媒体列表、详情和报告将远程大小显示为未知；原生size使用0占位，不代表远程文件为零字节。外链不计入本站文件字节配额，但登记信息仍占少量数据库空间。

## 外链图片编辑

活跃且可读取的已登记图片共用原有裁剪器：自由/固定/自定义比例、滚轮缩放、拖动、两次点击选点、数值区域、撤销及PNG/JPEG输出。比例和选点规则不变。

浏览器通过CORS读取外部像素，不发送跨站Cookie或Referer，不接受读取过程中的重定向；15秒超时，按响应长度及实际读取流双重限制为20MiB。返回类型须为受支持图片，随后由浏览器解码。来源拒绝跨域、需要登录、重定向、超时或超限时提示上传本地原图，原选择与草稿保留。

裁剪结果上传为当前本地/R2的新文件，仍检查媒体新增权限、原登记版本、目标字段、输出尺寸和配额；不会覆盖原外链或其他引用。远程内容可能随时变化，登记版本只代表本站记录版本。

本功能使用标准库、既有Python服务和原生浏览器能力，不增加生产依赖、常驻进程或前端编译流程。样式继续由统一后台主题控制。
