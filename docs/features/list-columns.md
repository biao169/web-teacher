# 列表推荐列与显示偏好

后台各功能共用列描述、列表模板和列设置控制器。初次进入时显示4–7个推荐内容列，最左复选列与最右操作列另计。第一个内容列标识当前记录，始终显示并沿用冻结规则；其他安全字段可在“列设置”中勾选。

文字继续使用两行截断及完整悬停文本；推荐“说明”等列不会创建摘要数据库字段。全局配置标识对应原生uid；媒体预览/引用位置和角色授权/成员概览复用现有派生视图。数据与备份、独立快传保持各自工具页面。

正文、个人长简介、完整引文、页脚HTML、日志详情载荷和密钥/密码摘要不提供为普通可选列。原生字段与编辑能力保留，隐藏列不会改变数据库、授权范围、查询条件或导出数据。需要对可选列筛选时，先在列设置中显示该列，再使用独立的表头筛选与排序按钮。已经生效的条件不会因隐藏该列而清除。

## 偏好与恢复

偏好保存在当前浏览器、当前站点的localStorage，按功能分开；不跨浏览器同步，也不修改数据库。普通入口与指向同一功能的自定义导航共用列偏好，导航固定范围仍独立受服务端控制。

- 勾选显示列或完成列宽拖动时保存；仅打开页面不写入偏好。
- “恢复推荐列”只重置当前功能的显隐，保留当前有效列宽。
- 有可恢复的旧版显隐数据时显示“恢复旧版方案”；恢复动作也保留当前列宽。
- 旧版会自动写入所有列的显示状态，因此初次使用新版先显示推荐列；旧版合法列宽自动继承，原显隐方案保留到手动恢复，不删除旧数据。
- 首列不能被偏好隐藏；未知字段、无效格式及非65–800px范围的列宽被忽略。手机将首列显示宽度限制到140px以内，桌面保存值仍保留。
- 取消拖动恢复之前宽度，单击拖动柄而没有移动不保存；保存的是实际调整值，不写入每个自动估算宽度。
- 浏览器存储不可用或已满时，允许本页调整并提示未能持久保存；损坏的偏好在用户主动操作前保持原样。

新版存储键为`teacher-native-columns:v2:功能名`，结构为`version:2`及`columns`字段映射；旧键`teacher-native-columns:功能名`保留。此处版本仅表示浏览器显示偏好格式，不是数据库版本。

## 布局与降级

推荐显隐直接包含在服务器返回的HTML中，页面不会先展开所有列再收起。禁用JavaScript时仍显示推荐列，列设置明确提示需启用脚本。隐藏单元格不占表格宽度；空结果行的跨列数量随可见列变化。新增或显示列后，复选列、首内容列及操作列仍按已有规则冻结，操作列继续自动测宽、超过三个按钮换行。

列选择窗口使用主题参数`--admin-column-menu-width`控制宽度，在手机限制到可视区域内，长标签可换行。颜色、字体、字号及间距沿用统一后台主题。


## 表头筛选与排序

点击表头文字打开当前列的筛选窗口，右侧箭头直接切换升序/降序，二者独立。文字旁圆点标识已生效筛选，箭头与可访问的排序状态标识当前方向；时间列首次选择通常从新到旧，其他列默认升序。筛选窗口不再提供排序下拉。

Enter/Space可激活按钮，Escape关闭筛选并返回焦点；点击外部或滚动关闭窗口。拖动列宽不触发排序。更换筛选/排序回到第一页，保留其他条件、每页数量和列偏好；全局搜索也保留排序。浏览器允许存储时，表头操作后恢复横向滚动及操作按钮焦点，该临时信息绑定当前账号、会话和目标地址，只使用一次。

自定义导航固定的条件仍不可清除；派生的预览、使用位置和权限概览不提供无效排序。18类主站列表及媒体回收站使用同一控制器，会话和快传的特殊列表只显示服务支持的筛选/排序操作。快传任务先服务端排序再分页，无100条总上限；缓存表头明确只处理当前读取批次，不伪装为整个目录排序。

翻译列表以原文组为单位，推荐列包含“来源记录”；首列同时提示格式和语言。组的来源数、历史记录数和人工版本差异单独显示，来源/格式属于派生列，不提供误导性的原生列排序。旧列宽和有效显隐偏好保留，可恢复推荐列。
