# 启动、示例数据与备份

start-windows.cmd启动主站，start-with-transfer.cmd联合启动快传。共享Python启动器允许省略mode，默认启动；TEACHER_PYTHON选择解释器，启动器重用已有环境或依据锁定依赖建立环境。

首次无账号时交互创建管理员；后续启动保留账号和内容。后台“数据与备份 → 示例中心”或`add-demo-data.cmd`显式添加16组、113条新版关联示例。命令行入口要求已有管理员登录；重复添加跳过已有记录，保留用户修改，不改变当前生效设置。旧`seed`及独立基础演示启动脚本保留约90条基础示例。详细规则与功能覆盖见[成套示例中心](examples.md)。

reset-data.cmd是显式破坏性操作，只删除已配置的主站和快传数据库及SQLite辅助文件。媒体与缓存目录不被递归删除；运行锁防止本项目服务运行时重置。普通代码更新不执行该操作。

数据根、数据库、媒体、缓存路径与配置文件放在源码外部，项目更换文件夹不改变明确配置。运行日志使用配置的缓存目录。联合启动器只停止自己创建的子进程，不结束未知占用端口的进程。

精简运行包与源码包共用启动入口及README；TEACHER_VENV可以复用源码外的虚拟环境，锁文件未变时不重新安装。更新的数据保留、清单核验与平台边界见[发布包](releases.md)。

后台数据与备份支持15张业务表的JSON/CSV导出、浏览器加密ACMS、预检及事务恢复，可附带受管理媒体。功能和容量边界见[业务备份](data-backup.md)。backend.maintenance.backup使用SQLite在线备份生成完整本地数据库文件，恢复要求目标服务停止且备份结构符合原生模型；不转换旧库，不包含媒体文件。网页业务恢复不包含账号、角色或独立快传数据库。
