## 运行边界

当前自动测试环境为Linux，模拟DOM不能证明Windows布局、触控、系统剪贴板授权或实际网络条件通过。未执行Windows.cmd命令解释器、真实systemd安装/卸载、修改防火墙、配置Nginx/Caddy或公网HTTPS；根目录sh只做语法检查。旧D1的实机和本地SHA函数差异沿用第四步说明。

Windows/Ubuntu生产运行仍沿用当前Python/SQLite架构，默认数据库和媒体位于项目根目录data/；发布包不包含运行数据、账号密码或本机配置。仅有database/schema.sql，cmd都在deploy/内，sh仍在根目录。
