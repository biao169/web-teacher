# 留言处理与只读操作日志

## 留言收件与处理

留言列表复用统一搜索、列筛选、排序、10/20/50/100条分页、固定列、列偏好及顶部通知。默认显示主题、姓名、邮箱、状态和提交时间，正文不会随整页列表载入。详情展示完整纯文本、换行、类型、时间、可见范围与可用附件；不执行HTML。查看详情不会自动改为已读。

处理状态为新留言、已读、已回复、已归档。原有自定义状态保留并可在编辑页继续保存；新设置的状态使用四个标准选项。已回复仅为人工标记，不触发邮件、站外消息或通知。邮箱复制仅写入本机剪贴板；受限浏览器尝试选中文字复制。

原始姓名、邮箱、类型、主题、正文、附件只读。编辑页复用统一分区表单，提交处理状态与可见范围；关闭JavaScript仍可保存。后台不新建或物理删除原始留言，归档用于结束处理并保留记录。可见范围仅决定后台角色可查看哪些记录，不会将留言发布为前台评论。业务备份的显式恢复沿用数据恢复规则，与留言日常处理分开。

详情页支持确认后更新单条状态；列表支持本页勾选后批量修改。批量动作逐条提交，首条错误或结果不确定时停止，分别报告成功、失败或待核对、未处理数量。已成功项目保持提交，不声称整批回滚。成功后复用列表片段刷新、列偏好、位置保留及末页回退；刷新失败只允许重新读取，不自动重放写请求。

写入服务复核CSRF、同源、模块查看/编辑权限、记录可见范围和原生updated_at。提交事务再次验证当前会话、角色版本、查看/编辑权限和记录版本；状态与操作日志一起提交，冲突时一起回滚。状态日志仅记录前后状态，不记录留言正文或邮箱。

## 日志查看与导出

操作日志始终只读，不提供新增、编辑、删除或保存接口。默认列为时间、操作者、模块、动作、结果，可选UID、操作者UID、目标UID、摘要和更新时间。列表按创建时间倒序，详情复用留言的分区模板、固定底栏和标识复制。

普通列表只从数据库读取白名单短字段，不载入详情JSON。详情、JSON导出和CSV导出共用服务端脱敏：凭据类字段隐藏，未知详情字段不公开；文本中的常见凭据赋值、Bearer/Basic令牌、JWT、邮箱、IPv4和大陆手机号码隐藏，URL去除用户信息、查询值和片段。它是诊断信息白名单，不保证能识别任意自由文本中的全部个人信息；写日志时仍应只记录必要元数据。数据库原始日志保持不变。

详情超过65536字符、无效JSON、非对象根、过深嵌套或过多项目时返回提示或截断；单段文本超过2048字符时不输出原文。详情JSON不允许作为筛选或排序字段，避免通过隐藏字段查询探查详情内容。

导出覆盖当前搜索、列筛选和排序下的全部匹配结果，不限于当前页或勾选项。默认不含详情，最多20000条；勾选脱敏详情时最多5000条。文件上限24MiB，超限整体拒绝，不交付部分文件。采用有限分页和固定最大ID，生成过程中新增日志留待下次导出；交付前再次核对会话与查看/导出权限。JSON保留结构，CSV使用UTF-8 BOM并防护公式型单元格。关闭JavaScript时，导出链接回退为不含详情的JSON。

留言附件入口需要媒体查看权限，并继续由媒体预览接口校验实际记录和文件状态。没有该权限或附件不可用时仅显示说明。原生表结构、公开前台、独立快传、运行依赖与部署方式不因上述管理功能改变。
