# 第五步：发布联调与现场验收（v0.15.36）

## 交付范围

以v0.15.35为基线，验证前四步修复的组合运行与重启行为。新增发布联调测试和可在Windows/Linux运行的统一验收入口，修正测试说明遗漏账号套件的问题。本轮没有发现需修改业务实现的新故障，业务代码、数据库契约与运行依赖均沿用v0.15.35。

当前执行环境是Linux，不是用户的Windows电脑；未连接生产数据库、真实快传服务或翻译供应商。自动化联调完成，Windows现场验收仍待执行。

## 本轮执行结果

统一入口实测通过：104项Python测试（含新增真实服务联调）、25项模拟DOM测试；130个Python文件通过语法检查。Python套件耗时48.31秒，模拟DOM套件约3.69秒。仅出现既有Starlette弃用警告和Node VM Modules实验性提示，没有测试失败。业务代码、数据库契约、共享启动器和依赖锁文件与v0.15.35逐文件一致。

## 统一验收入口

使用Python 3.12+的独立测试环境，在项目根目录运行：

```sh
python -m pip install -r requirements-test.lock
python -B tests/run_acceptance.py
```

若需要包括模拟DOM测试，先安装Node 20+，再运行：

```sh
npm --prefix tests install
python -B tests/run_acceptance.py --dom
```

统一入口自动将当前Python路径传给Node测试，Windows不需要另行配置python3命令。可用JSDOM_PATH指定已有jsdom模块。该入口不安装依赖、不重置现有网站、不读取生产数据；任一选中套件失败返回非零退出码。未选模拟DOM时明确显示not_run，真实Windows浏览器验收始终单独标记。

## Windows现场验收清单

先备份数据库、媒体及配置，停服后解压至新目录，沿用原数据路径并重启。不运行重置或重复添加示例。

1. **列表**：教师、课程、媒体、用户、角色等页面，点击表头文字打开筛选/排序；点击小箭头连续切换升序、降序；筛选、分页和操作后再次确认有效。
2. **翻译**：选择同原文、同语言和格式的公开来源，确认合并为一组；检查无本地译文来源的英文页共享结果；核对人工冲突、停用和历史记录保护。
3. **媒体**：优先使用此前失败的JPG，检查列表、预览详情、刷新及并发打开时的结果；若失败，记录资源标识、状态码和错误提示，提供不含敏感信息的样本。
4. **删除**：仅对测试普通账号和自定义角色操作。取消确认应无变化；已登录测试账号删除后主站旧会话应失效；有成员角色不能删除，空角色可删除；受保护记录不能删除。
5. **批量与恢复**：核对成功、失败和未处理数量；批量遇到首个失败会停止，已成功删除不撤回。操作后刷新，再正常重启，确认数据状态保持。
6. **快传边界**：确认独立快传可启动。主站账号删除不即时撤销已签发快传凭据：60秒票据可兑换300秒会话，最长剩余窗口约6分钟，沿用原机制。

真实Windows浏览器、失败JPG样本、现有业务数据、Cloudflare D1和生产负载均未在本环境验证。第五步现场部分只有上述清单实际通过后才能标记完成。出现失败时，提供版本、功能入口、操作步骤、预期/实际结果及脱敏错误截图；不要发送密码、Cookie或密钥。
