## 已接入

- 正式首页分为介绍区、论文、科研项目和新闻模块，仅输出有内容的模块。精选教师基本信息、简介和公开邮箱在介绍区显示；教育、经历、招生保留在详情。
- 首页在当前返回结果中按排序选择第一个精选教师；没有合适教师时回退站点首页标题/副标题。未设置站点首页标题则回退站点名称。
- 论文、新闻数量读取既有设置；0值隐藏模块。数量超过10的完整取数尚受服务端旧逻辑限制，未宣称已修复。
- 项目突出source与fund_name，不显示简介、内部经费；当前仅展示原服务端返回的精选项目，独立数量开关仍待新增。
- 新闻标题和详情图标新标签打开。封面与教师头像contain、透明背景、无边框；头像不裁剪成圆形。
- 公共页头只渲染受后台控制的导航列表，不追加写死的模块入口。后台未配置导航时保持空导航，品牌链接仍可回首页。现有导航标题、启用、顺序、链接和可见性立即生效；图标和hero位置分离待服务端准备。
- 中英文胶囊开关保留当前模块、详情、查询参数和片段。无JavaScript时仍可按相同模块/条目切换，查询参数保留属于渐进增强。
- 读取真实会话用户名；有实际可查看后台模块时显示后台入口。退出复用原POST、CSRF与跳转流程。没有更改共享登录页面、注册开关或原认证逻辑。
- 首页卡片抽取为公共模板；页头复用于现有列表、详情、联系与注册页面。原列表正文和新闻富文本渲染保留，待第三/四步改造。
- 页脚继续使用现有安全HTML与动态导航插槽，不改变HTML白名单。

## 原规划纠正

`database/native/editor-contract.json` 把 `homepage_profile_uid` 标为 `stored_hidden`，说明“首页教师选择不使用此兼容字段”，应当按公开、启用、精选和排序取第一位。前次规划仅看到数据库列和当前路由，误认为存在可编辑的单值选择入口。本次直接沿用教师既有is_featured与sort_order配置，不新增重复入口。

当前路由仍有两项遗留限制：最多先取10位教师，且历史homepage_profile_uid非空时仍按该值过滤。因此模板处理虽已落地，完整候选集的正确性必须通过下面的服务端补丁完成。不要通过手工修改生产数据库来绕过此问题。
