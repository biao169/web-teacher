# 翻译分组与来源版本

翻译列表按完整原文、摘要、源语言、目标语言和原文格式合并。同文在数据库分组后再分页，每页支持10、20、50、100组，数量没有100条总上限；数据库中每条来源和历史译文均保留。

## 列表与筛选

“来源记录”列显示两个可读来源及来源总数、记录总数；来源链接在新标签定位对应字段。每组的“来源与版本”打开独立核对页面，每页10条，可查看全部来源和历史译文、单独编辑获准的记录。详情只读取，不触发翻译。

来源分类支持论文、项目、教师、新闻等已授权模块多选。多个分类之间是“或”，再与搜索、表头筛选、状态、语言及导航固定条件共同取交集。先过滤符合条件的原始记录，再分组计数；因此状态筛选后，一组可能仅显示其中一部分来源或版本。核对不同状态版本时应清除状态筛选。

表头文字打开该列筛选，右侧箭头切换排序。切换排序和每页数量保留来源分类；每组状态显示待译、成功、失败记录数量及人工记录数。原文列同时显示格式和语言，防止相同文字的HTML、Markdown和纯文本被误认成同组。

0.15.34起，代表译文与提供方来自同一条可共享记录：优先人工，再按记录ID从新到旧选择；不再分别取文字最大值。候选必须当前成功、非空、未停用、对应仍公开有效且原文/格式未变化的来源。译文排序使用选中译文的完整内容，页面预览仍截取320字符。没有有效候选时显示“当前范围暂无可共享译文”，原始成功、失败及历史记录计数不会被改写。

## 人工差异与选用

当前筛选范围内多个可共享人工译文不同时，列表标记“人工版本有差异”，不指定统一代表译文。已经失效、停用或来源不公开的历史人工记录不参与共享冲突判定，仍可在来源与版本中查看；选用提交时再次核对来源与版本。

在版本页面点击“选用此版本”，随后对指定待译记录点击“填入此待译来源”。选用状态在来源分页时保留，提交重新检查版本。只能填入仍公开、未停用、非人工、尚无译文的待译或失败记录，成功/人工记录不覆盖。保存不调用供应商；其他版本仍保留，用户也可以不选用而分别维护。

按钮不会将选定译文设为全局默认。将来新增同文来源若仍有人工冲突，还需要核对；当有效人工译文一致时，可自动复用。自动候选不跨越原文格式、语言或访问权限，详见[翻译来源与批次管理](translation-batch.md)。

英文页面现在可即时共享其他公开来源中完全相同原文、语言及格式的有效译文，目标没有缓存或仍待译也可显示。读取不调用供应商、不写缓存，因此后台“待译”仍表示已保存记录状态。专用英文字段、本来源的人工缓存、明确选用版本及停用设置优先保留。存在共享人工冲突时，只保留本来源已有的有效版本；没有自身版本则显示原文。后台筛选仅控制管理列表范围，不改变公开页面的共享规则。

## 权限与导出

分组统计、可读名称、来源详情和导出只纳入当前角色能够查看的来源。来源模块未授权或记录超出可见范围时，不显示其数量与原文；系统管理员可维护已删除或未关联来源的历史记录。单条译文编辑保留既有原文快照维护规则，受限来源不产生可访问链接。

“导出当前组”导出当前筛选的全部组，“导出所选组”仅导出本页勾选的组。JSON包含组标识、格式及组内全部匹配来源记录，保留原始字段。最多20000条来源、4MiB；达到上限请缩小范围。选择、导出和明确选用均沿用当前列表及固定导航范围，不扩大到未显示的来源。

“批量扫描与翻译”另有明确的来源选择和持久任务状态，不继承列表临时筛选。不同原文仍分别调用供应商；当前优化减少的是重复原文及已有译文的请求。
