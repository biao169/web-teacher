# 新闻独立编辑窗口（0.15.43）

新闻正文选择富文本后，点击“独立窗口编辑”，可在页面内的大窗口编辑。窗口使用同一个Quill实例，不复制草稿、重新加载正文或新开浏览器标签。工具栏位于窗口顶部；点击图片后，图片控制区也在顶部显示。正文在下方独立滚动，长文和大图不会将整张新闻表单撑得过长，也不会滚走工具栏。普通嵌入编辑区采用同样的固定顶部、内部滚动布局。

图片控制区采用紧凑排列，空间不足时自身可滚动。宽度、单位、高度、最小宽高在输入有效数值时立即作用于编辑区和草稿，无需再点“应用”。无效或超范围数值不覆盖上一次有效效果；清空尺寸表示自动。保留“确认图片尺寸”按钮和回车校验。高度留空等比，最小尺寸仍可能使图片大于设定宽高；前台采用保存后的真实尺寸，不额外缩小原图文件。

点击“完成编辑 / 返回表单”或按Esc关闭窗口，正文、图片设置、撤销/重做记录都保留，并返回打开按钮焦点。关闭不会自动发布或保存，仍需在新闻表单点击保存。窗口内可继续使用原有图片/PDF选择器、排版、拖动及实际效果预览。对不支持原生dialog的浏览器，保留嵌入编辑区并提示，不丢失正文。

本版不改变数据库结构、保存接口和媒体文件。保留0.15.42及更早已完成的修改。发布静态资源版本已更新，升级前停服备份，保留现有数据库、文件目录和配置。

验证：46项模拟DOM测试通过，包括实际加载项目内Quill，检查窗口往返使用同一实例、关闭/Esc保留草稿和焦点、工具栏不属于正文滚动区、尺寸输入及单位改变即时生效、无效输入保护和不支持dialog时回退。14项新闻图片后端回归通过，覆盖安全清洗、保存、预览、公开页面和媒体引用。此次未重跑无改动后端的全部197项测试。真实Windows浏览器中的布局、原生焦点约束、触控与软键盘仍需目标环境验收。
