# 第五步快传前台及入口接入（0.15.52）

## 状态

用户已批准快传路由与必要模板上下文调整。本版已把独立前台接入 `/`；`/admin` 继续使用原管理页和权限；`/tasks` 复用原任务页。普通账号仅查看自己的任务，管理员仍按原权限查看任务。

本次服务端改动仅位于 transfer/backend/native.py 的页面路由及模板上下文分支。上传、下载、权限判定、额度计量和数据库结构均未改变。新前台文件为 portal.html、portal.css、portal.js、portal-core.js，不依赖后台样式或脚本。

## 已实现

- 桌面双区、移动端纵向排列；全部/发送/接收切换只隐藏节点，保留文件对象、进度和任务。
- 拖入/选择单文件，文件大小上限检查，按1MiB分块复用现有接口；暂停等待当前请求结束，不撤销服务器任务或预留额度。
- 恢复前从服务器读取检查点，逐块SHA256校验已上传前缀；最后一块响应丢失时通过检查点确认完成，不重复发送。
- 创建请求结果未知时阻止重复创建；分块失败后仅在再次点击继续时读取检查点。无自动写重试。
- 续传记录按服务端提供的账号标识、文件名、大小及修改时间隔离，保存在当前标签页sessionStorage；存储不可用时保留内存任务并提示。复制链接失败时选中文本供手动复制。
- 日/周/月本人剩余额度读取已有 /api/usage。服务器继续作最终裁决，不将前端检查视为授权。
- 接收仅允许本站 /s/43字符令牌 的精确链接，拒绝外站、凭据、附加参数和片段；不发预探测请求，不宣称下载完成。
- 当前页面最多保留10条已发送记录；这不是服务器上的“本人最近任务列表”。完整任务查看仍复用原页面。

## 已批准并完成的入口调整

1. `/` 渲染独立前台，匿名用户可以打开接收区，不能上传。
2. `/admin` 管理入口保留原有身份检查、模板与操作。
3. `/tasks` 复用原任务页、筛选与分页；访问时仍要求登录。管理员可见范围与原页面一致。
4. 新模板仅获得CSRF、账号隔离标识、已有显示名（缺失时“已登录”）、管理员标志、按原规则计算的单文件上限和发送不可用原因。没有输出完整管理员设置或身份规则。
5. 登录桥接仍返回 `/`，现在显示新前台；原登录票据、会话期限和校验没有变化。会话过期后可使用“刷新登录”，回到同一标签页重新选择同一原文件继续。
6. 新页面不会检查分享令牌或触发下载；用户点击接收时才进入原下载接口，服务器继续检查匿名开关、有效期、次数与额度。

frontend-step5-route-proposal.patch 保留为0.15.51到本版的历史审阅材料；补丁现已应用，不要在0.15.52重复执行。此版本没有新增数据库迁移，交付包未自动部署到现有网站。
