# 教师网站前台逐项优化规划

基准版本：teacher-site-windows-v0.15.57。当前交付：teacher-site-windows-v0.15.64；七步代码和自动化联调完成；Windows/手机真实浏览器验收仍待完成，不等同全平台验收通过。未部署或修改实际数据库。以下方案依据最新10项要求，优先于文末旧规划中冲突的规则。继续使用Jinja模板、Bootstrap及原生JavaScript，不引入Nuxt/Vue。

## 2. 唯一前台主题文件与共用交互

建议新增 `frontend/shared/static/css/public-theme.css`，作为所有前台UI字体、字号、字重、行高和颜色的唯一维护入口。放在shared静态目录便于主站及独立快传前台共同引用，但用明确的前台作用域隔离，不影响后台主题。

文件内按以下区域管理：中文/英文字体栈；正文、页面标题、卡片标题、元信息、标签、按钮、头像姓氏字号；主文字/次文字/链接/强调/边框/背景/状态/焦点/选择颜色；响应式字号与阅读模式。正文以16px为基准，卡片标题约17—18px、元信息14px、辅助信息13px作为起点，使用rem并保留浏览器缩放；小按钮视觉可紧凑，但点击热区不随之过小。

academic.css、home.css、public.css等保留布局、间距、圆角和排列，字体与颜色一律引用主题变量；迁移旧字面值和重复规则，不能只新增主题文件却被旧样式覆盖。Bootstrap已有样式通过作用域变量及前台覆写衔接，不修改第三方库源码。前台富文本阅读区的标题、正文、链接、引用等也服从同一UI样式；图片/PDF原始内容和必须保持原样的官方标志不是可由CSS统一重排的文字。

快传前台仅接入相同主题来源，不改发送/接收、额度、认证或后台；独立部署继续从自己的shared静态地址读取随包文件，不增加跨站样式请求。

共用组件包括：人物头像/姓氏占位、品牌链接、无边框图标按钮、简介折叠、字段排列、复制序列化、附件入口及返回顶部。视觉样式与行为不在每个模块复制一遍。

返回顶部使用右下角小型上箭头按钮，约滚动400px后出现，回到顶部后隐藏；避开手机安全区和浮动控件，支持键盘、焦点提示及减少动画偏好。优先使用页面顶部哨兵的IntersectionObserver，兼容环境再用节流滚动监听。按钮不进入条目复制内容。

## 3. 首页、教师列表与教师详情

### 3.1 首页两卡

桌面使用约3:2的两列，自适应收敛为单列；两卡顶部、外边距、内边距、底部对齐，不通过固定高度裁掉内容。

- 左卡：头像/姓氏占位、姓名、职称/头衔、团队角色、单位、实验室/团队、个人简介。姓名优先级最高，职称和角色紧随，单位/实验室次之。
- 右卡：办公室、邮箱、电话，以及学术与社交账号。无值字段不生成空行。联系方式沿用现有contact_visibility约束；前台显示补全不改变隐私设置。
- 删除硬编码的下方“教师详情”按钮。需要的下方按钮统一由已存在的`hero`位置“导航与按钮”配置控制，配置为空则不生成按钮区域。教师姓名可沿用教师详情链接。
- 无首页教师时继续显示后台首页标题、副标题与配置按钮，不出现两张空人物卡。

### 3.2 学术链接和“显示数值”

现有`google_scholar_value`、`github_value`等只是管理员手填的附加整数，不自动联网更新，不是系统统计的点击次数、访问量、论文数或被引次数；数据库也未定义每个平台数字的指标含义。填写0会展示0，留空则不展示。

建议本轮默认不渲染这些缺少指标名的裸数字，后台数值保留。若今后需要显示“论文数”“被引次数”等，应先明确指标名、来源和更新时间，不能擅自把历史数字解释成某种统计。

每个平台显示“官方图标 + 平台名 + 实际链接/账号标识”，例如ORCID编号或GitHub用户名及可辨认地址；提供完整有效链接，长地址允许换行。ORCID仅填编号时复用既有校验规则生成官方个人记录地址，不改后台存值。普通个人主页使用通用主页图标。图标按需本地打包，优先采用平台官方资产；第三方图标库不冒充官方资产。ORCID要求使用提供的原始标志、不擅自改形状或颜色，见[官方品牌规范](https://info.orcid.org/brand-guidelines/)。

### 3.3 教师列表与详情

列表左侧始终保留头像区；姓名突出，职称/团队角色次突出，单位/实验室、允许公开的联系信息及学术链接完整但紧凑排列；简介默认两行。动作位于已有信息末端，使用无边框的精细详情图标，悬停为浅色背景，键盘焦点明确；不单独占整行。

头像缺失、文件不可见或加载失败时，统一回退文字：中文识别常见复姓；英文优先显示可靠识别的姓氏，不能可靠识别时用姓名首字母组合，不武断把所有英文名的最后一个单词认定为姓氏。示例前缀不应被误当姓氏；显示姓名不被改写。长姓氏按主题中的字号档位缩放。真实图片仍完整contain、透明、无边框。

教师详情顶部为身份卡及联系/学术卡，正文依次按个人简介、教育经历、工作经历、招生信息分区，空区隐藏。长内容有阅读宽度，短资料可分栏，手机单列；返回、复制等操作集中为一条小工具行。列表与首页、详情复用同一字段和链接组件。

## 4. 前台两种可见范围与项目卡片

### 4.1 权限范围

| 访问身份 | 项目公开字段 | 负责人、金额、成员 |
| --- | --- | --- |
| 未登录、一般账号 | 来源、基金/计划、名称、编号、主持/参与、周期、状态 | 不查询为响应字段，不进入HTML、分片或复制内容 |
| 有效会话且获项目模块后台查看授权的管理账号 | 同上 | 按原模块权限允许显示与复制 |

判定复用服务端有效会话和模块权限，不根据用户名、URL参数或前端开关。仅拥有文件快传权限不等于有项目管理权限；其他模块后台权限也不自动授予项目私密字段。管理视图只丰富同一批公开项目的字段，不把未公开项目混进首页。

首页项目、列表、后续分片、筛选相关读取、旧链接定位与复制共享同一字段策略。匿名查询结果、错误提示和候选统计不得用私密字段反推内容。保留现有动态响应no-store策略，管理内容不得进入公共缓存；后续请求会重新验证身份。教师联系方式等其他内容继续执行原可见性规则，不因新增管理视图而放宽。

### 4.2 排列与复制

项目显示顺序：来源—基金/计划 → 项目名称 → 项目编号 → 主持/参与 → 起止周期 → 状态。管理模式在末尾追加负责人、金额、成员。合并起止日期为一个“项目周期”，减少重复标签，空字段及其分隔符一起省略。

根据现有project_role映射主持/参与：明确的主持/负责人显示主持，明确的参与/成员显示参与；未识别的旧值保留原义，不猜测、不批量改库。筛选和显示口径同步，兼容旧筛选地址。

中文金额如`12.5 万元`，英文如`CNY 125,000`；使用精确十进制计算，0有效，缺值不补0，不改变数据库中以万元存储的数字。界面与复制共用格式化函数。

视觉上可自然换行为两三行；复制时同一卡片的非空元素以空格或分号串联，不插入字段级换行，卡片之间保留换行。先采用有真实分隔文本的合理DOM；若浏览器对视觉分组仍插入换行，仅对项目范围的copy事件统一处理，同时提供一致的纯文本和HTML剪贴板内容。部分选中只复制所选片段，跨卡选择保留卡片边界；不得截获其他页面的正常复制。

## 5. 论文卡片与多格式复制

卡片主段保持网站设置指定的保存引文；现有姓名高亮增加下划线及适度字重，直接包裹安全文本节点，不改存储文本、不在复制内容中添加下划线符号。

最后一行左侧放DOI具体地址、原文链接、允许公开的PDF及小型复制操作；右侧放论文类型、收录等标签，通讯作者标记也归元信息区域。无值不占位。宽屏同排两端对齐，手机按整组换行，标签不挤压链接且不混入引文复制；具体刊名已在引文中时不无意义再复制一个长刊名标签。

多选工具行新增紧凑“复制格式”下拉：GB/T、Elsevier、APA、IEEE、BibTeX（引用数据文本）。默认跟随网站显示格式；切换仅控制复制，不修改网站设置、不重排卡片、不丢失勾选。卡片单条复制与该页选择保持一致；首页单条复制默认使用站点显示格式。

当前列表只有站点选定格式，不能仅添加下拉却仍复制原格式。复制其他格式时，按已选UID、一个指定格式有界读取已保存文本：建议每批最多20条、串行批次，不逐条请求详情，不抓取所有筛选结果或全部五种格式。接口校验允许的格式和UID数量，只返回当前公开记录，排除无关字段；本地缓存只用于本轮复制和失败重试，避免持久保留已变更记录。

所选格式缺失时提示缺少条数并中止本次整组复制，允许更换格式或补齐后再试，不混用另一种格式、不静默遗漏条目，也不覆盖人工编辑引文。查询/排序重置时仍按现有规则清空勾选；单纯切复制格式不重置。100篇示例用于检查长引文、追加选择和复制顺序。

## 6. 专利、学生和课程

| 模块 | 布局与交互 |
| --- | --- |
| 专利软著 | 标题+类型+状态标签；发明人/权利人/国家为紧凑信息组；申请号与申请日期一组，授权号与授权日期一组，缺项不留洞；简介限一行；证书入口为小图标，保持原附件权限，不新增详情页 |
| 学生 | 与教师复用左侧头像/姓氏占位；右侧姓名/学位/年级，学校/方向/状态按信息量分散对齐，通常与头像区域接近等高，但短内容不强行拉出大空白；简介有值才占位，默认一行，溢出才出现同排展开/收起按钮 |
| 课程 | 标题/学期/对象为首行，简介默认两行，溢出显示小型展开/收起按钮；课程大纲或资料为PDF时显示查看图标，隐藏资料不暴露地址；详情入口继续保留，PDF入口不代替课程详情 |

简介折叠统一一个控制器，按实际溢出决定按钮，保留aria-expanded、焦点和中英文提示；重新折叠后卡片恢复紧凑。短简介可直接展开已加载节点；超过列表摘要上限时，只在点击后通过白名单只读接口取该条完整公开文本，并复用翻译规则。学生不恢复独立详情页；无简介时不产生空段或不可用按钮。

“学校”需要真实数据来源：建议为学生增加可选school、school_en字段及对应现有编辑器输入项，配套显式无损迁移，旧记录默认空，不新增必填约束，不推断学校。这属于本轮唯一建议新增的数据字段，进入第五步前需把具体迁移/编辑器范围纳入批准。若暂不采用此扩展，先完成学位、年级、方向、状态和简介排布，隐藏学校项。

## 7. 新闻列表、详情与PDF

列表左侧总有封面区域；没有可用封面时显示第一分类的首个字符，英文界面缺少分类译文可保留中文字。分类为空用小型通用新闻占位；封面加载失败也回退，避免空白破图。真实媒体继续等比完整显示。新闻标题仍新标签打开。

详情取消额外自动渲染的封面，不修改正文内容；正文中作者明确插入的图片保留。正文与PDF间使用一条细分隔线和适度留白，下方为矮小工具行。每份PDF只有一组查看/收起和按设置允许的下载按钮；文件名有辨认需要时显示一次，正常状态不重复“打开文件”“阅读PDF”“按页加载”等多套工具。加载中或失败时再出现必要提示和重试，保留无JS/自动加载不可用时的手动入口。

从global_settings安全读取现有news_pdf_watermark、news_pdf_allow_download等所需配置，不能把整个全局设置含密钥传给前台。水印非空时，在在线阅读的每一页上显示经过转义的水印，位置和样式随页缩放；不遮挡链接、文字选择或辅助功能，不计入正文复制。下载开关关闭时不显示原文件下载/打开入口；“查看”进入受控阅读区，不能借原文件链接绕开界面策略。

必须区分两种水印：

- 本轮基础范围为**在线每页显示水印**，复用现有阅读器，不改变原文件字节。
- 若要求**下载到本地的PDF也带水印**，需增加带水印副本生成与缓存，按文件版本和水印设置区分副本，兼容现有存储和授权。不能把CSS/画布叠加水印称为文件已加水印。该服务端处理及跨平台运行依赖须另行明确批准后实施，不能静默扩展后台。隐藏下载按钮也不等于绝对禁止用户保存已经传到浏览器的PDF。

继续采用已有PDF.js与媒体Range响应：接近阅读区时才加载库、文档和第一页，继续滚动才渲染后页；保留请求排队、画布上限、离屏释放、失败重试、缩放重绘与不同纸张比例。现有上限是同时2个已解析文档、3个画布、每画布约400万像素，不据此承诺解析器总内存恒定。用户看到逐页加载，底层是PDF所需的字节分段，不是服务器按页拆文件；部分文件结构或服务端不支持范围读取时仍可能多读数据。相关能力见[PDF.js加载参数](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)。

news_body与news-reader目前被后台预览共用。实现时优先传入显式的前台展示配置/作用域，保留旧调用默认行为，不改后台富文本编辑、上传、预览提交及媒体访问权限。

## 8. 留言页面

采用居中的表单卡片；宽屏可配一个较窄的说明栏，手机单列。姓名/邮箱一行，主题独占一行，正文占主要区域，提交和反馈靠近表单底部。说明文字、必填/选填、输入边距、错误和成功状态统一主题与中英文，不重复显示模块大标题占空间。

主题为可编辑组合输入框，建议项包括招生咨询、科研合作、课程问题、网站反馈、其他；选择后仍可改写，可直接输入任意合规主题。预设只是便捷文本，保存仍是现有subject字符串，不硬编码为新枚举，不新增主题数据表。

## 2. 统一结构与视觉

继续使用现有Jinja模板、Bootstrap CSS及原生JavaScript，无Nuxt/Vue；不新建重复的首页/列表数据渲染逻辑。模块摘要和列表复用同一组字段、引文、媒体和按钮组件。

检索和操作仍是两条逻辑工具行，控件纵向居中；桌面控件视觉高度约32px，手机保留约40–44px可点击区域。窄屏自然换行，不挤压文字、不产生页面横向滚动。不额外重复当前模块大标题。

统一使用Bootstrap Icons SVG小子集：展开/收起chevron-down/up，详情arrow-right，新闻新标签box-arrow-up-right，复制copy，排序sort-up/down。图标约16–18px、按钮约30–32px，轻边框或浅背景，状态/悬停/键盘焦点清晰；名称由aria-label/title提供，禁用纯字符箭头。图标就地打包并保留许可文件，不运行时下载整个远程库。

官方参考：[Bootstrap Icons](https://icons.getbootstrap.com/)、[Chevron down](https://icons.getbootstrap.com/icons/chevron-down/)、[Box arrow up-right](https://icons.getbootstrap.com/icons/box-arrow-up-right/)。官方提供SVG、sprite与字体等用法，本项目采用本地SVG资源。

| 项目 | 第一行来源—基金计划，附状态等短标记；第二行标题，同行接负责人、角色、金额等；第三行按需放编号、周期、成员 | 标题可换行，不显示简介、不进入详情；普通长度目标2–3行，超长信息允许自然增加，不能遮挡或强制裁切 |
| 专利软著 | 名称、类型、状态；作者/发明人、权利人、国家/地区；申请号/授权号及日期紧凑排列 | 不进入详情；公开证书直接作为附件入口 |
| 新闻 | 序号/选择、左封面；右标题、分类、日期；可用时展示短摘要 | 标题及小按钮新标签打开新闻详情；封面在左侧区域内完整居中 |

教师/新闻媒体建议桌面约72–96px宽，按实际内容调节；无媒体时主内容补满。所有图片视频继续contain、透明、无边框、适当圆角，不用object-fit:cover裁切。

按钮与内容使用真实网格/弹性布局，不能绝对定位覆盖文字，也不另占一整行。鼠标阅读与复制使用DOM正常顺序，不能仅靠CSS把末尾媒体视觉搬到左侧后形成混乱的选择顺序。

## 6. 论文显示、复制与详情收敛

新增一个明确的站点“论文显示格式”设置，候选为现有GB/T、Elsevier、APA、IEEE；默认GB/T。BibTeX用于导出，不作为默认阅读排版。当前已有各条目引用字段与格式生成工具，但未见全站生效的格式设置，不能把编辑器解析选择或前台临时复制选择误称为网站配置。

首页和论文列表都按同一配置读取对应保存文本，保留手工修订；复制所选直接使用已加载卡片对应的原始引用字符串，取消逐条请求详情HTML。默认显示与复制一致，格式选择从日常工具栏移除，额外导出可收进小菜单。

缺少选定格式时不静默套用另一格式冒充正确格式；展示明确标注的基本著录信息，复制结果保持同样的回退内容，并提示有缺项。管理员或示例生成流程可复用现有格式生成函数补齐，无需访客每次浏览时重新生成。不能覆盖人工保护的引文。

通讯作者、已有姓名强调使用独立的安全匹配/标注方法，不直接修改保存引文，不盲目向原文插星号或重复姓名。正文文本复制以原始引用为准；短标签和按钮不加入复制文本。

仅保留profiles、courses、news的前台详情展示。students、publications、projects、patents、research_interests移除新链接和独立详情模板分支；先解除复制/展开脚本的详情依赖。已有公开旧链接可按语言跳回对应列表并定位条目，不新增展示页面；这项公开路由兼容处理需纳入服务端改动清单，不能误删管理编辑接口。

## 7. 检索行、下拉框与默认排序

检索行：关键词 → 各模块必要筛选 → 搜索/重置。操作行：全选已加载 → 已选数量 → 复制所选/取消选择 → 后台顺序升序/降序 → 结果数。移除“每批数量”和排序字段下拉，不再提供添加时间、名称或其他新的排序方法。

| 模块 | 优先筛选项 | 次要项 |
| --- | --- | --- |
| 教师 | 职称、单位 | 只有已有公开字段有区分价值时再增加 |
| 学生 | 后台学生分类、学位、年级、状态 | 研究方向 |
| 论文 | 论文类型、年份、收录类型 | 具体期刊/会议名称 |
| 项目 | 来源、基金计划、状态 | 已公开且有必要的承担角色 |
| 专利软著 | 类型、法律状态、国家/地区 | 申请/授权年份（需派生聚合） |
| 课程 | 学期、授课对象 | 不伪造不存在的课程分类 |
| 新闻 | 分类、发布年份 | 无实际值的筛选不显示 |
| 研究方向 | 关键词 | 无真实分类属性时只有搜索 |

筛选类型由各模块预设，候选值从所有允许公开的记录去空、去重、按语义统计，不能仅基于当前批次。默认保留全公开范围候选，筛选后无结果给出重置入口，不因当前结果为空丢失已选项。论文“论文类型”取publication_type，而venue是具体刊名，两者独立。多值字段复用已有分词/规范化规则，避免把“SCI;EI”作为不可拆的一个类型。年份从已有业务日期派生时只读聚合，不增加冗余年份字段。

主筛选直接显示，次要项可放“更多筛选”，以减轻工具行。无需新增无限数量的筛选框；多语与窄屏无法容纳时自然换行。

下拉框采用一套可复用增强组件：折叠宽度按“年份·全部”“期刊/会议·全部”等默认标签的实际字体宽度计算，与候选中最长刊名无关；选中长值时折叠区显示短摘要/数量，完整值在可访问名称、提示及候选面板中可见。弹出面板独立宽度，可换行和纵向滚动、受视口约束；不使用省略导致用户无法辨认候选。支持键盘方向键、Enter、Esc、焦点返回和屏幕阅读器，并保留原生select的无JS回退。原生select弹出宽度跨浏览器不一致，不能只靠给option写width保证效果。

默认所有模块按后台sort_order升序；同值按稳定ID排序，降序同时反转稳定次序，连续分片不跳项。学生沿用已确认的分类配置display_order顺序，组内sort_order升序；升降序仅切组内顺序，避免打乱教师设置的分类。去掉旧排序链接中不再支持的字段并规范到后台顺序，不能只隐藏控件却仍按created_at读取。

展示序号和排序字段分开处理：教师继续1起顺序编号，其他列表保留已确认的结果总数倒序编号；排序变化后按当前结果位置重新计算。序号不作为查询排序依据，不复制到条目内容。

## 8. 分片、勾选与复制

仍复用现有有界分页及IntersectionObserver加载，不展示批量大小选择；首批10条、后续每批10条作为当前建议，保留服务端上限。保留加载中、已全部加载、失败手动重试与节省流量模式。筛选/排序变化时取消旧请求、回到第一批并清空勾选；滚动追加保留已选，新追加条目不自动勾选。

首页多个模块共用请求队列，列表单请求在途并按UID去重。候选值也分页，不用为统计筛选候选把100篇正文全部传到浏览器。并发编辑/删除造成总数变化时按当前响应更新计数，不能宣称常规offset分页具有快照一致性。

鼠标复制和按钮复制遵循相同语义。项目为来源/计划→标题→人员/角色/金额→编号/周期；论文为原始引用文本；其他按姓名/标题→基本信息→补充信息。标签、序号、复选框和按钮不加入复制。安全和权限判断仍在服务端，不能只用CSS隐藏敏感字段。
