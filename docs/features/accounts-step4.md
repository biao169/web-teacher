# 第四步：用户与角色删除（v0.15.35）

> 本文记录0.15.35交付时的规则。0.15.37已允许删除其他管理员账号，并修正新建默认状态；当前规则见`admin-step1.md`和`accounts.md`。

## 原因与修复

原生目录将auth_users、auth_roles标记为不可直接删除，列表因此隐藏删除入口；角色权限与账号又通过外键引用角色，单独开放按钮不能处理关联关系。本版在应用层增加受保护的删除能力，不改原生表定义、数据库契约或依赖。

- 共享Content.delete继续负责权限、记录范围、导航约束、更新时间校验、事务与审计；accounts提供保护原因、事务内关联检查和权限清理语句。
- 用户和角色列表共用native-list-panel模板、native-list控制器、确认对话框、批量处理及刷新逻辑；其他列表沿用原行为。
- 账号删除通过原有外键级联清除主站会话。角色删除先在同一受保护事务内清理auth_permissions，再删除角色；任一语句失败全部回滚。历史审计保留。
- 保护条件在显示、提交前和事务内核对，防止打开列表后新增角色成员、提升目标权限或撤销操作者系统身份导致越权。

## 删除规则

| 对象 | 条件或行为 |
| --- | --- |
| 普通账号 | 系统管理员具有用户模块进入和删除权限，且账号在可见/导航范围内时可删除 |
| 当前登录账号、初始化账号 | 禁止删除 |
| 所有系统管理员账号 | 禁止直接删除，最后一个管理员同样受保护 |
| 未使用的自定义角色 | 可以删除，关联权限配置同时清理 |
| 有成员的角色 | 禁止删除；包括隐藏、禁用、锁定成员，需先调整所属角色 |
| 系统角色、注册默认角色 | 禁止删除，保证管理和注册入口继续可用 |
| 非系统角色 | 即使获授账号或角色模块删除权限，也不能执行删除 |

受保护记录显示锁标识及原因提示。批量操作沿用逐条事务，遇到首个失败即停止；已经成功的删除不会撤回，页面报告成功、失败和未处理数量。勾选到受保护记录也会被服务端拦截。

删除账号不删除其历史审计、业务内容或独立快传数据。主站会话即时清除，无法再签发新快传票据；独立快传已有票据有效期60秒、会话有效期300秒，沿用既有机制，不承诺跨服务即时撤销。尚未兑换的票据可在剩余有效期内换取300秒会话，最长剩余窗口约6分钟。

## 验证结果

新增22项Python账号回归，覆盖用户删除、会话级联、审计保留、角色权限清理、七类保护、普通角色伪造权限、来源/CSRF/版本/权限/固定范围、三类提交时竞争、审计失败回滚和完整页面/局部刷新模板。

新增2项模拟DOM测试，核验单条与批量账号删除使用专用确认说明、批量数量正确、取消不发送请求。累计103项Python测试及25项模拟DOM测试通过，128个Python文件语法检查通过；数据库文件和依赖锁定文件与v0.15.34一致。测试使用临时数据库、合成账号，未操作生产数据。

复现命令（先按requirements-test.lock安装测试依赖；Node测试需jsdom，设置TEST_PYTHON和JSDOM_PATH指向相应解释器/模块）：

```bash
python -B -m pytest -q tests/test_list_regression.py tests/test_media_regression.py tests/test_translation_regression.py tests/test_accounts_regression.py
node --experimental-vm-modules --test tests/list-dom.test.cjs tests/media-dom.test.cjs
```

Starlette依赖弃用警告、Node VM Modules实验性提示不影响测试结果。真实Windows浏览器、用户实际数据及Cloudflare D1生产环境未实测；上述测试不替代平台验收。

## 更新与验收

1. 备份数据库、媒体及配置，停服后解压到新目录，沿用原数据路径并重启；不要重建数据库或重新添加示例。
2. 用有相应权限的系统管理员打开用户管理，建立测试普通账号并登录；删除后列表应移除该账号，其主站旧会话失效，操作日志仍可查看。
3. 建立一个测试自定义角色并赋予权限；无成员时应能删除。有成员时应被拦截，将成员改属其他角色后再删除。
4. 确认当前账号、初始化账号、系统管理员账号、系统角色和注册默认角色显示保护提示；旧页面或伪造请求仍不能删除。
5. 检查取消确认、删除所选、首项/中途失败提示、筛选与排序保持，以及删除后局部列表刷新。
6. 结合前三步说明，复查教师等表头弹窗与快速排序、失败JPG样本、翻译合并及英文页面共享。若仍失败，保留页面入口、操作步骤和错误提示供定位。
