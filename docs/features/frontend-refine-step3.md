# 前台逐项优化第三步：0.15.60

基于0.15.59，完成项目与专利卡片；不涉及论文多格式复制（第四步）。

## 项目展示与复制

首页和列表共用project-card.html。阅读/复制顺序为来源—基金计划、项目名称、编号、承担角色、周期、状态，管理信息负责人/金额/成员追加在末尾。来源单独一行，正文以行内元素自然换行，空字段及分隔符同时省略，不展示简介或新增详情页。长标题和成员允许多行，不为了强制两三行而裁掉信息。

金额沿用数据库万元单位。public_projects.py使用Decimal精确计算；12.5000显示12.5万元 / CNY 125,000，0.0001万元显示CNY 1；0有效，缺失不补零，不更新存值。起止日期合成周期；仅一个日期时显示起于/截至或From/Until，不伪造日期。

明确的主持/负责人/PI/Lead归为主持（Lead），参与/成员/Participant归为参与（Participant）；Co-PI和顾问等不推断，保留原文。多个角色沿用原分号、中文分号和换行分词，再分别映射、去重显示。公开候选和查询使用同一映射；旧单值别名及完整多值筛选链接保留，未知单词仍完整词匹配，管理界面仍执行原精确筛选。英文候选在首屏和更多选项中都翻译标准角色，值保持统一。

按钮复制复用public-people.js，从已显示项目节点读取，一卡一段，多卡空行分隔。鼠标/键盘选中文字的copy事件仅在选区两端都落在同一项目流的项目文本内时接管，按实际选区裁剪每卡文本，压缩字段间换行，同时输出纯文本和转义的HTML段落；不复制序号/选择框，不补入未选字段。跨其他模块或选中整个页面时保留浏览器原复制。首页与滚动追加无需单独绑定监听，复制不请求后台或读取未加载记录。

## 专利软著

共用patent-card.html：标题旁排类型/状态标签，作者/发明人、权利人、国家为紧凑信息；申请号与申请日期一组，授权号与授权日期一组；缺项不产生空组。简介视觉限制一行，原摘要仍可选择复制。证书使用既有小图标入口和受控媒体地址，不改变鉴权，不新增详情页。
