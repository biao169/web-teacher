# 学生分类与匹配名单

学生分类在一个编辑页面维护分类标识、显示名称、关键词、启用状态及顺序。“匹配学生”区与字段区共用顶部目录、整表保存和底部按钮；分类列表使用“编辑”入口。

## 关键词规则

关键词按换行、中文或英文逗号、分号分隔，去除首尾空白并去重。任意一个关键词包含于学生的学位、分类、年级、研究方向或状态即可匹配；姓名和联系方式不参与匹配。英文ASCII字母不区分大小写，中文按原文匹配。百分号、下划线、反斜杠是普通文字，不作为搜索通配符。

一条分类最多20个不同关键词，每词最多120个字符，整个输入最多4096个字符。保存和预览共用同一校验方法。空关键词匹配0人；没有命中时明确显示空结果。既有超限规则仍能打开编辑页并修改。

## 预览与保存

修改关键词后约450毫秒自动预览；中文输入法组词期间等待输入完成。也可点击“预览匹配”手动刷新。预览通过POST发送草稿，不把中文关键词放到浏览器地址栏，不更新分类记录、学生记录或业务操作日志。

预览区区分“未保存的关键词草稿”与“已保存关键词”，规则状态则始终说明数据库中已保存的启用状态。新分类显示“尚未保存”。修改关键词后立即清除旧名单，取消过期请求；较迟到达的旧响应不能覆盖新草稿的结果。网络或服务错误保留输入，可手动重试。

“保存并激活匹配”提交整个编辑表单，将关键词等修改与enabled=1一起保存，随后显示成功提示和按保存规则查询的名单。普通“保存”遵循启用开关，可关闭规则。保存仍检查分类创建/编辑权限及记录更新时间；冲突不覆盖他人修改，当前输入保留，预览与保存按钮恢复可用。

规则改变不会改写students.category，不建立额外学生关系表，也不会为每个匹配学生创建写操作。空结果不阻止保存规则。多个分类之间不执行自动互斥或去重分配；后台匹配预览仍不进行互斥分配；0.15.48起访客前台按启用规则显示顺序分组，重复命中取最早组，不更改本预览结果或学生数据。

## 名单与权限

名单显示姓名、学位、分类、年级、方向和状态；只有拥有学生编辑权限时才显示“编辑”链接。链接在新页面打开，保留分类草稿。名单不返回邮箱等其他字段；单个显示字段最多返回500个字符，完整记录可在有权限时打开学生编辑页查看。

每页支持10、20、50、100人，按学生sort_order和id稳定排序，显示当前页、总页数和总人数。最多11页时显示所有页码；更多页时显示首末页、当前页附近页码与省略号，避免生成过多按钮。翻页和改变每页数量不提交分类表单，不丢失其他未保存字段。

服务器同时检查分类创建或编辑权限、学生查看权限及学生可见性范围。没有学生查看权限的账号仍可维护已获授权的分类，但名单、人数和预览操作不展示；手工请求预览接口也会被拒绝。只具备学生查看权限的账号看不到学生编辑链接。

## 布局与资源

名单与普通列表复用分页模板和Bootstrap控件；桌面工具区紧凑排列，手机可换行，名单在自身容器内横向滚动。颜色、字体和字号继续由admin-theme.css控制，提示使用已有的信息、草稿警告、成功和错误语义色，并以明确文字补充状态。

查询由数据库执行关键词筛选和计数，应用只读取当前页所需字段。关键词数量、结果行数和单元格长度都有上限；查询仍可能扫描学生表，耗时随数据量增长，不等同于常量CPU开销。无需新增运行库、后台任务或编译步骤。

数据库沿用原始主站的student_category_displays和students结构。数据库、缓存、媒体位置继续使用现有存储配置；更换代码不需要重建数据库或重新添加示例。
