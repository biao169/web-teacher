# 文件夹增强第三步：接收端按目录保存（0.15.83）

## 完成内容

- 文件夹分享链接进入统一快传页面接收区，自动填入链接。信息检查返回类型、大小、文件数与目录数，不扣下载次数。
- 目录接收显式创建folder模式会话；旧单文件接收仍拒绝把目录当单文件。复用现有密钥绑定、身份、Origin/CSRF、下载次数、流量额度及逐块哈希校验。
- 新增接收会话的manifest分页、touch续期、finish最终保存确认操作。清单每次最多100项、请求仅接受会话密钥，不泄露内部缓存对象键；暂停、撤销、过期、清理后不可绕过检查读取。
- 接收身份自己的文件数、任务总大小、单文件大小限制在创建会话前检查。续期不改变下载确认位置、不降低限速所需的长租期，也不会复活到期会话或延长分享有效期。
- 浏览器再次校验路径、父目录、规范化冲突、偏移、数量和总大小后才创建本地子目录；同名子目录自动加后缀，遇到意外同名条目停止。
- 新的folderSink复用原receive-core：每次一个文件写入流；最多1 MiB网络块可以跨越多个文件边界，逐段写入对应文件。一个文件完整写入并close成功才记为已保存。
- 保留空目录和零字节文件，包括空根目录和尾部空文件；最后一块ACK不等同于整个目录完成，必须完成本地文件及空项处理后调用finish。
- 暂停/继续与丢失ACK恢复复用同一会话，不重复写入已确认的本地分块。完整成功、暂停、取消、能力不足、磁盘失败均有不同提示。传输期间阻止页面的普通下载按钮切走活动接收。
- 目录选择器在点击手势内调用；不支持目录写入的浏览器清晰提示，无自动压缩包降级。CSS与按钮复用现有前台样式，未新增数据库表或独立端口。

## 恢复与兼容边界

同页短时网络失败可以继续。刷新/关闭页面后不保留目录句柄，不承诺跨重启恢复。写入或close失败后不继续写可能损坏的流，需取消并排除本地故障后重新接收；已完成文件与可能的空占位保留，网站不会自行删除。新接收受原分享下载次数控制。受限浏览器和非安全上下文不能按目录保存；单文件原有下载仍可使用。权限、符号链接、修改时间等操作系统属性不保留。

本轮仅打通缓存目录发送和保存。局域网直连/在线中转目录协议属于第四步；真实Windows浏览器授权和跨设备联调仍需后续实际环境验收。
