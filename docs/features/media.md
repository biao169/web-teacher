# 媒体库、使用位置与回收站

媒体信息统一保存在原生media_assets表；文件使用已配置的本地媒体目录或R2媒体桶/前缀。上传、内容中的媒体外键和新闻HTML中的受管理图片/链接共用这份登记。前台文件是否公开，另由实际引用和可见性决定。

## 范围与列表

后台媒体库提供“媒体库”“回收站”“全部”三个范围及各自数量。默认显示正常媒体；回收站也可从/admin/media/trash进入。搜索、表头筛选/排序、10/20/50/100分页、列设置、固定首列和操作列沿用通用列表。清除追加筛选仍保留当前媒体范围。

“预览”为派生列：图片懒加载后以缩略尺寸呈现，PDF/视频/其他文件显示对应入口，点击查看详情。图片使用原文件，不额外生成磁盘缩略图；懒加载减少同时请求，但不把原图下载流量变成缩略图流量。图片首次失败后如重新加载成功，会恢复图片并清除旧提示，不再永久隐藏。预览失败时在文件标题旁显示“预览失败”按钮，打开状态窗口查看原因、重试或新标签打开原文件；该入口位于固定标题列，窄屏不会被其他固定列遮挡。

“使用位置”展示当前账号可见的来源分组、字段和数量。一个可见位置时直接新标签定位；多个位置在列表内打开来源窗口，按来源分组、每页20条读取。详情页复用相同清单。具备来源编辑权限时定位编辑表单的配置项，仅具备查看权限时进入该来源的筛选列表。受限来源只提示存在受保护引用，不输出其名称、标识或编辑链接。

预览和使用位置不是数据库列，支持调宽与隐藏，不向服务器发送不适用的排序/筛选字段。

## 引用覆盖

| 内容 | 媒体用途 |
| --- | --- |
| 教师与团队、学生 | 头像 |
| 网站设置 | Logo、网站图标、分享图片 |
| 论文 | PDF |
| 专利软著 | 证书 |
| 新闻动态 | 封面、HTML正文及当前生效英文译文中的受管理图片和链接 |
| 课程 | 教学大纲、课程资料 |
| 留言 | 附件 |

固定字段来自原生结构中的11个媒体外键，按object_key关联。正文按与HTML安全清理相同的规则精确解析/media/媒体UID节点；普通文本中出现地址、相似UID或带额外查询参数的地址不会被误计为实际引用。仅明确可公开阅读的正文节点可以授予正文媒体公开访问。

正文译文同时核对当前标记、成功状态、英文目标语言和来源摘要；来源改变后已经过时的译文不计为正在使用。译文来源需同时具有新闻及翻译查看权限才显示，定位进入对应翻译记录。手工译文、供应商译文及重新启用旧原文都会校验媒体状态，避免过期译文激活已回收文件。

只有保存到内容记录中的引用才显示使用位置。选择但未保存的草稿不建立引用，取消草稿也不自动删除上传文件。超出200000字符的导入正文不能完整核对时，相关候选媒体显示待核对并受到回收保护。

## 预览权限

详情页/admin/media/媒体UID/inspect提供图片、浏览器PDF、视频或文件信息。后台预览接口/api/admin/media/媒体UID/content要求有效登录及媒体查看权限，支持正常媒体和回收站媒体；响应不缓存。公开/media/媒体UID入口仍拒绝回收站资源。

预览根据文件签名决定内联类型，未知类型仅下载，不按元数据中的任意MIME执行。浏览器支持的PDF/视频可预览，无法显示时可打开原文件。单文件遵循20MiB实际大小上限；本地每块最多64KiB、R2每块最多1MiB，并校验对象版本。GET、HEAD和单Range共用实际有界读取，不先读取整文件再切片。新闻详情和草稿预览接入共享逐页PDF组件，媒体库检查页仍提供浏览器预览。见[新闻正文与PDF](news-body.md)。

external按授权重定向到外部地址，服务器不读取远程正文；其类型为用户声明、大小未知。static仍未接入当前存储。文件正文缺失会返回明确错误，详情中的元数据与引用仍可查看。目录存在性和未登记文件可通过“目录核对与清理”入口核对。

## 回收与恢复

单条回收或批量回收均检查所有实际引用，包括当前账号无权查看的来源。存在引用时保持原状态；解除引用后可以回收。回收仅更改active/trash状态，不删除对象；恢复重新设为active，不自动公开。

批量操作逐条提交，遇到冲突、权限或引用错误停止，显示已处理数量，剩余项目不继续。单条和批量复用同一状态服务；更新时间变化的旧页面操作被拒绝。回收站编辑标题/分类后，“保存并返回”仍回到回收站。

引用写入在事务内重查媒体状态。回收检查期间在既有admin_mutation_guards中保留最多5分钟的短时锁；引用保存和回收相互校验，过期检查不能提交，遗留过期锁不阻塞普通引用保存。状态和审计在同一数据库事务内完成，检查失败时释放本次锁。

永久清理由管理员预检并确认，系统不因到达保留天数自动删除。统一媒体选择器、富文本图片/PDF插入和图片裁剪已接入。媒体字段采用链接输入和选择/上传按钮，旁侧完整预览；内部保留有界原生键选项。

存储适配中R2对象大小与正文的接口含义参见[Cloudflare R2 Workers API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/#r2object-definition)。


## 编辑字段旁侧预览

所有11个原生媒体关联字段复用同一控件。教师/学生头像、站点Logo/图标/分享图片、动态封面、论文PDF、专利证书、课程大纲/资料和留言附件旁都可预览。选择已有媒体后立即更新；清空后显示未选择状态，预览不改变字段、不保存记录、不建立引用。

图片和视频使用完整等比显示（object-fit: contain），不会拉伸或裁掉边缘；横图上下留白，竖图左右留白。桌面并排显示输入与预览，手机压缩预览容器但保留完整内容。图片懒加载，视频只预载元数据；PDF及其他附件提供完整预览/文件信息入口。链接在新标签页打开，当前草稿保持。文件缺失、不可读取或已回收均有文字提示。实际加载失败时，预览旁显示原因、重试及原文件入口；重试只读取当前文件，不改动输入或保存草稿。快速连续切换选择时会取消旧查询，旧响应不能覆盖新预览。

## 媒体目录双向核对

/admin/media/audit提供目录报告和到期回收站两个区块。检查只覆盖配置的媒体目录或R2媒体前缀；缓存和快传存储不会参与媒体扫描。按登记主键分页检查数据库，再按本地目录游标或R2列表游标检查文件，每批最多20条新目录项/登记；可暂停或关闭页面，返回后继续。

报告分类为已匹配、登记但缺失、存在但未收录、大小有变化、无法处理、清理待重试及外部链接（未验证）。外链不执行目录检查。“已匹配”表示存在且字节数一致，不代表已验证内容摘要。扫描不读取所有文件正文；收录时才校验字节及摘要。分类筛选和报告分页按缓存批次呈现，每页不超过20条；单项重新核对显示最新状态，顶部分类数量仍代表原扫描时结果。

每个账号保持一个活动报告，报告仅本人可见，绑定当前存储配置，有效操作期限为24小时。最多1000个结果批次；达到上限时停止并提示处理报告。缓存分页保存，不载入整盘文件清单；本地游标恢复需跳过此前目录项，巨大单目录仍会增加读取耗时。扫描结果是核对线索，目录同时被外部程序修改可能使枚举重复或遗漏；停止外部修改后重新扫描确认。无权限目录、符号链接、Windows联接点、特殊文件及超过32层的路径不跟随，按无法处理呈现。

清除报告只分批删除当前账号的报告/预检缓存，不删除媒体或清理意图。24小时是操作有效期，非定时物理删除；账号不用报告后应清除，整个缓存目录也始终是可清理数据。

## 显式收录

在未收录分类选择1至10项后预检，全部预检通过才显示确认窗口。原始路径、目标路径与具体操作一并呈现。安全ASCII相对键原地登记；中文、空格等不符合媒体键约束的文件创建规范名称副本并登记，原文件保留，不自动重命名或删除。相同内容已经有登记副本时提示使用已有媒体，避免重复复制。

收录检查扩展名、全局允许类型、文件签名、20MiB与全局上传限额中的较小值，并遵守已有500MiB登记容量限制。摘要使用SHA-256。预检凭据绑定账号、文件版本和用途，30分钟内有效；提交重新读取校验，文件变化即停止。副本采用独占创建或R2条件写入，不能覆盖不同内容；数据库提交失败后留下的同一计划副本可复核后继续登记，源文件保持。

权限、配额、唯一对象键、登记与日志在数据库事务中检查/提交。批量按顺序执行，遇错停止并显示成功数量；无需重建库或重新填充示例。

## 到期回收站永久清理

使用原生media_trash_retention_days，按回收站记录updated_at判断到期；编辑回收站元数据也会更新该时间，因此重新计算保留期。候选区显示最早20条到期或待重试记录。每次选择1至10条，预检后再次明确确认永久删除。仅当前存储类型、trash状态、版本一致、达到当前保留期且没有任何实际引用的记录可清理；文件已缺失时仅清理符合条件的登记。

删除前在既有admin_mutation_guards表写入持久清理意图，再删除媒体对象，最后删除登记并记录审计；没有新增数据库表/字段。对象删除或数据库提交失败时，记录保留在回收站并显示待重试，不会被当作正常文件；此状态不能编辑或恢复，管理员重新预检后继续清理。清除扫描缓存不清除该意图。重复提交已经成功的同一计划不会重复删除其他条目。

文件删除与数据库提交不是跨系统原子事务。应用操作通过短时锁、版本检查和持久意图协调；本地删除和R2 delete均不能对外部写入提供最终原子版本条件。清理期间媒体目录/前缀应只由网站管理，勿同时从外部覆盖文件。到期清理没有后台常驻任务，也不会在日常启动时自动执行。


## 统一媒体选择器

所有媒体字段以链接输入框呈现，旁侧提供“选择 / 上传”、适用图片编辑和“清空”。一个共用弹窗支持搜索标题、对象键和分类，按分类及适用媒体类型筛选，以10/20项分页展示。每页只查询当前候选，不预加载全库；隐藏的原生键控件保留最近20个适用媒体及当前已选记录，旧选择不因超出首批而丢失。无JavaScript时可保存已登记媒体的链接；选择、上传、动态类型和图片编辑工具需要JavaScript。

| 配置项 | 允许选择类型 |
| --- | --- |
| 教师/学生头像、动态封面、网站Logo/图标/分享图片 | PNG、JPEG、GIF、WebP |
| 论文PDF、正文PDF插入 | PDF |
| 专利软著证书 | 图片或PDF |
| 课程大纲/资料、留言附件 | 程序支持的图片、PDF、MP4、WebM、ZIP |
| 正文图片插入 | PNG、JPEG、GIF、WebP |

候选只包含当前存储类型的active媒体。确认时重新验证目标模块的编辑或创建权限、可见范围、导航固定条件、媒体更新时间、实际存在性及大小。回收、丢失、变化或类型不适用的媒体不回填。图片类型也在最终内容保存及正文译文保存时检查，手工请求不能绕过界面限制。候选列表按登记元信息筛选，确认检查存在性/大小；不会为了搜索读取所有文件正文。

图片卡片完整等比展示，PDF/视频/ZIP显示类型入口；完整预览在新标签打开。取消或Escape保留原字段值，确认后仅回填该字段并更新旁侧预览。清空只移除本字段草稿中的选择，不删除文件。搜索失败可手动重试；新查询和关闭弹窗会取消旧请求，旧响应不能覆盖当前结果。

本地文件先显示文件名/大小及适用图片预览，可填写200字符以内的媒体标题和分类。上传按钮明确将文件加入媒体库；实际允许格式取字段规则、程序支持格式、全局允许列表的交集，单文件上限取全局值和20MiB的较小值。沿用500MiB登记配额、鉴权、签名检测和同一上传服务，不新增运行依赖。标题、分类与登记在同一事务保存。临时图片预览使用可撤销blob地址，关闭或切换文件后释放；仅后台页面允许该类图片地址。

上传成功后仍需确认选择并保存内容，才建立正式引用。关闭或停止等待不会自动删除已经上传的文件；浏览器取消请求不能保证服务器尚未完成上传，因此提示先检查媒体库，再决定是否重试。批次上传按顺序处理、失败即停，明确已经收到成功确认的数量；已成功的文件保留，不反复自动重试。

## 富文本受管理媒体

新闻HTML编辑区提供“插入图片”和“插入PDF”，共用选择器及上传服务。图片可填写替代文字，PDF可填写显示标题；正文以/media/媒体UID关联已登记对象。数据库保存普通受管理链接，新闻实际预览和详情将有效PDF链接按正文位置展开为PDF.js阅读组件；原生结构和快传保持独立。

本地图片粘贴或拖入使用当前正文光标位置，先打开选择器确认上传；一次最多10张，正文总计最多10个不同媒体。取消保留正文，上传失败保留原草稿及已经成功的媒体。插入前核对正文未在等待期间变化，使用一次编辑操作插入整组，支持编辑器撤销。原文和图片/PDF在同一个内容表单统一保存。

## 图片编辑与裁剪

图片字段旁的“编辑图片”、选择器选中一张图片时的“编辑图片”，以及本地单张图片预览旁的编辑入口，共用同一窗口。新闻正文插入图片也使用该选择器。多个待选文件需逐张编辑；PDF、视频和压缩包不提供图片裁剪。

| 能力 | 行为 |
| --- | --- |
| 比例 | 自由、原图、1:1、4:3、3:4、16:9、9:16和自定义整数宽高；切换比例给出居中范围，可继续重新框选 |
| 两次点击 | 第一次确定一个角，第二次确定相对角；支持四个方向，固定比例始终受原图边界约束 |
| 视图 | 25%–800%的适配视图缩放；鼠标滚轮、滑条、双指缩放，鼠标/单指拖动平移；缩放和平移不更改原图裁剪坐标 |
| 防误选 | 拖动超过6个显示像素、多指操作、指针取消和滚轮操作不会确定裁剪角；手势结束后短暂抑制选点 |
| 精确输入 | X、Y、宽、高使用原图像素，支持小数；固定比例由宽计算高，必须位于原图内 |
| 键盘 | 方向键平移，+ / −缩放，Home适配；数值框可完成精确框选，Escape取消当前图片编辑 |
| 撤销/重置 | 撤销当前待定角或最近区域，最多保留20份区域状态；重置全部恢复自由比例、全图和初始视图；适配视图不改变裁剪区 |
| 输出 | PNG或JPEG，受全局允许扩展名限制；配置长边，宽高均为64–4096像素，可缩小或放大输出 |

原图仅在浏览器解码和绘制。文件不超过20 MiB，单边不超过16000像素，总量不超过3200万像素；PNG/JPEG/GIF/WebP先检查头部尺寸，再由浏览器解码。头部仅检查前1 MiB，无法识别尺寸的文件提示换图，不尝试无限读取或服务端转码。GIF和动画WebP输出静态首帧；PNG保留透明区域，JPEG以白底合成，原始EXIF等元数据不复制到新文件。

“生成裁剪图片”只产生本地待上传文件，不立即修改媒体库或内容记录。预览满意后通过同一上传服务另存新媒体，原图片及其他引用保持不变；上传成功后替换本次待选项，确认选择并保存内容才更新对应引用。取消裁剪不改变待选项；取消整个选择器不改变表单原值；取消不删除已成功上传的媒体。

已有媒体在进入编辑前与上传裁剪结果时复核目标字段、权限、导航范围、来源版本及实际文件。固定媒体条件或缺少媒体创建权限时不能新增裁剪副本。上传接口检查CSRF、实际PNG/JPEG类型、头部尺寸、全局扩展名、单文件限额和共享媒体配额；不执行服务端图像解码，也不声称头部检查是完整图片解码验证。

输出超限可保留裁剪区域并调小尺寸或改用JPEG；上传失败保留本地裁剪文件和旧选择，允许明确重试。来源变化拒绝当前上传，应重新打开来源编辑。停止上传等待不能保证服务端未完成登记，需先查看媒体库。全部配色、字体、字号及画布遮罩/参考线颜色均由admin-theme.css统一控制。

粘贴的HTML图片只保留受管理媒体地址；Base64、外部图片和任意嵌入不作为正文图片保留。服务器仍使用共用HTML安全清理及真实引用检查。删除图片或PDF链接节点不会删除媒体库对象，保存后对应使用位置随真实内容变化。原版图片裁剪、浮动排版和PDF.js完整阅读仍有各自实现边界，不由媒体选择器代替。


## 媒体链接

所有11类字段及正文选择器支持本站链接和HTTP/HTTPS外链。外链登记、整表原子保存、类型声明、权限入口、未知大小、仅清理登记及CORS裁剪的完整规则见[媒体链接与统一控件](media-links.md)。本站文件签名验证和原有本地/R2存储规则继续适用。


## 图片预览状态与恢复

列表、详情、字段旁侧和选择器卡片共用同一加载控制器。成功加载清除旧错误，未进入视口的懒加载图片保持等待，不以尚未解码判断失败。失败后可显式重试；成功后保留原图片尺寸与方向，不生成压缩替代文件。列表用状态窗口保持行内容紧凑，详情、字段及卡片在预览旁显示操作。选择器的重试与选择按钮互相独立。

本地媒体失败后使用既有授权内容接口的HEAD检查，仍受同一登录/媒体权限控制；只读取签名所需的少量字节，不将整张图片代理或聚合到内存。登录过期、无权限、缺失、对象变化、超限和服务不可用分别提示。HEAD成功仅说明文件可读；若图片仍未显示，明确提示可能是传输中断或解码失败，不把可读等同于可预览。

迟到的诊断结果不能覆盖成功重试；页面片段替换、字段更新或关闭选择器会取消旧检查。重试等待较长时可再次操作或打开原文件，不自动无限请求。外链只由浏览器直接加载，不做服务端探测，不额外发起外部HEAD；重试保留原有签名查询参数。

预览与重试不改变登记、原文件、引用、回收状态或草稿。扩展名与签名不符的上传继续拒绝；已有文件若被外部程序替换成不受支持内容，仍按原有安全规则作为附件处理，不放宽类型限制。
