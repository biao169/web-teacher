# 发布包与更新时的数据保留

源码包和精简运行包使用相同的Python业务代码、前后台模板、静态资源、原生数据库结构、部署入口及功能说明。精简包省去开发测试、计划与验收图片，不包含Python解释器、虚拟环境、真实数据库或用户媒体。两个包共用根目录README，避免启动和更新说明分别维护。

发布清单记录每个文件的大小和SHA-256摘要。核验检查缺失、额外及内容变化的文件；复制到新release目录时拒绝覆盖既有目录，不自动切换当前服务。清单校验用于发现变化，不是数字签名或发行者身份认证。

普通启动只初始化空数据库，符合原生结构的现有库继续使用。它不恢复已删除的示例、不重设管理员或密码、不覆盖人工译文和服务配置，也不清理媒体、缓存和快传任务。已有会话在正常访问时更新活跃时间，这是会话续期行为。只有明确的示例命令添加缺少的演示条目，只有显式重置命令清空配置指向的数据库。

数据根目录也属于持久化地址：联合启动密钥保存在其下，即使主站与快传的六个存储地址都被单独指定，数据根仍必须在源码目录外。配置文件中的相对路径以配置文件目录为基准，环境变量保持优先。日志使用指定的主站缓存目录，当前日志及上一份日志轮换保留。Linux停服后的TIME_WAIT连接状态不再被误报为真实监听占用；Windows检查采用独占绑定，启动器始终不停止未知进程。

`TEACHER_VENV`可指定源码外的共享Python虚拟环境。依赖锁定文件摘要不变时启动器复用环境，不重新安装；依赖改变时按锁文件安装，并要求预编译包。该行为不验证用户后来手动删除或更换的第三方包，损坏环境需要修复。新闻Markdown功能使用Mistune 3.2.1；业务备份加密采用浏览器WebCrypto，未新增运行依赖。数据库和示例始终不由依赖安装流程修改。

两套Worker准备工具只整理资源，使用明确的UTF-8读取中文模板与JSON，并生成UTF-8 Python资源和SQL，不依赖Windows默认代码页。D1绑定名、R2桶和前缀继续分别配置；准备包不发布到Cloudflare，也不执行数据库初始化。生成的初始化SQL只适用于空数据库。

本地发布核验和运行检查不表示Windows实机、500MB VPS或真实Cloudflare已验证。目标平台适配状态与功能边界分别见[存储配置](storage.md)、[网站功能](native-features.md)及[快传](transfer.md)。
