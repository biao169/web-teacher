# 前台逐项优化第六步：0.15.63

按用户最终七步表格实施本步新闻与PDF，不提前扩展留言步骤。

## 改动

- 新闻列表和首页共用news-media封面组件：始终保留媒体区域，无图用第一分类首字，空分类使用N；英文有分类译文则用译文首字，无译文保留原文首字。图片完整适配；损坏图片沿用全站错误回退。新闻标题仍新标签打开。
- 新闻详情删除自动附加的封面，正文作者插入的图片保持原样。正文内登记为PDF的媒体链接转为阅读区：细分隔线、一次文件标题、一组查看/收起和按设置允许的下载操作；下一页是逐页加载的手动备用操作。正常状态不再显示重复的“按页阅读”等说明。
- 只读取global_settings的news_pdf_watermark及news_pdf_allow_download两个字段；转义后传给前台专用阅读配置，不传全局设置。下载关闭时不生成原文件打开/下载链接，无JS时提示启用JavaScript；下载开启时保留原文件入口。外部链接不代理或改写。
- 每页使用安全文本在线水印，随页面缩放、换行；不响应鼠标、不被选择，也不混入新闻正文复制。离屏画布释放、重新渲染及折叠展开后均保留正确水印；后台默认预览不加前台水印配置。
- 接近阅读区才读取PDF库与文档；保留Range分块、disableAutoFetch/disableStream、最多两个解析文档、三个画布、每画布约400万像素。长文档滚动追加页，也可手动下一页；保留错误重试、离屏释放、缩放重绘。英文界面的阅读状态及页按钮对应英文。收起后焦点回到查看按钮。
- 字体、字号、颜色及交互状态仍集中public-theme.css；布局位于academic.css，共用阅读器以显式前台标志隔离，不改变后台编辑、上传、保存流程。

## 边界

在线水印没有改写PDF文件，允许下载时得到原文件。隐藏下载按钮也不等于绝对防保存。若需下载文件内嵌水印，须按原规划单独明确服务端生成/缓存范围，本版未增加该功能。逐页渲染不表示服务端逐页拆文件；PDF.js按文件结构读取字节，部分文档可能需要更多数据。两个文档/三个画布约束不代表解析器总内存固定。

没有数据库迁移、部署或用户实际数据修改。后台管理模板、数据库、快传和部署代码与0.15.62一致；news_body默认参数保留后台预览原标记，news-reader保留后台默认展示行为。新增服务端工作仅为新闻前台读取两项现有配置及安全标记输出。
