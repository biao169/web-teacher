# 业务数据导出、加密备份与恢复

## 入口与数据范围

后台“数据与备份”（`/admin/data_tools`，也支持 `/admin/import-export`）复用后台侧栏、置顶区块导航、固定底栏、字段说明和气泡通知。可选择15张业务表：媒体库、教师、网站设置、全局设置、导航、研究方向、论文、项目、专利、学生、学生分类、新闻、课程、留言、翻译。

跨表操作需要系统管理员身份、数据工具权限和所选模块权限；新增、更新、删除分别核对对应授权。服务端检查同源请求、会话和CSRF，最终事务再次检查当前角色、权限及数据更新时间。普通代码更新和服务启动不会触发任何恢复、清空或示例填充。

## 文件格式

| 格式 | 功能 | 内容边界 |
| --- | --- | --- |
| JSON | 完整业务字段交换，导入及导出 | 去掉数据库服务密钥及内部运行任务，不截短正文；安全导入保留目标已有密钥 |
| CSV | 单表导出供表格查看 | UTF-8 BOM，保留换行/引号；公式前缀转为文本；不支持CSV导入 |
| ACMS | 在浏览器加密/解密的业务备份 | 可保留数据库内的服务密钥，选配本地/R2媒体正文；与JSON复用同一恢复校验 |

业务备份排除账号、角色、权限、会话、操作日志、限流状态、部署环境变量及独立快传数据库/文件。它不是整机或完整数据库灾难恢复镜像。本地完整数据库使用 `backend.maintenance.backup`，媒体及快传存储另行备份；网站业务恢复不撤销或替换当前管理账号。

JSON内部格式为 `academic-cms-python-data-v1`。ACMS外层为 `academic-cms-python-acms-v1`，采用AES-256-GCM、128位认证标签、16字节随机盐、12字节随机IV；PBKDF2-SHA256固定600000次，派生256位密钥，格式标识参与认证。口令15–128位。口令仅用于当前浏览器的原生WebCrypto，不进入服务器、URL、日志或浏览器持久存储。浏览器必须支持安全上下文；错误口令、密文被改动或异常KDF参数均拒绝。原始主站原版ACMS二进制格式未提供，不宣称该文件格式与旧包互通；数据库结构仍完全遵循原生DDL。

## 预检与事务恢复

预检显示每张表预计新增、更新、删除数量，以及字段、唯一值、引用和媒体错误。错误列表不回显密钥正文。确认恢复前不修改业务表。已有记录以UID合并，保留本地数字ID及创建时间；新记录获得本地数字ID，所有恢复记录取得新的更新时间。

合并模式只新增或更新文件中的记录；替换模式还删除所选表中未出现在文件里的记录，执行前必须输入“替换所选表”。未选表保持原样；跨表外键、正文媒体、媒体回收状态和类型、导航唯一标识均受检查。仍被使用的媒体不允许从登记表删除，恢复不永久删除原媒体对象。

预检票据为随机标识，绑定会话、文件摘要、所选表、模式和所有业务UID/更新时间，有效期10分钟。业务数据变化、票据被取消、会话变化或授权被撤回都会阻止执行；执行成功后票据不能重放。为控制磁盘占用，全站只保留一个有效恢复预检；同会话新预检替换旧预检，其他会话等待有效期结束或取消。下一次预检清理上一份到期暂存；普通启动不清理用户缓存目录。

所有业务SQL及操作日志在同一个SQLite/D1批次事务提交，外键延后至提交时核对；普通编辑仍保留原25语句限制，恢复专用事务最多64条。失败不会留下部分业务记录。恢复全局设置清除旧翻译批次运行状态；设置和导航每请求读取，论文查询缓存包含设置更新时间，旧设置候选失效；译文展示仍按原文摘要判断是否适用。

## 媒体随包与暂存

选择媒体库及ACMS时可以包含受管理的本地/R2媒体，活跃和回收站登记均可导出。外链和静态资源不复制，浏览器不会请求外部URL获取文件。随包文件包括大小和SHA-256摘要。

浏览器解密后先发送记录/文件清单，再逐个发送媒体正文到配置的缓存位置；服务器不接收整个含Base64媒体的解密大包。媒体字节、扩展名、长度和摘要校验后才暂存。提交时复核文件，将缺失对象独占创建到配置的媒体位置；同名同内容复用，同名不同内容停止恢复。数据库失败时删除本次新建对象，原有文件保持原样。运行中断留下的未登记文件由现有媒体目录核对功能发现。

只有媒体登记而没有正文时，要求目标原文件存在且大小一致。独立目录、R2绑定及媒体/缓存前缀继续取自统一部署配置。VPS暂存文件沿用私有文件权限，缓存不作为公开媒体入口。

## 容量与平台边界

| 项目 | 当前上限 |
| --- | --- |
| 导出 | 20000条，字段字节合计4MiB，编码后8MiB |
| 在线恢复 | 所选记录共500条，记录与媒体清单4MiB，每表900KiB |
| 在线预检基线 | 全站业务UID/更新时间清单最多20000条 |
| 浏览器备份文件 | 48MiB，解密后文档32MiB |
| 随包媒体 | 最多100个对象，原始总大小24MiB，单个20MiB |
| 服务端媒体请求 | 每次一个原始文件，按清单长度限制，不超过20MiB |

原始设计的32MiB解密容量保留在浏览器；面向小内存服务器，记录请求另设4MiB及单表900KiB限制，媒体单独暂存。导出上限大于在线恢复上限，超限必须缩小范围或采用数据库维护工具，不会自动截断。D1还受账户每请求查询次数、事务时长和数据库容量限制；多表恢复可能超过免费查询配额，应缩小所选表或采用适合的配额，不能把本地D1适配器验证等同于真实云端容量验证。

本阶段没有新增Python或前端运行依赖，不需要Node或服务器编译。Windows实机、500MB VPS与v2ray/Caddy共存、真实Cloudflare配额及进程峰值内存尚未实测。

## 技术依据

浏览器加密接口与安全上下文要求参考[WebCrypto encrypt](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt)；云端实际数据库约束以[Cloudflare D1 Limits](https://developers.cloudflare.com/d1/platform/limits/)为准。
