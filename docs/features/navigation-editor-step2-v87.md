# 导航固定筛选第二步（0.15.87）

## 使用

1. 打开后台“导航与按钮”，新建或编辑导航。
2. 选择顶部、首页或页脚位置，类型为站内页面或按钮，选择内容模块。
3. 添加字段与值。名称等文本默认“包含”，也可选“等于”；枚举等精确字段仅允许“等于”。最多12个不同字段，多个条件取交集。
4. 预览匹配的公开记录，可翻页。预览不会保存导航，也不会显示隐藏记录及项目金额、负责人、成员。
5. 保存后重新编辑，条件完整回显。清空条件恢复普通模块链接；草稿重置保留标题等其他字段。

若将前台包含条件切换到后台位置，需要显式改成等于；不静默删除或改变原条件。目标模块查看权限、CSRF和原编辑权限继续生效。

## 实现与边界

复用原 navigation 模板、控制器、辅助接口、条件白名单、Content.listing 和结果分页模板。没有新数据库表或SQL初始化文件。条件保存在现有path中，使用nf Base64URL编码；中文值可恢复，地址仅ASCII。自动生成可编辑的ASCII标识并校验唯一性，编码不用于保密。

前台条件预览按公开可见性及公开字段投影查询，即使管理员也不会看到项目私密数据。后台入口保留原f.精确相等协议。快速修改条件、切换类型和保存时取消旧请求，旧预览不能覆盖新草稿；输入法组合期间不自动预览。

本步是配置层交付：带nf固定配置的导航尚不输出到前台，避免其落入未受限普通列表。普通导航继续显示。第三步将使用/en/n/ASCII标识与/zh/n/ASCII标识，由服务器读取固定范围，防止用户查询参数扩大范围；同时接入ASCII临时查询状态。动态选项翻译与缓存译文搜索在第四步实现。
