# 文件夹增强第一步：选择与清单（0.15.81）

快传前台新增独立文件夹预览区，复用已有布局、主题字体/颜色、大小显示函数和发送/接收区域切换。三种单文件传输方式不改协议或接口。

## 本轮可用

- 原生目录选择：安全上下文且支持 showDirectoryPicker 时，以只读方式请求用户授权，枚举文件和目录，保留空目录。
- 兼容选择：webkitdirectory + webkitRelativePath，保留文件相对路径和可推导的父目录。该方式无法识别空目录，界面明确提示。
- 拖放一个根文件夹：同步获取拖放句柄，优先原生句柄，兼容 webkitGetAsEntry；旧目录读取器循环读取所有批次，避免只取第一批。
- 本地清单包含根目录名、条目类型、相对路径、大小、最后修改时间、文件引用及计数。只读取元数据，不读取文件内容、不上传、不压缩。
- 按目录层级排序，子项紧跟父目录，每页展示100项。显示文件数、含根目录的目录数、总大小、扫描状态，支持取消和清除；过期异步结果不覆盖新选择。
- 拒绝路径穿越、绝对路径、反斜杠、跨平台非法/保留名称、大小写或Unicode等价冲突、文件/目录同路径冲突；总大小采用安全整数检查。
- 本地预览保护上限为10000文件、2000目录、32层、相对路径1024字符；不是后台传输额度，不新增后台配置项。

## 明确边界

这是第一步，不创建文件夹任务，不产生分享链接/配对码，不开始发送，也不写接收端目录。页面明确提示后续功能尚未接入；原有单文件传输仍可使用。

目录清单保存在当前页面内存，关闭或刷新页面会失去选择。文件引用不写入数据库或浏览器存储。空文件允许进入清单，后续任务协议需专门处理零字节文件。当前不承诺保留操作系统权限、符号链接等文件系统属性。
