# 前台固定入口与ASCII查询状态（0.15.88）

## 完成内容

- 复用现有导航记录的url_name和path，不新增表或SQL文件。顶部、首页、页脚固定按钮生成/en/n/slug和/zh/n/slug。
- 每次请求重新查询启用状态、导航可见性、公开显示位置、目标模块及固定条件。失效、重复标识、错误目标和非法配置均拒绝访问。
- 公开可见性 AND 服务端固定条件 AND 访客临时条件，先统计再分页。项目私密字段仍按当前管理员身份决定是否投影；固定字段和下拉项不允许使用私密字段。
- 保留列表模板、排序、学生分类及分片加载。下拉选项首次显示及“更多选项”仅统计固定范围。重置回到同一入口。
- 搜索和字段条件通过UTF-8 JSON/Base64URL的s参数编码。服务器校验字段白名单、值长度、重复键、编码结构、分页和排序参数。条件编码仅用于ASCII URL，不是加密或授权凭据。
- 原始q/f./c.列表链接和无JavaScript的GET表单由服务器规范成编码链接。分页页码、数量和排序方向保留可读ASCII参数。非法或试图覆盖固定配置的参数被拒绝。
- 详情使用同一固定入口下的条目地址；简介、引文和下拉API携带nav上下文重新解析范围。移除上下文后是独立的普通公开页面，并不代表该记录拥有额外可见权限。
- 分页和按需读取携带导航版本摘要nv。入口修改后旧摘要返回409，停用或不再可见返回404，避免旧页面继续混入新范围。移除固定条件后旧固定地址404，普通导航恢复。
- 中英文切换保留入口和当前查询；前台按钮与后台配置一致。列表及按需响应禁止缓存。

## 使用示例

导航位置选“顶部导航”，目标选“项目”，英文标识ai-projects；添加“名称/包含/人工智能”，再添加“状态/等于/进行中”。

访问/en/n/ai-projects显示同时满足条件的公开项目。在搜索框输入“医疗”后，只检索上述范围中包含“医疗”的项目；清空或重置恢复原来的两项固定条件。后台修改固定关键词不改变入口地址。

固定条件仍按数据库原值匹配。没有译文的中文记录目前不会凭空匹配英文同义词；第四步接入已有有效缓存译文，不在搜索时调用在线翻译。
