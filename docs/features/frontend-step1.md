# 前台第一步：视觉基础与交互样稿（0.15.44）

## 范围与打开方法

本步完成原生 HTML、CSS、JavaScript 前台样稿，没有替换网站当前运行的前台，也没有修改任何后台功能。无需部署、构建或连接数据库。

解压后，用浏览器打开 `frontend/public/static/design-preview/index.html`。保持该目录及 `frontend/shared/static/vendor/bootstrap.min.css` 的相对位置。单独交付的 `teacher-site-frontend-preview.html` 已内嵌全部资源，可直接打开。不要将样稿当作真实网站入口；它使用明确标注的虚构数据，登录、发送、接收不会请求任何业务接口。

顶部“预览状态”可切换无首页教师、普通用户、管理用户、开放注册和精简导航；“窄屏预览”将容器限制为390px，也可直接调整浏览器宽度。新闻标题和详情按钮打开新标签；样稿文件需下载到本地后测试该能力。

## 视觉规范

| 项目 | 实施值与用途 |
| --- | --- |
| 正文 / 次要文字 | #213b4b / #607680，标题层次主要靠字号与字重 |
| 强调色 | #1c6e6a，链接、来源与计划、当前导航、焦点 |
| 页面 / 卡片 | #f8fafb / #ffffff，细边界#dce5e7 |
| 最大内容宽度 | 1180px，桌面左右32px，窄屏16px |
| 卡片 | 单列、10px圆角、18×20px内边距、11px卡片间距；窄屏14×12px |
| 字号 | 正文14px，卡片标题16px，次要信息12–13px；不通过极小字号强行挤成一行 |
| 交互 | 160ms颜色、边界与轻阴影反馈；尊重减少动画偏好 |
| 媒体 | contain、透明背景、无边框、完整居中；人物不采用圆形裁切 |
| 宽度适应 | 1050px以下导航移到下一行；650px以下调整工具行与卡片布局；极窄导航内部滚动 |
| 控件 | 原生表单、语义按钮、键盘焦点、名称与状态提示，样稿按钮图标为内联SVG |

视觉样式全部限定在 `.academic-public` 下，样稿工具条/对话框采用独立前缀。现有共享Bootstrap仅作为基础库，没有改动共享样式和管理端主题。

| 组件 | 本步可以检查的行为 | 真实接入时复用 |

| 页头 | 品牌、居中导航、窄屏换行、胶囊语言切换、账号状态 | 统一前台页头模板，导航由已有配置传入 |

| 复制 | 按当前列表顺序复制公开文本，过滤标签/操作，保留通讯作者星标，失败提供手动复制 | 不使用卡片innerText；无用户点击不访问剪贴板 |

| 页脚 | 同主题HTML结构、文字与示例按钮布局 | 继续调用现有HTML清洗与动态按钮插槽 |

样稿只筛选内置少量示例，未冒充全库查询；页码仅展示一页。首页样例条数不代表配置已生效。没有上传进度模拟、虚构P2P模式、真实登录或自动下载。登录框不接受真实账号密码，避免用户误把样稿当作登录页面。

## 前台数据契约与批准清单

下面是后续接线要求，不表示本步已经修改这些功能。服务端目前与后台功能共用文件，因此即使是公开读取也需先获得具体授权。

| 事项 | 已存在 / 缺口 | 涉及位置 | 建议顺序 |
| --- | --- | --- | --- |
| 首页教师 | homepage_profile_uid存在；当前未设置时仍可能列出多位教师 | backend/app/native/web.py公开首页准备 | 第二步最小公开读取修正；缺失/不可公开时仅回退站点标题副标题 |
| 论文、新闻条数 | homepage_publication_limit、homepage_news_limit存在；先取10条再截断，0回退默认 | 同上 | 第二步修正取数与0值含义；不改变后台设置表单 |
| 项目首页条数 | homepage_project_limit尚不存在 | database/native及后台网站设置字段注册 | 第二步单独批准新增字段和显式无损迁移；未批准不新增 |
| 受控导航与图标 | 当前导航准备丢失图标，hero/header混合 | backend/app/native/public_footer.py、公开路由 | 第二步保留图标、区分位置，继续复用可见性与排序判断 |
| 登录状态 | principal、admin_menu、csrf已有；独立前台登录与注册标志缺口 | backend/app/native/web.py认证/公开上下文 | 后续新增前台入口前批准；不改原后台登录行为 |
| 筛选和序号 | 公开搜索分页排序已有；完整分类聚合缺失 | 公开只读查询准备层 | 第三/四步批准完整分类读取，公开总数用于跨页序号 |
| 媒体 | UID地址映射已有，MIME上下文不完整 | 公开媒体准备 | 按真实媒体类型接入；不只凭扩展名猜测 |
| 快传 | /与/admin共用模板；匿名落地与不扣次数元信息缺口 | transfer/backend/native.py | 第五步批准最小路由分流，保持配额/上传/下载授权逻辑 |

推荐第二步先处理首页模板与现有字段的布局接线。进入上述服务端修改前，按具体文件和最小补丁征询用户，不能把“继续第二步”视为对所有后台修改的概括批准。

## 可供后续正式接线的HTML页脚

现有清洗器允许下面的结构和class。`data-footer-navigation`由既有页脚逻辑替换为后台配置的footer位置按钮，不在HTML里写死动态按钮。不改变现有清洗器或放开任意脚本。

```html
<section class="footer-grid">
  <div class="footer-brand">
    <strong>探索知识，连接未来。</strong>
    <p class="footer-note">教师学术网站 · Research &amp; Discovery</p>
  </div>
  <nav data-footer-navigation aria-label="页脚导航"></nav>
</section>
```
