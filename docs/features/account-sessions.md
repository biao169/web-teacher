# 账号登录会话

已有账号的单页编辑包含“登录会话”区块，沿用顶部区块目录和固定保存栏。新账号尚无会话，不显示此区。此功能仅供拥有账号查看、编辑权限及目标记录可见范围的系统管理员使用，普通角色即使获授账号模块权限也不能进入。

## 显示与查询

会话列表展示编号、状态、登录时间、最近活动、失效时间及撤销原因。状态分为活动、已过期和已撤销；“活动”表示未撤销且闲置、最长有效期均未到期，账号与角色的有效状态仍由每次请求重新验证。当前浏览器会话附有文字标识和操作保护。

编号支持包含搜索，状态有计数；登录时间、最近活动、最晚失效时间支持正反排序。每页可选10、20、50、100条，使用共享数字分页，页码过多时显示首尾和相邻页。切换筛选、每页数量、页码或刷新会清空本页选择，账号草稿保持不变。

时间沿用后台统一格式`YYYY-MM-DD HH:mm:ss`及当前UTC展示设置。闲置期限为最近活动后30分钟，上限为登录后12小时；失效列展示两者中较早的时间，悬停可以查看两个期限。已撤销记录显示撤销时间及原因，过期、已撤销记录保留历史。

会话编号可能截断，悬停显示完整值。列表内部水平滚动，选择列、编号列和操作列固定；窄屏工具条换行，页面不发生横向溢出。状态同时使用图标、文字和主题语义色；颜色、字体、字号由`frontend/admin/static/css/admin-theme.css`集中控制。

## 撤销行为

- 单条撤销：只撤销该行活动会话。
- 撤销所选：仅处理本页勾选的活动会话，一次最多100条；任何标识不属于该账号、已失效或事务检查失败时，整批撤销及日志均不提交。
- 撤销其他活动会话：管理自身账号时保留当前浏览器；管理其他账号时撤销该账号的全部活动会话。此操作覆盖执行时的全部活动会话，不受搜索条件、当前页和每页数量限制，也包含打开列表后新建立的登录。

所有撤销都需要明确确认，成功后立即生效，下次请求必须重新登录。撤销不删除账号、内容或会话历史。当前浏览器不能通过选择或伪造请求被本功能撤销；退出自身登录仍使用既有退出入口。

会话操作独立于账号资料保存，既不提交账号草稿，也不更新账号表单原有的版本值。请求期间阻止并行点击保存；结果使用顶部气泡，不插入表格上方造成跳动。撤销成功后只刷新会话区；刷新失败会区分“撤销已成功”和“请求结果待核对”，不会自动重复写请求。

账号资料在另一页面改变时，旧会话区的操作被拒绝，刷新本区后需重新确认。所选会话在服务端读取最新原生`updated_at`，再在事务内比较，因此普通浏览产生的心跳不会因为页面上的旧时间而反复冲突；读取和提交之间再次变化仍会使整批回滚。全部模式按执行时的活动集合处理，以目标账号版本、当前权限和会话有效状态作为事务门禁。

## 权限、数据与资源

HTTP层复用同源检查、会话CSRF及导航解析；服务层复用账号可见范围、系统管理员限制和原子审计。事务再次检查当前会话、账号/角色版本、系统角色及账号查看/编辑权限。会话撤销原因使用原生`admin_revoked`，操作日志记录目标账号、操作种类和所选数量等元数据。

只使用现有`auth_sessions`、`auth_users`、`auth_roles`、`auth_permissions`、`admin_mutation_guards`和`operation_logs`；数据库表、字段及DDL不变。读取仅选择非敏感字段，不向模板或API返回令牌摘要、密码摘要、设备指纹。原生表没有设备名称或IP地址，因此界面不推测或虚构这些信息。

单页最多100条；所选写入按30个标识分组，整个事务最多15条SQL，单条绑定参数不超过100；全部撤销直接在SQL中执行并只返回数量，不在Python或浏览器内载入全部历史。历史不会自动清理，长期累积会增加磁盘占用和查询工作量。没有新增后台进程、依赖或前端编译步骤。

本功能仅管理主站登录。独立快传已签发的会话、访问令牌及进行中的任务继续由快传控制，不会随主站会话撤销而自动终止。公共用户的自助会话面板、设备/IP采集、登录通知及自动清理策略不包含在此功能内。
