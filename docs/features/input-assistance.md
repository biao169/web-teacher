# 历史写法与引用解析

辅助输入复用已保存的字段值和原版引用解析方法。历史候选来自当前账号有权查看的数据，引用解析在浏览器本地完成，不调用外部AI或元数据服务。所有选择仍需通过原编辑页统一保存。

## 历史字段范围

| 模块 | 可查询的字段 | 支持多个值的字段 |
| --- | --- | --- |
| 教师 | 角色、职称、单位、实验室 | 无 |
| 论文 | 期刊/会议、年份、作者、论文类型、作者角色、通讯作者、索引类型、展示标签、关键词 | 除期刊/会议、年份外的其余字段 |
| 项目 | 来源、基金、承担角色、负责人、成员、状态 | 承担角色、成员 |
| 专利软著 | 国家、类型、发明人、权利人、法律状态 | 发明人、权利人 |
| 学生 | 培养层次、分类、年级、方向、状态 | 分类、方向 |
| 学生分类 | 匹配关键词 | 匹配关键词 |
| 新闻 | 分类 | 无 |
| 课程 | 学期、授课对象 | 授课对象 |
| 媒体 | 分类 | 分类 |

共9个模块、34个字段使用同一服务端目录。表单聚焦或输入后显示历史建议；点击或使用上下方向键、Enter选择，Escape关闭。中文输入法组字期间不发出中间查询，输入结束后再读取候选；服务失败可手动重试，原输入保持可编辑。

多个值使用英文分号、中文分号或换行分隔。建议匹配光标所在片段，选中后只替换该片段，保留前后的值及分隔符。姓名或单位内部的逗号保留，例如 `Smith, Alice` 不会拆为两个人。其他片段中已经选用的候选会排除。

候选按最近更新时间优先，规范化宽窄字符、大小写和空白后去重，呈现时保留已有写法。查询使用文本包含匹配，英文字母忽略大小写，中文按输入片段匹配；这不是全库分类统计或通用模糊拼写搜索。

## 独立历史词库

`/admin/translation/suggestions` 提供模块、字段和关键词查询。只显示当前账号有查看权限的模块，支持点击候选复制；浏览器不允许复制时可手动选取文本。模块、字段或关键词变化会清除上一组结果。

支持历史建议的编辑页提供“历史词库”入口，在新标签页打开，保留当前草稿。查询关键词通过请求正文提交；地址不携带关键词或候选内容。

## 权限、范围与资源

`POST /api/assistance/suggestions` 接受 `_csrf`、`table`、`field`、`query`、`exclude`，以及可选的 `nav`、`nav_stamp`。仅允许目录中的模块和字段，不允许查询账号、密钥、联系方式或任意数据库列。

查询需要当前模块查看权限，并在数据库中按账号可见范围筛选。从固定导航打开的表单还会提交导航标识和版本，候选只取该固定范围内的记录；导航改变后旧上下文查询被拒绝。媒体只使用正常状态的记录。

每次最多读取最近300条匹配记录，只投影目标字段，最多返回50项。单个候选和搜索片段最多240个字符，已选项最多50项；超过4096个字符的来源字段不参与建议，避免截断后形成错误候选。读取上限不表示数据库实际扫描量恒定，较大数据集的搜索与排序成本仍由数据库承担。

浏览器合并短时间内的输入请求并取消旧请求，不在本地长期缓存候选，避免切换账号或权限后复用旧结果。查询不写业务数据或审计记录，不增加数据库表、缓存文件、服务进程或运行依赖。

## 原始引用解析

论文“原始引用与输入辅助”区保留唯一的 `source_citation` 多行输入框。粘贴一条引文后点击解析，支持GB/T、APA、IEEE、Elsevier及BibTeX，显示识别格式、规则匹配完整度和人工核对提示。完整度依据已识别字段数量估算，不代表结果正确的概率。

解析可建议题名、作者、期刊/会议、年份、卷期页、DOI、URL、论文类型及关键词。空值、额外字段、摘要和非HTTP/HTTPS链接不会成为回填选项；网页标记以普通文本显示。没有英文标题或摘要编辑区。

解析结果与DOI查询共用一套差异面板，在当前辅助区显示来源、当前值和建议值。已有值的差异默认不勾选，空字段可预选；点击回填才更新选中字段，同时更新未保护的引文。手工引文和高亮继续受保护。

单项撤销和整组撤销共用最近一次回填历史；不同辅助来源再次回填会替换这组历史。后续手工修改的字段保留，原始引用文本也保留。原文修改后旧解析建议失效；点击解析会取消尚未完成的DOI查询，晚响应不能替换较新的解析结果。

单次解析上限20000个字符。空文本、超长文本或无法处理的内容会显示提示，原文不会被丢弃。成功回填及原文均需通过底部保存按钮持久化，继续受权限、CSRF、版本和固定导航范围保护。

引文标点、姓名缩写、题名中的句点及非标准排版可能存在歧义。解析不保证准确还原每位作者，应重点检查作者分隔和卷期页。题名查询、多供应商检索/回退及独立DOI查询页仍属于后续专题。
