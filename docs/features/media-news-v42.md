# 媒体与新闻图片优化（0.15.42）

## 回收站手动永久删除

修正手动删除复用到期清理规则而提示“尚未达到当前设置的回收站保留期”的问题。媒体回收站单条和批量永久删除均不再等待保留期，也不需要额外勾选“立即删除”。拥有媒体删除权限的普通管理员同样可以操作，不限定系统管理员。

仍先预检再确认，检查媒体处于回收站、当前权限和导航范围、没有内容引用、数据库版本和磁盘文件版本一致。确认后删除文件及数据库登记；外部链接只删除本站登记。批量遇错停止，响应丢失后可按现有机制重新预检重试。自动/目录核对的到期清理仍执行保留期规则。

## 大小/KB

默认列宽100px，支持原有拖动列宽；主动保存的个人列宽保留。整数显示，按1024字节向上取整：1至1024字节显示1，1536字节显示2。悬停可看原始字节数。外链大小显示“—”，悬停说明未核验远程大小。排序和数据库仍使用字节；精确筛选仍支持KB小数，不改变已有查询和导出约定。

## 新闻富文本图片

正文格式选择富文本后，使用原有“插入图片”按钮。插入后自动选中图片；也可点击已有图片，在“当前图片”面板操作：

- 靠左、靠右、居中；原来的左右文字环绕和宽图仍可选。
- 宽度：1至4096px，或正文容器宽度的1至100%。留空采用自动宽度。
- 高度：1至4096px，留空按原图比例缩放。
- 最小宽度、最小高度：1至4096px，留空不设置；最小宽度不会突破正文容器。
- 0.15.43起尺寸输入即时更新，不必另点应用；“确认图片尺寸”用于主动校验。操作先修改草稿，保存新闻后正式生效。
- 拖动图片到正文的新位置；一次移动对应一次撤销，重做会保留图片尺寸、排版和替代文字。兼容两种浏览器光标定位接口。

同时指定宽高时通过contain保持图片内容比例，尺寸框内可能留白；通常只填写宽度、让高度自动即可。最小尺寸高于指定尺寸时以最小尺寸为准；窄屏限制图片不超出容器。原媒体文件不被缩放或裁剪，不复制上传文件。

原有安全清洗会去掉任意内联样式，本版只允许受限的数字图片尺寸属性，并在服务端生成对应CSS；不放开任意style、事件属性或外部图片地址。保存、实际效果预览和公开新闻页共用处理规则，PDF正文展开仍正常。尺寸和排版只适用于富文本，转换为纯文本或Markdown可能丢失格式，沿用原转换提示及草稿恢复。

## 升级与验证

沿用0.15.41的全部功能，无数据库结构变更。升级前停服备份，保留原数据库、媒体与配置。早于0.15.38的数据库仍须先完成原媒体字段安全升级。

验证包括：未到期文件手动单条/批量删除、非系统管理员成功删除与权限撤销、引用/版本/确认保护、自动清理保留期、整数列宽，以及项目自带Quill 2.0.3在模拟DOM中的尺寸回填、重新打开、拖放、撤销/重做；通过服务端保存、草稿预览和公开新闻的尺寸一致性检查。完整回归197项Python测试和43项模拟DOM测试通过，142个Python文件语法检查通过，Cloudflare本地构建与资源编译成功；数据库文件与0.15.41一致。真实Windows浏览器布局和触控交互仍需目标环境验收。
