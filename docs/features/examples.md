# 成套示例中心

后台“数据与备份 → 示例中心”提供16组、共113条新版示例。系统管理员可按组勾选添加，逐项显示进度，随时暂停；刷新页面只读取已存在数量，不自动继续。添加前仍检查数据工具、目标模块及关联模块权限；运行中撤权会阻止后续写入。

| 示例组 | 数量 | 可查看的效果 |
| --- | --- | --- |

| 教师与团队 | 10 | 中英文姓名、头像、教育与经历、精选排序及隐藏记录 |

先添加媒体，再添加引用它的内容；新闻还依赖论文、项目及学生，账号依赖角色，翻译依赖其原文。全选时按此顺序执行。已回收、缺失或大小变化的关联媒体不会自动恢复；修改过的原文不会被填入预置译文。

新版与旧版约90条基础示例使用不同标识。再次添加只补新版缺失记录，保留已经编辑的记录、附件和权限。删除过的新版业务记录可通过再次明确添加补回；示例媒体登记尚在时不会因为文件缺失而自动上传替换。中途失败停止本次添加，已经提交的记录保留；刷新核对后再继续。旧版数据集标记不会覆盖新版标记。

示例人物、单位、项目及成果均为虚构，图片和PDF为原创演示材料。添加会写入实际数据库、占用媒体存储并产生真实操作日志。人工示例译文标记为人工来源，不调用任何外部翻译服务，不发送邮件。

示例角色不会分配给现有账号，也不会修改真实管理员。需要使用示例账号时，由管理员在账号编辑页自行设置密码并启用；没有通用密码。普通启动、更新以及打开示例中心都不会填充示例或重置配置。

## 联动操作

页面下方连接现有服务设置、账号会话、操作日志、备份与恢复及快传功能。全局设置保持当前值，五种翻译通道和论文检索配置由原有页面展示。会话由真实登录产生，日志由实际操作产生；备份通过已有导出/加密/恢复功能体验，不伪造历史。

快传管理员在独立工具的“示例任务”区分别生成可下载、已暂停、已撤销的小文本任务及辅助缓存。它们使用真实上传、额度结算和状态控制，受当前服务启用、分享规则、权限及容量限制。按钮不会替用户启用服务或放宽额度；未保存的设置草稿保留。任务示例可以使用正常任务控制和缓存管理功能清理。重复点击保持已有状态，已经清理或中断的场景不会自动重建；中断后可通过任务及缓存列表核对已保存部分。

## 命令行入口

`add-demo-data.cmd`或`python -m backend.cli seed-examples`使用同一新版示例服务，要求输入已有系统管理员账号和密码。Windows入口应在本站服务停止时运行；在线添加请使用示例中心。无管理员时先运行普通启动入口完成初始化。控制台登录也产生真实会话并在结束后注销。

旧`seed`命令和独立基础演示启动脚本保留原有约90条基础样例，供基础演示与已有流程使用；不会升级已有条目的内容。两个数据集都只在明确调用时添加。
