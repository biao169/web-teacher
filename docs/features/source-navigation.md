# 原文对照与来源定位

翻译编辑页上方使用“原文与译文”区块：宽屏左右排列，手机上下排列。原文是该条译文对应的已保存快照，译文沿用现有整表保存、人工保护和版本校验。语言、状态、人工标记和服务来源显示在对照区上方。

原文与当前来源文字或摘要不一致时，显示“来源原文已变化”，保留原快照和当前草稿。来源删除或超出当前账号权限时不显示记录名称或链接；仍可查看本来就有权访问的翻译记录。不会读取或显示来源模块的密钥等额外内容。

HTML与Markdown原文提供可读文本和可展开的原始文本。可读区由已有安全解析生成纯文本，不加载原文图片或执行原文脚本；原始内容仅作为转义文本展示。

来源信息显示“模块、记录名称、字段”。有来源编辑权限时，新标签打开后台编辑页并定位对应配置项；只有查看权限时打开该记录的筛选列表。新页面仍重新执行授权与可见范围检查。原页面保持草稿，不自动保存。

媒体使用位置复用同一规则。列表中只有一个可见位置时可直接定位；多个位置打开本页来源窗口，按字段分组、每页20条读取，每条均可新标签定位。详情页提供相同清单。关闭窗口返回原入口焦点，读取失败可重试；受限来源不输出标题、位置或数量，只保留已有受保护提示。

字段锚点为`field-字段名`，只读列表记录锚点为`record-记录标识`。跳转时短暂突出目标，焦点与滚动限定在后台内容区，不修改输入值。列表的单一来源链接在已有分组查询中批量取得，避免为每张图片逐条查库；分页来源仍按当前权限实时读取。
