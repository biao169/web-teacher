# 第四步完成：公开取数、分类与附件（0.15.50）

用户已批准0.15.49包内公开取数补丁。本版完成第四步收尾，基于已交付六类卡片、详情、序号、排序、多选复制与滚动加载。

## 生效内容

- 论文列表直接显示卷期页码、通讯作者标记/强调，支持类型、收录、显示标签和原文链接；标签不参与复制。完整引文继续只在详情或用户显式选择复制格式时读取，不放大列表载荷。
- 专利软著列表补齐国家、申请/授权编号及日期，详情沿用已有完整公开文字。
- 分类下拉：论文年份/类型/期刊/收录；项目来源/基金计划/状态；专利类型/国家/状态；新闻分类；课程学期/对象。来自完整公开范围的SQL去重查询，隐藏记录和未到发布时间新闻不贡献选项，不用当前页推断分类。每次最多50项，“更多选项”继续读取并保留当前值。年份按新到旧排列，数值统一转为字符串保证后续选项读取与选中一致。研究方向没有独立分类字段，继续关键词搜索与排序。
- 证书、教学大纲、课程资料使用媒体ID链接；只映射本次响应引用的活跃媒体，不返回对象键/磁盘路径作为链接。隐藏课程资料和隐藏论文PDF不查询映射、不渲染链接。原/media接口仍执行访问检查，公开页面不存在扩大附件访问范围的例外。

项目仍突出来源/计划、不显示简介和经费；新闻新标签及完整居中封面、富文本/PDF阅读保持不变。学生默认按后台学生分类配置分组，重复命中取首组、未匹配置后，也保持不变。
