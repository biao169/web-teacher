# 第七步：留言与整体联调（0.15.64）

按用户确认的七步表格完成留言代码与自动化联调。Windows/手机真实浏览器验收仍未完成，不能把模拟DOM结果写成实机验收通过。

## 留言体验

宽屏为说明栏+表单卡片，手机单列；姓名/邮箱在宽屏同排，主题一行、正文主要占位。字段明确选填/必填，提供原生label、自动填充、长度约束及反馈区。主题使用datalist建议（招生咨询、科研合作、课程问题、网站反馈、其他），也允许自由输入和修改，仍保存为原subject字符串。中英文标签、状态及公开错误提示完整对应。字体、字号、颜色和交互状态由public-theme.css统一，academic.css只承担布局。

匿名关闭时明确提示登录，禁用提交；服务端仍实时判断，不能靠前端绕过。JavaScript只作渐进增强：提交期间禁用重复操作及编辑，失败恢复输入，成功停留并提供“再写一条”。反馈获焦点，aria-live播报。20秒超时或未知网络结果保留内容并明确提示结果不确定，不自动重发。成功后本表单锁定，避免同页重复提交；不声称实现跨设备/请求的幂等去重。

无JavaScript时仍可原生提交；预期错误重新呈现表单并安全保留内容，成功303跳转回留言页，短期反馈cookie只显示一次，避免刷新POST重复提交。留言输入不存localStorage/sessionStorage，保留仅指当前页面及可恢复的服务端校验失败；不承诺关闭浏览器后恢复草稿。

## 服务端边界

public_actions.contact的保存、私密visibility、固定new状态、身份限制、频率限制未改变。新增public_contact只做显示错误翻译及保留字段白名单；web仅调整公开contact表单及响应分支，注册分支保持原样。仅留言请求体允许到65536字节，以容纳URL编码的5000个汉字；正文仍最多5000字符、姓名150、主题300、邮箱254。Origin及表单cookie校验保留，明确拒绝缺失cookie；失败返回新表单令牌，内容安全转义。公开JSON响应no-store，无私密配置泄露。

后台模板/管理CRUD、原生数据库/迁移、登录注册服务、媒体鉴权、快传及部署代码没有修改。没有部署、发送真实留言或更改实际网站数据库；所有写入测试使用隔离测试数据库。
