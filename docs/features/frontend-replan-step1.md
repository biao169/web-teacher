# 前台重规划第一步：配置与公开数据（0.15.53）

依据用户“执行第一步”落实当前规划第11节。此次修改包含必要的网站设置字段、显式迁移和公开取数，未部署到用户运行环境，也未写入30名学生或100篇论文示例。

## 已实现

- 页头Logo取当前启用网站设置的logo_key，经已有媒体UID映射访问；站点名称支持中英文回退。未配置/回收站Logo不渲染图片；网络或解码失败时隐藏失败图片，站点文字保留。
- 同时接入已有favicon_key、seo_title与seo_description。页头站名、首页hero标题、浏览器标题分别使用各自配置；详情标题包含条目名称。
- 首页首位精选教师补充办公室、电话、公开邮箱及已有ORCID/Google Scholar/DBLP/GitHub/CNKI/个人主页和已填显示数值。复用新提取的联系方式与学术链接模板，不展示首页教育/招生长文。
- contact_visibility继续控制邮箱、电话和办公室；公开投影SQL也使用条件表达式遮蔽非公开联系方式，不能靠手工选择投影绕过。学号、项目简介、新闻正文仍不进入列表读取。
- 新增homepage_student_limit（首页学生数量）与homepage_patent_limit（首页专利数量），默认0。设正数后复用现有首页模块样式与分片读取，0隐藏；本轮保留纵向排布，多列布局为下一步内容。
- 新增publication_citation_style（论文显示格式），默认gbt，候选gbt/elsevier/apa/ieee。复用现有网站设置编辑器和枚举校验，不新建后台页面。
- 论文公开查询只读取配置选中的一种引用文本及相应强调字段，保留人工原文，提供明确的引用样式与文本数据。**本轮完成配置与取数，论文卡片直显和复制改造按计划在第三步完成；当前卡片不会因此变成新版引用排版。**
- 学生日期/去向/获奖，项目金额/成员，专利权利人/证书，课程公开大纲/材料所需字段进入白名单。附件仍通过原媒体接口检查可见性。
- 所有列表及首页模块默认sort_order升序，同值稳定按ID；降序时按对应方向处理同值次序。学生仍固定按已启用分类的display_order分组，组内使用后台排序。后台管理页的排序实现保持原行为。
- 旧的前台手工排序选项及每批数量控件暂保留兼容，第四步统一移除并规范旧URL参数。本步仅改变默认排序。

## Windows/VPS升级

从0.15.46—0.15.52升级需要新增字段。先停止网站进程，在新版本目录沿用原来的配置和数据路径，执行：

```text
upgrade-data.cmd
```

Linux/VPS或直接Python运行则沿用原配置执行：

```sh
python -m backend.cli migrate
```

迁移前生成“原数据库文件名.before-v0.15.53.sqlite3”快照；旧记录保持原值，仅新增默认0、0、gbt。完整结构验证成功才提交，失败回滚；已升级数据库再次执行返回current，不重复加字段。不需要重置数据库或添加示例。

支持精确识别的0.15.37、0.15.38—0.15.45和0.15.46—0.15.52结构；其他手工修改过的结构会拒绝自动变更，需先核对。已有同名快照不会被覆盖。运行中的服务通过既有锁机制阻止迁移。
