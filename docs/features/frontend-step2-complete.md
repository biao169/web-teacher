## 读取与复用方式

- 复用Content.listing中的公开范围、参数化过滤、排序和分页；默认每批10条，最高20条，首页固定10条。页码过大遵循现有页码边界规则。
- 分片仍请求同一语言和模块路径，使用X-Public-Fragment请求头获得JSON中的服务器模板片段，不重复传送页头、页脚与整页资源。不同内容类型共享模板入口，不另造第二套卡片。
- 公开列表投影采用固定字段白名单；新闻不读content，论文不读完整引文/摘要，人员不读教育/工作/招生等详情字段。不得用投影参数请求账号或私有字段。
- 简介、方向说明和课程摘要在译文匹配后输出最多2000字符；完整原文仍用于精确译文匹配，详情页不截断。不会触发实时翻译或修改译文缓存。
- 媒体映射仅查询当前响应引用的avatar/cover/pdf键，以最多40个键一批查询，不遍历全部媒体库。
- 首屏仍由服务器输出HTML。保留已有节点，自动加载不更改浏览器URL；后续选择复制功能可监听public:appended事件。
- 普通公开列表只读public内容；登录不会扩大公开字段/记录范围，新闻仍检查发布时间；每次读取重新检查可见性。

这是按页读取与传输优化，没有测量生产网站响应耗时，不承诺固定毫秒或倍数提升。当前分页仍为LIMIT/OFFSET：列表动态新增/删除时不是历史快照，UID去重可防重复，内容变化导致页码不一致时提示刷新。长列表追加后的DOM会累积，必要时可用普通分页；本版没有引入虚拟列表。

## 本地/Windows升级（必须先停服）

1. 停止主站及使用同一主站数据库的进程，保留原外部配置、数据库、媒体与缓存路径。
2. 将0.15.46解压到新目录，继续使用原TEACHER_CONFIG或同一启动器数据目录。
3. 在新版目录运行 `upgrade-data.cmd`。Linux运行原配置下的 `python -m backend.cli migrate`。
4. 脚本核验完整旧结构并创建 `.before-v0.15.46.sqlite3` 快照后，在事务中新增字段；校验成功才提交。成功后按原启动方法启动。
5. 检查网站设置中的首页项目数量，以及首页、导航和滚动加载。账号、密码、角色、原设置、媒体原文件名和业务记录保持。

已识别前驱：0.15.38—0.15.45结构，只增加homepage_project_limit；0.15.37结构会同时补齐original_filename。已是当前结构时迁移为空操作。未知结构、服务运行中或备份文件冲突时拒绝修改；校验失败回滚，快照保留。不要运行reset-data.cmd、重置数据库或重新添加示例。曾失败留下快照时，先保留并核查快照与失败原因，再处理命名冲突，不覆盖唯一备份。

回退需要停服，使用旧代码与对应升级前快照配套恢复；不能用旧版代码直接打开新版结构。恢复旧快照会丢失升级之后的新写入，因此应先保存当前数据库副本。
