# 前台重规划第二步：首页布局（0.15.54）

本版在0.15.53的配置与公开取数基础上完成首页重排。只有前台专属模板、样式与验证材料发生变化，没有改后台、数据库、共享资源或快传实现，也没有添加示例数据。

## 首页结构

1. 教师人物区：桌面头像左置，正文在右；姓名、职称/单位、简介、联系方式、学术链接按自然阅读顺序排列。头像完整显示，区域透明无边框；窄屏缩小头像并按一列排布。无教师继续使用后台首页标题/副标题；无头像不留下头像空列，联系信息为空时不渲染空容器。
2. 第一组模块：论文和新闻以约3:2比例并列。只存在其中一个时占满该组宽度。
3. 第二组模块：项目、专利软著、学生三列，模块内部使用较轻的分隔线，减少重复卡片边框；两个模块时二列、一个时一列。平板改为两列，手机一列。
4. 新闻封面左置且contain居中。标题及查看按钮继续新标签打开；查看按钮与日期/分类处在同一行，保留可点击面积，不另占一行，不以绝对定位覆盖内容。
5. 首页论文、项目、专利和学生不再生成条目详情入口；各模块“查看全部”仍进入对应列表。其他功能列表和旧详情路由未在本步修改，统一收敛在第三步进行。

本步增加轻量SVG箭头，以统一首页按钮的大小与笔画；是独立原始路径，不将其标为Bootstrap资源。全部卡片按钮的完整图标规范在第三步一并实施。

## 复用与响应式

- 新增home-section.html复用模块标题、卡片列表和加载区域；初始卡片与后续片段继续共用home-card.html。
- 联系信息与学术链接继续复用第一步组件，保留公开策略和转义。
- 新增home.css只在首页及首页分页回退页面加载；普通列表、详情、联系页及后台不加载此样式。原academic.css和所有共享样式保持不变。
- 桌面模块间距24px，卡片内边距约12–14px；窄屏自然换行。所有网格内容列使用minmax(0,...)避免长标题/邮箱撑破页面，不固定模块高度，也不加模块内部滚动条。
- 当前断点：小于1100px时次要模块最多二列；小于768px时模块单列；小于576px时教师头像与正文单列。真实浏览器的字体、触控与像素效果仍需实机验收。

## 数量、空状态和加载

后台原有五项首页数量继续控制显示总上限，数量0或无公开精选内容时整个模块隐藏；所有模块为空时保留教师/站点介绍和页脚，不创建空模块网格。

分片仍由未修改的public-stream.js执行：各模块独立保存进度与已加载UID，全部模块共用单请求队列。页面滚动触发后逐个读取下一批，不并行堆积；保留无脚本分页、节省流量模式及失败手动重试。首页数量11等不整批值，最后一批仍严格截断到上限。

## 本步与后续边界

本次完成首页布局。论文引用文本已经在第一步准备，但所有论文卡片的引文直显、默认复制及缺失格式回退，以及项目2–3行信息布局、其他列表左侧媒体与详情收敛，统一在第三步完成；本版不宣称已完成这些卡片规则。

顶部工具栏、下拉选择和移除每批数量为第四步；30名学生与100篇论文示例为第五步。本轮只在隔离测试库产生测试记录，没有向用户数据库写入。

## 升级和验证

从0.15.53升级没有新增迁移；沿用原配置与数据路径更新代码即可。从0.15.52及更早版本升级仍需先停止服务并执行上一版引入的upgrade-data.cmd，详见frontend-replan-step1.md。没有自动部署。

新增验证覆盖五模块结构/中英文、单模块与空组、无头像与空联系信息、媒体在DOM中的左侧顺序、新闻新标签、非详情首页条目、跨批上限与同一模板、五模块共享单请求队列。Worker打包已核验全部新模板与home.css。与0.15.53比较，backend/database/frontend/admin/frontend/shared/transfer/deploy范围509个既有文件逐字节相同。

本环境未发现可用浏览器可执行文件；HTTP与模拟DOM测试不等同于真实浏览器布局验收。未进行Windows浏览器或生产平台验收。完整结果见frontend-replan-step2-verification.json。

本次完整回归：295项Python/HTTP、108项前端模拟测试全部通过，其中新增6项Python和1项模拟DOM测试。此前论文联网缓存的偶发槽碰撞实现未改，本次通过不表示该问题已修复。
