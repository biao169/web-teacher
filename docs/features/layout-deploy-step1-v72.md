# 布局与部署整理：第一步（0.15.72）

基准：0.15.71。本次仅完成首页和学生卡片调整，不执行后续项目权限、数据库SQL合并、目录迁移或部署脚本重构；没有操作实际站点数据或部署。

## 首页

首页教师双卡由3:2改为约2:1，右卡最小260px；850px及以下上下排列。桌面头像180×214px，中等宽度150×180px，手机108×136px，保留contain完整显示、透明媒体背景及姓氏占位。少链接的右卡自然高度且顶部对齐，避免空白被拉满；无公开联系方式和链接时，简介卡铺满。超窄屏头像和身份上下排列。

身份、职称、团队角色、单位、实验室、简介继续复用组件；右卡新增“联系地址”“学术与社交”分组标题，列出公开的办公室、邮箱、电话和现有学术链接。联系方式仍由contact_visibility统一控制，不会因首页丰富信息而泄露隐藏字段。没有填写的内容不生成空标题或占位。

新增首页公开招生信息，复用原字段、翻译覆盖与取数长度限制；普通教师列表不追加该字段。教育/工作经历仅保留在教师详情。原固定详情按钮不恢复，按钮仍来自导航配置。下方新闻和论文模块布局不变。

## 学生

姓名、学位、年级、分类、状态及其他基本字段保留；研究方向、获奖情况抽为共享重点行，标签强调，内容长时自然换行且不裁切。列表与首页学生小卡共用字段模板，避免重复字段。简介可空，有内容时仍是一行的次要文字，沿用现有展开/收起、完整译文按需加载功能；不新增学生详情页。保留原分类顺序、连续加载和复制能力。

## 修改边界

字体、字号和颜色继续引用frontend/shared/static/css/public-theme.css；只改局部排布，不新增硬编码字体/色彩。复用person-overview、person-fields、person-connections和原头像/简介组件。只调整首页所需公开取数；管理员业务、项目权限规则、数据库结构、传输协议和部署入口未改。
