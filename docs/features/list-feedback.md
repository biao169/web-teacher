# 后台操作通知与列表更新

0.15.32将表头筛选/排序作为共享布局中的独立入口，普通搜索及分页不依赖列表增强功能。核心列表完成绑定后才启用其操作控件；列设置、媒体预览、分组导出等附加功能按需加载，失败时显示各自提示，不再阻断已加载的表头。详见[第一阶段修复与验收](list-step1.md)。

后台共享布局提供固定在右侧顶部的通知区，成功、失败、警告、信息和处理中使用图标及文字区分。样式、字体、颜色、间距和尺寸统一读取admin-theme.css，通知不占用列表高度，不改变侧栏或表格的位置。手机通知随右侧区域调整宽度。手机列表操作列复用紧凑图标、完整悬停说明及可访问名称，为中间可滚动字段保留空间。

成功通知约3秒关闭，信息通知约6秒、普通警告约10秒；错误、处理中及需要核对结果的警告保持显示，用户可手动关闭。鼠标悬停或键盘聚焦暂停自动关闭。相同操作更新同一气泡，最多同时保留4条通知；文本通过文本节点显示，不执行HTML。

## 单条操作

普通列表中的快捷开关复用既有写入服务，由服务端核验会话、来源、CSRF、操作权限、可见范围、固定导航条件和原生updated_at。成功后返回实际保存值、最新原生时间戳及统一格式的显示时间，当前行立即更新，连续切换使用新的时间戳。

列表写入期间暂停其他列表写入及多选修改，防止连续点击造成重复请求。失败保留原状态并恢复按钮。请求超时或响应丢失时，结果可能已写入，界面提示核对，不自动重放写请求。

存在搜索、筛选、指定排序或固定导航时，开关操作重新获取当前列表区域。删除、媒体上传、回收和恢复也重新读取列表及分页。服务端复用同一列表模板并再次验证读取权限和固定范围；删除末页最后一项时自动回到有效页码。URL中的搜索、筛选、排序、每页数量和导航入口保持有效。

局部更新保留主区域与表格的合理滚动位置、未提交搜索文字、列显隐和列宽；即使浏览器拒绝存储，当前页的列选择仍能在局部更新后保留。仍存在的选中记录保持选中，已经完成的批量条目取消选择。替换列表时释放旧的监听器和观察器，复用列控制器、表头筛选、操作列测量及媒体缩略图处理。

导航及网站设置中的快捷开关可能影响侧栏或网站名称，因此刷新完整工作区；自身必须改密仍跳转账户安全页面。编辑表单继续保留必要的保存跳转。成功消息按账号、会话及目标路径绑定，在目标页面显示一次；刷新、切换账号或会话均不重放。浏览器存储不可用时仅省略跳转后的消息，不妨碍保存。

## 批量与失败处理

批量删除、媒体回收和恢复依次调用已有单条接口，每项独立校验权限及时间戳，遇到第一个失败立即停止。单一气泡显示进度，最终汇总成功、失败或结果待核对、未处理数量；后续条目不会自动重试。重新读取列表后仍保留失败及尚未处理记录的选择。

若操作已经成功、后续读取列表失败，通知明确区分两种结果，暂停陈旧列表的写入并提供“刷新列表”按钮。该按钮只发送读取请求，不重复保存、删除或上传。重新读取成功后恢复正常操作。

编辑表单的字段校验、保存错误、未保存草稿以及媒体选择/裁剪、联网查询等专用工具的局部反馈仍由各工具维护，避免错误随成功气泡关闭而丢失。通知本身不改变数据库或任务状态，也不替代服务端授权。

权限不足的异步请求同时使用共享弹窗说明原因，列表既有失败通知及状态恢复继续保留。401提示重新登录，权限403提示联系管理员；CSRF等其他403保留服务端具体原因。关闭弹窗不会重试写入，也不会清除表单草稿。
