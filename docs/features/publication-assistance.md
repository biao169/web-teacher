# 论文编辑与引用辅助

论文使用同一张表单录入原题名、作者、发表信息、分类、引用、附件和展示设置；复用原字段、权限、版本检查与底部统一保存。没有独立的中英文双标题或摘要输入区，英文展示仍通过翻译模块处理。

## 页面分区

原始引用与输入辅助放在最前，其后依次为联网元数据检索、题名与作者、发表信息、分类与标签、多格式引用、附件、展示控制。顶部跳转目录与实际顺序一致。题名/作者默认两行；分类、收录类型、标签和关键词默认一行，桌面四列、平板两列，手机按可用宽度换列。多值仍可用分号或换行分隔，文本框可拉高。

每种引文与自己的高亮成组：GB/T、Elsevier、APA、IEEE四组，BibTeX单独显示；窄屏自动上下排列，底部保存栏继续固定。

## 联网补全与字段原值

支持六家服务的DOI/题名查询，配置、回退、权限和缓存沿用[元数据检索](metadata-search.md)。查询只展示候选，即使唯一DOI候选也先由用户选择。点击“填入这篇”后，来源提供的合法非空字段立即填入对应输入框；缺失或空建议不清空当前内容，相同值不产生多余撤销记录。

题名、作者、通讯作者、期刊/会议、年份、卷期页、DOI、URL、论文类型、关键词可回填。每个变化字段下方紧接显示原填写内容、来源和独立撤销按钮，不再集中在页面另一处核对或撤销。原值为空时明确显示“原来为空”。外部内容只按文本呈现，不执行网页标记。

撤销仅恢复该字段最近一次自动填入前的值，其他字段保留。连续选候选时，每个实际变化字段更新自己的原值；未变化字段保留自己的撤销记录。之后又手工修改的字段禁用直接撤销，并保留原值供复制，避免覆盖后续编辑。

原始引用解析继续复用原格式解析器及勾选回填；应用后同样在各字段旁显示原值和撤销。完整恢复到某次来源回填前时，未被保护或后续修改的派生引文也可恢复。页面离开、刷新或保存重开后，临时撤销记录不再保留。

## 引用更新与保护

“多格式引用”标题右侧的“更新全部引用”按当前题名、作者、发表信息等，一次更新GB/T、Elsevier、APA、IEEE及BibTeX五种文本，包括已保护项。变化项下方保留原值供撤销，更新不会直接保存数据库。

每项输出仍有保护开关。保存过的非空内容默认受保护，手工编辑或清空也会保护；普通来源字段变化只自动更新未保护的项。显式点击更新按钮代表重新生成，不受背景自动更新的保护开关阻挡。生成后的变化项受保护，可取消保护后继续随来源字段变化。快速保存前会同步尚未执行的背景生成。

## 首页教师与自动高亮

“提取首页教师”通过受保护的只读接口重新读取首位公开、启用、首页精选教师，按sort_order、记录顺序选择。中文、英文分开显示；英文优先教师资料中的name_en，其次使用当前原文完全匹配的有效英文译文。原文变更、译文停用或无英文名时不使用旧译文，不自动调用翻译服务。在其他页面改好姓名后，返回当前草稿点击提取即可更新；失败保留现有姓名和高亮。

各高亮字段标题旁有“自动高亮”，只更新本格式。复用既有姓名匹配与格式生成规则，按GB/T原姓名、APA/Elsevier姓与缩写、IEEE缩写与姓匹配；最终只采用本项实际引用中出现的字面文本，保留实际大小写。相关姓名优先完整匹配，避免重叠短名；没有教师、引文为空或无法匹配时保留当前高亮并提示核对，不报告虚假匹配成功。

“更新全部引用”同时生成未保护且确实匹配的高亮；已经保护的高亮可通过各自“自动高亮”按钮显式更新。高亮更新同样显示原值，可独立撤销。

## 保存和失败处理

补全、引用与高亮更新都是表单草稿操作，底部保存才持久化，继续执行原生权限、CSRF、记录版本及固定范围校验。查询词/类型/服务变化、取消等待、离开或保存会停止旧等待；迟到结果不能覆盖新状态。服务失败时保留已有输入，可以重试。保护和撤销状态仅属于本次页面，不新增数据库字段。

独立元数据检索页保持只读。禁用JavaScript仍可按新顺序手动填写和保存；自动补全、生成与撤销需启用JavaScript。未新增生产依赖或数据库字段。


## PDF 附件与辅助加载

附件区提供“上传 PDF”和“从媒体库选择”。上传按钮直接打开共享媒体选择器的本地上传页；确认后填入pdf_key，整页保存后建立引用。取消选择保留旧附件；失败不清空草稿。无上传权限时显示原因，仍可在拥有媒体查看权限时选择已有PDF；目标论文、媒体和固定导航范围继续由服务端核验。

后台辅助分别加载，一处加载失败显示对应提示，不连带停用历史输入建议、媒体操作和表单保存。相关按钮在模块就绪前暂时禁用，避免加载期间点击无反馈。本地静态响应明确指定JS/MJS类型，避免系统文件关联将模块当成普通文本；已更新模块使用版本地址，脚本与样式响应要求缓存重新验证。无JavaScript时仍可手动填写和保存，上传需要JavaScript。
