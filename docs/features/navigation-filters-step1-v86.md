# 导航与双语筛选第一步：统一基础（0.15.86）

## 本步内容

新增 `backend/app/native/filtering.py` 作为共享条件工具，复用原生字段类型、标签、枚举定义及现有 SQL 查询方法，不新增数据库表或初始化文件。

条件示例（服务端内部接口，不是浏览器可提交的固定范围）：

```python
conditions = [
    {'field': 'name', 'operator': 'contains', 'value': '人工智能'},
    {'field': 'status', 'operator': 'eq', 'value': '进行中'},
]
page = await public_listing(
    resources, 'projects', {'q': '医疗', 'page': 1},
    fixed_conditions=conditions,
)
```

执行顺序是公开可见性 AND 固定条件 AND 用户字段筛选 AND 关键词匹配；先在 SQL 中匹配并统计，再按既有后台排序分页。用户同字段条件不会覆盖固定值；清空临时条件也不会删除传入的固定条件。分页本身每次必须由服务端入口解析器重新传入该固定范围，后续第三步负责路由接线。

## 统一约定

- 结构为 `field / operator / value`，支持 `eq` 与 `contains`。旧结构省略 operator 时仍代表 eq，不改变已保存后台入口的含义。
- 最多 12 个固定条件，一个固定字段只配置一次。用户追加条件独立组合，可以进一步限制同一字段。
- 文本新增条件的编辑元数据默认 contains；状态、类型、承担角色、学位、日期、编号 UID、整数及布尔等精确字段仅提供 eq。项目编号、专利申请号等文本编号仍支持包含。
- 包含使用参数绑定与 LIKE ESCAPE；百分号、下划线及反斜杠作为普通字符，英文 ASCII 大小写不敏感。不是正则、模糊同义词或自动关键词翻译。
- 固定值长度为 1–500 字符，去除首尾空白；拒绝空值、非法类型、控制字符和无效整数/枚举。整数如 02026 规范成 2026。
- 字段名只来自白名单，条件值不拼接进 SQL。公开固定 eq 是原始字段精确相等；已有多值分类下拉的 token 相等语义不变。

## 接入和复用

| 位置 | 改动 |
| --- | --- |
| `navigation.filter_value()` | 调用共享值校验；后台路径 build/parse、编辑预览、写入范围校验保持原协议 |
| `Content.listing()` | 增加独立 `fixed_conditions` 参数；后台 c. 包含与 q 搜索共用字面包含构造器 |
| `public_listing()` | 接收服务端固定条件，沿用既有权限投影、排序和分页；首页零条目时也校验固定条件 |
| `public_filter()` | 使用集中公开字段白名单；原有派生年份与多值选项匹配保留 |
| `PUBLIC_SEARCH_FIELDS` | 集中各模块原文/人工英文字段搜索范围，为第四步有效缓存译文搜索提供字段边界 |

公开项目搜索包括名称、来源、基金计划、项目编号、承担角色、状态。普通前台筛选不允许项目负责人、金额、成员；其他模块不允许隐私联系方式、学生编号、可见性控制字段、媒体存储键、原始导入引用等。管理员的公开页面搜索也使用相同白名单，已有管理员项目私密字段显示规则未改变。

## 本步尚未开放的界面能力

导航编辑界面目前仍为原版本；不会把前台目标自动配置成受控入口。本步提供基础方法，未创建新的公开固定入口路由、未将固定条件作为访客可修改的请求参数。ASCII 标识及临时查询状态编码在第三步接入。

已有人工英文字段（例如学生 name_en）可参与搜索；缓存译文搜索、动态下拉项翻译在第四步实现。当前不会在用户搜索时调用在线翻译，也不声称英文可检索没有英文内容的中文记录。

## 验证

`tests/test_navigation_filters_v86.py` 使用独立 SQLite 数据库，覆盖：

- 包含/相等区别、中文、英文 ASCII 大小写、特殊字符、SQL 注入形态文字；
- 多固定条件、用户关键词与同字段相反条件的交集，清空用户条件后的固定范围；
- 12 条匹配跨两页、总数和升降序；隐藏/停用记录及未发布新闻排除；
- 私密字段 f. / c. 请求拒绝、私密文本不参与 q 搜索；
- 条件数量、值长度、类型、未知运算符和重复字段校验；
- 已保存后台入口、原相等预览、入口内临时筛选及旧中文参数编码保持；
- 人工英文名称搜索和公开字段元数据。

实际通过数量与范围见同目录 `navigation-filters-step1-v86-verification.json`。本步无界面改动，未进行新浏览器视觉验收。
