# 前台重规划第三步：统一卡片与详情收敛（0.15.55）

在0.15.54基础上，完成论文引文直显、项目紧凑排布、教师/新闻媒体左置及详情入口收敛。复用Jinja模板、Bootstrap CSS和原生JavaScript，不增加前端框架或运行依赖。

## 已实现

- **论文**：首页、普通列表及后续分片共用citation.html，按站点publication_citation_style显示对应保存引文，不另设重复标题块。GB/T、Elsevier、APA、IEEE均支持。显示标签、通讯作者和链接置于独立信息区；标签和动作不混入复制内容。
- **复制与强调**：批量复制和单条复制直接使用已加载引文，不读取论文详情、不在访客端重新生成。保留保存文本的字符、空格和换行；highlight_*仅对安全匹配的原文片段加粗，通讯作者复用原姓名匹配工具在标签区标注，不向保存引文插星号。缺少所选格式时显示带明确提示的基本著录信息，复制同样的提示和内容，不以另一格式冒充。
- **项目**：第一行来源—基金/计划及状态；第二行标题、负责人、承担角色和金额；第三信息区按需放编号、日期与成员。金额0保留，空值不生成占位；简介不显示。普通长度以2–3行组织，长标题或成员允许自然换行。
- **教师与学生**：名称和基本属性同行排列，媒体在DOM和视觉中均位于左侧；简介两行。教师超长简介才显示展开按钮，展开仍按需读取教师公开详情，按钮与末尾正文共用布局空间。学生不再请求详情，增加入学/毕业时间、去向、获奖、公开联系方式及主页；保留分类分组与学号保护。
- **新闻**：左侧封面完整居中，标题和SVG详情按钮均新标签打开。日期/分类与按钮同排，保留既有新闻阅读功能。
- **专利、课程、研究方向**：专利补齐权利人，公开证书从卡片直接打开；课程大纲及公开资料卡片可直接打开，隐藏资料仍由原媒体访问规则保护。研究方向说明、专利说明不因移除详情而丢失尾部内容；课程继续保留详情。
- **图标**：四个本地Bootstrap Icons v1.13.1 SVG路径，用于展开、详情、新标签、复制。首页箭头也复用同一宏；不从CDN动态下载。MIT许可及来源位于frontend/public/static/vendor/bootstrap-icons。

## 详情与旧链接

只保留教师profiles、课程courses、新闻news的详情展示。学生、论文、项目、专利、研究方向不再生成条目详情入口。

既有公开详情链接先使用原公开读方法检查可见性，再303跳到同语言列表的f.uid精确筛选及record-UID锚点。只加载对应条目并提供“查看全部条目”；即使原条目排在后续分页也立即可见。隐藏或不存在的条目仍返回404，from参数不能改变跳转目标。无脚本语言切换也保留此精确筛选。

这是普通列表的既有筛选能力，不新增详情页面或管理接口。访问老链接不修改数据。论文复制已解除详情依赖；学生简介保持摘要，不再提供详情式展开。

## 复用及改动范围

content-body.html供首页和列表复用，引文单独复用citation.html；card-fields.html统一项目元信息；card-icons.html统一SVG；人员继续使用person-fields/contact/links。卡片采用正常grid/flex流排列，去掉旧的绝对定位动作和为其预留的大块内边距。图片区透明、无边框、contain，保留适当圆角。

服务端仅调整backend/app/native/web.py的公开旧链接兼容及trim调用、public_data.py的专利说明投影/摘要处理。列表依旧首批10条、最多20条有界读取；媒体仅解析本批引用，不扩大私有字段公开范围。无数据库迁移，无管理写入/权限/上传/快传功能修改。

工具行密度、后台排序升降序、短折叠下拉及移除“每批数量”留到第四步；新增30学生和100论文示例留到第五步。没有向用户数据库写入测试或示例记录。

## 更新与验收

从0.15.53/0.15.54更新无需新增数据库迁移；继续沿用原配置及数据目录。从0.15.52及更早版本更新，仍须按第一步说明停服并执行upgrade-data.cmd。未部署生产网站。

验证包含四种格式的原文保留/转义、首页/列表/分片一致性、批量复制零请求、缺项回退、姓名高亮不改文本、旧链接晚分页定位/404、金额0、长说明、媒体DOM顺序、学生隐私及现有附件访问。历史上要求隐藏金额、论文详情和逐条取引文的测试按本轮需求更新，不再作为旧标准。

完整验证数字和文件边界核验见frontend-replan-step3-verification.json。本环境仅进行HTTP和模拟DOM验证，未进行真实Windows浏览器像素、字体和触控验收；Worker资源准备也不等同于线上Cloudflare部署测试。
