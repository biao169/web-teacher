# 新闻正文、编辑与PDF阅读

新闻只有一个正文content和原生content_format字段。纯文本保留换行并转义HTML；Markdown保留原始源码，经Mistune解析后再用同一HTML白名单清理；HTML使用Quill可视编辑。新闻详情和后台“实际效果预览”共用服务端渲染，预览不保存、不发布，也不改变数据库记录或操作日志。

## 单页编辑

正文编辑与标题、封面、日期和可见性位于同一表单。可视工具支持二至四级标题、加粗、斜体、下划线、删除线、编号/项目列表、引用、代码块、段落对齐、分隔线、撤销和重做。可填写HTTP、HTTPS及mailto链接；脚本、事件属性、任意嵌入和可执行媒体不被保留。

图片和PDF复用统一媒体选择工具，可选已有媒体或上传新文件。每篇正文最多引用10个不同文件；取消选择不改变正文，上传成功的文件保留在媒体库。图片可从剪贴板粘贴或从本地拖入，上传前确认；可拖动已有图片改变正文位置。点击图片可编辑500字符以内的替代文字及普通、左右浮动、居中、宽图排版；手机阅读时左右浮动自动改为独立图片。需要裁剪时在统一媒体选择器中编辑副本。

PDF链接的可读文字作为阅读标题，在媒体选择器中填写说明即可。正文保存使用Quill语义HTML，编号列表和项目列表保持区别。图片与正文的布局、后台字体及配色分别由共享正文样式和admin-theme.css控制；PDF文字层字号由原PDF字形位置决定。

纯文本转HTML只做转义；其他格式切换会先提示转换。Markdown与可视HTML之间不保证无损往返，例如下划线、浮动排版可能丢失。“恢复转换前草稿”可在当前页面恢复最近一次转换前的正文，恢复会替换当前正文；保存、刷新或关闭页面后不保留该临时副本。预览或转换失败保留输入，迟到预览不能替换新草稿。编辑器资源不可用时显示原始正文输入框，并提供加载重试。

## 媒体引用与访问

正文只允许使用精确的/media/媒体UID作为受管理图片地址。Markdown代码示例、纯文本地址和转义HTML不构成媒体引用；不因此公开文件。有效图片/PDF链接与当前英文译文共用真实引用检查、回收保护和公开访问判断。原文变更导致译文哈希过期时，旧译文不再授予媒体公开访问。

预览检查新闻新增或编辑权限、当前updated_at、固定导航条件版本和可见范围；含受管理媒体的预览还要求媒体查看权限。文件本身仍由媒体网关鉴权。链接指向已回收、缺失或无权访问文件时不会绕过访问控制。

## PDF自然展开

PDF在正文链接位置显示分隔线和标题，使用随包PDF.js按页展开，不使用固定高度iframe或浏览器原生工具栏。接近视口才加载文档与第一页；滚动接近末尾追加下一页，也可点击“加载下一页”。不支持IntersectionObserver的浏览器使用手动阅读按钮。每页按自己的纸张比例呈现；有可提取文本时提供文字层，扫描件没有OCR。

全页面最多保留3个已绘制画布，每个画布限制400万像素；离开附近视口的页面释放画布并保留原比例占位，可返回或点击重新显示。最多同时解析2个文档，再打开其他文档时会释放较早文档，提供明确的继续阅读按钮。“收起”释放当前文档和页面。单文档最多2000页。

文档加载、字体或绘制失败会显示重试或原文件链接；无JavaScript时正文和原PDF链接仍然可读。外链PDF继续通过授权媒体记录跳转；浏览器跨域策略不允许读取时使用原文件链接，不通过服务器代理任意外站。

这些限制约束画布和并发文档数量，不是PDF解析器总内存的严格上限；PDF按字节范围请求多个片段，并非服务器把文件切成单页。自0.15.63起，新闻前台接入news_pdf_allow_download与news_pdf_watermark：下载开关控制前台原文件入口，水印在在线每页显示，不改写原PDF。news_pdf_engine保持原有字段，当前仍使用内置PDF.js；后台预览默认行为不变。

## 存储与依赖

公开媒体和管理预览共用GET、HEAD及单一区间Range响应，支持后缀范围和If-Range版本判断。媒体实际大小超过20MiB时拒绝读取。平台读取先检查大小和签名，本地每块最多64KiB，R2每块最多1MiB；不会先把整份PDF读进Python再切片。对象版本变化时中断读取；下一个HTTP请求重新核验权限与公开引用。回收站内容仅供有权限的管理预览，响应不缓存。

新增运行依赖Mistune 3.2.1为纯Python解析库，其许可证位于legal/licenses；其余使用现有Quill 2.0.3、PDF.js 6.3.289和justhtml。没有新增Node、前端编译、服务器PDF转换或OCR服务。

实现参考：[Mistune渲染接口](https://mistune.lepture.com/en/latest/guide.html)、[Quill语义HTML接口](https://quilljs.com/docs/api)、[PDF.js加载选项](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)、[R2对象与范围读取](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)。实际部署边界仍见跨平台存储说明。
