# 管理与访客功能

后台19个基础入口：教师与团队、学生、学生分类、研究方向、项目、论文、专利软著、课程、新闻、导航与按钮、网站设置、全局设置、翻译、媒体库、留言、账号与权限、操作日志、数据与备份、文件快传。角色权限从账号页面进入；自定义侧栏导航可增加入口。

教师的身份、联系方式、介绍、教育、工作经历、招生与学术社交链接整合于单页分区。教育与经历是自由文本，不拆分日期。学生、项目、论文、课程等复用统一模板和原生字段。论文不分中英文标题、不提供摘要输入；五种引用由原版引用辅助方法生成并可人工修改；每项输出独立保护，DOI通过差异核对选择回填并支持撤销，详见[论文引文与DOI辅助](publication-assistance.md)。项目简介不在访客页面展示；新闻不设简介。

列表共用搜索、筛选、多选、10/20/50/100条分页和所有页码跳转。表头就地弹出筛选/排序，文本列支持包含搜索；列宽依据内容估算并允许拖动，偏好保存在浏览器。左两列与右操作列固定，操作列按可见按钮、文字和字体实时重测，支持增宽与缩窄，操作按钮每行最多3个；表格内容最多显示两行并保留完整悬停文字。布尔编辑使用状态开关，保存检查权限和版本。

后台侧栏独立滚动，可折叠并适配手机抽屉；顶部目录与底部通用保存区固定。颜色、字体和字号集中于admin-theme.css，布局尺寸在admin.css。

学生分类通过关键词匹配学位、分类、年级、方向和状态；同页支持未保存关键词自动预览、10/20/50/100人的匹配分页、保存激活和权限提示，不改写学生原始分类。规则、资源限制及保存边界见[学生分类与匹配名单](student-categories.md)。自定义后台导航的中文固定筛选保存在原生path，浏览器使用ASCII的url_name；权限、固定范围与后续筛选按AND相交。导航编辑支持条件回显、增删、重置及授权结果预览，导航版本与条目版本共同保护保存。完整规则见[后台导航与固定筛选](navigation.md)。

媒体采用原生media_assets与本地/R2存储。默认仅授权用户可读；被公开内容引用后按具体引用权限开放。支持上传、信息编辑、回收与恢复，拒绝危险文件类型、越权引用及无效对象。单次媒体上传上限20MiB，可由配置限额进一步收紧；大文件使用独立快传。

翻译条目使用原生来源键、文本摘要、目标语言和当前版本标志。可从原始内容建立任务、人工编辑译文或明确调用MyMemory、Google、DeepL、Microsoft、LibreTranslate；空配置提供MyMemory通道，凭据及格式边界见[翻译服务](translation-services.md)。论文元数据支持六家服务的DOI/题名候选、配置顺序回退、独立查询及可撤销回填；[翻译批次管理](translation-batch.md)支持11类公开来源扫描、相同原文复用、逐条批次、暂停、恢复和有限重试；页面关闭不再发起后续请求。

新闻plain、Markdown和HTML共用安全渲染；随包Quill提供单页图文编辑、明确格式转换及草稿恢复，后台实际预览与新闻详情复用按页PDF阅读。完整边界见[新闻正文与PDF](news-body.md)。访客内容检查可见性、启用状态、发布时间与公开联系方式；英文展示只使用与当前源内容摘要对应的成功译文。

账户使用原生auth表、角色和模块权限，密码派生与登录限流共用服务方法。账号/角色复用紧凑列表和单页分区编辑；权限矩阵支持筛选、行列批量勾选及撤销，隐藏模块的已选权限保留。账号状态和范围用中文显示，密码确认、重置会话处理及系统角色只读保护见[账号、角色与权限](accounts.md)。公开注册由设置控制，注册者只能获得普通注册角色。留言默认隐藏；匿名留言须开启对应设置。留言原文只读，支持状态处理、归档与批量更新；操作日志只读详情和JSON/CSV导出统一脱敏，见[留言与日志](message-logs.md)。后台业务工具提供JSON/CSV导出、浏览器加密ACMS及带预检的事务恢复，复用SQLite/D1和本地/R2接口，可附带媒体；本地完整数据库备份仍由维护命令提供，账号、运行状态和独立快传不在网页业务恢复范围。见[业务备份](data-backup.md)。

列表导出保留当前筛选范围，每次最多20000条且编码结果不超过4MiB，避免大文本占满小型VPS内存。超限需要缩小范围或使用数据库备份。

教师、论文、项目、专利、学生、学生分类、新闻、课程和媒体的34个字段共用历史建议；支持中文组字、光标片段替换和独立词库查询。论文原始引用可本地解析五种格式，通过共用差异面板选择回填与撤销，规则和边界见[历史写法与引用解析](input-assistance.md)。

## 媒体管理

媒体库与回收站共用预览列、使用位置分组分页及批量回收/恢复。引用检查覆盖原生11个媒体外键与新闻HTML、Markdown及生效正文译文的真实节点，受限来源仅提示受保护。回收站通过后台授权接口预览；公开媒体地址仍拒绝回收站文件。目录分批扫描、未收录文件预检收录、到期回收站清理及全部媒体字段旁侧完整等比预览已接入；统一选择器、适用类型筛选和本地上传已接入，新闻图片/PDF引用复用同一服务。图片编辑支持比例裁剪、缩放拖动、两次点击选点和数值区域，浏览器生成新文件后统一上传，不覆盖原图。完整功能边界见[媒体说明](media.md)。


媒体链接输入和选择器的外链来源已接入，统一覆盖11个原生外键与正文图片/PDF；支持原子登记、外链预览和CORS允许时的图片裁剪。回收清理只删除外链登记，不触及远程文件；类型和大小不伪装成已核验。详情见[媒体链接功能](media-links.md)。
