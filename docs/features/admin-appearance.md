# 后台工作区外观与交互

后台继续复用统一工作区、列表、单页表单、媒体选择器和Bootstrap控件。外观参数由frontend/admin/static/css/admin-theme.css维护；frontend/admin/static/css/admin.css负责布局并读取这些参数，访客界面使用自己的样式。

## 内容间距

主区域在桌面和平板使用12px外侧留白，767px及以下使用8px。列表面板统一提供左右12px、手机8px的内部留白，标题、搜索、多选工具、表格和分页在同一条内侧边线上。面板上下留白8px；单元格上下5px，左右桌面10px、手机8px，复选列保留独立间距。

表格在自身容器内水平滚动。最左复选列、首个内容列和右侧操作列沿用冻结规则；操作列仍根据现有按钮文字和数量测量。右侧顶部目录与底部操作栏独立于内容滚动，侧栏可以单独滚动、收起或在手机上展开。

搜索标签、多选数量和工具按钮保持完整单行文字。平板侧栏占用宽度时，搜索和多选工具条允许整组控件换行；手机继续使用原有分行结构，避免将按钮文字挤成逐字排列。

| 主题参数 | 用途 |
| --- | --- |
| `--admin-main-inset` | 右侧主区域四周留白 |
| `--admin-bar-inset` | 固定顶部与底部栏左右留白 |
| `--admin-list-inset`、`--admin-list-block-inset` | 列表面板水平、垂直留白 |
| `--admin-block-gap` | 列表标题与分页的紧凑间距 |
| `--admin-cell-inset`、`--admin-cell-block-inset` | 单元格水平、垂直留白 |
| `--admin-check-inset` | 最左复选列水平留白 |

这些参数控制共享工作区及列表；媒体窗口、裁剪画布、权限矩阵等专用组件仍保留各自适用的结构尺寸。

## 点击与键盘反馈

按钮、链接、分页和可展开摘要共用160ms过渡，只改变颜色、背景、边框颜色、阴影和透明度。悬停与按下使用内侧轮廓，普通链接悬停有下划线；有鼠标悬停能力时才启用新增悬停效果。按钮不通过改变位置、字号、行高或边框厚度产生动态效果，避免影响表格测宽与冻结列。

键盘焦点显示2px实线轮廓，与控件间隔2px。禁用控件保留既有禁用行为，并显示降低透明度及不可操作光标。现有aria-busy状态使用等待光标；编辑保存过程中沿用原来的“正在保存”文字、禁用按钮和防重复提交逻辑。

| 主题参数 | 用途 |
| --- | --- |
| `--admin-motion-duration`、`--admin-motion-easing` | 过渡时长和速度曲线 |
| `--admin-focus-width`、`--admin-focus-offset` | 键盘焦点轮廓宽度与间距 |
| `--admin-hover-shadow`、`--admin-pressed-shadow` | 悬停、按下时不占布局空间的内侧轮廓 |
| `--admin-disabled-opacity` | 禁用控件透明度 |

开启系统“减少动态效果”偏好时，控件过渡时长归零并关闭相应控件动画，焦点和状态说明仍然可见。状态含义继续由图标或文字辅助表达，不能只依赖颜色。

## 0.15.37 概览、预览与导航

侧栏按内容管理、资源与工具、网站配置、系统管理分组；已有自定义入口另组显示并保留相对顺序。权限仍由原有菜单生成和后端检查决定，收起、手机抽屉、锁标识和当前入口沿用原逻辑。

概览卡片与详情/预览使用--admin-preview-inset（桌面20px、窄屏16px）和--admin-preview-gap（桌面16px、窄屏12px）；列表仍使用原有紧凑参数。范围覆盖概览、媒体详情、只读记录详情、译文版本预览、正文预览和论文检索预览。长文本局部滚动、长名称换行，媒体保持原预览比例。受保护账号的具体原因在操作列直接显示。

新增间距与布局在admin-theme.css和admin.css统一维护，后台CSS资源版本更新为0.15.37，避免旧缓存影响更新。模拟DOM验证导航交互，不替代浏览器的实际布局验收。
