# 前台体验第三步：整体适配与自动化验收

版本：v0.15.101。

## 本步修复

1. 原公共字号脚本在跨标签页收到字号变更时，会同步 HTML 字号，但不会通知正在打开的浮层。本步复用 `public-reading-change` 事件通知筛选组件，并调用原定位函数，保留筛选值与焦点，不额外请求数据。
2. 引用格式控件允许换行，宽度不超过父容器；导航账号区允许收缩。窄屏大字体下导航文字自然换行，不强制一行。
3. 快传长文件名和状态文字允许断行；900px 以下且启用大字体时，接收码入口改为单列。背景不参与页面布局或鼠标命中。
4. 更新相关静态资源版本号，确保已访问过网站的浏览器取得新版字号和布局脚本。

业务代码修改均在前台模板、脚本与样式；同时更新了测试、版本号及说明文档。后台服务、管理界面代码、数据库 SQL 和 schema 校验快照保持不变。

## 自动化范围

使用真实服务端模板、临时合成数据和现有 DOM 用例检查首页、教师/学生、项目、论文、专利、课程、新闻、留言、登录及文件快传相关行为。覆盖大字体偏好记忆、语言切换、保存受限场景、筛选/排序/复制、连续加载、弹窗、背景可见性暂停与后台隔离。

前端交互测试 264 项通过，页面接口、模板与快传回归测试 288 项通过（1 项依赖弃用警告，无失败）。测试数量与结果见 `public-appearance-v101-verification.json`。全部前端交互测试通过不代表浏览器实际渲染已经人工验收。

## 真实浏览器验证限制

环境内没有可执行的 Chromium。本轮尝试安装 Playwright Chromium Headless Shell，但下载得到的压缩包无效，安装失败。因此**未执行真实浏览器截图、像素尺寸、实际横向溢出或 Windows 视觉验收**。不声称已经完成这些检查。

下面的现场清单留作 Windows Chrome/Edge 验收；它不是已执行结果。

| 场景 | 检查内容 |
| --- | --- |
| 320 / 375 / 390 / 412px 手机宽度 | 标准和大字体均可操作，导航/工具栏合理换行，页面没有横向撑开 |
| 768 / 1440px 平板与桌面宽度 | 首页两卡、列表、详情和快传区域排布自然 |
| 中英文 × 标准/大字体 | 文字不遮挡，按钮标题、输入框和长链接可用；刷新后保留字号 |
| 首页、教师、学生、课程 | 简介截行及展开保持正常，头像与占位不被挤压 |
| 项目、论文、专利 | 多选、复制和格式切换可用，勾选不丢失，筛选浮层不离开可视区 |
| 新闻、登录与留言 | 正文/PDF分隔、弹窗、表单校验和错误提示可读 |
| 连续加载 | 滚动追加内容后仍遵循当前字号；按钮、复制和展开可操作 |
| 文件快传 | 字号/语言切换不清空所选文件、代码或传输进度 |
| 减少动态效果、打印、高对比度 | 背景按相应模式静止或隐藏，不影响文字内容 |

## 更新方式

从 v0.15.95～v0.15.100 更新不需要重建数据库。保留运行数据并更新源码、重启网站。根目录 README 是 Windows 和 Ubuntu/Debian 启动教程入口。
