# v0.15.102 淡几何背景

共享背景脚本自动绘制两组 SVG：细线多边形、节点连线与曲线。教师网站及文件快传共用，不增加图片请求或第三方库。背景不接收鼠标事件，不进入读屏内容。

颜色、透明度、线宽、速度在 public-theme.css 的 --public-pattern-* 变量中统一调整；图案数量及形状由 public-background.js 管理。手机隐藏右侧图案；减少动态效果时静止，页面隐藏时暂停，打印和高对比度模式隐藏。

验证：8 项背景/字号 DOM 测试、2 项页面模板与后台隔离测试通过；矢量生成、重复执行不重复插入与表单值保持的冒烟检查通过。后台代码、快传后端、数据库与上一版逐文件一致。没有执行真实浏览器截图或 Windows 视觉验收。

更新源码并重启网站即可，无需初始化数据库。
