# 辅助输入与论文元数据

## 历史值联想

辅助输入从已保存的指定字段提取候选，帮助统一单位名称、期刊名、分类、作者等写法。它是已有数据建议，不是通用 AI 写作功能。

聚焦字段或输入文本后，下拉显示匹配候选。可选择候选，也可继续键入新值；建议接口暂时不可用时仍能手动输入。候选最多显示 50 项，来源查询读取最近更新的至多 300 条匹配记录，因此它不是全库分类统计。

| 模块 | 支持建议的字段 | 其中支持多值拆分的字段 |
| --- | --- | --- |
| 教师 | 角色、职称、单位、实验室 | 无 |
| 论文 | 期刊/会议、年份、作者、论文类型、作者角色、通讯作者、索引类型、展示标签、关键词 | 作者、论文类型、作者角色、通讯作者、索引类型、展示标签、关键词 |
| 项目 | 来源、基金、承担角色、负责人、成员、状态 | 承担角色、成员 |
| 专利软著 | 国家、类型、发明人、权利人、法律状态 | 发明人、权利人 |
| 学生 | 培养层次、分类、年级、方向、状态 | 分类、方向 |
| 学生分类显示 | 匹配关键词 | 匹配关键词 |
| 新闻 | 分类 | 分类 |
| 课程 | 学期、授课对象 | 授课对象 |
| 媒体 | 分类 | 分类 |

多值可使用英文分号、中文分号或换行分隔。输入新的一项时，建议匹配当前正在输入的片段；选中候选只替换该片段，保留此前已输入的值。候选按规范化后的内容去重，并排除已选项；不要用逗号代替分号拆分含逗号的姓名或机构名。

`/admin/translation/suggestions` 提供按模块、字段、关键词查看候选的入口。各模块表单是实际录入入口。

## 粘贴引用文本解析

在论文表单的引用辅助区域粘贴原始引用，系统识别支持的 GB/T、APA、IEEE、Elsevier 或 BibTeX 特征，显示识别格式、可信程度和提示，并提供可回填字段。

`source_citation` 保存原始引用文本；题名、作者、期刊、年份、卷期页、DOI 等使用独立字段保存。格式不完整或含歧义时可能无法全部识别，应对照原始文献确认。

## DOI 与题名查询

可用 DOI 或论文题名发起元数据查询，使用默认服务、选定服务或已配置的服务回退。支持的来源为 Crossref、OpenAlex、Semantic Scholar、DataCite、Europe PMC、PubMed，实际可用性受网络、来源覆盖和服务配置影响。

结果会说明服务尝试情况，如成功、未找到、限流、暂时失败或未配置。候选可能包含题名、作者、期刊/会议、年份、卷期页、DOI、URL、论文类型、通讯作者、摘要和关键词。

在差异表中比较“当前值”和“建议值”，只勾选需要更新的字段，再回填当前表单。可撤销单项或本次辅助回填，最后保存记录。查询不会自动上传论文 PDF，也不保证返回 SCI 等所有索引标签。

独立查询入口 `/admin/publications/metadata` 用于检索和查看元数据；正式写入仍通过内容表单完成。

## 引用与作者高亮生成

生成器读取当前论文表单的结构化字段，提供下列输出。

| 输出 | 保存字段 |
| --- | --- |
| GB/T 引用与高亮文本 | `citation_gbt`、`highlight_gbt` |
| Elsevier 引用与高亮文本 | `citation_elsevier`、`highlight_elsevier` |
| APA 引用与高亮文本 | `citation_apa`、`highlight_apa` |
| IEEE 引用与高亮文本 | `citation_ieee`、`highlight_ieee` |
| BibTeX | `bibtex` |

后台样式名称包括 GB/T 7714—2025、APA 7、Elsevier 编号式和 IEEE。生成结果用于本站展示及复制，应检查缺失字段提示；不同出版单位可能仍要求调整具体标点或字段。

作者高亮依据首位公开、启用、精选教师的中英文姓名匹配，不会可靠识别任意未配置的缩写、重名或别名。勾选输出项回填后需保存。

## 专利元数据与其他选取辅助

`/admin/patents/metadata` 支持按专利号码调用 PatentsView，展示查询结果供检查和录入。是否需要服务凭据由接口情况及后台配置决定。当前实现没有 EPO OPS 查询通道，相关数据库字段仅保存配置。

头像、封面、PDF、证书和课程资料使用媒体选择器；新闻的关联论文、项目和学生使用记录选择。它们保存受管理对象的 Key 或 UID，不应填写开发机绝对磁盘路径。

表单中标记了唯一性检查的字段会检查已有值冲突，例如账号或角色名称等相应字段；编辑已有记录时排除当前记录自身。必填、长度、格式和重复值提示属于录入校验，最终保存仍由服务端再次确认。

建议内容、外部元数据和引用生成都属于录入辅助。记录公开状态、精选、排序及附件权限仍由表单中的对应字段控制。
