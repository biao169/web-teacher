# 媒体库与选择器

## 支持的资源

媒体库用于统一管理人物照片、站点图标、新闻封面、正文图片、PDF、证书、课程资料及其他允许文件。数据库存储媒体元数据，文件按受管理的 object key 保存。

当前上传程序支持 `png`、`jpg`、`jpeg`、`gif`、`webp`、`mp4`、`webm`、`pdf`、`zip`。实际可上传格式还需在全局允许列表中，单文件大小取配置上限与程序 20 MiB 上限的有效较小值。

图片、视频、PDF 等按适用类型提供预览；ZIP 提供文件信息。媒体库能预览某个格式，不代表新闻富文本编辑器可以嵌入该格式。

## 选择与上传

在头像、封面、论文 PDF、证书、课程资料或富文本图片/PDF 字段打开媒体选择器。可以搜索名称和适用元数据、选择分类、翻页浏览、查看预览，确认后把对象 Key 填入表单。

媒体卡片以预览为主，标题和文件信息紧凑排列。图片区域保持透明背景，不额外绘制边框。按字段的类型限制选择，例如 PDF 字段只接受合适的 PDF。

上传后可维护标题、分类；分类支持多值历史建议。表单仍需保存，才建立该内容记录的正式引用。

## 图片裁剪

图片上传流程可使用裁剪功能，支持预设比例、原始比例、自定义宽高、缩放、拖动焦点、输出格式与质量；也可以选择使用原图。输出宽高范围为 64–4096 像素。

裁剪会生成待上传文件，不是对所有已引用同一 object key 的图片进行全站原地修改。正文图片的位置、浮动和替代文字则在富文本编辑器中维护。

## 引用与访问

主要媒体字段包括头像 `avatar_key`、封面 `cover_key`、论文 `pdf_key`、证书 `certificate_key`、课程 `syllabus_key`/`material_key`、站点 Logo/图标/分享图及留言 `attachment_key`。新闻正文中的图片和 PDF 也属于受管理引用。

媒体详情可查看引用来源，定位关联记录。引用中的媒体不能移入回收站；先解除实际引用，再决定是否回收。媒体 Key 不是公开访问授权，前台读取还要满足引用记录及附件的可见性条件。

## 回收站与清理

回收站入口为 `/admin/media/trash`。移入回收站后保留资源以便恢复；单条或适用批量操作均检查权限和记录版本。保留天数由全局设置配置。

永久清理只处理已经进入回收站且达到保留期的对象，清理会删除对应文件和媒体记录。可手动清理符合条件的资源或触发一批处理；受保护或变化中的记录会被跳过或报错。不要用直接删除磁盘文件代替媒体管理，否则数据库引用会失效。

## 数据字段

`media_assets` 保存 `object_key`、标题、分类、MIME 类型、字节大小、存储类型、状态、校验值及系统标识和时间。存储类型包括 `static`、`local`、`r2`、`external`；状态为 `active` 或 `trash`。完整约束见 [02_database_schema.md](02_database_schema.md)。
