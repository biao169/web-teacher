## 行为

安装、整站更新、恢复源码、依赖单独更新复用 install_dependencies。每次仅指定一个 HTTPS 索引，默认清华；不静默添加官方 extra-index，不关闭证书验证，也不修改全局 pip 配置。来源存入现有受管安装状态；旧状态没有 pip_source 时默认清华。

下载进程忽略 pip 配置文件和继承的 PIP_* 参数（保留显式 PIP_CERT），从而避免错误索引、额外索引或 trusted-host 设置干扰。普通 HTTP(S) 代理、系统网络和证书配置仍保留，因此网络环境仍可能影响结果；镜像变更不能保证所有网络故障永不发生。通过 pip-source 切回官方源是显式选择。

续装用于激活前的依赖阶段失败：确认受管目录/状态、唯一暂存源码、没有 current 或已有系统服务，校验清单后继续已有安装步骤。无额外数据清理、迁移或数据库重建。依赖再次失败时保留未激活状态供重试；后续配置/初始化阶段失败不能盲目套用此命令。
