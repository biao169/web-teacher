# 第三步：六位码前台接入（v0.15.96）

## 已完成

- 统一接收入口自动识别 LAN、在线中转、临时缓存，切到对应功能区。保留发送/接收区域的切换。
- 两种在线模式、临时文件和临时文件夹共享发码组件：六位码、复制、有效期、手动更新。未取得传输码不触发重新上传，原离线分享链接保留。
- 在线接收复用解析接口已建立的会话，不重复 join；网络结果不确定时重试沿用接收密钥。已有在线配对或接收会话时阻止新码覆盖。
- 接收信息确认与保存位置选择分开，文件/目录选择器由用户点击直接触发，保留浏览器手势要求。不会在解析码时自动下载或扣次数。
- 派生离线令牌仅接受本站严格格式路径，兼容原分享链接、文件夹落地入口及逐块接收。
- 状态、错误、标签支持即时中英文切换；复制不可用时选中文字。码过期后清除显示，取消在线配对时隐藏发送码。在线房间可能早于码的最大有效期失效，解析由服务端最终确认。
- 小屏表单纵向排布，输入和按钮不挤占整行；沿用全站字体和颜色变量。

## 范围

不更改后端传输策略、数据库结构或流量计算。v0.15.95 的 42 张表保持一致。已有的短码后台限流、权限、到期及撤销继续生效。

本版本对三种模式进行了模拟 HTTP 与 DOM 测试，不等同于实机跨设备 WebRTC/云网络验证。浏览器保存能力限制仍然存在：在线接收和原层级目录保存需要 HTTPS/localhost 及相应的文件系统 API。
