# 前台体验优化第一步：标准 / 大字体

版本：v0.15.99。

- 复用原 `teacher-reading` 浏览器存储键、`data-reading` 属性及已有 16px / 20px 根字号。
- 共用前台导航头增加 A / A+ 按钮。标准为默认，大字体按既有配置放大 25%；用户可在公共主题文件调整两档字号。
- 首次绘制前读取偏好；按钮使用原生键盘交互、焦点提示、双语标签与 aria-pressed。
- 切换中英文及快传动态替换头部后同步按钮状态，不重建内容区域，不清空文件选择、输入或进度。
- localStorage 不可用时仍允许本页切换；同源其他标签页变更偏好后同步。历史 comfortable 值归入大字体。
- 快传原固定像素字号改为等值 rem；标准模式原尺寸不变，大字体时一并放大。公共主题文件是字体、字号和颜色的统一入口。
- 大字体下导航、操作栏允许换行，品牌长文本可断行，输入控件不超过容器。原简介截行/展开规则保留。
- 管理后台不使用前台偏好；后台服务代码、数据库 SQL 及 schema 快照未改动。

验证：28 项 Python 页面/权限/登录兼容检查与 15 项 DOM 交互/主题检查通过。覆盖主站、快传、登录入口、保存偏好、禁用存储、跨标签页、头部替换及语言切换。本轮没有执行 Windows 实机浏览器视觉验收；后续第三步将继续检查整站布局。

下一步：CSS 自动生成浅色渐变、缓慢光晕及淡网格背景，适配窄屏和系统“减少动态效果”。
