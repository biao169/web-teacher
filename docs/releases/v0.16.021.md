# v0.16.021：快速重试与持久唤醒（第三步）

基于本分支 v0.16.020。新增后台站点级快速重试间隔，默认 10 秒；任务重试次数仍独立设置。慢速重试最多半小时，有持久进度即重置连续失败。修正异常远期失败任务，不改变定时计划周期。

原生辅助新增 SyncCoordinator SQLite Durable Object，Alarm 私有 RPC 唤醒主站/执行器，Cron 兜底；后台创建/继续/取消后轻量请求唤醒。没有新增 Worker。部署采用先创建辅助、主站部署成功后接入回调绑定；通过 Cloudflare Service 元数据核对迁移标记，保留主站 TransferCoordinator。

无需数据库结构变更：新增配置使用 service_meta；唯一初始化 SQL 仍为 database/schema.sql。DO 类迁移属于 Cloudflare 配置，不增加 SQL 初始化文件。

教程见 [网页部署与重试设置](../sync-retry-setup.md)。下一步为完整克隆：账号认证数据、完整媒体清单、跨 D1/SQLite 数据范围及大文件断点传输。
