# v0.16.023 · 第五步：同步后台布局与任务监控

基于本对话 v0.16.022 继续修改，入口仍为 `/admin/site-sync`。

## 界面调整

- 手动拉取、推送和定时计划使用多选卡片，不再使用滚动多选框；支持全选普通模块、清空选择和已选数量提示。整站克隆与普通模块互斥，不会因全选而意外选中覆盖账号的克隆模式。
- 复用后台颜色、按钮、输入框和基础模板。增加顶部留白，连接、密钥与接收策略集中折叠，保留直接可见的连通性测试入口。卡片按屏幕宽度排列，窄屏单列；宽表格在自身容器内滚动。
- 参数下增加用途、单位、范围及继承说明。修正旧的 200KB/20MiB 提示，明确当前 1MiB 正文和 1GiB 单媒体边界，以及正文切片与 R2 分段的区别。
- 保留分页、暂停、继续、取消、删除、任务日志折叠和统一 UTC+08:00 时间。可见页面约 10 秒刷新，编辑输入时避免轮询干扰；任务不依赖页面打开。
- 整站任务详情增加子阶段、当前业务表及阶段表进度、断点保存位置。整站审核按钮改为“批准整个克隆任务”，候选行不再逐项勾选。监控接口只返回经过筛选的状态，不返回账号暂存正文和密码哈希。
- 本站非 JSON 错误响应及连通性测试失败可显示 HTTP 状态、1101/1102 和响应提供的 Ray ID；完整任务诊断仍在折叠日志中。

## 使用方法

1. 打开“连接、密钥与接收策略”检查或修改已有配置，保存后测试连通性。
2. 在手动任务区点击内容卡片，可多选普通模块或单独选择整站克隆，再点击拉取或推送。
3. 在任务行点击“展开进度 / 日志”，查看子阶段、时间、当前记录、断点与错误。整站应用过程可能持续较久，传输完成不等于账号切换完成。
4. 定时任务使用独立的卡片选择，编辑计划会恢复其原有选择，不影响手动任务区。

本步不改变数据库结构和部署变量。更新主站代码与静态资源即可使用；全包可沿用原部署流程，CSS/JS 地址已更新缓存版本。
