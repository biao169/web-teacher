# v0.16.076：导航保护与读取取消

新增共享 navigation-guard.js。首次普通同源链接保留原生跳转，派发teacher:navigation-start；锁定期间阻止后续同类点击。组件已preventDefault的链接、弹窗、新标签页、下载、外链、修饰键、页内锚点不进入保护。3秒仍未pagehide则解锁并派发teacher:navigation-cancel恢复读取；pagehide清定时器，pageshow解锁。不接管表单提交、不取消写请求或服务器同步任务。

接入Public fragment队列、身份与私有字段、导航预取、筛选/简介/引用读取、筛选弹层及待执行图片重试。导航取消恢复队列、身份验证和图片重试机会；被取消的旧响应不得写入当前页面。Admin概览、共享requestJSON的GET/HEAD、媒体摘要与使用位置读取接入取消，POST等写请求继续执行。媒体摘要恢复从未完成批次继续，不遍历其他分页。公开与后台已显示业务内容不被全页清空。

主要改动：frontend/shared/static/js/navigation-guard.js（新增）、frontend/shared/templates/base.html；frontend/public/static/js/public-stream.js、public-session.js、public-prefetch.js、public-people.js、public-filters.js、academic.js；frontend/admin/static/js/native-http.js、native-dashboard.js、native-media-locations.js。相关模板/调用模块更新静态版本号；HTML ETag表示版本同步更新。数据库、同步协议、Executor、Native和Worker部署策略不改。

验证：40项Python测试、148项前端DOM测试通过；simple+separate离线打包/快照验证通过。包括首次/重复点击、3秒恢复、特殊链接、取消后迟到响应、恢复身份、GET取消但POST继续、图片、媒体、筛选、概览回归。未进行真实浏览器跨PoP、线上CPU/缓存HIT或Cloudflare发布验收。

取消是浏览器读取生命周期控制，不保证停止服务器上已经开始的Python/D1操作，不销毁Worker isolate。本轮不宣称消除1101/1102。

下一步：进一步完善BFCache与Worker请求取消信号传递。保留共享页面仅校验公开revision、私有组件重新鉴权；评估并验证Public→Admin的AbortSignal传递、兼容标志和取消日志分类，避免将正常取消误报为503。随后双平台及线上指标验收。
