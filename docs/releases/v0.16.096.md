# v0.16.096 — 身份显示缓存第一步：双平台接口契约

本步只完善已有 /api/public/session-summary，不启用前端身份缓存或心跳。Worker Admin 与 Ubuntu/Debian 继续复用同一个接口和 Auth.public_principal。

响应保留现有字段，新增 checked_at、display_ttl_seconds（登录300、匿名60）、heartbeat_interval_seconds（300）。已登录额外返回 idle_expires_at、absolute_expires_at。时间沿用数据库UTC格式。后续前端应基于服务端checked_at计算时间差，显示有效期不得超过会话期限；这些仅是显示提示，不能用于授权。

public_principal读取现有idle_expires_at字段；确需续期时在原UPDATE增加RETURNING，直接取实际保存值，无额外SELECT，最多120秒更新一次，不能复活失效会话或超过绝对期限。无需数据库变更。

未登录/无效会话返回200 authenticated=false；存储或普通应用异常返回503 SESSION_CHECK_UNAVAILABLE、retryable、request_id及Retry-After:60，不返回authenticated=false，记录现有结构化诊断，不向客户端暴露异常正文。CancelledError不被普通异常捕获。响应仍no-store，不进共享缓存；成功身份响应保留CSRF供旧前端使用，后续浏览器摘要严禁持久保存CSRF和令牌。

43项Python回归通过，覆盖local/r2配置、已登录/匿名/撤销/失效/禁用账号角色、写入节流、绝对期限、故障分类、原私有接口及版本锁检查。simple+separate离线源码打包与快照检查通过；未执行真实Worker D1或云端发布。

清理148份源码/文档未引用的历史.log（原始约468381字节）；保留部署教程、源代码、测试、数据库升级描述及运行资源。Python临时字节码与pytest缓存不进入交付包。移除文件列表如下。
