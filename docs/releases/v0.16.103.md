# v0.16.103 — 粗粒度公开 Read Model

基线：v0.16.102-public-page-cache-step2。本轮完成第三步，未部署线上。

## 实现

新增 backend/app/native/public_read_model.py。build(resource,module,lang) 只读生成完整模块/语言模型。支持 profiles、students、research_interests、projects、publications、patents、courses、news 八类内容及 zh/en；模型键如 profiles-public-index-zh。

模型生成器不接受用户筛选、排序、分页或登录权限参数；独立使用 Content.scope(public=True)，即使调用者是系统管理员也只读公共范围。当前未新增 HTTP 路由，未接入 PublicData entrypoint，未改前端筛选。PublicPage HIT/MISS 路径与 v0.16.102 相同，不调用模型生成器。

## 模型契约

- schema_version、model_key、module、lang、revision、generated_at。
- complete=true、total、items，仅当全部所选公开记录通过预算与一致性检查后返回。
- 每条记录包含 uid、display、filter_values、filter_tokens、search_values、order、media、links、detail_url。
- display 为当前语言的公开列表字段，简介沿用原列表2000字符摘要规则；filter_values/search_values保留预算内的完整源文本，不能拿被裁剪摘要替代完整筛选/搜索输入。
- 过滤键保持原文；多值字段按半角/全角分号及CR/LF拆分，保留原始组合值，同时提供完整词项。
- 原文和有效英文均可搜索，zh模型也保留有效英文搜索值；匹配为字面子串，ASCII大小写不敏感，不把%/_/反斜杠当作通配符。
- 筛选字段元数据包含数据类型、允许的eq/contains与原值/完整词项比较语义。派生年份来自现有日期规则；项目角色复用原别名规范化。
- 公开列表既有排序按rank复现；学生先按启用分类规则分组，再按sort_order/id稳定排序，倒序只反转组内次序。内部数据库ID和原sort_order不导出。
- facets 为当前模型全部公开记录的完整选项，保留原文value与英文label分离；不只读取第一页或前50个选项。学生多值选项按现有ASCII NOCASE规则去重。
- 自定义导航固定条件仍标记为server fallback，留第五步完成前端语义一致性后启用，不能按不完整字段擅自扩大范围。

## 隐私与媒体

不读取或导出session、权限、CSRF、后台凭据及账户数据；邮件/电话/办公室在SQL投影时按contact_visibility='public'过滤。模型不沿用调用者r.p或r.content的权限。

项目principal/amount/members从SQL投影、展示、搜索和过滤中全部排除。新闻仅包含公开已发布记录，正文不进入模型；论文abstract/source_citation不读取，较大的citation/highlight内容不进入列表索引，后续仍按既有引文接口按需获取。

只批量解析当前公开记录引用的active媒体，PDF和课程材料必须明确public。返回/media/<uid>，不导出object_key或存储地址。结构化链接仅允许HTTP/HTTPS及合法ORCID；JSON展示字符串仍须在前端作为文本处理，不能直接插入HTML。

## 翻译读取

复用现有翻译字段、原文hash、公开来源资格、格式和winner规则；批量读取local/shared有效候选，不逐条调用overlay、不调用翻译服务或写翻译表。

保持native English > 本地停止/手工/明确选定规则 > 无冲突共享winner > 有效本地结果的原语义。精确匹配原文、hash、语言和plain格式；私有/失活/未发布来源不能作为共享donor。使用hash限制候选范围，JSON打包绑定键避免超过D1绑定变量上限。

## 预算与失败

默认硬上限（仅可在代码中降低，不能通过旧缓存变量无限放大）：

| 项目 | 上限 |
|---|---:|
| 单模块记录 | 500 |
| 最终UTF-8 JSON | 512 KiB |
| 普通字段 | 4096字符 |
| 简介字段 | 8192字符 |
| 学生分类规则 | 50 |
| 每批记录读取 | 25 |
| 每批翻译字段 | 80 |
| 单次模型查询总数 | 40 |

先查询max_rows+1个UID作超限检测，再按有限批次投影字段。超过任何预算、源记录消失、生成前后持久内容revision变化都会抛ModelUnavailable（503，PUBLIC_MODEL_UNAVAILABLE，内部reason），不返回partial success，不截取前500条冒充全量。

complete表示本次枚举范围的完整索引；多次查询不等于数据库事务快照。revision检测覆盖遵守既有内容版本更新规则的写入，不承诺对绕过版本规则的直接数据库写入或所有并发变化提供事务级一致性。Sync协议未改。

stats包含实际查询数和最终JSON字节量。没有SQL缓存、Python Cache API、Cron巡检、数据库迁移或新服务绑定。
