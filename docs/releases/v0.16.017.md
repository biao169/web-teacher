# v0.16.017 — 可选部署密钥与教程（第五步）

基于 v0.16.016-step4。部署时未填同步密钥允许发布，填入无效值仍拒绝。辅助API未传密钥时保留既有Secret；主站传空JSON密钥文件而非空密钥值，保留既有Secret。数据库后台密钥不由发布器修改。

cloud-check 将平台配置与同步就绪状态分开。固定只读D1查询只返回valid/invalid/missing，不返回密钥；查询失败标记not_verified，管理员可检查D1 Read权限和后台配置。环境Secret存在性不能证明内容相同。平台检查成功不代表同步业务验收完成。

主要修改 deploy/cloudflare/deploy_config.py、companion_release.py、pipeline.py、cloud_check.py，新增 credential_probe.py。教程 docs/sync-key-setup.md、deploy/cloudflare/README.md、deploy/linux/README.md。唯一 database/schema.sql不变。

验证覆盖两模式无密钥发布编排、辅助Secret保留、非法密钥拒绝、数据库诊断缺失/有效/损坏/无权限、只读SQL和固定API契约。尚未使用真实Cloudflare凭据执行部署；D1诊断查询仅本地SQLite及API模拟验证。

后续：综合验收两平台新安装、密钥轮换、三种同步模式及真实Worker错误恢复；完成真实浏览器桌面/移动端检查。本轮未修改Linux系统依赖安装策略。

验证结果：241项Python测试、33项子测试通过；实际Wrangler 4.143.0 dry-run接受空密钥JSON，并生成保留secret_text/secret_key的上传元数据，不包含空同步密钥。此工具契约验证使用既有原生探针配置，不代表真实云端发布。
