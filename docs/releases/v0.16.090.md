# v0.16.090 — 应用层恢复与缓存边界精简

基于 v0.16.089。删除应用内部 stale HTML 保存/回退及 middleware 捕获异常后寻找旧页的分支。保留应用层无缓存错误提示与原始异常日志，Public 正常请求仍直接 dispatch。

## 当前边界

- simple：不使用 Worker SQL/Page Cache API；成功 Public HTML 默认30分钟浏览器/边缘策略，保留 ETag/304。
- full：保留内部完整缓存，Page Cache TTL 恢复正常值；使用 teacher-public-pages-v2 避免旧版长寿命条目。不再由 Python 读取旧 HTML 进行 stale 回退。
- off：保持原有 TTL=0、关闭预取及内部缓存的部署配置。
- Admin/Auth/Sync/写操作保持原有鉴权与 no-store 边界。
- 成功页面仍发送 stale-while-revalidate=120、stale-if-error=86400。这是 HTTP 声明，不保证所有浏览器或 CDN 都会提供旧页，真实命中行为需线上验收。
- 错误页不缓存，不清理浏览器全站缓存。恢复页取消自动计时和自动导航；只有用户点击才发起 __recover=1 的手动新请求。再次失败也不会自动重试。成功后仍清除恢复参数。
- 保留纯浏览器 SVG 拖动，无 Worker 动画开销。Ubuntu/Debian LocalPageStore AST 与089一致，页面LRU未改；无Linux部署文件变更。

## 验证

83项Python回归、14项DOM测试通过。包括full正常HIT/TTL/错误不写入，simple/off内部缓存关闭，错误no-store，Public入口直通，Admin恢复边界，手动重载和BFCache。未真实部署Cloudflare，不能宣称已定位或根治空白500。
