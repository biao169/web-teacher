# v0.16.074：标准 Worker Public 共享 HTML 与 ETag

标准 Worker Public GET/HEAD（首页、内容列表、可共享详情、列表fragment）使用 r.p=None，不调用 principal/public_principal，不读取会话或更新心跳。公共导航、通知身份指纹和公开正文采用匿名上下文。账号、CSRF退出、后台入口和项目私有字段仍由 v073 的私有组件提供。项目列表查询仍排除私有字段。

新闻详情按唯一 UID 查询 allow_comments：有留言表单时保留认证、表单挑战Cookie及 no-store，不进入共享路径。联系表单、自定义导航 /en/n/*、/zh/n/*、私有API、Admin/Auth/写操作保留原鉴权。Ubuntu/Debian原页面认证、LRU与缓存策略不变；数据库和同步代码未修改。

共享响应不按 Cookie/Authorization 区分，Vary保留X-Public-Fragment，ETag由公开版本、语言路径、规范查询、表示类型、配置等构成。普通登录、管理员、匿名和无效Cookie对应相同HTML与ETag。共享详情先验证记录存在和公开性后才能304；错误和Set-Cookie响应仍禁止缓存。新闻留言详情不生成共享ETag。

BFCache恢复时仅共享页面请求 /api/public/cache-revision?shared=1，Worker省略身份读取；本地端仍验证身份。私有组件按原逻辑重新鉴权。尚未启用Workers边缘缓存，未改变默认页面TTL。

验证：107项Python回归、33项DOM测试通过；separate离线产物验证通过。覆盖跨身份字节/ETag一致、认证方法零调用、304/HEAD、fragment隔离、新闻表单鉴权、自定义导航鉴权、私有接口、权限变化、删除/隐藏记录不得304及本地缓存回归。未执行线上部署、真实D1/R2、CPU或Wrangler SDK bundle验收。

实现文件：backend/app/native/web_common.py、web_public.py、public_http_cache.py；frontend/public/templates/native.html、layout.html；frontend/public/static/js/public-stream.js。另更新版本信息、测试和发布说明。
