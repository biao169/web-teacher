# v0.16.002：第一步，维护页面合并与独立同步导航

基于本分支 v0.16.001，沿用指定 v0.15.160 网站来源，没有引入其他版本。

## 本次完成

- 删除独立日志管控页面及其控制器、模板、菜单。`/admin/log-maintenance` 不再提供服务，不保留兼容跳转。
- `/admin/runtime-maintenance` 成为统一维护入口。本地显示资源、磁盘、日志轮转和清理；Worker 显示数据库日志策略、每批最多20条的预览/清理和最近手动清理结果，不访问本地文件系统。
- 本地保存日志策略后立即应用日志处理器设置；Worker 使用同一策略保存逻辑，并保留既有 Cron 日志清理。
- 新增侧边栏“两站同步”，入口 `/admin/site-sync`，使用独立同步图标与选中状态。运行维护补齐 SVG 图标。
- 从数据与备份页面移除同步链接，删除旧 `/admin/data-tools/sync` 页面入口，不提供兼容跳转。
- 保留系统管理员、模块权限和 CSRF 校验；操作仍按权限区分查看、编辑与删除。

## 验证

70项针对性测试通过：本地/Worker维护、保存、预览、清理批量上限、旧地址不可用、权限、跨域名访问、图标、同步业务集成及启动检查。
Chromium真实后台验证通过：登录、同步导航、批准/暂停/设置/计划、移动宽度、维护状态加载与预览。
Worker源码暂存、快照导入、图标静态资源、双域名与VPS配置生成检查通过。未执行生产部署或Cloudflare实机验收。

本步没有数据库结构变化，仍只有 `database/schema.sql` 一个初始化SQL。
