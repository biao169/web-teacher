# v0.16.120：登录身份交接（第一步）

基于 v119，仅修改登录显示及身份确认。保持 v113 缓存政策、v119 Header/悬浮手机菜单和全部 Sync 源码不变。未新增固定入口缓存，未发布线上。

登录成功的 no-store JSON 返回 authenticated、username、display_name、can_enter_admin、checked_at 五个显示字段；直接复用登录用户查询，使用 EXISTS 取得后台入口显示提示，不增加登录后 principal/session-summary 读取。原登录返回 token 接口保持兼容；session INSERT RETURNING 验证真实建立会话后才返回登录成功。密码、token、CSRF、权限和私有数据不进入身份快照。

同页弹窗登录：保存快照、更新身份、关闭弹窗及聚焦账户，不重载页面，不立即重查。跨页面返回：一次性同源路径/查询绑定的30秒显示交接，目标页面消费一次；之后普通新页面先显示快照，再后台确认Cookie。原页面的前台筛选及短时间 BFCache/可见性恢复继续复用快照；活跃心跳及失败退避不变，避免同一页面重复验证。

接收登录结果后中止旧读取并递增 generation，使旧匿名结果或旧私有字段响应不能覆盖新状态。跨标签页变更只广播失效标记。请求失败保留用户名，明确 authenticated=false 才切回登录按钮。退出仍先实时取得CSRF；后台权限和私有数据由服务器验证。

验证：58项Python回归、54项DOM测试通过。真实Chromium验证同页立即登录UI、登录后0额外summary请求、下一公开页后台确认、503保持身份和无页面JS异常；快照只有5个显示字段。覆盖旧响应竞态、一次性交接路径/过期/失效、存储禁用、失败登录和原生303回退。

部署需完整更新Python与静态资源。已有浏览器/边缘HTML和旧JS缓存不会被本地源码更新自动清除；按现有部署流程刷新 public-layout 对应页面，并确认加载 public-auth/public-session/identity-cache 的120版本资源。未执行线上清理。线上1101及实际缓存传播不在本次本地验证结论中。
