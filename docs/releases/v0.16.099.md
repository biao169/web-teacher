# v0.16.099 — 活跃心跳与双平台身份组件（第四步）

Public使用同一身份摘要请求完成验证及会话续期。页面可见且最近10分钟有点击/按键/滚动时，最多约每5分钟核验一次；活动监听只更新时间，不立即发送请求。匿名无周期心跳。隐藏、离开、导航开始清除定时器及只读请求；恢复可见/BFCache按摘要期限判断，过期才核验，不补发错过的心跳。无操作时不无限保活。

临时错误和请求超时采用60/120/240秒等待，最多240秒；等待信息只保存在当前标签页sessionStorage，跨页面/可见性变化不绕过退避。显式登录变化及用户点击退出可强制核验。不会把失败解释为未登录，不吞掉服务端异常。请求代次与单请求合并沿用原实现，无新服务端接口、Cron、后台任务或SQL缓存。

Linux标准Public GET/HEAD也启用已有public_shared/public_components，身份由私有摘要接口核验；普通HTML不再查询身份和后台菜单。保留Linux原LRU/Data LRU/预取/并发与部署结构，只让登录用户的标准公共内容也可复用原匿名缓存。表单、允许评论的新闻详情、自定义导航、后台、私有API继续鉴权。不改变Sync Executor/Native及协议。

由于Linux标准HTML身份边界发生变化，统一更新ETag representation版本。浏览器已有新鲜旧HTML仍可能在原30分钟TTL内复用，可正常刷新当前页面加载新脚本；不发送Clear-Site-Data或清全站浏览器缓存。

服务端仍使用096规则：120秒写入节流、空闲30分钟、绝对12小时；心跳不能恢复已过期/撤销会话，不能超过绝对期限。浏览器后台休眠可能延迟计时，不保证永不过期。缓存身份仅是显示，私有API实时检查。

验证：77项Python、25项DOM测试；覆盖两平台共享HTML/ETag/不读取Auth、身份接口、私有权限、原Linux LRU/预取、写入节流与失效会话。前端虚拟时钟验证五分钟心跳、隐藏暂停、恢复合并、无操作停止、匿名不轮询、60秒退避。simple+separate离线打包/快照通过。未真实云端发布、真实D1额度或浏览器长时间运行验收。

清理临时字节码与pytest缓存，不增加依赖、截图或浏览器工具到源码包。版本和实际uv.lock同步。无需数据库结构变更。
