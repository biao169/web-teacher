# v0.16.123：统一论文卡片模板（第一步）

基于 v122，仅修复前台论文卡片。backend、缓存政策、Worker runtime、PublicData schema、登录脚本、Sync及数据库内容不变；更新发布元数据和 public-list 静态资源版本。不修改标签拆分和新闻分类。

没有新增HTML文件。普通论文页输出一次惰性template，直接include现有content-card.html，其content-body.html继续复用精选入口与首页的引文、底部链接、复制图标和标签。JS对论文提前分支克隆该完整模板，填充uid/序号/选择说明、引文、DOI/原文/公开PDF和标签，不再单独拼装publication布局、文字复制按钮或标签位置。首页保留原有网格外壳，列表保留序号与选择外壳；共享正文及footer结构一致，不改首页布局。

citation.html用同一fallback宏生成服务端和动态占位内容，保持四种引文格式、缺失提示、卷期页及DOI一致。publication-tags.html只增加绑定槽，仍保留四类标签原有整字段显示和通讯作者说明/标注；下一步才处理多值拆分。复制SVG仍来自既有card-icons.html，状态aria-live及安全外链rel属性保留。数据均用textContent和受限URL赋值，模板之外不插入数据HTML，不增加SQL或PublicData请求。

旧HTML缺少新模板时保留服务端卡片和原有筛选/分页，不用另一套JS卡片作为fallback。空列表也能输出模板，后续模型切换正常。

验证：59项Python回归及45项DOM测试通过。覆盖普通/固定/首页分片同一论文正文、服务端模板复用、复制图标、通讯作者、中文英文、DOI与公开PDF、缺失引文四种格式、HTML文本安全和旧模板兼容。真实Chromium153的中英文×390/1440px四个场景确认SSR与PublicData替换后及精选入口内容一致，动态筛选/分页不重复请求公开数据且无页面JS异常。

未部署或清理线上缓存。完整源码重建后发布才能生效；本轮不增加或调整任何缓存功能。
