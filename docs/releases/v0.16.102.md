# v0.16.102 — 重建 PublicPage 路由与成功响应缓存

基线：v0.16.101-public-cache-reset-step1。本版仅完成第二步，未部署线上。

## 路由与缓存

Default 平台缓存保持关闭；只有静态白名单GET/HEAD转发到缓存开启的PublicPage入口。Host在转发及可能的平台HIT之前校验，Cookie/Authorization从转发副本删除，原请求保持不变。公开HTML是匿名公共视图，登录状态继续由独立摘要接口确认。

启用路由：/en、/zh；profiles、students、research_interests、projects、publications、patents、courses、news 的中英文标准列表；profiles/courses 的公开详情。详情只允许无query，或系统生成的返回对应语言、对应模块默认列表的唯一from编码。带筛选/分页条件的from以及其他query均动态处理。因此每个详情至多有两个允许的URL变体，不缓存无限自由query。

新闻详情可能包含评论表单，尚未拆出身份相关部分，全部暂不进入PublicPage。项目、论文等详情目前是原应用的跳转入口，不缓存跳转。自定义导航、筛选/排序/分页query、JSON片段、Range/写入前置条件、Admin/Auth/session-summary/Sync及非GET/HEAD不走共享入口。

Public HTML MISS直接执行原FastAPI/D1/Jinja，不依赖PublicData、不使用Python Cache API、不缓存SQL。共享入口平台HIT可跳过页面应用和D1；Default仍执行静态分流和Host检查。

## 成功响应与ETag

只有白名单路由、共享匿名视图、完整200 text/html、无Set-Cookie，且原页面正常生成完成后，才设置X-Teacher-Render-OK: 1及公共缓存响应头。中间件再次核对成功标记、方法、路由、类型和共享范围；仅有200状态或public响应头的错误模板也会被禁止缓存。

- Cache-Control: public, max-age=1800
- Cloudflare-CDN-Cache-Control: public, max-age=1800, stale-while-revalidate=300, stale-if-error=86400
- Vary: X-Public-Fragment
- ETag: 最终HTML的SHA256弱验证值

条件匹配可返回304；HEAD与GET对应相同ETag及表示长度。公开详情先读取并验证存在/可见性后，才可能返回304。动态内容、表单、JSON片段、错误、Set-Cookie均no-store，错误响应的成功标记和ETag被移除。

当前ETag由完成的HTML计算，应用层条件请求MISS仍需查库和渲染；304节省传输，不宣称它减少页面重建CPU。版本号仍保持旧持久键兼容，不新增数据库迁移。

## 故障回退边界

旧成功内容回退由Workers Caching处理。只有已有且未淘汰的成功条目，并位于允许的stale窗口内，刷新错误才可能返回旧成功内容；没有旧条目的MISS、Default入口故障、平台故障不由本版保证。未新增Recovery层、Service Worker、缓存巡检或故障时purge。

尚未接入后台修改后的Cache-Tag invalidate/purge通知（第七步）；普通公开更新可能延迟至缓存到期，浏览器旧HTML也不能被服务器直接清除。内容撤回及敏感数据变更的即时失效仍需后续实施和线上验证。
