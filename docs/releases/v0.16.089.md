# v0.16.089 — Public 请求链精简（第三步）

基于 0.16.087，未复用 088。此版本是受控减负候选，不是已确认的线上根因修复。

## 修改

- Public 正常请求直接 dispatch，移除 080 的 Worker 外层 eligible/run Recovery。
- request_diagnostics 移除响应包装失败后的第二层恢复；保留 077 已有响应包装、追踪和异常日志。
- snapshot 移除新增 Public Recovery 显式预加载及模板预热。保留原有依赖预加载和 Admin 修复。
- 应用层恢复页、stale、恢复脚本仍保留，留待下一步处理；不能宣称所有 Recovery 已移除。
- 修正测试替身缺少 __spec__ 的问题；历史 Recovery 测试改为直接验证保留的辅助函数，新增实际入口直通测试。

## 验证

Public/启动/诊断/保留辅助函数 66 项通过；Admin 32 项通过，共 98 项。本地 Python 测试，不等于真实 Pyodide、D1、Cloudflare 冷启动验证。未线上发布。

## 边界与下一步

不改缓存 TTL、Linux、认证业务、Sync Executor/Native、协议、checkpoint 或数据库。错误日志保留；移除外围兜底后，应用层之前发生的异常仍可能产生平台错误，不保证恢复页必达。

无需新增部署变量，沿用 simple/separate。部署后记录 /en、/zh 的状态、Ray ID、时间及平台错误。087 与本候选对比仍需固定环境；生产当前稳定的 077 应保留为回退版本。

下一步精简应用层 stale/recovery 及自动重试路径，仍保留成功页30分钟缓存和错误 no-store；应结合线上对比结果，不再叠加恢复层。
