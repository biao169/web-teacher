# v0.16.011：单构建项目辅助 API 发布

基于本分支 v0.16.010-step1，原始来源 v0.15.160-step6。没有使用此前暂停的分项目发布草稿。

## 修改

- deploy_config.py：集中检查主站构建身份、账号 ID、辅助发布令牌与同步密钥。保留 CI 名称/tag 校验。
- companion_release.py：固定 Cloudflare API 地址，拒绝重定向，API 错误只显示状态/错误码，限制响应体及重试。检查辅助对象归属，拒绝未标记的同名对象；明确新建与权限失败的区别。
- 从官方 multipart 产物中仅更新 metadata，注入归属及同步 Secret，保持二进制模块不变。上传后关闭 workers.dev/preview URL，核对绑定、密钥类型及 Cron。
- pipeline.py：辅助 dry-run 导出实际 API 上传包；辅助通过独立授权令牌上传，主站仍由关联 Wrangler 发布。主站同步密钥通过 secrets-file 随版本发布；临时文件权限 0600 并及时删除。辅助令牌不传入子进程/运行时。
- 先辅助后主站，最后激活独立 Cron。切回 inline 停用归属匹配的旧执行器 Cron，不删除 Worker。发布不是跨组件原子事务，失败需重试完成；不宣称自动回滚。
- site_sync/integration/package.py 与 companions.py 统一辅助命名，避免长名称截断规则漂移。
- deploy/cloudflare/README.md 改为当前网页部署教程，包含每个变量的位置、内容、权限和发布步骤。

## 验证

Cloudflare 测试目录：199 项测试、20 个子测试通过。最终更改后的发布器/流水线针对性测试：27 项、14 个子测试通过。测试使用模拟 API，覆盖 inline/separate、重复发布、已有冲突、权限失败、临时网络/503重试、私有配置失败后重试和模式切换。

实际 JavaScript multipart 与 Python multipart（1345个模块）分别注入 metadata 后，逐个模块摘要保持一致。独立执行器离线装配、快照导入、VPS 配置、静态资源检查通过。唯一初始化 SQL 仍为 database/schema.sql。

真实 Cloudflare 账号 API 上传、平台 Python 启动、真实 Secrets/Cron/私有访问及业务调用未验证。无用户账号凭据；未操作线上资源。部署器写权限只在相应实际调用时能最终确认。已有旧版辅助对象缺少归属标记时会停止，不自动接管。

下一步：在真实 Cloudflare 构建中联调首次部署及恢复路径，再优化原生辅助模块独立打包开销。当前包已接入 API 自动发布代码，不把本地测试等同于线上成功。
