# v0.16.015 — 后台密钥运行接入（第三步）

基于 v0.16.014-step2。保留唯一 database/schema.sql，无表结构变更。

Python主站连接配置、签名来源接口、Linux拉取及推送使用异步统一读取；JS原生流式模块读取同一D1配置。独立同步执行器继续通过同一原生服务签名。数据库优先，环境后备；配置损坏不退回旧密钥，不使用长期进程缓存。请求内复用密钥，后续操作重新读取。

HTTP401/403表示远端未授权（无法仅凭状态码区分密钥、导出策略或代理原因），任务以CredentialRetryError保留断点、按已有快速/慢速退避继续尝试。不会忽略鉴权或写入未验证数据；本地授权撤销、人工暂停仍保持停止；响应签名篡改仍拒绝。密钥保存不改变任务授权修订号，不重置任务，不唤醒人工暂停任务。

接口 runtime_integration=active。管理页面按钮尚未接入；当前仍需原有部署环境密钥，部署必填限制与cloud-check将在后续步骤调整。两端换密钥建议先暂停，分别保存同一密钥后继续。已开始的一次请求可以按其启动时密钥结束；新操作使用新密钥。

新增 site_sync/worker/credentials.mjs；修改 integration/host.py、web.py、proposals.py、credentials_api.py，worker/native_dispatch.mjs、source_media.mjs、transport.mjs，Python传输错误分类与日志。密钥不进入任务日志。

验证包括真实本地HTTP切片传输、SQLite/D1适配器模拟、连续12次密钥错误后恢复、已有正文分片在鉴权失败中不变及最终完成、Python签名接口旧密钥拒绝/新密钥接受、JS数据库优先与轮换。未执行真实Cloudflare发布、D1或额度验收。
