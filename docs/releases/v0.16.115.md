# v0.16.115 — 登录成功身份交接

基于v0.16.114，未发布线上。

## 修改

登录使用现有用户查询同时取得后台显示提示；会话INSERT RETURNING确认实际创建成功。Auth.login默认仍返回token，公开登录调用显式请求最小身份显示结果。JSON成功响应附带authenticated、username、display_name、can_enter_admin、checked_at五字段，Cookie仍仅通过Set-Cookie传递。默认跳转复用已取得的显示结果，不再额外调用principal；必须修改密码的用户不显示后台入口。登录及表单响应同时声明浏览器和Cloudflare no-store。

前端成功时先更换跨标签失效stamp，再保存新快照、清除重试退避，然后触发navigation-start取消旧请求并跳转。不会发出旧identity-change事件，避免离开页面前强制session-summary或私有数据读取。新页面在300秒窗口直接复用快照。显式身份恢复可取消旧请求并复用成功快照；迟到响应不能覆盖它。其他标签页仅收到stamp变动并静默重新确认，不共享身份或凭据。脚本版本统一更新。

独立登录页面和弹窗都使用同一提交处理。无JavaScript普通表单仍返回303；服务器无法直接写入sessionStorage，也不会用Cookie存在或URL参数假定身份。缺少快照时公开页面保持默认登录按钮并做一次静默确认。缓存仅控制显示；退出获取真实CSRF、后台访问、私有数据和写入仍实时鉴权。身份失败、心跳、300秒TTL规则保留。

## 验证

63项Python测试通过：公开认证/身份验收22、账户/Worker角色回归33、新交接/默认匿名显示8。53项DOM测试通过：真实提交处理的快照保存顺序、缓存复用、迟到响应、失败静默、心跳及登录弹窗等。三个JS语法检查通过。测试证明登录响应不重新调用principal/public_principal，五字段不含token、CSRF、权限或私有字段，错误登录无快照，密码检查期间账号停用不能返回成功。

DOM环境不支持真实页面跳转（记录有预期的navigation not implemented诊断）；交接顺序与跳转前事件已验证，真实浏览器Cookie/跨页导航与线上Cloudflare发布未执行。本轮未重复全仓库、Worker dry-run或缓存平台验证。

Sync和deploy所有原清单文件逐字节不变。没有新增Worker、缓存层、Cron、预热或同步协议改动。
