## 复现入口

安装项目测试依赖及 tests/package.json 的Node依赖后，在源码根目录运行：

```bash
python -B tests/run_acceptance.py --dom --report /tmp/teacher-acceptance.json
```

该命令不安装依赖、不发布、不使用生产数据库。完整浏览器测试另需安装Playwright及Chromium，加入--browser。平台没有Node或浏览器时报告应保留not_run，不应当作通过。
