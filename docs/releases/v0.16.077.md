# v0.16.077：BFCache与Public→Admin取消传递

Public/Admin生成enable_request_signal与request_signal_passthrough，移除相反标志，不变更兼容日期，Sync Executor/Native不继承。Service Binding继续原样转发Request；不读取正文、不构建Public应用、不手动重放请求。

新增worker_runtime/request_cancel.py，要求已确认signal.aborted并符合AbortError/Pyodide DOMException或asyncio.CancelledError才分类为取消；其他异常仍保留诊断。已取消只读请求提前结束；可返回时499+CLIENT_CANCELLED+no-store。记录HTTP-CANCELLED/INVOCATION-CANCELLED与application_outcome=cancelled。asyncio取消重新抛出，不吞掉运行时取消。真正Admin转发异常保持503并增加Retry-After:1。

共享页BFCache恢复验证revision失败时保留可读内容，暂停新分片，提供重试检查按钮，成功才恢复加载；旧恢复请求通过序号失效。身份组件仍独立重新鉴权；Linux及身份敏感路径保留原恢复策略。

修改文件：deploy/cloudflare/site_workers.py；deploy/cloudflare/runtime/request_cancel.py（新增）、entrypoint.py、admin_entrypoint.py、request_diagnostics.py；frontend/public/static/js/public-stream.js及layout.html；README.md、deploy/cloudflare/README.md；相应版本和测试文件。数据库与同步执行逻辑未改。

验证：40项Python、46项DOM测试通过；simple+separate离线源码/快照验证通过，检查Public/Admin具有信号标志而Executor没有。Wrangler4.143最小JS探针dry-run确认compatibility_flags进入multipart。未进行完整Python SDK线上发布、真实跨Worker信号传播、D1取消、PoP性能或真实浏览器BFCache验收。

客户端取消不保证已运行Python/D1立即停止，1102平台强制终止也不保证能捕获。取消后客户端可能收不到499响应；此状态主要用于应用诊断。
