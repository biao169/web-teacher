# v0.16.009：Cloudflare 部署入口修复

基于本分支 v0.16.008，保留同步页面样式及全部业务功能。

## 修复

deploy/cloudflare/build.py 根据 __file__ 将源码根目录加入 sys.path，修复 domains.py 导入 backend.app.security.origins 时的 ModuleNotFoundError。继续复用原域名解析器，无需安装源码包或复制解析逻辑。

预检查增加域名解析模块导入验证。WORKERS_CI=1 时，check 自动复用 pipeline.settings 校验部署参数；本地可运行 python build.py check --deployment-config。校验过程不安装依赖、不联网、不发布。

## Cloudflare 配置

构建根目录：deploy/cloudflare
构建命令：python build.py check
部署命令：python build.py deploy
保留 SKIP_DEPENDENCY_INSTALL=1，使用 Python 3.13 或符合清单要求的版本。按原说明提供 Worker、域名、D1、R2 等部署变量，不必新增 PYTHONPATH。

## 验证

38 项测试及 16 个子测试通过，包含清除 PYTHONPATH 的独立进程、项目根目录/部署目录/临时目录、inline/separate、多域名及缺失部署配置时提前失败。当前宿主 Python 3.12，路径回归测试仅对预检查传入受支持的版本参数；实际版本门禁保留并独立测试，不代表 Python 3.13 实际打包成功。

独立同步执行器离线装配、快照导入、VPS 配置与静态资源验证通过。未执行 Wrangler 完整 bundle、云端发布或真实 D1/R2 操作。未改数据库，仍仅 database/schema.sql 一个初始化 SQL。
