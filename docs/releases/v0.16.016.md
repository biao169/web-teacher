# v0.16.016 — 后台同步密钥界面（第四步）

基于 v0.16.015-step3，数据库结构和唯一初始化SQL不变。

进入「后台 → 两站数据同步 → 同步连接 → 同步密钥」。输入框默认为空且隐藏，不会自动读取密钥；状态显示来源、修改时间（北京时间）和管理员。生成按钮在浏览器用安全随机数创建32字节草稿；也可直接粘贴对端64位十六进制密钥。

生成、输入、复制均不会保存。点击「保存密钥」校验并保存后，后续同步操作使用新密钥，无需重启；输入框清空。请将相同密钥保存到两端，换密钥建议先暂停任务再继续。不会重置已传输内容。

空输入框下点击显示或复制，通过受控POST读取当前生效密钥；有草稿则操作草稿，并提示尚未保存。复制受浏览器限制时选中内容供手动复制。页面离开时清理输入框；未保存编辑会触发浏览器的离开提示。密钥不写入URL、HTML、浏览器持久存储或控制台日志。使用HTTPS，避免公开展示或分享密钥。

布局沿用后台主题变量、按钮和控件，新增响应式密钥区、状态标识及适当间距；手机宽度下按钮换行。

修改：site_sync/frontend/templates/page.html、static/credentials.mjs、static/panel.css。新增DOM+真实HTTP测试与可选Playwright脚本。DOM流程已验证；由于Chromium下载受网络限制，本轮未进行真实浏览器视觉/移动端布局验收。剪贴板授权成功和失败采用模拟；未执行真实Cloudflare部署。

下一步：部署配置中TEACHER_SYNC_KEY改为可选，调整辅助发布及cloud-check识别数据库密钥，补充Ubuntu/Debian和Cloudflare网页配置教程。当前构建仍沿用原有环境密钥要求，数据库密钥优先。
