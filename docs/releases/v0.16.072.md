# v0.16.072：共享 Public 边界与私有接口（Step 1）

新增 shared_public_route 白名单，仅允许标准中英文首页、内容列表和详情 GET/HEAD；排除自定义导航、表单、API 和 nav/nv 上下文。此轮仅定义边界，不启用匿名共享渲染或边缘缓存。

Admin 安装 GET /api/public/session-summary 与 GET /api/public/admin-project-fields。后者使用重复 uid 参数，每批1—20个，去重后参数化查询，仅系统管理员且具备 projects 查看权限、无需修改密码时返回公开项目的 uid/principal/amount/members。拒绝请求 no-store。成功响应 private,max-age=60，Vary: Cookie, Authorization。身份摘要仅公开必要用户字段与 CSRF，不返回完整权限、会话ID或口令信息。

两接口直接复用 factory 和 public_principal，不调用通用 resources，不重复完整认证，不创建 Public SQL/Page Cache。Worker 精确路径通过 SITE_ADMIN 提前转发；Linux 注册相同接口但不改变原页面认证和缓存。

验证：56项回归通过；separate 离线产物生成验证通过。未执行线上发布、真实 D1/R2 或 Wrangler SDK bundle 验收。测试明细见同目录 v0.16.072-tests.txt、v0.16.072-stage.txt。

下一步：前台身份/私有字段组件。接入页头账号、后台入口、CSRF退出与可见项目补充字段；失败不阻塞页面，控制批次、去重及页面切换取消；清除登录切换和 BFCache 残留身份。完成组件后再切换共享 HTML。
