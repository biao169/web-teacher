# v0.16.119：回退 v113 缓存，仅更新前台导航

以完整 v0.16.113 源码为基线。backend、Worker runtime、pipeline、site_workers、PublicData、PublicPage、失效逻辑、身份查询及 Sync 均与 v113 字节一致；仅项目版本元数据更新至119。移除 v114–118 引入的固定入口缓存、Read Model 扩展及身份交接修改。
