# v0.16.012 — 部署恢复与原生轻量构建

基于本分支 v0.16.011-step2；保留 inline/separate 与唯一 database/schema.sql，不调整业务数据库。

- cloud-check：只读检查云端 Worker、D1/R2、服务绑定、密钥存在性、私有入口、Cron 和 TransferCoordinator。
- 辅助产物使用与 multipart 随机边界无关的内容指纹；重跑发布可跳过已完成上传，继续配置。代码、配置或同步密钥变化触发重新上传。
- verify-native 及 inline 的 verify-companions 无需安装 Python 应用依赖或打包整站；实际 Wrangler 产物 18,839 字节、1个 JavaScript 模块。
- 故障注入覆盖私有入口配置失败、Cron 激活失败、主站发布失败、权限拒绝与平台临时错误；主站失败时不激活执行器，清除临时密钥文件。

关键修改：deploy/cloudflare/{build,pipeline,companions,companion_release,cloud_check,native_build}.py、site_sync/integration/package.py、deploy/shared/worker_package.py；教程位于 deploy/cloudflare/README.md。

验证记录见同目录 v0.16.012-tests.json 与 v0.16.012-native.json。真实账号上传、Python 云端启动、实际同步、CPU额度和云端故障恢复尚未验证；当前没有账号凭据。本地模拟成功不等于线上部署成功。发布跨多个 Worker 非原子事务，不提供自动回滚；中断后应重新运行构建。
