# v0.16.001：指定 v0.15.160 基线的新同步模块接入

完整网站唯一来源：本分支 `teacher-site-windows-v0.15.160-step6.zip`。新同步引擎来自此前独立设计的模块；未读取或复用其他完整网站版本，尤其未参考 v0.15.181。版本号从本次起为 v0.16.001。

## 已完成

- 用新 `site_sync/` 替换基线旧同步代码，接入原网站后台、会话、权限、CSRF 和静态资源。
- 手动拉取先预览和批准；自动同步在接收端定时拉取；发送端只能提出拉取请求，由接收端批准。
- 持久化游标、片段、任务与租约；正文自适应缩片，媒体流式传输。任何有效进度重置连续失败计数，快速重试耗尽后慢速重试，无整体任务超时。
- 真实教师数据、必要关联和媒体映射使用原数据库；只处理明确删除墓碑，保留本地独有媒体。
- 唯一初始化 SQL `database/schema.sql`。本地自动备份及事务升级；Cloudflare 部署自动检查、保存 D1 恢复书签、批量迁移并复验。仅支持精确 v0.15.160 前驱。
- 复用原日志轮转和缓存；同步历史和过期快照有限量清理，后台执行一次只推进有限步骤。
- 保留 v0.15.160 的首页数值字段、favicon/Apple 图标、多域名、日志及缓存、单端口快传等功能。

## 升级和下一步

部署时必须停止旧程序对同步表的写入，保管自动生成的 SQLite 备份或 D1 恢复记录。旧连接、任务不续跑；教师业务数据保留。两端配置相同的 64 位十六进制 `TEACHER_SYNC_KEY`，分别登录后台保存 HTTPS 对端连接。

下一步在测试站验证 Worker ↔ Ubuntu/Debian：先用少量教师资料和图片做手动预览/批准，再开启单向自动计划，模拟中断和资源限制，确认前台响应与续传。确认测试站结果后再切换生产。当前代码包已经包含该验证所需的部署入口和操作说明。
