# v0.16.114 — Header布局与手机菜单

基于v0.16.113；未发布到线上。

品牌靠左，工具和身份紧凑靠右；移除身份固定宽度与空白网格。主导航使用剩余空间，空间不足或中等宽度时独占第二行并可水平滚动。ResizeObserver仅测量Header，不请求数据或身份接口。手机脚本增强后默认折叠菜单；无脚本时导航仍可访问。按钮支持aria-controls/expanded、Escape关闭并返回焦点、点击链接关闭及断点切换重置。图片、语言链接、账号钩子、字体设置保持原功能。

相关CSS及academic.js资源版本升为0.16.114。身份交接与固定导航缓存留待后续步骤，本轮没有修改后台、缓存、Sync或部署运行逻辑。

验证：菜单/图片/身份DOM 51项通过；默认身份和PublicReadModel Python 56项通过（1项依赖弃用警告）；JS语法检查与两份CSS解析通过。DOM不验证实际布局，当前环境无可运行Chromium，375/390/412、1024/1280/1440像素、长用户名与大字体的真实视觉验收尚未执行。本轮未重复全仓库或Worker构建，因为未改后端或Worker。
