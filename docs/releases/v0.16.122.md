# v0.16.122：导航标签、提交后精确失效与故障验证（第三步）

基于 v121。每个成功固定入口HTML增加 public-nav-<slug的SHA256前32位> 专属标签及 public-navigation 分组标签，保留真实内容模块、布局、翻译与媒体依赖。同一导航中英文共享标签；不同入口互不混用。带query、错误与私有响应没有成功缓存标签。

普通标题、排序及显示修改沿用 invalidate，保留成功旧内容回退。地址重命名、固定条件path、可见性、启用状态、位置、类型、fragment变更及删除使用专属标签purge；重命名同时处理旧、新地址。Header布局仍按公共依赖invalidate；翻译公开性变化沿用既有隐私清理规则。不是每次导航改动都全站purge。

有before/after的后台内容写入使用现有mutation_hint，只在事务成功提交后记录计划。失败及回滚不发失效。缺少行上下文的批量工具写入按 public-navigation 分组有界处理，不扫描Cache、不读取额外SQL；专属标签过多时压缩至分组，保持64标签预算。同步源码与协议不修改。

复用原 commit header、Admin/Main relay 及 PublicPage.update_public_cache RPC。专属导航和导航分组标签只传Page，PublicData仍仅接收真实模块/翻译/媒体依赖；内容模块更新能同时覆盖标准页、该模块固定入口HTML及公开Read Model。通知异常仍标为pending，不重试保存、不自动清空成功内容、不预热。管理员模块缓存清理维持既有白名单。

验证通过：538项Python测试、26个subtests、58项DOM测试。覆盖中英文/HEAD/304标签一致、query无缓存、500/503 no-store、私有导航实时鉴权、重命名双地址purge、撤回及删除、普通invalidate、批量压缩、事务回滚、RPC分发与故障隔离。DOM包括1101/1102/500/503非成功身份响应、网络/超时、旧匿名响应竞争、存储禁用和一次性交接。真实Chromium再次确认同页立即显示身份、0额外summary请求、下一页后台确认以及503保持用户名且无JS异常。

未发布或执行线上purge。上述HIT/失效RPC为模拟测试，未证明真实Cloudflare标签传播、1101/1102硬终止回退或生产CPU。Cloudflare清理不删除浏览器已经持有的HTML副本；固定入口浏览器TTL仍为60秒，边缘120秒。完成完整源码重建部署后再验收实际HIT与后台修改传播。
