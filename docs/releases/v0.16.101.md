# v0.16.101 — Public 缓存重构第一步

基线：teacher-site-windows-v0.16.100-identity-acceptance.zip。
本版仅完成“清理旧 Public 缓存，统一策略入口”，未部署线上。

## 已完成

- 移除 PublicSQL / WorkerPublicSQL / RequestSQL 和应用 HTML 缓存实现及调用。
- 删除本地 PublicReadCache 初始化、文件状态缓存版本检测和写入后内存缓存清理。
- 保留原子业务内容版本号写入与既有版本接口，供后续更新通知使用。
- PublicPerformance 统一策略，只保留列表分片并发（本地默认2、Worker固定1）。旧 TTL、预取、缓存预算及 simple/full/off 变量不再启用旧缓存；Worker 构建不导出旧变量。
- Default 与 PublicPage 平台缓存关闭，旧 PublicPage 转发禁用。公开 HTML/列表片段不再返回旧 ETag/304 或 X-Public-Page-Cache。
- 公开页面、列表片段统一 no-store；登录摘要与私有组件 private, no-store；异常状态保留且禁止缓存。
- 删除 Public 预取脚本、恢复页面/脚本和无引用的 Public Recovery 模块；保留一般异常处理与日志。
- 返回页面不再发起缓存版本检查、整页刷新或显示版本检查重试按钮；原列表分片仍按原规则工作。
- 删除旧缓存机制专用测试/基准脚本，以真实数据库与路由基线测试替换；保留媒体 ETag 验证测试。
- 发布版本及 Worker 锁文件统一为 0.16.101。

## 范围

身份显示 sessionStorage 快照与活动心跳保留 v0.16.100 行为，留到第六步调整。
模板编译缓存、媒体 HTTP 缓存、翻译业务结果、文件快传缓存保留。
Sync Executor、Sync Native、协议、checkpoint、同步状态机及媒体同步协议未改。
本地 site_sync/integration/database.py 仅移除已删除 PublicReadCache 的清理调用；事务执行、提交与回滚语义不变。
Ubuntu/Debian 仍为原单服务结构；部署示例不再生成旧 Public 缓存变量，重新生成配置时不再保留旧变量。未重新生成的用户环境文件可含旧变量，运行策略忽略它们。
未增加 PublicData 模型、浏览器全量筛选或缓存失效通知。

## 过渡行为

本版 Public 请求均走原 FastAPI / 数据库 / Jinja 路径，未提供新30分钟缓存、PublicData HIT 或旧副本故障回退，缓存关闭可能暂时增加数据库查询。这是重构基线，不应作为性能改进版直接承诺加速。
此前已进入浏览器/边缘的 v0.16.100 响应不会被源码删除远程清除，按原 TTL、平台版本和部署规则消退。
