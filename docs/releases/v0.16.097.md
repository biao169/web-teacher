# v0.16.097 — 前端身份显示缓存（第二步）

复用096身份摘要接口。新增共享小型identity-cache.js，Public身份组件、认证成功事件及原生登录/退出formdata共用失效逻辑。无数据库变更、无新服务端缓存或Worker。

当前标签页sessionStorage只保存版本、变更标记、登录显示布尔值、用户名/显示名、后台入口提示以及有效期。登录最多5分钟、匿名最多1分钟；用服务端checked_at与到期时间的差值规避浏览器时钟偏差，不超过服务端返回的空闲/绝对期限。缺少期限元数据则不缓存。不会保存CSRF、uid、Cookie、令牌、权限集合及私有项目数据。

有效期内进入新Public页或BFCache恢复直接显示摘要，不重复请求session-summary。过期保留尚未到会话期限的旧显示，后台核验；同页面并发触发合并。错误/超时不解释为未登录；明确authenticated=false才显示登录。已知会话期限过去则移除旧显示。页面离开取消只读请求，旧响应不能写DOM或摘要。

缓存用户的退出按钮点击时先强制核验取得当前CSRF，再按原POST退出流程提交；失败保留重试入口。CSRF仅在当前DOM/内存。登录成功、退出提交或账号变化清理摘要；localStorage只放失效通知，跨标签页传播，切页读取时也比较通知标记。

缓存入口提示不是授权：若当前页面含项目私有字段，仍调用已有私有接口进行实时鉴权，可因权限不足失败，不会信任缓存返回私有数据。后台完整鉴权不变。前端缓存属于显示优化，不保证权限撤销立刻改变按钮。

41项Python、19项DOM测试通过；simple+separate离线打包及快照检查通过。未真实浏览器视觉验收、未云端部署或CPU验收。Ubuntu/Debian与Worker共用脚本和接口，Linux部署结构、Public浏览器30分钟缓存、ETag及Sync均不变。

延续096清理结果；临时字节码/pytest目录不入包，保留必要测试和部署资源。静态脚本版本及实际Worker uv.lock同步更新。

下一步（第三步）：固定账号区域宽度、移动端布局及初始绘制，减少元素变化造成的导航跳动；复用本步退出流程。第四步再加入活跃心跳、隐藏暂停和失败退避，本步无周期轮询。
