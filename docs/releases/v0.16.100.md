## 当前行为与限制

共享公共HTML默认缓存30分钟，与标签页身份显示缓存分离。登录显示新鲜期5分钟，匿名1分钟；sessionStorage只存展示白名单，不存CSRF、Cookie、私有字段或完整权限。过期、禁用或撤销会话不能被心跳恢复。后台、写操作和私有接口始终实时鉴权。

活跃可见页面约5分钟核验一次；最近10分钟无操作或页面隐藏后不继续无限保活。空闲期限30分钟，绝对期限12小时；服务端120秒条件写入节流。多个活跃标签页可各自发送summary请求，不保证全浏览器只发送一次；服务端条件更新避免同一会话重复续写。未引入跨标签页选主或全局锁。

跨标签页通知只保证缓存失效提示，不保证与登录/退出POST原子排序；另一标签页若在退出提交完成前核验，可能短暂显示旧用户名，最迟后续核验修正。后台与私有API不会信任这个显示状态。休眠期间浏览器不保证计时器运行，不承诺永不过期。存储受限时退化为当前页核验，不因此放宽权限。

## 部署后真实验收

无需新变量或SQL迁移。Cloudflare维持simple + separate以及SITE_ADMIN绑定；Linux沿用原安装与服务配置。更新后正常刷新当前页面加载新脚本，旧的新鲜HTML可能在原30分钟期限内复用；不要清空全站缓存。

1. Worker与Ubuntu各用一个测试账号，Network筛选`session-summary`，正常缓存设置下切换20个前台页面：5分钟新鲜期内不应每次都验身份。首次加载允许1次，项目私有字段请求另算。
2. 可见页面轻度交互持续15分钟，记录summary时间；约5分钟一次，不能每次滚动发请求。隐藏10分钟无请求，恢复只核验一次，不补发。
3. 两标签页测试退出/重新登录、后台撤销会话或项目权限；允许前台显示短暂陈旧，后台/私有API必须立即拒绝。验证退出仍获取实时CSRF。
4. 临时阻断summary，确认旧显示或“身份确认中”，不能误显示未登录；恢复网络后按退避恢复。检查无重试风暴。
5. 手机锁屏超过30分钟后恢复，过期会话应明确退出而非续活；在真实Edge/Chrome与手机浏览器验证导航位置稳定。
6. 分别记录平台Public缓存HIT/MISS、Worker CPU p50/p95、请求失败数、1101/1102、D1查询/写入；注明测试时段、请求数量、版本及缓存是否命中。服务器平台指标与前端Network共同核对，不能用浏览器缓存命中误充Worker缓存命中。

本轮不增加生产计数器、日志数组或D1采样查询。线上验收失败时保留request ID、Ray、路径、时间及响应状态；不要导出Cookie/CSRF或公开HAR中的账号信息。
