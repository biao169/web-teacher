# v0.16.088 — Public早期异常边界与原地恢复

entrypoint.py仅导入Workers SDK并声明入口类。Default.fetch无decorator，在try内导入site_entrypoint并调用内部traced处理器，覆盖业务模块导入及diagnostics异常。原业务入口移至site_entrypoint.py；Transfer DO、Cron、sync_tick保留原入口语义，按调用加载，不在Public启动时运行。

snapshot.py删除Transfer、cleanup、media_uploads以及inline Sync HTTP预加载。Public所需web_public、渲染器、资源声明仍在延迟加载的snapshot中，不加载无关业务。startup_check在隔离进程验证最外层不导入FastAPI/业务快照，随后验证Public依赖不导入Transfer/Maintenance/Admin/Sync HTTP重模块；同步执行器及Admin已有独立检查保留。

early_recovery.py是stdlib+workers.Response静态兜底，无FastAPI/Jinja/D1。只保护普通Public GET/HEAD，返回503、两个no-store缓存头、Retry-After=1、request_id及发布号，日志PUBLIC-EARLY-ERROR含路径/Ray/类型/栈位置。不保证Workers SDK自身启动失败、平台强制终止或兜底响应构造失败仍能响应。非Public/写入异常不套用此页面。没有CPU/内存超限根因结论。

恢复JS取消location.replace，自动最多一次同源fetch(__recover=1)，失败停留原恢复页，手动按钮可再尝试；无时间戳参数、无服务器循环。请求no-store、不接受重定向，仅接受200 HTML且不是恢复页，15秒超时，流读取累计最大2MiB。失败停止计时；pagehide取消请求，旧结果不可覆盖新页面；BFCache不重启自动请求。成功后清理参数并使用已经取得的HTML替换document，不再发第二次主文档导航。依赖HTML内的同源页面脚本正常初始化。纯按钮替代链接，避免修饰点击直接跳转恢复URL。SVG拖动保留。

原恢复响应CSP的default-src none会阻止fetch，已明确允许同源connect，并与普通Public所需脚本/样式/媒体来源一致，避免恢复后的页面被旧恢复文档策略阻断。无unsafe-eval或新增第三方源。

验证：76项定向Python通过，另30项启动/模板检查通过（其中17项与前一组重复）；17项DOM通过。真实Chromium拦截响应验证自动fetch失败停留、手动成功原地替换、URL干净、无脚本异常。simple+separate离线打包/快照通过，未执行Wrangler真实SDK打包、Cloudflare发布、D1/R2或CPU/内存验收。

部署后：查看x-teacher-release=0.16.088；普通窗口访问/en与/zh，对照恢复请求及PUBLIC-EARLY-ERROR日志。如果仍收到空500且没有新增头/日志，核对路由、日志采样及平台错误；不能据此直接归因某PoP。此包不修改同步协议、checkpoint、业务表或Linux LRU；仅恢复页面JS/HTTP安全策略跨平台共用。
