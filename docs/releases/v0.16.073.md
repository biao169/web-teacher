# v0.16.073：前端身份与项目私有字段组件

Worker 标准 Public 页面采用独立身份区域：匿名登录入口先显示，随后从 Admin 私有接口加载账号、后台入口和含 CSRF 的原生退出表单。普通页面仍沿用原鉴权和缓存策略；本步不启用共享 HTML 或边缘缓存。Ubuntu/Debian、自定义导航、联系表单保持原服务端显示。

项目列表和 fragment 的私有字段不进入组件页面 HTML；当前进入视口的卡片按最多20个UID、并发1、批次间200ms加载；追加卡片按需处理，复用服务端项目金额格式化。接口每次验证系统管理员与项目查看权限，只返回公开项目。DOM 使用文本插入，不解析用户字段为 HTML。

pagehide、visibilitychange、导航开始、查询切换会取消组件读取、清理定时器、身份、CSRF和私有字段。请求15秒超时，代次编号阻止取消后的旧响应写回。BFCache恢复、回到可见页面及账号变更重新读取，使用 no-store 防止复用旧身份响应。跨标签页通知仅存无身份含义的随机变更标记；不存用户、CSRF或私有字段。退出在 formdata 捕获 CSRF 后清理；未取消退出写请求。组件失败不阻塞公开内容。

验证：63项Python回归、13项DOM测试通过；separate离线产物验证通过。未执行线上部署、真实D1/R2或Wrangler SDK bundle验收。测试输出随包保存。

主要文件：backend/app/native/web_common.py、web_context.py、web_public.py、public_data.py、public_session.py、public_http_cache.py；frontend/public/templates/header.html、project-card.html、layout.html；frontend/public/static/js/public-session.js（新增）、public-auth.js。另有版本、测试与发布说明更新。数据库与同步执行代码不变。

下一步：标准 Public HTML 不再读取登录身份，审查全部身份相关输出，统一公开内容和ETag；自定义导航、表单及私有接口仍保留鉴权。边缘缓存启用在后续部署配置步骤完成。
