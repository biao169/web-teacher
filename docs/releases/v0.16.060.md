# v0.16.060 — Step 5：导航意图预取

基于 v0.16.059，新增独立 public-prefetch.js；保留普通 HTML 导航、URL、History、SEO、ETag、浏览器缓存、Render Cache 和现有分片加载器。

## 行为

只对品牌首页链接（a.academic-brand）和现有导航按钮（a[data-navigation-id]）响应意图；不在启动时扫描并请求全部链接。

- 桌面指针进入后等待120ms，提前移出则取消。使用委托 pointerover/out，并过滤同一链接内部元素间移动。
- 键盘 focusin、移动端被动 touchstart 可直接预取。
- 不拦截 click，不 preventDefault，不把预取 HTML 插入页面。
- 允许同源 /en、/zh、公开列表、/en|zh/n/<slug>；保留规范分页/筛选/导航版本参数。
- 跳过当前页面、跨域、详情、contact、admin/auth/api/sync/transfer、下载、新窗口、锚点和未知/重复查询参数；重定向请求停止，正常点击仍使用原网站导航。

## 配置与边界

TEACHER_PUBLIC_NAV_PREFETCH_CONCURRENCY 默认1，允许0～2；0不注册预取监听器。配置从 PublicPerformance 经后端模板变量传到 data-public-nav-prefetch-concurrency，后端仍负责非法环境变量校验。

等待队列最多4项；每个文档最多尝试32个URL；同URL包含排队、执行中和已完成状态的去重。失败不自动重试，避免持续请求。查询串最多4096字符；内容最多读取256KiB；请求超时10秒。超过这些边界的页面仍可正常点击访问。

Save-Data开启、离线或页面隐藏时不启动；Save-Data切换、离线、隐藏/pagehide会清除等待意图并中止活动请求。pageshow不会自动补发队列。边界只针对预取；现有首页分片并发保持独立，因此默认情况下仍可能同时有2个分片和1个预取请求。

## HTTP缓存与内存

fetch使用 credentials:same-origin、redirect:error、priority:low 和 Accept:text/html；不使用 cache:no-store 或 cache:reload，不添加改变表示或 Vary 的预取头。HTTP响应与真实导航保持同一表示和ETag。

只接受成功HTML和可缓存响应；no-store、非HTML、错误和超限响应会中止。用 ReadableStream reader 分块读完响应，不调用 text()/json()/arrayBuffer()，不解析DOM，不构建或长期保存HTML字符串；浏览器HTTP缓存负责保存可能可复用的响应。

登录用户仍遵循 private,no-cache，不进入匿名共享Render Cache；预取不改变服务器授权、Cookie、CSRF或表单策略。所有预取异常仅取消可选预取，不替代普通导航反馈。
