# v0.16.104 — PublicData 可缓存 entrypoint

基线：v0.16.103-public-read-model-step3。本轮完成第四步，未部署线上。

## 请求路径

新增 /api/public/data/{lang}/{table} GET/HEAD。允许 zh/en 和 profiles、students、research_interests、projects、publications、patents、courses、news，共16个固定URL。无自由query、访客排序/筛选/分页参数或revision URL变体。

Default保持cache OFF，先判断PublicData白名单，再判断PublicPage，其他请求保持原动态分流。转发复用原Host检查和匿名副本处理，Cookie/Authorization删除仅作用于转发副本。PublicData export配置cache.enabled=true；PublicPage保持启用，Admin/Default关闭。

平台HIT直接返回此前成功JSON，不构造页面应用、资源客户端或读取D1。测试使用模拟平台HIT验证Default不初始化页面应用、不需要DB/R2绑定；真实平台HIT仍需线上验收。

MISS进入PublicData.fetch，直接准备配置的D1绑定及现有D1SQL适配器，调用完整Read Model；不创建FastAPI应用、Jinja、R2、身份/翻译服务客户端，不增加service binding，不经HTML生成路径。绑定初始化失败也返回no-store 503。

本地Ubuntu/Debian单服务与完整应用提供相同JSON路由，共用响应生成器；Admin独立应用不安装该路由。不改变服务结构。

## 成功响应与条件请求

新增 backend/app/native/public_read_api.py 和 deploy/cloudflare/runtime/public_data.py。仅完整、正确模块/语言/版本、符合预算且可序列化的模型才返回200并设置X-Teacher-Data-OK: 1。

- Content-Type: application/json; charset=utf-8
- Cache-Control: public, max-age=300
- Cloudflare-CDN-Cache-Control: public, max-age=1800, stale-while-revalidate=300, stale-if-error=86400
- ETag: 公开数据语义的SHA256弱验证值
- X-Public-Revision: 模型内容revision
- X-Content-Type-Options: nosniff
- X-Robots-Tag: noindex, nofollow

没有Vary Cookie/Authorization，模型本身与身份无关。GET/HEAD具有相同表示ETag/长度，HEAD不发送正文。条件匹配返回304并保留成功表示的验证及缓存头，不把304当作新的完整模型。

弱ETag排除generated_at和stats运行元信息；生成时间/查询统计变化不让相同公开数据每次都变成200。内容、版本、模块、语言、字段和分类等变化仍会改变ETag。条件请求在应用MISS时仍重建模型，不能宣称它不查D1；不查D1的是平台HIT。

中间件再核对路由、成功状态、成功标记、JSON类型、无Set-Cookie以及生成器成功状态；未标记200错误JSON、伪造标记的4xx/5xx、带Cookie响应均no-store，移除ETag和成功标记。

## 失败与旧内容

非法模块/语言或路径404；自由query、Range、片段等400；写入方法405；模型不完整、生成预算超限、D1异常及绑定初始化失败503，均禁止缓存。错误不附加成功标记，不因If-None-Match把失败转成304。

不调用Python Cache API、purge/invalidate，不添加成功副本存储或Cron巡检。已有成功副本的错误回退由平台stale-if-error处理；没有旧成功条目、缓存淘汰、Default外层故障不由本版本保证。生产1101/1102、HIT/STALE及实际CPU必须上线后验证。

Cache-Tag及后台修改后的invalidate/purge通知留第七步，当前公开更新、撤回和权限范围变化可能受缓存窗口影响；不声称已实现即时撤回所有浏览器/边缘副本。
