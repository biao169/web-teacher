# v0.16.065 · 第二步 Worker Public轻量认证与菜单精简

基于v0.16.064，保留Worker simple/full/off。

## 修改

- backend/app/native/auth.py新增public_principal：一个SELECT读取有效session、用户基本字段、角色、可见范围和两个EXISTS权限摘要；不加载完整权限表。保留项目can_view最小兼容映射及退出表单CSRF。last_seen不进入身份摘要；约120秒后条件续期，避免每次写会话。
- web_common.py仅Worker Public只读路由选择轻量认证并标记public_light；local、Admin/Auth、媒体、联系表单、写操作保持完整认证。
- web_context.py跳过Worker Public完整后台菜单、admin-sidebar查询和后台权限编辑上下文；header.html根据can_enter_admin显示后台入口，非轻量场景保留原菜单判定。
- web_public.py缓存版本接口使用一致的轻量身份摘要，避免与页面身份指纹不一致。
- public_http_cache.py仅Worker轻量路径使用新表示版本，local ETag版本和缓存策略未改。
- 新增tests/test_worker_public_auth_v065.py；更新发布标记和教程。

没有缓存身份对象，不弱化会话过期、账号禁用、角色禁用、撤销、强制改密及项目私密字段规则。SQL在查询时返回当前角色的必要权限布尔值，权限修改影响下一次请求与ETag身份摘要。session更新条件再次核对有效期和撤销状态。
