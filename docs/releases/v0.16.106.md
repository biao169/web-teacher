# v0.16.106 — 简化身份显示、异步确认与心跳

基线：v0.16.105-browser-list-step5。本轮完成第六步，未部署线上。

## 显示快照

sessionStorage的teacher:identity-display:v2只保存authenticated、username、display_name、can_enter_admin、checked_at五个显示字段。checked_at采用成功响应到达客户端的时间，用于约300秒复用窗口，避免依赖服务端/客户端时钟差及session过期元信息。身份变更标记与失败退避元信息独立存储；localStorage只有无身份内容的跨标签失效标记。旧v1复杂过期快照丢弃，升级后首次页面需要确认一次，不迁移旧CSRF/权限数据。

不保存Cookie、session/token、CSRF、uid、权限集合、私有字段、idle/absolute expiry。can_enter_admin仅决定是否显示后台链接，访问/admin、读取私有字段及所有写入仍使用现有服务器实时鉴权，显示快照绝不授权。

公共HTML保持匿名视图，沿用已有header.html身份占位与账号区域布局；本轮未改变其匿名缓存模板、CSS或后台鉴权。快照新鲜时脚本直接恢复身份，普通切页/BFCache/可见性恢复不请求session-summary。快照过期后先显示旧成功身份，再在后台确认；没有成功快照显示“身份确认中”。

300秒是后台确认的新鲜窗口，不是强制删除显示的期限。故障期间保留旧成功显示，可超过300秒；只有成功且明确authenticated=false才显示登录，主动账号变更/退出失效则先清除旧身份进入确认态。长时间保留显示不代表服务器session仍有效。

## 异步确认与心跳

继续使用/api/public/session-summary，无新增身份接口或Recovery层，GET使用credentials same-origin、cache no-store。请求15秒超时，单页合并并发确认；取消后的迟到响应不能更新UI。

已登录或确认失败待重试的页面，只有可见且近10分钟有活动时才调度；正常确认间隔约5分钟，匿名确认成功后不循环心跳。pointerdown/keydown/scroll记录活动；隐藏、pagehide和离开导航取消定时器、请求和请求态私有值，恢复时最多补一次需要的确认，不补历史次数。用户恢复活动时可触发一次到期确认。

确认失败按60/120/240秒退避，标签内切页保留退避时间，成功后清除。500/503、Cloudflare1101/1102非成功响应、超时、abort、无效JSON/身份结构不把已登录UI改成未登录，不显示后台查询报错，不阻塞页面；保留旧成功身份或确认占位。手动退出需要用户知道是否成功，继续保留原有确认/重试提示，不静默声称退出成功。

服务端已有会话续期节流与绝对/闲置过期规则未修改。心跳仍走实时session校验；已撤销、禁用或过期的会话不会被前端快照续期。

## CSRF与私有组件

快照恢复出的退出按钮没有缓存CSRF。用户点击时强制实时确认，取得新鲜CSRF后才提交原/auth/logout表单；失败不提交、允许再次点击。CSRF只存在当前成功请求后的DOM，pagehide/导航清理。退出formdata沿用共享identity-cache的失效广播，去掉重复广播。

本地列表public:querychange取消旧私有请求；public:appended恢复组件，新鲜快照不重复确认身份。上一次实时确认的私有字段可读结果只存在本页内存，不写显示快照；新页面最多用后台链接提示发起实时鉴权的私有接口探测。私有接口失败暂停该页探测直到新的身份成功确认，避免每次筛选都再次探测失败接口。私有字段清理与身份/CSRF清理分开，私有接口失败不删除当前成功身份或退出表单。

API实际权限由服务器决定。共享PublicPage/PublicData、列表模型及其浏览器缓存从不包含私有项目值；所有动态身份/私有响应保持no-store。
