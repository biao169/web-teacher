# v0.16.075：30分钟TTL及Worker边缘缓存

默认公开整页TTL 1800秒，显式配置优先。simple启用Workers平台cache.enabled（整页TTL>0），关闭内部SQL/Page Cache API，预取0/stream1。full保留原内部Cache API比较路径，平台cache关闭。off关闭两层并强制Public TTL为0。cross_version_cache=false，版本隔离。

Admin生成cache.enabled=false，发布前校验multipart metadata.cache_options与配置一致。主站响应中只有shared公开GET/HEAD 200/304、无Set-Cookie且public Cache-Control时允许Cloudflare-CDN缓存；其他响应明确no-store。媒体浏览器HTTP策略不变。Sync Native/Executor配置不继承cache块；同步协议、数据库未修改。Linux仅默认公开整页TTL变化，其他性能与认证策略不变。

主要修改：backend/app/public_performance.py、backend/app/native/web_common.py、public_http_cache.py；deploy/cloudflare/runtime/cache_policy.py、pipeline.py、site_workers.py、companions.py（仅Admin产物校验分支）；README.md、deploy/cloudflare/README.md、deploy/linux/README.md；相应版本与测试文件。

验证：94项核心回归+10子测试、20项发布产物回归通过。simple+separate离线源码与快照验证通过，确认主站/Admin/同步辅助配置边界。锁定Wrangler4.143.0对最小JS探针分别生成cache开启和关闭multipart，确认metadata.cache_options实际写入；这不代表完整Python SDK bundle或线上发布验收。未测真实D1/R2、边缘HIT、CPU或1101/1102改善。

部署：主站Worker的Settings→Builds→Variables and secrets配置TEACHER_WORKER_CACHE_MODE=simple，TEACHER_PUBLIC_PAGE_CACHE_TTL_SECONDS=1800后重新部署。仅修改运行时变量不能改变已发布版本的边缘缓存开关。Admin与辅助配置由项目自动生成。

数据库revision不能主动清除新鲜缓存，公开内容修改可能延后至TTL到期才可见；新部署使用独立缓存版本，但浏览器已缓存页面仍可能有效。紧急可off重部署并清除缓存/强制刷新。未启用stale-while-revalidate，不设置覆盖私有页面的Cache Everything规则。完整操作及验收方法见根目录与Cloudflare教程。
