# v0.16.110 — 第二步：默认登录按钮，静默恢复身份

基线v0.16.109，未部署线上。

header.html取消初始登录链接hidden，补齐用户图标，删除Checking identity/身份确认中节点。public-session.js以默认登录按钮代替等待占位；有成功快照优先显示，明确authenticated=true/false更新身份。未知、非成功响应、超时、abort和网络异常保留当前显示，不触发后台核验错误提示。

导航停止仍取消旧请求、清私有字段及CSRF表单；使用仅在本页内存中的显示字段恢复同样的姓名/后台/退出按钮，不把它用于授权。跨标签页通知清除存储快照并重新核验，旧显示保留到明确结果；晚到的旧响应不能更新页面。主动退出仍获取实时CSRF，主动操作反馈保持。

identity-cache.js既有五字段快照、300秒有效期、跨标签页失效和60/120/240秒退避满足本轮要求，未改其存储结构或权限含义。心跳、真正服务器鉴权、Sync、缓存策略、数据库及Cron未改。layout.html将public-session.js引用更新到0.16.110。

45项身份DOM回归通过；65项相关Python回归通过，包括中英文/local/r2真实HTTP默认按钮及图标、匿名共享缓存、身份错误no-store、撤销权限、私有字段拒绝和登录心跳。JS语法与separate源码staging/snapshot/资源检查通过，详见validation-v0.16.110。未重复108全仓库验收，未运行真实云端故障注入或Wrangler SDK打包。
