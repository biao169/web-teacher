# v0.16.117 — 固定入口复用PublicData浏览器筛选

基于v0.16.116，未发布线上。

## 数据流与条件

匿名公开固定列表输出public-fixed-scope-v1最小JSON（module、slug、stamp、conditions），tojson转义内联文本，不输出后台配置、权限或会话字段。受限导航与不支持的能力不输出本地列表钩子。Jinja卡片先正常显示，PublicData使用原16个模块/语言URL，没有导航参数或新缓存键；完整、有界、字段和custom_navigation能力声明匹配后才替换SSR。

固定eq严格比较原始值，整数/布尔按数值比较；contains按原始完整字段执行字面子串、ASCII大小写折叠，不把百分号/下划线当通配符。与访客多值token/角色别名匹配分离，不允许访客条件覆盖固定条件。先求固定范围，再叠加用户筛选、配置排序、组内升降序和分页。分类选项限定在固定范围内，语言、返回、详情、分页、重置保留固定入口；详情链接携带nv，简介/复制引文沿现有nav/nv接口实时验证。卡片继续复用同一SVG模板。

公开固定列表包括直接访问的query/fragment也匿名渲染、跳过会话查询；带query和fragment的HTML仍no-store，只有原query-free入口可短缓存。配置在同一请求加载一次并验证nv，不能因复用scope而跳过版本校验。受限入口、详情、私有API继续原实时鉴权。表单加入nv隐藏值，JS和普通表单都保留版本。

不支持的条件/数据类型、未知或旧能力声明、缺字段、模型不完整/超限/失败时静默保留SSR，释放localPending并恢复原分页/分片处理。旧HTML没有descriptor时直接走服务端。没有巡检、预热、SQL缓存、Worker Cache API或新的缓存层。PublicReadModel仍500行/512KiB/40查询上限，已加载公开数据的交互不再读取模块数据；私有组件和用户主动详情/引用请求仍可调用实时接口。

固定条件只控制公开显示，不是权限依据，也不保证后台修改后即时撤回已加载页面。模块/导航tag与v116精确失效策略不变，管理员模块维护同时影响Page与Data。浏览器已有HTML/模型不受边缘purge即时控制。
