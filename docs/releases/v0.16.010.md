# v0.16.010：辅助 Worker API 上传产物验证

基于本分支 v0.16.009，未采用此前暂停的独立构建项目草稿。

新增 deploy/cloudflare/companions.py：校验官方 Wrangler multipart 文件、明确辅助名称、检查入口模块/依赖/绑定，构造但不发送 Workers Scripts API PUT 请求。保留原始 multipart 字节及其 boundary；不将 CI 主站名字用于辅助 API URL。拒绝混入网站专用配置、密钥、缺失入口、绑定漂移和截断数据。

build.py 新增 verify-companions 和可选 --report；pipeline.py 在临时目录调用锁定 Wrangler 4.143.0 的 deploy --dry-run --outfile，验证后退出。此路径不执行发布、密钥写入及远程数据库/存储操作。

实际验证使用 Python 3.13.15、锁定 workers-py 1.17.4、workers-runtime-sdk 1.9.1、Wrangler 4.143.0。官方 pywrangler sync 成功，完整 verify-companions 命令成功，两个实际辅助模块产物通过校验。Python 上传包含源码及 vendored 依赖，不是已在 Cloudflare 验证启动成功的运行快照。

原生上传包 18,839 字节；Python 上传包 12,622,759 字节（1,345 个模块）；Wrangler 报告 Python 模块 gzip 大小约 2,977.59 KiB。它们是上传体积，不是 Worker 运行内存。multipart boundary 每次随机，完整包摘要可随运行变化。

30 项测试及 16 个子测试通过。真实 HTTP API 上传、平台 Python 初始化、Cron、私有访问与业务调用均未验证；环境无账号凭据。secret/subdomain/schedules 不由 multipart 自动完整配置，必须由下一步发布器补齐。

下一步统一账号/名称/权限配置并实现辅助 API 发布编排，包含现有 Worker 归属检查、私有访问、密钥及定时任务配置；先辅助后主站。当前旧 deploy 在主站关联 Workers Builds 中的多 Worker 名称覆盖问题尚未接入修复，不能将本版本当成一键部署已完成。

详细产物报告：v0.16.010-artifacts.json。网页验证教程：deploy/cloudflare/README.md。
