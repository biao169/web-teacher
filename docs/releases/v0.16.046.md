# v0.16.046 — 同步后台内部多页与统一结果弹窗

基于本分支 v0.16.045 完整源码。本轮只调整同步管理页面及页面选择参数，未部署线上，不修改数据库、同步模式、任务范围、断点或接收审核策略。

## 页面入口

Ubuntu和Worker使用相同路由、模板及静态文件。顶部导航可直接切换；各页支持刷新、收藏和浏览器前进/后退。

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 任务监控（默认） | /admin/site-sync?section=tasks | 列表、分页、详情、日志、批准及任务参数 |
| 创建任务 | /admin/site-sync?section=create | 20项多选、手动拉取、推送、发送记录 |
| 定时计划 | /admin/site-sync?section=schedules | 计划列表、启停、删除、新增和编辑 |
| 连接与授权 | /admin/site-sync?section=connection | 连接、接收策略、更新授权、密钥及诊断 |
| 执行参数 | /admin/site-sync?section=settings | 默认切片、重试次数及快速重试等待 |

直接打开 /admin/site-sync 显示任务监控。顶部“同步运行控制”卡片及对应脚本不再加载；单条任务操作保留。全局控制服务接口未删除，不改变数据库中既有控制状态。

服务端只渲染当前页分区，并非将全部表单隐藏起来。仅任务和计划页自动刷新，间隔60秒。页面隐藏、操作中、弹窗打开或编辑输入时避免打扰。设置页不读取任务和计划列表，也不触发同步执行。

## 统一结果弹窗

复用后台媒体管理的 native-audit-dialog 样式、按钮和通知模块。弹窗包含标题、执行状态、北京时间、可滚动的纯文本结果和关闭按钮。

覆盖拉取、推送、任务暂停/继续/取消/删除/批准/参数保存、计划保存/启停/删除、历史清理、授权更新、连接保存、重试参数保存、连通性测试和密钥操作。危险操作使用统一确认弹窗。筛选、详情及分页仍在页面展示，自动刷新不弹窗。

创建成功返回任务ID，实际进展到任务监控查看；推送提示任务在对端运行。错误保留错误码、请求ID及已有诊断。若操作已被服务端接受，但后续刷新失败，明确提示状态读取失败，不误报为提交失败。

密钥弹窗仅显示生成、复制、保存等结果，不记录密钥及完整密钥接口响应。日志不解析HTML、不保存至浏览器持久存储。关闭执行中弹窗不会取消后台任务。
