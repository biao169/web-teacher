# v0.16.064 · Worker轻缓存

基于v0.16.063，默认TEACHER_WORKER_CACHE_MODE=simple。

## 实现

- 新增 deploy/cloudflare/runtime/cache_policy.py：构建与运行时共用纯配置策略，只允许simple/full/off，无数据库访问。
- pipeline.py：验证模式并输出有效变量。simple/off强制导航预取0、stream并发1、REQUEST_CACHE=0；off还强制两种TTL=0。
- site_resources.py：快照阶段预加载轻量策略定义，按请求取得有效策略；将worker_cache_mode及public_request_cache注入资源。Admin忽略Public配置并固定off。
- public_page_cache.py：只在非local路径增加full模式门槛；simple/off不创建PageCache，不调用Cache API。LocalPageStore实现逐字节未变。
- site_workers.py：Admin固定mode=off、REQUEST_CACHE=0，继续剔除四项Public配置。
- entrypoint.py：路由流程未改，仅发布版本标记；验证/admin、/api/admin、/auth、/setup经现有SITE_ADMIN先转发，不初始化Public app。
- README.md和Cloudflare教程更新模式表与网页构建设置。静态前端预取/stream代码未变，使用现有0预取与1并发能力。

simple保留原浏览器TTL和ETag/304；full保留现有缓存实现；off关闭动态Public缓存，但不更改静态资源及媒体缓存协议。减少跨Python/JS缓存调用与额外请求不等于保证消除所有1101/1102。

## 保持不变

逐字节核对：deploy/linux/tweb.py、deploy/vps/release.py、backend/entrypoints/vps.py、deploy/linux/README.md、local runtime、Data LRU、公共参数默认值、导航预取JS、stream JS及database/schema.sql均未变。Local Page LRU亦未变。无数据库迁移或同步业务修改。

## 验证

第一组105项Python测试及10项子测试通过；补充组83项通过（两组有交集，不相加为唯一测试数）。前端56项通过。覆盖模式校验、强制并发/预取、simple/off不创建缓存、simple浏览器缓存/304、off no-store、full原缓存、Admin转发与本地缓存回归。将旧Worker缓存测试显式标为full并修正既有浏览器max-age预期。

separate模式离线部署暂存、Public/Admin快照、executor导入、资源配置与本地VPS生成检查通过。日志见validation-v0.16.064。未线上发布、未测真实CloudflareCPU/内存配额，未宣称线上1101/1102消除。

## 部署

在Public Worker的Builds普通文本变量中设置TEACHER_WORKER_CACHE_MODE=simple（可省略），重新运行既有deploy命令。Admin及辅助Worker由程序自动更新。full/off切换也建议通过Builds重新部署，避免沿用之前模式生成的显式TTL/并发值。详见deploy/cloudflare/README.md。
