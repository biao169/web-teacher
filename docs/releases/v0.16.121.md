# v0.16.121：公开固定导航入口短 HTML 缓存（第二步）

以 v120 为基线，识别后台“导航与按钮”配置所对应的 /{en|zh}/n/{slug} 无 query GET/HEAD。泛化 slug 校验，不写死域名、模块或导航ID。其余原有 v113 标准公开页面/PublicData 政策不变，v120身份交接与v119悬浮手机导航源码不变。

Default缓存仍关闭，固定入口候选交给现有 PublicPage。HIT/STale无需构建FastAPI或访问数据库。MISS从navigation_items读取配置一次，要求前台位置、启用、公开、有效route/button类型、无fragment以及有效公开固定条件；复用同一行与解析结果生成原有匿名Jinja HTML。r.p=None且public_components=True，无用户名、CSRF、私有字段进入共享HTML。私有配置不产生成功缓存，真实带会话Cookie的浏览器可在匿名404后一次回退现有动态路由实时鉴权，未引入Recovery层。

仅成功HTML200及内部确认后的304/HEAD保留 Render-OK/ETag。浏览器 max-age=60，边缘 max-age=120、stale-while-revalidate=30、stale-if-error=300。最终中间件复用同一请求策略，避免覆盖为标准页面1800秒。任何visitor query（s、size、direction、page、nv等）、详情、fragment、JSON偏好、Range、写操作及错误均不进入此共享入口缓存。查询参数不删除、不重映射为基础缓存页。

附加实际内容模块tag与现有public-layout/public-media/public-translations。普通内容变更沿用模块失效；导航变更当前沿用现有 public-layout，公开转私有、停用及删除已有hard purge。专属导航tag和更精确提交失效属于下一步。保留现有管理员模块清理机制，不增加新Worker、PublicData扩展、Cron、预热或Cache API手工操作。

验收：542项Python测试及26个subtests通过，覆盖真实临时SQLite/HTTP中英文及local/r2路径、同Cookie和匿名HTML一致、一次解析且无session SQL、HEAD/304、query不缓存、私有配置仍实时鉴权、非法配置、4xx/5xx no-store、未验证scope的200不缓存，以及模拟Worker HIT不构建应用/不查询D1和私有404一次回退。四个Worker构建配置等deploy/cloudflare测试也通过。未运行真实线上Cache HIT/失效传播/CPU测量，未上传部署或purge。

部署必须从完整源码重建主Worker与现有配套产物，不能仅上传静态资源。已有未过期浏览器缓存不会被本地修改自动刷新。
