# 08 源码功能说明阅读指南

## 文档映射规则

每个项目自有文件在 `docs/10_源码说明/` 下有一份镜像说明：

- `app/components/admin/Topbar.vue` → `docs/10_源码说明/app/components/admin/Topbar.vue.md`
- `server/services/auth/session-service.ts` → `docs/10_源码说明/server/services/auth/session-service.ts.md`
- 根目录文件统一放在 `docs/10_源码说明/_根目录/`。

每个源码目录还包含 `_目录说明.md`，用于快速查看本目录的文件边界。

## 单文件说明内容

1. 文件定位：路径、类型、职责、规模与内容校验值。
2. 依赖和调用方：基于静态 import/export 关系整理。
3. 方法与函数：名称、源码位置、用途、使用方式和调用签名。
4. 类型与导出数据：接口、类型、枚举、类与共享常量。
5. 专项信息：Vue 组件交互、HTTP 路由、SQL 变更、CSS 规则或测试场景。
6. 维护注意事项：说明修改时需要共同检查的层级。

## 阅读顺序

- 理解产品目标：先读 `01–04`。
- 理解整体实现：读 `06_网站设计与系统架构.md`。
- 查找某个文件：使用 `07_项目目录规划与文件功能索引.md`。
- 调试具体模块：从该文件的“直接依赖”和“直接调用方”向上下游展开。

## 静态分析边界

Nuxt 自动导入、文件路由、Vue 模板组件解析和运行时动态注册不一定产生显式 import。说明文档会标注框架自动加载方式；涉及真实业务行为时，仍应以源码、类型检查和测试结果为准。

后台统一编辑壳是刻意采用显式导入的例外：`admin/shared/AdminEditorShell.vue` 的自动名称带目录前缀，所有调用方都必须以显式 import 建立 `AdminEditorShell` 模板绑定。具体约束见 `09_后台对象编辑统一设计.md`。
