# v0.15.181：第二步，预构建网页应用

## 网页访问优先

v180只恢复模块定义预加载，首次请求仍注册整组路由。本版新增worker_runtime/web_application.py，在部署快照阶段调用create_app、安装首次设置路由、组装中间件，创建供普通网页使用的应用。默认入口直接复用该对象，不再在首次首页或后台请求中执行这组构建工作。

资源工厂通过request_resources在请求时导入并调用；快照中没有数据库绑定、当前用户、会话令牌、数据库查询结果或同步任务进度。前后台权限与身份检查仍逐请求执行。快传协调器继续使用独立懒构建应用，以免其随机标识和会话状态进入快照；普通网站不安装快传实例。

同步路由分流与Cron调度保持v180逻辑，仍为五分钟一轮、内部三小时巡检、预检查分轮、断点与冷却。预构建网页不执行同步，也不把任何任务标为完成。Cron所在Worker会携带预构建网页对象，但不在每次Cron中重建该对象。

## 验证

12项隔离启动检查通过，阻止启动期随机数、时钟调用、数据库连接、网络、子进程及文件写入；要求网页路由和中间件已经构建，并禁止快传状态及运行时资源提前初始化。

46项功能/恢复测试通过，包括复用预构建对象访问中英文首页、真实登录、后台访问、匿名客户端权限隔离、路由数量稳定且不重建应用，以及快传隔离、Cron预检查、巡检恢复与同步轻量接口。

测试SDK为替身，本地结果不代表实际Cloudflare快照/SDK资源测量。未线上部署；部署后需核对v0.15.181并验证首页冷启动与Cron到达。快照内容增加，不能保证平台资源优先级或完全消除1101/1102。首次资源工厂、模板加载与页面数据渲染仍在运行时，本步不声称消除全部首次请求开销。
