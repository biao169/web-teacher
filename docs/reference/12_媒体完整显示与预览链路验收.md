# 12 媒体完整显示与预览链路验收

## 统一显示规则

教师头像、学生头像、新闻封面、通用编辑字段、媒体选择器、媒体库及回收站统一遵循以下规则：

- 图片和视频使用 `object-fit: contain` 与 `object-position: center`，长边贴合可用区域，短边自动居中，完整内容不会因容器比例不同而被截断。
- 媒体元素、占位区和容器不绘制边框或底色；保留小幅圆角。列表头像不再使用圆形遮罩。
- 新闻卡片不再在悬停时放大媒体，避免放大后的边缘被卡片容器裁切。
- 新闻详情封面不绘制背景和阴影；富文本图片限制最大宽高并按原比例居中。
- 无媒体时继续显示姓氏、新闻分类或媒体类型文字。地址解析失败、资源不存在和浏览器加载失败使用不同提示；适合交互的预览区提供“重新载入”。

## 后台预览链路

`AdminMediaPreview.vue` 是编辑字段、媒体选择器、媒体编辑区和媒体预览弹窗的统一渲染组件。它支持 Object key 解析、直接 URL、本地待上传文件、图片、视频、PDF、加载状态、失败状态及重试。

媒体库列表批量读取授权预览地址。单项重试重新申请授权地址；回收站继续通过仅管理员可访问的原对象预览接口读取。列表单元格自身是预览按钮，因此其中不嵌套重试按钮；点击后在预览弹窗中重试。

图片、视频和 PDF 的批量预览授权统一使用内联响应。视频保留 Range 请求支持，使浏览器能够读取元数据和拖动播放进度。其他文件类型仍按附件下载处理。

## 文件与职责

| 文件 | 本阶段职责 |
| --- | --- |
| `app/components/admin/shared/AdminMediaPreview.vue` | 完整显示图片与视频；区分加载、地址解析失败、对象不可用和媒体加载失败；支持重新解析或重建媒体元素。 |
| `app/components/admin/shared/AdminListAvatar.vue` | 教师和学生列表头像完整显示，取消圆形裁切，保留轻量圆角和姓氏回退。 |
| `app/components/admin/shared/AdminFieldRenderer.vue` | 所有媒体字段在选择器旁复用统一预览。 |
| `app/components/admin/complete/AdminCompleteMediaWorkspace.vue` | 媒体库、回收站、媒体信息编辑区和大图弹窗共享预览状态；单项失败可重新获取地址。 |
| `app/components/admin/complete/AdminCompleteMediaPicker.vue` | 已有媒体候选以统一尺寸完整显示；读取失败可重新载入列表及授权。 |
| `app/assets/public/base.css` | 统一头像、新闻封面和富文本媒体的透明、居中、完整显示规则。 |
| `server/services/complete-admin/media-service.ts` | 为图片、视频和 PDF 生成内联预览授权。 |
| `tests/backend/admin-media-preview-tools.test.mjs` | 验证统一组件、透明 contain 规则、新闻无放大裁切及视频内联授权。 |

## 验收

本阶段使用以下门禁：

```sh
pnpm typecheck
node --test tests/backend/admin-media-preview-tools.test.mjs tests/backend/admin-list-style-regression.test.mjs tests/backend/admin-media-trash-workflow.test.mjs
pnpm test:stage3:offline
pnpm build:ubuntu
```

生产浏览器验收覆盖后台全部列表页和全部对象编辑入口，确认媒体库、回收站及编辑字段的统一预览组件能在生产构建中挂载。

本阶段未修改 01—04 设计基线文档，也未修改数据库表结构。
