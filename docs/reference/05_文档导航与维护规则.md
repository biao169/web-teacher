## 维护规则

1. 01–04 需求基线不得修改。
2. 文件新增、删除或移动时，同时更新 07 索引与 10 中对应镜像说明。
3. 每份说明记录当前源码路径、功能、方法用途和 SHA-256；源码变化后同步更新。
4. 专项设计可以保留阶段证据，必须标明阶段；既有全站基线见 21，本轮前台查询专项结果见 22，公共模板及字体结果见 23，不把历史测试数字作为当前证据。
5. 检查文档覆盖、相对链接与受保护文档；代码验收与浏览器视觉验收分开记录。
