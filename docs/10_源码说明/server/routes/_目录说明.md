# server/routes 目录

本目录记录 4 个直属项目文件。

| 文件 | 功能定位 |
| --- | --- |
| [health.get.ts](health.get.ts.md) | GET /health 的服务端接口入口；负责接收请求并委托安全、服务或存储层处理。 |
| [index.ts](index.ts.md) | 根地址的动态默认语言入口，替代固定跳转 /zh 的 routeRules。 |
| [robots.txt.ts](robots.txt.ts.md) | 无数据库依赖的 GET/HEAD /robots.txt。 |
| [sitemap.xml.ts](sitemap.xml.ts.md) | GET/HEAD /sitemap.xml 的动态 HTTP 入口。 |
