# shared/admin 目录

本目录记录 7 个直属项目文件。

| 文件 | 功能定位 |
| --- | --- |
| [content-modules.ts](content-modules.ts.md) | 后台内容模块字段配置；教师外部链接组增加六个可选显示数值，项目金额明确以万元填写。 |
| [identity.ts](identity.ts.md) | 后台稳定 UID、资源白名单、硬唯一/提示型查重规则及对象编辑地址的共享定义。 |
| [paths.ts](paths.ts.md) | 后台共享注册表与路径定义；作为前端导航和服务端权限映射的共同依据。 |
| [publication-tools.ts](publication-tools.ts.md) | 纯函数论文工具：解析 BibTeX、IEEE、APA、GB/T 和常见 Elsevier 引文，归一化 DOI，生成引用与主页教师姓名高亮。 |
| [registry.ts](registry.ts.md) | 后台共享注册表与路径定义；作为前端导航和服务端权限映射的共同依据。 |
| [suggestion-tools.ts](suggestion-tools.ts.md) | 历史输入建议的分词与替换；兼容中英文分号，仅替换当前未完成项并保留已完成分类。 |
| [translation.ts](translation.ts.md) | 工程配置与支持文件。 |
