# 前台体验第二步：程序生成动态背景

版本：v0.15.100。

## 实现

- 前台共用一个无语义装饰层；CSS 绘制浅色底渐变、柔和光晕与淡网格，不依赖图片、Canvas、第三方库或外部请求。
- 颜色、透明度、网格间距和动画时长统一在 `frontend/shared/static/css/public-theme.css` 的 `--public-ambient-*` 参数中配置。
- `public-background.css` 负责几何布局、适配和关键帧；只对 `body.section-public` 生效。仅动画变换一个渐变层，不持续改变布局、不使用模糊滤镜。
- 独立固定层裁剪溢出，覆盖当前视口；长页面不依赖超长图片，也不增加页面宽度。负层级置于正文下方，禁用鼠标事件与选择，aria-hidden 隐藏纯装饰。
- 主页透明度略高；列表、详情、登录和快传使用更淡的装饰。卡片、导航、表单原有底色保留。

## 适配

- 窄屏减少为两处光晕，隐藏网格，动画周期由 64 秒放慢至 90 秒。
- 系统 `prefers-reduced-motion: reduce` 时禁用此背景动画，显示静态渐变。
- 打印及 forced-colors 高对比度模式隐藏背景。
- 极小的 `public-background.js` 只管理标签页可见性；隐藏/离开时暂停，返回后恢复。不运行逐帧 JavaScript，不修改内容区域或阅读字号。
- 不支持 CSS 动画或关闭 JavaScript 时仍有渐变底色；不影响正常功能。

## 验证与范围

13 项 Python 页面检查和 17 项 DOM/样式检查通过：前台资产引用、单层装饰、后台隔离、阅读字号、快传布局切换、可见性暂停和静态/打印回退。

后台服务文件与数据库 SQL、schema 校验快照保持不变。版本升级无需重建数据库。

当前执行环境没有可运行的 Chromium 二进制，本轮未完成真实浏览器截图或 Windows 人工视觉验收；不将 DOM 检查等同于浏览器渲染验证。第三步将继续做整体适配与可执行环境下的验收。
