# 文件快传使用说明

## 发送与接收

前台入口为 `/zh/transfer` 或 `/en/transfer`，共用教师网站导航。页面内切换“发送”和“接收”，无需分别进入多个功能页。

发送方选择文件、文件夹或拖放内容，检查清单、总大小和重名提示，选择可用方式，生成接收入口并向对方提供接收码、链接或二维码。接收方输入接收信息，确认来源及保存方式后开始。在线直连和中继需要双方保持页面在线；临时分享在上传完成后允许发送方离线。

是否允许匿名、发送、接收及某条链路，由后台规则决定。前台显示当前可用方式、有效速率、个人剩余额度及禁用原因。选择文件后的本机整理不等于已经上传文件。

## 传输方式

| 方式 | 适合场景与使用体验 | 可用条件 |
| --- | --- | --- |
| 局域网直连 | 同网设备直接传输，默认不限速，减少经过服务器的文件流量 | 双方在线；配置并核验局域网范围，确认真实文件路由绕开受限 VPN |
| 广域网直连 | 远程设备尝试直接连接，减少服务器中转 | 双方在线；允许的公网范围与绕行核验有效，浏览器能够建立连接 |
| 服务器中继 | 直连无法建立时，可主动选择由服务器转发 | 管理员开放；身份、路径和适用 VPN 预算均允许 |
| 临时分享 | 先上传，接收方稍后领取 | 存储空间、有效期、领取次数、权限及适用 VPN 预算允许 |

系统不会在直连失败时悄悄改走受限 VPN 或中继；选择和恢复保持明确的传输方式。局域网识别依赖配置与实际路由核验，不能只凭两台设备地址相似认定不消耗 VPN。

## 文件夹与保存方式

支持保留相对目录结构，具有原生目录能力时可保留空文件夹。兼容目录选择如果浏览器没有提供空目录信息，工具无法还原未被提供的空目录。

| 保存方式 | 行为 |
| --- | --- |
| 单文件保存 | 用户选择目标文件，分块写入，成功关闭文件后确认本机保存 |
| 文件夹保存 | 用户选择父目录，创建独立子目录，逐项恢复文件与目录 |
| 流式 ZIP/ZIP64 | 写入用户选择的 ZIP 文件，保留目录结构；只打包、不压缩 |
| 兼容浏览器下载 | 在允许大小内完成打包后交给浏览器下载 |

能力按浏览器实际接口检测，目录和文件写入通常需要安全上下文及用户授权。兼容下载最多缓冲 128 MiB，包含 ZIP 格式开销，超过时应分批或使用支持流式保存的环境；不会自动改为服务器上传。

单集合最多 20,000 个文件/目录，路径元数据最多 8 MiB；中继和临时分享的网络控制清单还有 256 KiB 上限。后台更低的文件数、单文件或任务大小限制仍优先生效。

重名内容会明确显示改名结果，如添加 `(2)` 后缀；不默默合并同名根文件夹。目录保存不是整体原子事务，中途取消可能保留已经写好的文件，页面会说明保存位置与完成情况。

## 速度和个人额度

局域网全局速率默认留空，即不限速。管理员可为规则配置速率；用户也可为本次任务主动降低速度。最终速度取双方有效规则和双方任务设置中的最低非空值。速率单位为 Kbit/s，按每个连接执行，并发连接的速率可能相加。

个人总量按任务声明的文件大小核算，发送与接收分别计入。创建或加入先预留，获准连接时计入整项授权额度；授权后取消或失败不退回。给自己的同一账号发送一份文件会合计发送和接收两份大小。清单、协议开销和实际 VPN 字节由另一套口径处理。

使用“恢复同一任务”可沿用原个人授权；重新创建任务会重新占用额度。匿名用户也受各自规则约束，管理员可以再设置所有匿名访客共享的日/月总量与并发上限。

P2P 正文不经过服务端，正常客户端会执行速率与文件检查，但这不等于服务器能对被恶意修改的双方客户端实施网卡级硬限速。

## 暂停、重试与恢复

任务可暂停并在期限内恢复。网络中断默认最多自动重试 3 次，可由后台调整为 0–5 次；权限、路径、计量和文件校验错误不会被无限重试。

可选“在本机保留恢复记录”，默认关闭，最多保存 10 项恢复元信息。刷新后发送方要重新选择原文件/文件夹，接收方重新选择原文件或此前的接收子目录。记录不保存文件正文或浏览器文件句柄，关闭页面后不会继续浏览器后台传输。

恢复需要原账号或原匿名身份、原内容和有效期限，并再次通过当前权限与路径检查。在线直连及中继需要两端恢复；临时上传/领取由当前端恢复。单文件和目录可从确认的检查点继续；ZIP 在原任务授权内重新生成。

恢复同一次临时领取不重复消耗领取次数，重新从分享入口创建另一项领取则按新任务处理。VPN 实际重传仍占用新的预算，不能用“恢复免重复个人计量”理解为网络流量免费。

## 临时分享与记录

临时分享显示到期时间、领取次数和状态。发送方可使用提供的操作撤销，管理员也可在管理页撤销或清理。到期与撤销后不能继续新领取，临时文件按清理规则回收。

移除浏览器本机恢复记录，只删除该浏览器保存的信息，不等于撤销服务器分享。匿名恢复需要原匿名 Cookie；清除 Cookie、换浏览器或无痕窗口可能丢失原任务身份。

## 独立服务诊断与备份

文件快传管理数据、桥接密钥和临时文件独立保存，不在教师网站媒体库中。运行配置检查和只读诊断可使用工具目录下的 `pnpm check:config`、`pnpm doctor`、`pnpm health`。

工具提供停机备份：先停止教师服务、快传服务及相关统计写入程序，再在工具目录执行，目标必须为工具目录外尚不存在的新目录：

```sh
node scripts/maintenance.mjs backup "../private-transfer-backup" --stopped
node scripts/maintenance.mjs verify "../private-transfer-backup"
node scripts/maintenance.mjs restore "../private-transfer-backup" "../transfer-restored-data"
```

`--stopped` 表示操作者已完成停机，不会自动停止服务。备份包括有效配置、实际数据目录、私钥、SQLite 和临时文件；是未加密的私有普通目录，需保护访问权限。恢复到新位置，不覆盖运行目录；清单校验大小和 SHA-256，默认要求受支持的 SQLite 日志模式。

备份不包含教师数据库或用户本机文件。恢复旧备份后，应对照当前真实账单检查流量、授权和分享撤销状态；运营商已消耗流量不会因恢复磁盘备份而退回。
