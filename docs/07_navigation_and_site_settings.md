# 导航、首页与页脚设置

## 网站设置

在 `/admin/settings/site` 管理站点配置，选择当前启用的配置。建议保持一个明确启用项。

| 配置 | 作用 |
| --- | --- |
| 中文、英文站点名称 | 品牌名称及语言展示 |
| Logo、浏览器图标、社交分享图 | 从媒体库选择对应图片 |
| SEO 标题、描述、关键词 | 页面搜索与分享元信息的适用默认值 |
| 首页论文、动态数量 | 控制首页相应列表显示数量 |
| 页脚内容 | 保存前台统一使用的安全 HTML |
| 当前启用 | 控制使用的站点配置 |

`hero_title`、`hero_subtitle` 仍保存标题类信息，供适用的元信息或回退使用；当前首页不重复显示一段独立站点简介。`homepage_profile_uid` 为兼容保留，主教师由公开、启用、精选和排序决定。

## 导航与按钮

在 `/admin/navigation` 配置项目，主要字段如下。

| 字段 | 用途 |
| --- | --- |
| `title`、`title_en` | 中英文显示文本 |
| `kind` | 类型 |
| `url_name`、`path` | 预设路由或链接路径 |
| `fragment` | 页面锚点 |
| `icon`、`style` | 图标与按钮样式 |
| `location` | 显示位置，如顶部导航、首页按钮或页脚 |
| `visibility` | 可见性 |
| `enabled` | 是否启用 |
| `sort_order` | 排序 |

使用站内预设路由或路径时，前台按当前语言构建适用地址。可使用外部链接和页面锚点；链接须通过安全校验。只有满足启用、可见性和位置条件的项目才进入对应前台区域。

教师后台侧栏本身由权限模块注册表控制。数据库允许保存某种位置值，并不表示可通过普通导航记录任意替换后台的权限菜单。文件快传入口由已接入的模块提供。

## 固定筛选导航

使用列表链接生成器选择目标模块，再选择需固定的条件。例如，选择论文模块，固定年份为 2026，将文本设为“2026 年论文”，保存并启用到顶部导航。

从该导航进入后，年份 2026 构成基础范围。用户再搜索作者或选择期刊，只会在 2026 年论文内检索；年份控件隐藏，清除追加条件也不会解除 2026 年限制。当前导航高亮只标识这个入口。

各模块可固定的条件与前台支持的筛选项一致，见 [03_frontend_requirements.md](03_frontend_requirements.md)。中文等非 ASCII 筛选值会由生成器编码，导航上下文使用 `nav` 标识；应直接使用生成的链接，不要手写压缩筛选参数或随意删除导航标识。

普通列表地址与带导航上下文的固定范围入口用途不同。若修改了导航保存的条件，之后从该入口进入时使用新的配置。

## 首页教师与学术链接

在教师记录中设置“启用成员”“首页精选”和“公开”，并调整排序。满足条件的首位成员成为首页主教师。其个人简介完整显示，照片使用媒体库头像。

学术链接字段为 `orcid`、`personal_homepage`、`google_scholar`、`dblp`、`github`、`cnki`，对应数值字段均为原字段名加 `_value`。数值是管理员录入的展示值，不会自动从第三方网站抓取更新。仅需链接时可不填数值。

首页研究方向展示为标签。首页下一行快捷入口来自对应位置的导航记录，可自行维护名称和目标路径。

## HTML 页脚

在网站设置的“页脚内容（支持 HTML）”填写内容。例如：

```html
<p>© 2026 智能系统与可信计算实验室</p>
<p><a href="https://example.com">机构主页</a> · <a href="mailto:office@example.com">联系我们</a></p>
```

示例域名和邮箱仅供替换演示。页脚支持允许的文本格式和链接；脚本、事件处理及任意嵌入不会执行。

版权行、演示数据说明、联系信息均由这个配置统一维护。需要删除某句话时，直接从页脚配置删除；不要在多个导航记录和页脚正文中重复维护同一段版权文本。
