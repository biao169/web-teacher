# 第四步：快传管理嵌入教师后台

版本：v0.15.97。

## 页面与复用

`/admin/transfer` 继承教师后台布局，右侧直接渲染快传管理内容，不使用 iframe，也不需要新端口。分区快捷入口定位工具与额度、流量用量、磁盘状态、全站/个人任务和缓存清理。开发示例区默认折叠，避免占用常规管理空间。

现有管理内容提取为 `transfer/frontend/native/management.html`，与兼容任务页面共用，继续包含原设置、专属规则和任务模板。`management_context` 统一提供原管理服务的分页结果、权限范围和设置状态。管理操作继续访问 `/transfer/api/*`，复用原 CSRF、版本冲突、权限、签名预检与批次机制。

嵌入页面不重复提供旧版发送表单；使用页头“前台发送与接收”进入完整快传界面。管理脚本支持发送表单缺省；显式选取当前管理区的 CSRF，避免教师后台其他组件影响。任务局部刷新只替换任务区域，保留设置草稿、侧栏和当前分区锚点。

样式限定在 `.transfer-admin` 内，使用教师后台主题变量，不加载旧独立页面的全局布局样式。窄屏下标题和入口换行，表格在容器内横向滚动。

## 权限与兼容

- 全站管理沿用快传的查看、编辑、删除权限组合。
- 只有查看权限时只显示自己的任务；不返回管理设置表单、全站任务或缓存操作区。
- 示例生成还需发送/创建权限。
- 原 `/transfer/admin` 通过原有管理权限检查后，跳转至 `/admin/transfer` 并保留查询参数。
- `/transfer/tasks` 及旧独立运行模板保留兼容；未挂载本地快传的外部服务部署保留原外部入口。
- 数据库 SQL 和校验快照均未改变，不需要重置。
