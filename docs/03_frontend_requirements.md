# 前台功能与使用说明

## 入口与公共布局

中文入口为 `/zh`，英文入口为 `/en`。下表省略语言前缀。

| 页面 | 路径 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 首位精选教师、研究方向、精选成果与动态、快捷按钮 |
| 教师与团队 | `/team` | 成员照片、身份、简介与适用链接 |
| 研究方向 | `/research` | 研究方向列表 |
| 论文 | `/publications` | 全部公开论文及筛选、引用复制 |
| 精选论文 | `/publications/featured` | 公开精选论文 |
| 科研项目 | `/projects` | 来源、基金、承担信息、状态与经费 |
| 专利与软著 | `/patents` | 类型、申请授权信息、法律状态 |
| 学生 | `/students` | 分类分区、培养与个人信息 |
| 新闻动态 | `/news` | 标题信息列表及新闻详情 |
| 课程 | `/courses` | 学期、授课对象、简介和可访问材料 |
| 留言 | `/contact` | 向管理员提交联系信息 |
| 文件快传 | `/transfer` | 发送与接收切换 |

顶部导航保留在各公共功能页。当前页面或当前自定义筛选导航会突出显示；面包屑保留页面路径，列表前不重复堆叠页面名称和介绍。

登录、账号、退出及后台入口位于顶部右侧；后台入口依权限显示。下方阅读控制行提供语言与三档字体切换，登录后显示用户名称。标准字体较紧凑，舒适和大字模式增加阅读尺寸。

页面使用浅绿色背景与低对比度标签。人物照片支持竖向展示、适当圆角，图像容器背景透明且没有装饰性边框。返回顶部按钮位于右下角，滚动后按需出现。

## 首页展示规则

首页主教师从 `profiles` 中选取 `visibility=public`、`is_active=1`、`is_featured=1` 的记录，按 `sort_order` 升序、`id` 升序取第一位。简介展示已保存的完整内容，不做两行截断；内容长度仍受后台字段限制。

学术链接读取 ORCID、个人主页、Google Scholar、DBLP、GitHub、CNKI。链接存在时显示对应入口；配有 `*_value` 时附带数值，数值 0 也显示。邮箱、电话等联系方式按独立公开设置展示。

首页研究方向以一行多个标签排列，不展开长解释，不显示多选及复制工具。快捷按钮来自“导航与按钮”的首页位置配置，可连接普通页面、锚点、外部地址或固定筛选列表。

首页论文和新闻数量由网站设置控制；精选内容还需满足各自公开、精选及发布时间等条件。`homepage_profile_uid` 为兼容保存字段，不改变上述主教师选择规则。

## 搜索、筛选与固定范围

搜索框与各筛选控件直接排列，宽度不足时换行。下拉框以当前功能名称为基础保持紧凑，展开的选项面板可更宽。条件变化后列表与候选项联动更新。

| 列表 | 当前支持的分类筛选 |
| --- | --- |
| 教师 | 角色、单位 |
| 论文 | 年份、期刊/会议、论文类型、索引类型、精选 |
| 精选论文 | 年份、期刊/会议、论文类型、索引类型；精选范围固定 |
| 项目 | 年份、项目来源、基金/计划、承担角色、状态 |
| 专利软著 | 年份、国家/地区、类型、法律状态 |
| 学生 | 分类、培养层次、年级、研究方向、状态 |
| 新闻 | 分类、年份 |
| 课程 | 学期、授课对象 |
| 研究方向 | 文本搜索 |

项目年份基于开始日期。各模块搜索字段随记录类型不同，不能把列表搜索当作附件全文搜索。

从后台创建的“2026 年论文”等导航进入时，导航自身条件构成固定范围。后续搜索及其他筛选只在这个范围内进行，对应固定条件控件隐藏；清除用户追加条件也不会解除导航范围。此时仅突出该自定义入口，不同时突出普通“论文”入口。设置方法见 [07_navigation_and_site_settings.md](07_navigation_and_site_settings.md)。

## 懒加载与列表内容

列表按页请求，滚动接近底部时加载下一页。改变搜索、筛选或导航范围后，从新条件的第一页开始。加载中避免重复请求；失败时保留已有条目并允许重试；浏览器不支持自动观察时使用手动加载入口。

| 类型 | 卡片信息安排 |
| --- | --- |
| 论文 | 题名、作者和引用信息；期刊论文、SCI 等类型/索引标签位于末行，与 DOI、来源入口同区域 |
| 项目 | 突出项目来源和基金名称；显示负责人、角色、起止时间、状态，以及已填写的经费 |
| 专利软著 | 名称、发明人/作者、申请号、授权号、日期、状态和可访问证书 |
| 学生 | 照片、姓名、培养类别和适用的个人信息；按分类分区 |
| 教师 | 照片、姓名、身份、简介和公开链接 |
| 课程 | 名称、学期、授课对象、简介及可访问的课程资料 |
| 新闻 | 标题、分类、日期和相关信息；正文仅在详情中展示 |

紧凑列表中的简介在适用卡片中最多显示两行；首页主教师简介及新闻详情正文不受此截断规则影响。标签使用浅色背景。

项目经费存储单位为万元，最多四位小数。中文例如 `12.5 万元`，英文对应 `CNY 125,000`，按原值乘以 10,000；未填经费不显示金额。

学生分类显示可配置匹配关键词、中文/英文名称和排序。多分类学生以第一个分类词确定所在区，避免同一学生在多个区重复出现；未匹配记录使用适用的原分类或未分类显示。滚动加载时各分区继续增加数据，当前显示数量代表已加载记录。

## 选择与复制

论文、项目、专利、学生、研究方向和课程支持多选；精选论文与普通论文共用论文选择集合。教师与新闻不提供这套多选复制功能，首页研究方向也不提供。

选择条目后点击复制，直接写入剪贴板，不弹出多选编辑窗口。浏览器拒绝剪贴板访问时，按页面提示进行手动复制。每个模块最多选择 200 条，复制前会再次检查条目是否仍可公开读取。

论文支持 GB/T、Elsevier、APA、IEEE 和 BibTeX 等格式；实际格式内容来自已保存字段及可用生成结果。可按提供的选项决定是否包含编号。公开条目的编号以模块公开数据基准计算，单次筛选不会重新从 1 编号；增删或排序变化可能改变编号。

## 新闻、富文本与 PDF

打开新闻详情后，先显示标题相关信息和封面，再显示正文。正文支持纯文本、Markdown 和经过安全处理的 HTML。可视化编辑器保存的富文本包含标题、段落、列表、链接、引用、代码、图片排版及 PDF。

插入正文的 PDF 使用页面内阅读组件，前方仅保留分隔线，不显示浏览器 PDF 工具栏或外层框架。滚动接近 PDF 时开始加载，当前页准备完成后继续按滚动加载下一页；不同尺寸页面按比例展示，正文高度随页数增长。失败可重试。

这里的“懒加载”指逐页渲染及按需启动阅读组件，不承诺浏览器网络请求永远只下载当前页字节。新闻正文内 PDF 当前固定使用 PDF.js；全局表中的旧引擎、下载、水印字段不控制该内嵌组件。

富文本只接受安全标签和媒体引用，不执行脚本或任意 iframe。详细编辑方法见 [06_rich_text_and_pdf.md](06_rich_text_and_pdf.md)。

## 留言、页脚与缓存

顶部留言入口进入独立表单。新闻启用 `allow_comments` 时，可点击详情留言按钮展开同类表单。匿名是否允许由全局设置决定；填写姓名、邮箱、主题、类型和正文后提交。当前前台表单不提供附件上传。

提交成功表示记录已进入后台；留言正文和邮箱不作为公共评论展示。新闻来源由服务器确认并写入记录上下文。没有开放匿名留言时先登录；请求过密时按页面提示稍后重试。

页脚统一读取当前网站设置的 `footer_text`，允许安全 HTML 和链接。版权说明或演示提示只有在配置中存在时才显示，不另加重复固定页脚。

公开数据使用前台与服务端缓存，缓存按语言和实际查询条件区分。后台保存内容、导航、设置或有效译文后，相关缓存会失效更新。账号、私有资料、留言提交和文件传输不作为公共内容缓存。页面加载错误有重试反馈，前台不通过无限重试绕过限流。
